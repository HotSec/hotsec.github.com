# 知识库目录与文件命名规范

## 一、目录编号规范

### 1.1 顶层目录编号

使用双数字编号格式：`{编号}_{名称}`

```
mybook/
├── 01_go/           # Go语言
├── 02_python/       # Python
├── 03_cpp/          # C/C++
├── 04_lua/          # Lua
├── 05_web/          # 前端/Web
├── 06_agents/       # AI智能体
├── 07_algorithms/   # 算法
├── 08_architecture/ # 架构设计
├── 09_devops/       # 运维
├── 10_os-linux/     # Linux操作系统
└── 11_other/        # 其他
```

### 1.2 子目录编号

子目录同样使用双数字编号：

```
01_go/
├── 01_语言基础/
├── 02_并发编程/
├── 03_内存管理/
└── ...
```

## 二、文件命名规范

### 2.1 标准格式

`{双数字编号}_{中文名称}.md`

**正确示例**：
- `01_介绍与环境搭建.md`
- `02_数据类型.md`
- `03_控制语句.md`

**错误示例**：
- `1_介绍.md` (单数字)
- `intro.md` (无编号英文)
- `介绍.md` (无编号)

### 2.2 特殊文件

以下文件可不受编号限制：
- `README.md`
- `index.md`
- `SUMMARY.md`
- `assets/` 目录下的资源文件

## 三、内容组织规范

### 3.1 知识点层级

```
语言/
├── 01_语言基础/        # 入门必学
├── 02_核心特性/        # 语言核心
├── 03_标准库/          # 标准库
├── 04_第三方库/        # 常用库
├── 05_框架/            # Web框架等
├── 06_性能优化/        # 性能相关
├── 07_工程实践/        # 最佳实践
└── 08_高级专题/        # 深入主题
```

### 3.2 编号连续性

文件编号应保持连续，避免跳号：

**正确**：01, 02, 03, 04, 05...
**错误**：01, 02, 05, 08, 12...

如需插入新内容，使用小数编号：
- `02_数据类型.md`
- `02.1_类型推断.md` (新增)

## 四、ALL.md 索引规范

### 4.1 链接格式

文件链接：`> [📄 文件名.md](./mybook/路径/文件名.md)`
目录链接：`> [📁 目录名/](./mybook/路径/目录名/)`

### 4.2 折叠标签

使用 `<details>` 组织内容：

```markdown
<details>
<summary>主题名称</summary>

- 要点1
- 要点2

> [📄 文件名.md](./路径/文件名.md)
</details>
```

## 五、禁止事项

1. 禁止在同一目录下使用重复编号
2. 禁止使用中英文混合命名
3. 禁止在编号前添加 `0_` 前缀（如 `0_大型网站架构.md`）
4. 禁止跳号（除非使用小数编号补充）

- [ ] 是否存在重复编号
- [ ] ALL.md 链接是否有效
- [ ] 命名是否使用中文
