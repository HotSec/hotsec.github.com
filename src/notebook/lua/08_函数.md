## 概述

函数是一组一起执行任务的语句。

### 定义

```lua

    if a>b then
        return alua

        return b

print(max(19,20))
```

### 调用

当创建一个lua函数，给什么样的功能，必须做一个定义。要使用一个方法，将不得不调用该函数来执行的任务。

当程序调用一个函数，程序的控制转移到被调用的函数。被调用函数进行定义的任务和在执行它的return语句或当其功能的终端到达时，程序控制返回到主程序。

而调用只需要传递所需的参数以及方法名的方法，如果方法返回一个值，那么你可以存储返回的值。
