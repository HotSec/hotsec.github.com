# 7_分库分表

## 1. **GORM Sharding**

GORM Sharding 是一个基于 GORM 的分库分表插件，支持水平分表和分库功能。

* **特点** ：
* 基于 GORM，易于集成。
* 支持自定义分片规则。
* 支持读写分离。
* **GitHub地址** ：[https://github.com/go-gorm/sharding](https://github.com/go-gorm/sharding)
* **示例** ：

```go
  package main

  import (
      "gorm.io/driver/mysql"
      "gorm.io/gorm"
      "gorm.io/sharding"
  )

  func main() {
      dsn := "user:password@tcp(127.0.0.1:3306)/dbname?charset=utf8mb4&parseTime=True&loc=Local"
      db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{})
      if err != nil {
          panic(err)
      }

      // 使用分片中间件
      db.Use(sharding.Register(sharding.Config{
          ShardingKey:         "user_id", // 分片键
          NumberOfShards:      4,         // 分片数量
          ShardAlgorithm:      func(value interface{}) (suffix string, err error) {
              userID := value.(int64)
              return fmt.Sprintf("_%04d", userID%4), nil
          },
          PrimaryKeyGenerator: sharding.PKSnowflake, // 主键生成器
      }, "orders")) // 表名
  }
```

## 2. **ShardingSphere-Proxy**

ShardingSphere 是一个强大的分布式数据库中间件，支持分库分表、读写分离等功能。虽然 ShardingSphere 是用 Java 开发的，但它提供了通用的 MySQL 协议支持，Go 程序可以通过 MySQL 驱动连接 ShardingSphere-Proxy。

* **特点** ：
* 支持多种分片策略。
* 支持读写分离、分布式事务。
* 兼容 MySQL 协议。
* **GitHub地址** ：[https://github.com/apache/shardingsphere](https://github.com/apache/shardingsphere)
* **示例** ：

```go
  package main

  import (
      "database/sql"
      "fmt"
      _ "github.com/go-sql-driver/mysql"
  )

  func main() {
      dsn := "user:password@tcp(127.0.0.1:3307)/sharding_db?charset=utf8mb4&parseTime=True&loc=Local"
      db, err := sql.Open("mysql", dsn)
      if err != nil {
          panic(err)
      }
      defer db.Close()

      rows, err := db.Query("SELECT * FROM orders WHERE user_id = ?", 123)
      if err != nil {
          panic(err)
      }
      defer rows.Close()

      for rows.Next() {
          var orderID, userID int
          var amount float64
          err = rows.Scan(&orderID, &userID, &amount)
          if err != nil {
              panic(err)
          }
          fmt.Println(orderID, userID, amount)
      }
  }
```



## 3. **GoSharding**

GoSharding 是一个轻量级的 Go 分库分表库，支持自定义分片规则。

* **特点** ：
* 轻量级，易于使用。
* 支持自定义分片算法。
* **GitHub地址** ：[https://github.com/zeromicro/go-sharding](https://github.com/zeromicro/go-sharding)
* **示例** ：

```go
  package main

  import (
      "fmt"
      "github.com/zeromicro/go-sharding"
  )

  func main() {
      shard := sharding.NewShard(4) // 4 个分片
      shardID := shard.GetShardID(123) // 根据分片键计算分片ID
      fmt.Println("Shard ID:", shardID)
  }
```

## 4. **XORM Sharding**

XORM 是一个流行的 Go ORM 库，支持分库分表功能。

* **特点** ：
* 基于 XORM，易于集成。
* 支持自定义分片规则。
* **GitHub地址** ：[https://github.com/go-xorm/xorm](https://github.com/go-xorm/xorm)
* **示例** ：

```go
  package main

  import (
      "github.com/go-xorm/xorm"
      _ "github.com/go-sql-driver/mysql"
  )

  func main() {
      engine, err := xorm.NewEngine("mysql", "user:password@tcp(127.0.0.1:3306)/dbname?charset=utf8mb4")
      if err != nil {
          panic(err)
      }

      // 自定义分片规则
      engine.SetTableMapper(xorm.NewPrefixMapper(xorm.SnakeMapper{}, "user_"))
  }
```

## 5. **Atlas**

Atlas 是一个 MySQL 代理，支持分库分表功能。虽然 Atlas 本身不是 Go 语言开发的，但 Go 程序可以通过 MySQL 驱动连接 Atlas。

* **特点** ：
* 支持分库分表。
* 支持读写分离。
* **GitHub地址** ：[https://github.com/Qihoo360/Atlas](https://github.com/Qihoo360/Atlas)

## 6. **Vitess**

Vitess 是一个用于 MySQL 的数据库集群系统，支持自动分片、读写分离等功能。Vitess 提供了 Go 客户端库。

* **特点** ：
* 支持大规模数据分片。
* 支持分布式事务。
* **GitHub地址** ：[https://github.com/vitessio/vitess](https://github.com/vitessio/vitess)
* **示例** ：

```go
  package main

  import (
      "context"
      "fmt"
      "github.com/vitessio/vitess/go/vt/vitessdriver"
  )

  func main() {
      dsn := "username:password@tcp(127.0.0.1:15306)/keyspace"
      db, err := vitessdriver.Open(dsn)
      if err != nil {
          panic(err)
      }
      defer db.Close()

      rows, err := db.QueryContext(context.Background(), "SELECT * FROM orders WHERE user_id = ?", 123)
      if err != nil {
          panic(err)
      }
      defer rows.Close()

      for rows.Next() {
          var orderID, userID int
          var amount float64
          err = rows.Scan(&orderID, &userID, &amount)
          if err != nil {
              panic(err)
          }
          fmt.Println(orderID, userID, amount)
      }
  }
```

## 总结

在 Go 语言中，分库分表的实现可以借助以下第三方库：

* **GORM Sharding** ：适合使用 GORM 的项目。
* **ShardingSphere-Proxy** ：功能强大，兼容 MySQL 协议。
* **GoSharding** ：轻量级，适合简单场景。
* **XORM Sharding** ：适合使用 XORM 的项目。
* **Vitess** ：适合大规模分布式场景。

根据项目需求选择合适的库，可以显著降低分库分表的开发复杂度。
