# 接口

- 接口类型定义了一组方法的集合，如果某个自定义类型为这些方法提供了具体的实现，则该自定义类型就实现了该接口。

- 延迟绑定，可以实现类似虚函数的多态功能

- 接口类型转换

  - ```go
    var (
        a io.ReadCloser = (*os.File)(f) // 隐式转换, *os.File 满足 io.ReadCloser 接口
        b io.Reader     = a             // 隐式转换, io.ReadCloser 满足 io.Reader 接口
        c io.Closer     = a             // 隐式转换, io.ReadCloser 满足 io.Closer 接口
        d io.Reader     = c.(io.Reader) // 显式转换, io.Closer 不满足 io.Reader 接口
        )
    ```

- 接口的最大意义就是实现多态的思想
  - 为不同数据类型的实体提供统一接口的能力被称为多态

- 接口优势
  - 隐藏细节
  - 解耦
  - 权限控制

- 接口比较 == !=
  - 接口值由两部分组成：类型和数据
  - 两个接口值相等当且仅当它们的类型相同，并且它们的数据也相等
  - 接口值可以与 nil 比较，如果接口值的类型和数据都为 nil，则接口值为 nil
