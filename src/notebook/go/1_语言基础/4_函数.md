# 函数


- 具名函数

  - ```go
    func Add(a, b int) int {
        return a+b
    }
    ```

- 匿名函数

  - ```go
    var Add = func(a, b int) int {
        return a+b
    }
    ```

- 多个参数
- 多个返回值

  - ```go
    func Swap(a, b int) (int, int) {
            return b, a
        }
    func Find(m map[int]int, key int) (value int, ok bool) {
        value, ok = m[key]
        return
    }
    ```

- 可变数量的参数 ...

  - ```go
    func Sum(a int, more ...int) int {
            // more 对应 []int 切片类型
            for _, v := range more {
                a += v
            }
            return a
    }


    func main() {
        var a = []interface{}{123, "abc"}

        Print(a...) // 123 abc 相当于Print(123, "abc")
        Print(a)    // [123 abc] 相当于Print([]interface{}{123, "abc"})
    }

    func Print(a ...interface{}) {
        fmt.Println(a...)
    }
    
    ```

- 闭包
  - 函数捕获了外部函数的局部变量，这种函数我们一般叫闭包
  - 闭包对外捕获的外部变量并不是传值，而引用
  
  - ```go
    func main() {
        for i := 0; i < 3; i++ {
            defer func(){ println(i) } ()
        }
    }
    // Output: 在 for 迭代语句中，每个 defer 语句延迟执行的函数引用的都是同一个 i 迭代变量，在循环结束后这个变量的值为 3，因此最终输出的都是3。
    // 3
    // 3
    // 3

    // 改进
    func main() {
        for i := 0; i < 3; i++ {
            i := i // 定义一个循环体内局部变量 i
            defer func(){ println(i) } ()
        }
    }

    func main() {
        for i := 0; i < 3; i++ {
            // 通过函数传入 i
            // defer 语句会马上对调用参数求值
            defer func(i int){ println(i) } (i)
        }
    }
    ```

- 递归

## defer

- 执行顺序：后进先出
- 使用场景：
  - 释放资源
    - 文件句柄
    - 数据库连接
    - 锁等
- 触发时机：
  - 当前函数的作用域结束
  - 正常返回、异常返回、panic
- 注意事项：
  - defer 后面跟的函数，如果函数有参数，参数的值在 defer 语句出现时就已经确定了
- return的过程
  - 设置返回值
  - 执行defer语句
  - 真正返回

- ```go
    package main
    
    import "fmt"
    
    func main() {
       defer func() {
          if r := recover(); r != nil {
             fmt.Println(r)
          }
       }()
       a := 1
       b := 0
       fmt.Println("result:", a/b)
    }
  ```
