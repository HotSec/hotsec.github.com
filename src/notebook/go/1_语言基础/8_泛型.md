## Go语言泛型实现

- Go语言泛型实现是通过接口来实现的，接口中定义了类型约束，通过类型约束来实现泛型

```go
package main

import "fmt"

type MyInt int

type Number interface {
	int | int8 | int16 | int32 | int64 | float32 | float64 | MyInt
}

func Add[T Number](a, b T) T {
	return a + b
}

func main() {
	fmt.Println(Add(1, 2))
	fmt.Println(Add(1.1, 2.2))
}
```

- go会将int、float等类型编译出具体的函数，而MyInt会通过加载对于字典数据到寄存器中，调用int的函数

## 反射

- 反射是指计算机程序在运行时（Run time）可以访问、检测和修改它本身状态或行为的一种能力。
- Go语言中的反射是通过`reflect`包来实现的，通过反射可以获取到变量的类型、值等信息

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	var a int = 10
	fmt.Println(reflect.TypeOf(a))
	fmt.Println(reflect.ValueOf(a))
}
```

通过反射来调用函数

```go
package main

import (
	"fmt"
	"reflect"
)

func Add(a, b int) int {
	return a + b
}

func main() {
	var a int = 10
	var b int = 20
	f := reflect.ValueOf(Add)
	result := f.Call([]reflect.Value{reflect.ValueOf(a), reflect.ValueOf(b)})
	fmt.Println(result[0].Int())
}
```

## 如何比较两个对象完全相同

- 简单类型可以直接使用==比较，结构体类型可以通过==比较，如果结构体中包含不可比较的字段，则无法使用==比较
- reflect.DeepEqual() 可以比较两个对象是否完全相同
- 实际项目中跟推荐自定义Equal方法来比较两个对象是否完全相同
