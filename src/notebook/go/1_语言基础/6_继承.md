# 继承


- 在结构体内置匿名成员来实现继承

  - ```go
        import "image/color"

        type Point struct{ X, Y float64 }

        type ColoredPoint struct {
            Point
            Color color.RGBA
        }

        var cp ColoredPoint
        cp.X = 1
        fmt.Println(cp.Point.X) // "1"
        cp.Point.Y = 2
        fmt.Println(cp.Y)       // "2"
    ```
