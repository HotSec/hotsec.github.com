# 国密算法证书

## 一、国密算法概述

国密算法是由中国国家密码管理局认定的国产密码算法，主要包括：

| 算法 | 类型 | 说明 |
|------|------|------|
| SM1 | 对称加密 | 分组密码，128位密钥，已嵌入芯片 |
| SM2 | 非对称加密 | 基于椭圆曲线，ECC椭圆曲线密码 |
| SM3 | 哈希算法 | 杂凑算法，输出256位散列值 |
| SM4 | 对称加密 | 分组密码，128位密钥，DES替代 |
| SM7 | 对称加密 | 分组密码，用于非接触式IC卡 |
| SM9 | 身份认证 | 基于配对的身份加密算法 |

## 二、SM2算法（重点）

### 2.1 SM2 vs RSA

| 对比项 | SM2 | RSA |
|--------|-----|-----|
| 密钥长度 | 256位 | 2048位 |
| 安全强度 | 128位 | 128位（相当） |
| 签名速度 | 更快 | 较慢 |
| 存储空间 | 更小 | 较大 |

### 2.2 SM2算法流程

SM2主要用于：
- **数字签名**：SM2DSA
- **密钥交换**：SM2KE
- **加密**：SM2EE

```go
// SM2签名算法示例
func SM2Sign(msg []byte, privateKey []byte) ([]byte, error) {
    // 1. 计算Z值（用户身份标识）
    // 2. 计算e = Hash(Z || msg)
    // 3. 生成随机数k
    // 4. 计算点R = k*G
    // 5. 计算r = (e + R.x) mod n
    // 6. 计算s = (d + r*k)^{-1} * (r + 1) * dA mod n
    return signature, nil
}
```

### 2.3 SM2证书结构

SM2证书基于GB/T 32918标准，采用ASN.1格式：

```asn1
SM2Certificate ::= SEQUENCE {
    tbsCertificate       TBSCertificate,
    signatureAlgorithm   AlgorithmIdentifier,
    signatureValue       BIT STRING
}

TBSCertificate ::= SEQUENCE {
    version           [0] Version DEFAULT v1,
    serialNumber      CertificateSerialNumber,
    signature         AlgorithmIdentifier,
    issuer            Name,
    validity          Validity,
    subject           Name,
    subjectPublicKeyInfo SubjectPublicKeyInfo,
    extensions       [1] Extensions OPTIONAL
}
```

## 三、SM3哈希算法

### 3.1 特性

- 输出长度：256位
- 迭代结构：Merkle-Damgård结构
- 分组长度：512位
- 压缩函数：72轮F函数

### 3.2 vs MD5/SHA-1/SHA-256

| 算法 | 输出位长 | 碰撞攻击 |
|------|----------|----------|
| MD5 | 128位 | 已可破解 |
| SHA-1 | 160位 | 已发现碰撞 |
| SHA-256 | 256位 | 安全 |
| SM3 | 256位 | 安全 |

## 四、SM4对称加密算法

### 4.1 特性

- 分组长度：128位
- 密钥长度：128位
- 迭代轮数：32轮
- 结构：Feistel结构（与DES类似但更安全）

### 4.2 工作模式

SM4支持多种工作模式：
- **ECB**：电子密码本模式
- **CBC**：密码分组链接模式
- **CFB**：输出反馈模式
- **OFB**：密码反馈模式
- **GCM**：伽罗瓦计数器模式（推荐）

```go
// SM4-GCM模式加密
func SM4GCMEncrypt(plaintext, key, nonce, aad []byte) (ciphertext, tag []byte) {
    block, _ := sm4.NewCipher(key)
    gcm, _ := cipher.NewGCM(block)
    ciphertext = gcm.Seal(nil, nonce, plaintext, aad)
    tag = ciphertext[len(ciphertext)-16:]
    return
}
```

## 五、国密证书格式

### 5.1 证书编码

国密证书采用DER编码（ASN.1），文件扩展名：
- `.cer` 或 `.crt`：DER格式
- `.pem`：Base64编码格式

### 5.2 查看国密证书

```bash
# 查看证书信息
openssl x509 -in sm2-cert.cer -inform DER -text -noout

# 转换为PEM格式
openssl x509 -in sm2-cert.cer -inform DER -outform PEM -out sm2-cert.pem

# 查看公钥信息
openssl ec -in sm2-key.pem -pubout -text
```

### 5.3 国密证书特征

1. **签名算法**：SM2withSM3（1.2.156.10197.501）
2. **公钥算法**：SM2 Elliptic Curve
3. **椭圆曲线**：256位素数域曲线

```bash
# 国密证书签名算法OID
2.16.156.10197.501  # SM2withSM3
```

## 八、面试题

### Q1：国密算法有哪些？与RSA相比有什么优势？

**答**：国密算法包括SM1、SM2、SM3、SM4、SM7、SM9。

SM2相比RSA的优势：
- **密钥更短**：256位 vs 2048位，存储传输更高效
- **签名更快**：SM2签名速度约为RSA的10倍
- **安全相当**：都达到128位安全强度
- **自主可控**：核心算法自主研发，避免国外算法后门风险

### Q2：SM2数字签名流程是什么？

**答**：
1. 计算ZA = Hash(ENTL || ID || a || b || xG || yG || xA || yA)
2. 计算e = Hash(ZA || M)
3. 生成随机数k ∈ [1, n-1]
4. 计算点(x1, y1) = [k]G
5. 计算r = (e + x1) mod n，若r=0或r+k=n则返回步骤3
6. 计算s = (dA + r)^{-1} · (k - r·dA) mod n，若s=0则返回步骤3
7. 签名结果为(r, s)

### Q3：什么是国密证书？与X.509证书有什么区别？

**答**：国密证书是采用SM2算法进行签名、基于GB/T 32918标准的数字证书。

与X.509证书的区别：
- **签名算法**：SM2withSM3 vs RSA/SHA-256/ECDSA
- **公钥算法**：SM2 ECC vs RSA/ECDSA
- **曲线参数**：国密推荐曲线 vs 国际推荐曲线
- **标准体系**：GB/T 32918 vs RFC 5280

### Q4：SM4有哪些工作模式？如何选择？

**答**：SM4支持ECB、CBC、CFB、OFB、GCM等模式。

选择建议：
- **ECB**：简单场景，不推荐（泄露明文结构）
- **CBC**：通用加密场景，推荐
- **GCM**：需要认证加密，推荐（AEAD）
- **CTR/OFB**：流式数据加密

### Q5：为什么需要国密算法？

**答**：
1. **政策要求**：等保2.0、密码法等法规要求
2. **安全可控**：避免依赖国外算法，降低供应链风险
3. **合规需要**：政府、金融等行业强制要求
4. **性能优势**：SM2签名速度远快于RSA

### Q6：SM3的安全性如何？

**答**：SM3输出256位杂凑值，安全性与SHA-256相当。

- 采用Merkle-Damgård结构
- 压缩函数包含72轮F函数
- 目前没有公开的有效攻击方法
- 已通过国家密码管理局安全性审查

### Q7：国密SSL证书如何部署？

**答**：

1. **获取证书**：从CA机构申请国密证书
2. **服务器配置**：配置支持国密协议的Web服务器
3. **Nginx配置示例**：
```nginx
server {
    listen 443 ssl;
    ssl_certificate sm2-cert.pem;
    ssl_certificate_key sm2-key.pem;
    ssl_protocols TLSv1.2;
    ssl_ciphers ECDHE-SM4-SM3:SM2DHE-SM4-SM3;
}
```

### Q8：国密算法在哪些场景使用？

**答**：
- **电子政务**：政府机构内部系统
- **金融行业**：银行、证券、保险系统
- **电子商务**：支付、交易系统
- **物联网**：车联网、智能家居
- **VPN**：安全通信隧道

## 九、实战代码

### 9.1 生成国密证书

```go
package main

import (
    "crypto/x509"
    "crypto/x509/pkix"
    "encoding/pem"
    "math/big"
    "time"

    "github.com/emmansun/gmsm/sm2"
    "github.com/emmansun/gmsm/x509"
)

func main() {
    // 生成SM2密钥对
    privateKey, _ := sm2.GenerateKey()

    // 创建证书模板
    template := &x509.Certificate{
        SerialNumber: big.NewInt(1),
        Subject: pkix.Name{
            Organization: []string{"Example Inc"},
            CommonName:   "example.com",
        },
        NotBefore:             time.Now(),
        NotAfter:              time.Now().AddDate(1, 0, 0),
        KeyUsage:              x509.KeyUsageDigitalSignature,
        ExtKeyUsage:           []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
        BasicConstraintsValid: true,
    }

    // 自签名证书
    certDER, _ := x509.CreateCertificate(template, template, &privateKey.PublicKey, privateKey)

    // 输出PEM格式
    certPEM := pem.EncodeToMemory(&pem.Block{
        Type: "CERTIFICATE", Bytes: certDER,
    })
    print(string(certPEM))
}
```

### 9.2 SM4加解密

```go
package main

import (
    "crypto/cipher"
    "crypto/rand"
    "encoding/hex"
    "fmt"
    "github.com/emmansun/gmsm/sm4"
)

func main() {
    key := make([]byte, 16)
    rand.Read(key)

    plaintext := []byte("Hello, 国密SM4!")

    // 加密
    block, _ := sm4.NewCipher(key)
    iv := make([]byte, sm4.BlockSize)
    rand.Read(iv)
    stream := cipher.NewCBCEncrypter(block, iv)
    ciphertext := make([]byte, len(plaintext))
    stream.CryptBlocks(ciphertext, plaintext)

    fmt.Printf("密文: %s\n", hex.EncodeToString(ciphertext))

    // 解密
    dstream := cipher.NewCBCDecrypter(block, iv)
    decrypted := make([]byte, len(ciphertext))
    dstream.CryptBlocks(decrypted, ciphertext)

    fmt.Printf("明文: %s\n", string(decrypted))
}
```

## 十、总结

| 类别 | 算法 | 用途 |
|------|------|------|
| 对称加密 | SM1/SM4 | 数据加密 |
| 非对称加密 | SM2/SM9 | 密钥交换/数字签名 |
| 哈希算法 | SM3 | 完整性校验 |
| 身份认证 | SM7/SM9 | 身份标识 |

**核心要点**：
- SM2是国密核心，替代RSA的趋势明显
- SM3与SHA-256安全强度相当
- SM4是DES的国产替代
- 国密证书采用SM2withSM3签名
- 等保2.0和密码法推动国密算法普及
