# 协程池

## 基础概念

- 进程：进程直接被操作系统调度，是系统资源分配的基本单位，进程拥有独立的内存空间，进程间通信需要通过 IPC（进程间通信）机制。
- 线程：线程是进程的子任务，是 CPU 调度的基本单位，线程共享进程的内存空间。线程间通信可以直接使用共享内存。
- 协程：协程是用户态的轻量级线程，协程的调度完全由用户控制，协程间通信通过 channel 实现。

## Goroutine

- Goroutine 是 Go 语言中的轻量级线程，由 Go 运行时管理，不需要操作系统参与调度，因此协程的创建、销毁和切换开销非常小。
- Goroutine 的数量受限于 GOMAXPROCS 环境变量，默认值为 CPU 核心数。可以通过 runtime.GOMAXPROCS() 函数设置。
- Goroutine 的调度由 Go 运行时管理，不需要程序员手动干预。Go 运行时会自动将 Goroutine 分配到不同的 CPU 核心上执行。
- Goroutine 的栈空间是动态分配的，初始大小为 2KB，最大为 1GB。可以通过 runtime/debug.SetMaxStack() 函数设置最大栈空间。

---

- Goroutine 的调度是非抢占式的，只有当 Goroutine 调用 runtime.Goexit() 函数或者执行完毕后，Go 运行时才会调度其他 Goroutine 执行。
- Goroutine 的调度是协作式的，当 Goroutine 执行 I/O 操作或者调用 runtime.Gosched() 函数时，Go 运行时会主动让出 CPU 资源，让其他 Goroutine 执行。
- Goroutine 的调度是公平的，每个 Goroutine 都有机会执行，不会出现某个 Goroutine 长时间占用 CPU 资源的情况。

## 手动实现协程池

```go
package main

import (
    "fmt"
    "sync"
    "time"
)

type Pool struct {
    workerNum int
    taskQueue chan func()
    quit      chan struct{} // 用于优雅关闭
    wg        sync.WaitGroup
}

func NewPool(workerNum int) *Pool {
    return &Pool{
        workerNum: workerNum,
        taskQueue: make(chan func()),
        quit:      make(chan struct{}),
    }
}

func (p *Pool) AddTask(task func()) {
    p.taskQueue <- task
}

func (p *Pool) Start() {
    for i := 0; i < p.workerNum; i++ {
        p.wg.Add(1)
        go p.worker()
    }
}

func (p *Pool) worker() {
    defer p.wg.Done()
    for {
        select {
        case task := <-p.taskQueue:
            task()
        case <-p.quit:
            return
        }
    }
}

func (p *Pool) Stop() {
    close(p.quit)
    p.wg.Wait()
}

func main() {
    pool := NewPool(5)
    pool.Start()
    defer pool.Stop() // 确保main函数结束时优雅关闭

    for i := 0; i < 10; i++ {
        idx := i // 修复数据竞争
        pool.AddTask(func() {
            time.Sleep(1000 * time.Millisecond)
            fmt.Println("Task", idx)
        })
    }
}
```

```go
package main
 
import (
	"fmt"
	"sync"
	"time"
 
	"github.com/panjf2000/ants/v2"
)
 
func add(d int) {
	sum := 0
	for i := 0; i < d; i++ {
		sum += i
	}
}
func main() {
	var wg sync.WaitGroup
	now := time.Now()
	for i := 0; i < 5; i++ {
		wg.Add(1)
		ants.Submit(func() {
			add(10000000000)
			wg.Done()
		})
	}
	wg.Wait()
	fmt.Println(time.Since(now))
	now = time.Now()
	for i := 0; i < 5; i++ {
		add(10000000000)
	}
	fmt.Println(time.Since(now))
}
```
