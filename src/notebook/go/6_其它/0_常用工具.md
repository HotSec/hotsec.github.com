# 常用工具

## Docker多阶段构建

- Dockerfile.multist

```yaml
FROM golang:alpine as builder
WORKDIR /go/src
COPY httpserver.go .
RUN go build -o httpd ./httpserver.go
From alpine:latest
WORKDIR /root/
COPY --from=builder /go/src/httpd .
RUN chmod +x /root/httpd
ENTRYPOINT ["/root/httpd"]
```

`docker build -t repodemo/httpd-multi-stage -f Dockerfile.multist`

## go build

- `-ldflags` 指定链接器参数
- `-gcflags` 指定编译器参数
- `-ldflags "-X main.version=1.0.0 -X main.buildTime=$(date +%Y-%m-%d\ %H:%M:%S)"`  添加版本信息
- `-ldflags "-s -w"` 去掉调试信息
- `-trimpath` 去掉编译后的二进制文件中的路径信息
- `-o` 指定输出文件名
- `-v` 打印详细信息
- `-x` 打印编译过程
- `-race` 检测竞态条件
- `-gcflags "all=-N -l"` 禁用编译器优化和内联
- `-asmflags "all=-trimpath=$PWD"` 去掉汇编代码中的路径信息
- `-extldflags "-static"` 静态链接
- `-p` 指定并行编译的CPU核数
- `-a` 强制重新编译所有包
- `-n` 打印编译命令但不执行

## go fmt

- `go fmt ./...` 格式化代码
- `-s` 去掉多余的空格
- `-w` 将格式化后的代码写回文件
- `-l` 只打印有问题的行
- `-r` 指定格式化规则
- `-d` 只打印格式化后的代码，不写回文件
- `-x` 打印格式化命令但不执行
- `-e` 打印错误信息
- `-c` 指定要格式化的文件或目录
- `-i` 指定要格式化的文件或目录的路径

## go vet

- `go vet ./...` 检查代码中的潜在错误

## go test

- `-v` 打印详细信息
- `-x` 打印测试命令但不执行
- `-c` 只编译测试代码，不执行测试
- `-cover` 生成测试覆盖率报告
- `-coverprofile` 指定测试覆盖率报告的文件名

## golangci-lint

- `golangci-lint run` 运行代码检查
- `golangci-lint help` 查看帮助信息
