# 常见陷阱

## 短变量

- 短变量声明不总是会声明一个新变量
- 短变量声明会导致难于发现的变量遮蔽

## for range

- 针对string类型的for range迭代不是逐字节迭代，而是逐字符迭代
- 对map类型内元素的迭代顺序是随机
- 在“复制品”上进行迭代
- 迭代变量是重用的
  - 循环变量v仅仅被声明了一次并在后续整个迭代过程中被重用

## string

- string是只读的byte切片，不能修改
- 字符串长度：len()函数返回的是字符串的字节数，而不是字符数。

## 方法

- 使用值类型receiver的方法无法改变类型实例的状态
- 值类型实例可以调用采用指针类型receiver的方法，指针类型实例也可以调用采用值类型receiver的方法

## break

- 不接标签（label）的break语句会跳出最内层的switch、select或for代码块。

## time包

```go
packgae main
import (
    "fmt"
    "time"
)


func main() {
    // Go语言采用参考时间的方式，来进行格式化
    fmt.Println(time.Now().Format("2006-01-02 15:04:05"))
}
```

## encoding/json

- 未导出的结构体字段不会被编码到JSON文本中
- nil切片和空切片可能被编码为不同文本
- 字节切片可能被编码为base64编码的文本
- 当JSON文本中的整型数值被解码为interface{}类型时，其底层真实类型为float64

## net/http

- http包需要我们手动关闭Response.Body
- HTTP客户端默认不会及时关闭已经用完的HTTP连接

## 低效的切片初始化

- 预分配切片容量以避免多次分配
- 使用make函数创建切片时，指定长度和容量
- 避免在循环中频繁扩展切片

## 切片为nil与空混淆

- `var s []string` nil切片
- `s := make([]string, 0)` 长度为0的空切片

## 没有正确检查切片是否为0

- 使用`len(s) == 0`检查切片是否为空

## 错误的切片拷贝

- 使用`copy`函数进行切片拷贝
  - `src := []int{1, 2, 3}`
  - `dst := make([]int, len(src))`
  - `copy(dst, src)` 
  - 返回值为实际拷贝的元素数量
  - 目标切片容量不足时，只会拷贝部分元素

## 切片使用append的副作用

- append函数可能会导致底层数组重新分配
  - 翻倍 每次增加25%
- 切片截取 s[low:high:max] 前两个参数左闭右开控制切片区间，第三个参数控制新切片的容量
- 有可能会影响原切片的数据

## 切片和内存泄漏

- 切片引用了底层数组的一部分，可能会导致整个数组无法被垃圾回收
- 使用copy函数创建新的切片，避免引用不必要的底层数组
- 将切片赋值为nil，释放对底层数组的引用

## 低效的Map初始化

- 预分配Map容量以避免多次扩展
- `mp := make(map[string]int, 100)` 指定初始容量

## Map和内存泄漏

- Go语言的Map只能增长大小，并不能自动收缩，即使内部元素被删除

## 错误的值比较方式

- 使用逻辑运算符不可以比较的数据类型
  - 切片
  - map

## 忽视元素在range循环中是拷贝

- range循环中，迭代变量是每次循环的元素拷贝

## 忽略在range循环中如何评估表达式

- range循环中，迭代表达式只会被评估一次

## 忽略在range中使用指针元素的影响

- range循环中使用指针类型的元素时，迭代变量仍然是指针的拷贝
- 需要使用索引访问切片元素以获取正确的地址

## 对map遍历的错误假设

- map遍历顺序是随机的，不要依赖特定顺序

## 忽略break的作用

- break语句只会跳出最内层的循环或switch语句
- 使用标签（label）可以跳出多层循环

## 在循环中使用defer

- defer语句会在函数返回时执行，而不是在循环的每次迭代时执行
- defer语句的参数在声明时就会被求值，而不是在执行时求值

## 不理解rune的概念

- rune是Go语言中表示Unicode码点的类型
- `type rune = int32`
- 使用range循环遍历字符串时，返回的迭代变量是rune类型
- 使用len函数获取字符串长度时，返回的是字符串的字节数，而不是字符数
  - `len([]rune("汉"))` 获取字符串的字符数 3

## 优化不足的字符串拼接

- strings.Clone(s string) string
  - 返回字符串s的一个副本，确保返回的字符串与原字符串不共享

## 不知道选择哪种类型的方法接收者

- 值类型接收者
  - 方法不会修改接收者的状态
  - 接收者是小型类型（如int、float、struct等）
- 指针类型接收者
  - 方法会修改接收者的状态
  - 接收者是大型类型（如大struct、数组等）
  - 避免值类型接收者的拷贝开销
