## 单元测试

- unittest
- pytest
  - pytest.mark.parametrize 表测试驱动
  - pytest.fixture 创建可复用的测试固定件

TDD测试驱动开发

## 有关单元测试的建议

- 写单元测试不是浪费时间
- 不要总想着‘补’单元测试
- 难测试的代码就是烂代码
- 像写应用代码一样对待测试代码
- 避免教条主义
