# 代码保护 


## pyarmor

[pyarmor](https://pyarmor.readthedocs.io/en/latest/) 是一个用于加密 Python 脚本和项目的工具，它可以将 Python 脚本编译成 C/C++ 代码，并生成一个独立的可执行文件，从而保护 Python 代码不被反编译和修改。

## 使用 pyarmor 保护代码的步骤

1. 安装 pyarmor：
   ```bash
   pip install pyarmor
   ```
2. 初始化项目：
   ```bash
    pyarmor init --src=src --entry=main.py myproject
    ```
