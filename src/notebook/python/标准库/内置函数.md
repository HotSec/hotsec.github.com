# 内置函数

- 类型转换
  - str(object='') 返回一个字符串
  - bytes
  - float(1)  转换为浮点数
  - chr(i)
  - ord(c)
  - int(x, base=10)
  - oct(x)
  - hex(x)
  - ascii(object)
  - bin(x) 将一个整数转换为带前缀 "0b" 的二进制数字符串
  - bool(x=False) 返回布尔值
  - complex(string) complex(real=0, imag=0) 将字符串或数字转换为复数
- 数学相关
  - abs(x) 返回数字的卷对值。
  - round(number, ndigits=None) 返回 number 舍入到小数点后 ndigits 位精度的值。 如果 ndigits 被省略或为 ，则返回最接近输入值的整数
  - max
  - min
  - sum(iterable, /, start=0) 从 start 开始自左向右对 iterable 的项求和并返回总计值。
  - pow(base, exp, mod=None) 返回 base 的 exp 次幂
  - divmod(a, b)
- 序列相关
  - len(s)
  - iter
  - aiter(async_iterable) 异步版 iter()
  - next
  - awaitable anext(async_iterator)
  - awaitable anext(async_iterator, default)  next()的异步版本
  - all(iterable) 如果iterable的所有元素均为真则返回True
  - any(iterable) 任一元素为真，则返回True
  - range(start, stop, step=1)
  - bytearray
  - list(iterable)
  - tuple(iterable)
  - dict
  - set(iterable)
  - frozenset(iterable=set())
  - enumerate(iterable, start=0)
  - filter(function, iterable)
  - map
  - zip(*iterables, strict=False) 在多个迭代器上并行迭代，从每个迭代器返回一个数据项组成元组。
  - reversed(seq)
  - sorted(iterable, /, *, key=None, reverse=False) 根据 iterable 中的项返回一个新的已排序列表。
- 类相关
  - class slice(start, stop, step=None) 返回一个切片对象
  - @classmethod
  - @staticmethod
  - class super(type, object_or_type=None) 访问已在类中被重载的继承方法很有用
  - hasattr(object, name)
  - getattr(object, name, default)
  - property
  - getattr
  - setattr
  - deleter
  - isinstance(object, classinfo)
  - issubclass(class, classinfo)
- 其它
  - print
  - input(prompt)
  - format
  - callable(objcet)
  - compile(source, filename, mode, flags=0, dont_inherit=False, optimize=- 1)
  - eval(expression, globals=None, locals=None)
  - exec(object, globals=None, locals=None, /, *, closure=None)
  - globals()
  - locals()
  - class type(object) 返回object的类型
  - type(name, bases, dict, **kwds) 返回一个新的 type 对象
  - vars(object) 返回模块、类、实例或任何其它具有 __dict__ 属性的对象的 __dict__ 属性。
  - id(object)
  - hash(object)
  - open
  - repr(object)
  - dir()
  - help()
  - breakpoint(*args, **kws) 断点
  - class memoryview(object) 返回由给定实参创建的“内存视图”对象
  - class object 返回一个不带特征的新对
  - __import__(name, globals=None, locals=None, fromlist=(), level=0)
