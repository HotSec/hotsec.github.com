# 唯一ID生成器

## 分布式唯一ID

- UUID

- 唯一生成器特点
  - 空间占用少
  - 高并发与高可用性
  - 唯一ID可用作数据库主键

- 单调递增的唯一ID
  - Redis INCRBY命令
    - `INCRBY seq_id 1`
  - 基于数据库的自增主键

- 批量获取ID的思路

- 高可用架构

- 雪花算法 Snowflake

- 时钟漂移 （石英晶体会有误差，一天1s以内）
  - 如果回拨的时间较短（如10ms）则阻塞一段时间后再重新执行
  - 如果回拨的时间较长，可以直接拒绝请求
