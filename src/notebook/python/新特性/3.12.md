# 3.12

## 类型注解简化

类型别名简化
```
type Point = tuple[float, float]  # 等价于 typing.TypeAlias + Tuple
type IntList = list[int]
```

引入 typing.override 装饰器，显式标记方法重写，帮助类型检查工具捕获错误
```python
class Parent:
    def method(self) -> int:
        return 1

class Child(Parent):
    @override  # 明确表示重写父类方法
    def method(self) -> int:
        return 2
```
