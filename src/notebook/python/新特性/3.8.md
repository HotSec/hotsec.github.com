# 3.8新特性

## 赋值表达式（海象运算符）

```python
# 传统写法
n = len(a)
if n > 10:
    print(f"List is too long ({n} elements)")

# 3.8+ 写法
if (n := len(a)) > 10:
    print(f"List is too long ({n} elements)")
```

## 位置参数强制语法 /

```python
def func(a, b, /, c, d):
    pass
# a 和 b 必须作为位置参数传入

func(1, 2, 3, 4)  # 合法
func(1, 2, c=3, d=4)  # 合法
func(a=1, b=2, c=3, d=4)  # 错误（a、b 不能用关键字）
```

## 新增 asyncio.run() 函数

```python
import asyncio
async def main():
    print("Hello")
    await asyncio.sleep(1)
    print("World")
asyncio.run(main())
```
