## 结构化模式匹配

```python
while True:
    match command.split():
        case ["quit" | "exit"]:
            break
        case ["load", filename]:
            load_from_file(filename)
        case ["save", filename]:
            save_to_file(filename)
        case ["add", *items] if items:
            add_items(items)
        case _:
            print("Unknown command")
```
