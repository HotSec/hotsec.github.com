# 3.14

## uv install

`uv python install cpython-3.14.0+freethreaded-linux-x86_64-gnu`

## 自由线程的官方支持：
Python 3.14 正式支持自由线程版本，该版本承诺通过消除全局解释器锁（GIL）为 Python 程序中的线程实现真正的并行性，且自 Python 3.13 以来，自由线程功能有了显著改进，之前未启用的专门化自适应解释器现在已可用。
## 标注的迟延求值
根据 PEP 649 和 PEP 749，函数、类和模块上的标注将不再被立即求值，而是存储在专门的标注函数中，仅在必要时进行求值。新引入的annotationlib模块提供了检查延迟注解的工具。
## 模板字符串字面值
PEP 750 引入了模板字符串字面值（t - strings），它允许将模板与一个作用于模板结构的函数相结合，可对模板中的变量进行更灵活的处理，使编写模板引擎变得更容易。
## 标准库中的多解释器
CPython 运行时支持在同一个进程中同时运行多个 Python 的副本，新增的concurrent.interpreters模块使得该特性可通过标准库使用，支持全新的并发模型，能实现真正的多核心并行。
## 新增compression.zstd模块
根据 PEP 784，标准库新增了compression.zstd模块，提供了对 Zstandard 压缩算法的支持。
## except表达式简化
PEP 758 允许except和except*表达式省略括号，使代码更加简洁。
## 语法高亮和彩色输出
PyREPL 中增加了语法高亮功能，同时unittest、argparse、json和calendar的 CLI 也支持颜色显示，提升了用户体验。
## 安全的外部调试器接口
PEP 768 为 CPython 提供了零开销的外部调试器接口，增强了调试的安全性和效率。
## uuid模块改进
uuid模块现在支持 UUID 版本 6 - 8，并且生成版本 3 - 5 的速度提高了 40%。
## 错误消息改进
Python 3.14 对错误消息进行了改进，使其更加用户友好和准确，帮助开发者更快地定位和解决问题。
## 实验性的即时编译器
Windows 和 macOS 系统的官方二进制发布包中包含了实验性的 JIT 编译器，可通过环境变量PYTHON_JIT=1或命令行标志启用，但默认情况下处于禁用状态。
## 平台支持扩展
Emscripten 成为官方支持的平台，处于第 3 层级。
