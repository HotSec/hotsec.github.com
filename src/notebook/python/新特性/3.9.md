# 3.9新特性

Python 3.9 于 2020 年 10 月发布，带来了多项实用的新特性和改进，主要包括：
## 字典合并与更新运算符
新增 | 运算符用于字典合并，|= 运算符用于字典更新，例如：
```python
a = {"x": 1}
b = {"y": 2}
c = a | b  # 合并为 {"x": 1, "y": 2}
a |= b    # a 变为 {"x": 1, "y": 2}
```
## 字符串方法增强
`str.removeprefix(prefix)`：移除字符串开头的指定前缀。
`str.removesuffix(suffix)`：移除字符串结尾的指定后缀。
例如："hello_world".removesuffix("_world") 结果为 "hello"。
## 类型提示改进
支持标准集合类型（如 list、dict、tuple）直接用作泛型，无需再导入 typing.List 等，例如：
```python
def func(x: list[int]) -> dict[str, int]:
    return {str(i): i for i in x}
```
新增 typing.Annotated 用于为类型添加元数据。
## 新增数学函数
math.lcm(*args)：计算多个数的最小公倍数。
math.gcd(*args)：支持多个参数的最大公约数计算（此前仅支持两个参数）。
math.perm(n, k)：计算排列数 P (n, k)。
math.comb(n, k)：计算组合数 C (n, k)。
## 时间模块优化
zoneinfo 模块正式引入，提供了标准的时区数据库访问，无需依赖第三方库即可处理时区。
## 性能提升
内置函数 int、str、tuple 等的性能优化，部分操作速度提升 10-20%。
列表和字典的底层实现优化，减少内存占用。
## 其他特性
放宽了装饰器的语法限制，允许更多类型的表达式作为装饰器。
asyncio 模块新增 asyncio.to_thread() 函数，方便将同步函数转换为异步任务。
命令行参数 python -m module --help 可直接显示模块的帮助信息。
