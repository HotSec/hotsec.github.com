## 3. 是否为特权容器

- /proc/self/status的capeff匹配到到3fffffffff

```text
	if strings.Contains(matched, "3fffffffff") {
			p.Result["CAP"] = append(p.Result["CAP"].([][]string), []string{"Privileged", "True"})
			return true
		}
```

## 16. 判断是否为容器环境

1. 检查/.dockerenv文件是否存在
2. 检查/proc/1/cgroup内是否包含"docker"等字符串
3. 检查是否存在container环境变量
4. hostname是否为06e33f788f23格式
5. 进程数量
