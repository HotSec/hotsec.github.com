## 一、链表篇（14题）

### 核心知识点
| 技巧       | 说明                          |
| ---------- | ----------------------------- |
| 虚拟头节点 | 统一处理头节点，减少边界判断  |
| 快慢指针   | 找中点、找环、找倒数第k个节点 |
| 链表反转   | 迭代与递归两种方式            |
| 链表拼接   | 断链与重连的指针操作          |

### 1.1 BM1 反转链表
**问题**：反转整个链表

**思路**：
- 迭代：三指针 prev、curr、next逐步翻转
- 递归：先反转后续节点，再处理当前节点

**代码**：
```python
def reverse_list(head):
    prev, curr = None, head
    while curr:
        next_tmp = curr.next
        curr.next = prev
        prev = curr
        curr = next_tmp
    return prev
```

**复杂度**：时间O(n)，空间O(1)

**关键点**：保存下一个节点，断开当前节点的next指向

### 1.2 BM2 反转链表II
**问题**：反转从m到n的链表

**思路**：
1. 创建虚拟头节点，避免处理头节点的边界情况
2. 找到m位置的前驱节点
3. 从m开始反转n-m+1个节点（头插法）
4. 重连链表

**代码**：
```python
def reverse_between(head, m, n):
    dummy = ListNode(0)  # 虚拟头节点，统一处理
    dummy.next = head
    prev = dummy  # prev指向m位置的前驱
    for _ in range(m-1):
        prev = prev.next

    start = prev.next
    then = start.next
    for _ in range(n-m):
        start.next = then.next  # 将then节点插入到prev之后
        then.next = prev.next
        prev.next = then
        then = start.next
    return dummy.next
```

**复杂度**：时间O(n)，空间O(1)

### 1.3 BM3 合并两个排序链表
**问题**：合并两个有序链表

**思路**：双指针 + 虚拟头节点
- 同时遍历两个链表，每次选择较小的节点接入结果
- 任一链表遍历完后，直接连接剩余部分

**代码**：
```python
def merge_two_lists(l1, l2):
    dummy = ListNode(0)  # 虚拟头节点
    curr = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            curr.next = l1  # 选择较小值接入结果
            l1 = l1.next
        else:
            curr.next = l2  # 选择较小值接入结果
            l2 = l2.next
        curr = curr.next
    curr.next = l1 or l2  # 连接剩余部分
    return dummy.next
```

**复杂度**：时间O(n+m)，空间O(1)

### 1.4 BM4 删除链表的倒数第n个节点
**问题**：删除倒数第n个节点

**思路**：快慢指针，快指针先走n步
- 快指针先走n步，然后快慢指针同时移动
- 当快指针到达末尾时，慢指针正好在倒数第n个节点的前一个位置

**代码**：
```python
def remove_nth_from_end(head, n):
    dummy = ListNode(0)
    dummy.next = head
    fast = slow = dummy  # 快慢指针初始化
    for _ in range(n):
        fast = fast.next
    while fast.next:
        fast = fast.next
        slow = slow.next  # 同步移动
    slow.next = slow.next.next  # 删除倒数第n个节点
    return dummy.next
```

**复杂度**：时间O(n)，空间O(1)

### 1.5 BM5 链表是否有环
**问题**：判断链表是否有环

**思路**：快慢指针（Floyd判圈法）
- 慢指针每次移动一步，快指针每次移动两步
- 如果存在环，快慢指针必定在环内相遇

**代码**：
```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next  # 慢指针走一步
        fast = fast.next.next  # 快指针走两步
        if slow == fast:
            return True  # 快慢相遇，有环
    return False
```

**复杂度**：时间O(n)，空间O(1)

**原理**：有环时快慢指针必定相遇

---

### 1.6 BM6 链表中环的入口
**问题**：找到链表中环的入口

**思路**：两阶段法
1. 第一阶段：快慢指针相遇，确定链表有环
2. 第二阶段：从头节点和相遇点同时出发，再次相遇即为环入口

**代码**：
```python
def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            slow = head  # 一个指针从头部出发
            while slow != fast:
                slow = slow.next
                fast = fast.next
            return slow  # 返回环入口
    return None  # 无环
```

**复杂度**：时间O(n)，空间O(1)

**数学证明**：设起点到入口距离为a，环长度为b，快慢指针相遇时有：2a + nb = a + mb → a = (m-n)b

### 1.7 BM7 两个链表的第一个公共节点
**问题**：找两个链表的交点

**思路**：双指针同步遍历
- 两个指针分别从A和B的头部出发
- 当一个指针走完自己的链表后，开始走另一个链表
- 由于两个指针走的总路径长度相同（均为LA+LB），必定会在交点相遇

**代码**：
```python
def get_intersection_node(headA, headB):
    pA, pB = headA, headB
    while pA != pB:
        pA = pA.next if pA else headB
        pB = pB.next if pB else headA
    return pA
```

**复杂度**：时间O(n+m)，空间O(1)

**原理**：A走完走B，B走完走A，路径长度相同

### 1.8 BM8 链表倒数最后k个节点
**问题**：返回链表倒数最后k个节点

**思路**：快慢指针
- 快指针先走k步，然后快慢指针同时移动
- 当快指针到达末尾时，慢指针正好指向倒数第k个节点

**代码**：
```python
def get_kth_from_end(head, k):
    fast = slow = head
    for _ in range(k):
        fast = fast.next
    while fast:
        fast = fast.next
        slow = slow.next
    return slow
```

**复杂度**：时间O(n)，空间O(1)

### 1.9 BM9 判断是否为回文链表
**问题**：判断是否为回文链表

**思路**：快慢指针 + 反转
1. 快慢指针找中点（慢指针走一步，快指针走两步）
2. 反转后半部分链表
3. 比较前半部分和反转后的后半部分

**代码**：
```python
def is_palindrome(head):
    if not head or not head.next:
        return True
    slow = fast = head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next
    mid = slow.next  # mid指向后半部分
    slow.next = None
    prev = None  # 反转后半部分
    curr = mid
    while curr:
        next_tmp = curr.next
        curr.next = prev
        prev = curr
        curr = next_tmp

    while head and prev:  # 比较前后部分
        if head.val != prev.val:
            return False
        head = head.next
        prev = prev.next
    return True
```

**复杂度**：时间O(n)，空间O(1)

### 1.10 BM10 合并多个有序链表
**问题**：合并k个有序链表

**思路**：小顶堆（优先队列）
- 将所有链表的头节点入堆
- 每次弹出堆顶（最小节点），接入结果链表
- 将弹出节点的下一个节点入堆，重复直到堆为空

**代码**：
```python
import heapq  # 小顶堆维护最小节点

def merge_k_lists(lists):
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))  # 所有链表头节点入堆

    dummy = ListNode(0)
    curr = dummy
    while heap:
        val, i, node = heapq.heappop(heap)  # 弹出最小节点
        curr.next = node
        curr = curr.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))  # 后继节点入堆
    return dummy.next
```

**复杂度**：时间O(n log k)，空间O(k)
- n为所有节点总数，k为链表数量

### 1.12 BM13 链表中节点删除
**问题**：删除链表中值为val的所有节点

**思路**：虚拟头节点 + 遍历
- 使用虚拟头节点简化头节点删除的边界处理
- 遍历链表，当遇到目标值时跳过该节点

**代码**：
```python
def delete_node(head, val):
    dummy = ListNode(0)
    dummy.next = head
    prev = dummy
    while prev.next:
        if prev.next.val == val:
            prev.next = prev.next.next
        else:
            prev = prev.next
    return dummy.next
```

**复杂度**：时间O(n)，空间O(1)

### 1.13 BM14 链式A-B
**问题**：删除链表中A到B的所有节点

**思路**：定位 + 断链
- 使用虚拟头节点简化边界处理
- 找到位置A的前驱节点
- 从位置A开始，删除B-A+1个节点

**代码**：
```python
def delete_range(head, A, B):
    dummy = ListNode(0)
    dummy.next = head
    prev = dummy
    for _ in range(A - 1):
        prev = prev.next
    delete_count = B - A + 1
    for _ in range(delete_count):
        prev.next = prev.next.next
    return dummy.next
```

**复杂度**：时间O(n)，空间O(1)

### 2.1 BM15 二叉树层序遍历
**问题**：逐层遍历，返回每层节点值

**思路**：BFS（广度优先搜索）+ 队列
- 使用队列存储当前层的所有节点
- 逐层取出并访问，同时将下一层节点入队

**代码**：
```python
from collections import deque

def level_order(root):
    if not root:
        return []
    result = []
    queue = deque([root])  # BFS用队列
    while queue:
        level = []
        for _ in range(len(queue)):  # 遍历当前层所有节点
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)  # 下一层节点入队
            if node.right:
                queue.append(node.right)  # 下一层节点入队
        result.append(level)
    return result
```

**复杂度**：时间O(n)，空间O(w)，w为二叉树最大宽度

### 2.2 BM16 二叉树的右视图
**问题**：从右边看二叉树，返回每层最右节点

**思路**：层序遍历变体
- 层序遍历，每层取最后一个节点即是右视图看到的节点

**代码**：
```python
from collections import deque

def right_side_view(root):
    if not root:
        return []
    result = []
    queue = deque([root])
    while queue:
        level_size = len(queue)
        for i in range(level_size):
            node = queue.popleft()
            if i == level_size - 1:  # 每层最后一个节点
                result.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    return result
```

**复杂度**：时间O(n)，空间O(w)

### 2.3 BM17 二叉树的最近公共祖先
**问题**：找两个节点的最近公共祖先

**思路**：后序遍历（深度优先搜索）
- 从底向上递归，当遇到p或q时返回
- 如果左右子树都返回了非空结果，说明当前节点是LCA
- 如果只有一个子树返回非空结果，说明LCA在那个子树中

**代码**：
```python
def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root  # 左右子树都找到，LCA为当前节点
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if left and right:
        return root  # 左右子树都找到，LCA为当前节点
    return left or right  # LCA在某一子树中
```

**复杂度**：时间O(n)，空间O(h)，h为树高

### 2.4 BM18 二叉树的镜像
**问题**：将二叉树左右翻转（生成镜像）

**思路**：递归（深度优先搜索）
- 先递归处理左右子树
- 再交换当前节点的左右子节点

**代码**：
```python
def mirror(root):
    if not root:
        return None
    root.left, root.right = root.right, root.left  # 交换左右子节点
    mirror(root.left)
    mirror(root.right)
    return root
```

**复杂度**：时间O(n)，空间O(h)

### 2.5 BM19 重建二叉树
**问题**：从前序和中序遍历构建二叉树

**思路**：递归分治
- 前序遍历的第一个元素是根节点
- 在中序遍历中找到根节点位置，左边是左子树，右边是右子树
- 递归构建左右子树

**代码**：
```python
def build_tree(preorder, inorder):
    if not preorder:
        return None
    root = TreeNode(preorder[0])
    idx = inorder.index(root.val)
    root.left = build_tree(preorder[1:idx+1], inorder[:idx])
    root.right = build_tree(preorder[idx+1:], inorder[idx+1:])
    return root
```

**复杂度**：时间O(n²)，空间O(n)

**优化**：用哈希表记录中序遍历的值到索引的映射，避免重复查找

```python
def build_tree_optimized(preorder, inorder):
    inorder_index = {val: i for i, val in enumerate(inorder)}

    def build(pre_start, pre_end, in_start, in_end):
        if pre_start > pre_end:
            return None
        root_val = preorder[pre_start]
        root = TreeNode(root_val)
        idx = inorder_index[root_val]
        left_size = idx - in_start
        root.left = build(pre_start + 1, pre_start + left_size, in_start, idx - 1)
        root.right = build(pre_start + left_size + 1, pre_end, idx + 1, in_end)
        return root

    return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

**优化后复杂度**：时间O(n)，空间O(n)

### 2.6 BM20 树的子结构
**问题**：判断B是否为A的子结构

**思路**：递归遍历 + 匹配
- 递归遍历树A，对于A中的每个节点，都尝试与B进行匹配
- recur函数判断以A和B为根的子树是否匹配

**代码**：
```python
def is_sub_structure(A, B):
    if not A or not B:
        return False
    return recur(A, B) or is_sub_structure(A.left, B) or is_sub_structure(A.right, B)

def recur(A, B):
    if not B:
        return True  # B为空，匹配完成
    if not A or A.val != B.val:
        return False  # 不匹配
    return recur(A.left, B.left) and recur(A.right, B.right)
```

**复杂度**：时间O(n*m)，空间O(h)，h为树A的深度

### 2.7 BM21 二叉树中和为某一值的路径
**问题**：找到从根到叶子的路径，和为目标值

**思路**：DFS前序遍历
- 从根节点开始，记录当前路径和
- 到达叶子节点时，判断路径和是否等于目标值

**代码**：
```python
def path_sum(root, target):
    result = []

    def dfs(node, current_sum, path):
        if not node:
            return
        current_sum += node.val
        path.append(node.val)
        if not node.left and not node.right:
            if current_sum == target:
                result.append(path[:])
        else:
            dfs(node.left, current_sum, path)
            dfs(node.right, current_sum, path)
        path.pop()

    dfs(root, 0, [])
    return result
```

**复杂度**：时间O(n)，空间O(h)

### 2.8 BM22 二叉树深度
**问题**：求二叉树最大深度

**思路**：递归（后序遍历）
- 树的高度 = max(左子树高度, 右子树高度) + 1

**代码**：
```python
def max_depth(root):
    if not root:
        return 0
    return max(max_depth(root.left), max_depth(root.right)) + 1  # 树高=max(左子树,右子树)+1
```

**复杂度**：时间O(n)，空间O(h)

### 2.9 BM23 对称二叉树
**问题**：判断二叉树是否对称

**思路**：递归比较左右子树是否为镜像
- 两棵树互为镜像的条件：
  1. 根节点值相同
  2. 左子树的左子树 与 右子树的右子树 互为镜像
  3. 左子树的右子树 与 右子树的左子树 互为镜像

**代码**：
```python
def is_symmetric(root):
    def check(p, q):
        if not p and not q:
            return True
        if not p or not q:
            return False
        return p.val == q.val and check(p.left, q.right) and check(p.right, q.left)  # 递归检查镜像关系
    return check(root, root)
```

**复杂度**：时间O(n)，空间O(h)

### 2.11 BM25 二叉搜索树第k小的节点
**问题**：BST第k小的节点

**思路**：中序遍历得到有序序列
- BST的中序遍历结果是有序序列
- 迭代中序遍历，第k次访问即为第k小的节点

**代码**：
```python
def kth_node(root, k):
    stack = []
    curr = root
    while curr or stack:
        while curr:
            stack.append(curr)
            curr = curr.left
        curr = stack.pop()
        k -= 1
        if k == 0:
            return curr.val
        curr = curr.right
```

**复杂度**：时间O(n)，空间O(h)

### 2.12 BM26 平衡二叉树
**问题**：判断是否为平衡二叉树

**思路**：后序遍历计算高度
- 自底向上计算每个节点的高度
- 如果左右子树高度差大于1，则不平衡
- 使用-1标记不平衡的子树，提前终止

**代码**：
```python
def is_balanced(root):
    def check(node):
        if not node:
            return 0
        left = check(node.left)
        if left == -1:
            return -1
        right = check(node.right)
        if right == -1 or abs(left - right) > 1:
            return -1
        return max(left, right) + 1
    return check(root) != -1
```

**复杂度**：时间O(n)，空间O(h)

### 2.13 BM27 二叉树完全性检验
**问题**：判断是否为完全二叉树

**思路**：层序遍历
- 使用队列进行层序遍历
- 遇见空节点后不应再出现非空节点

**代码**：
```python
from collections import deque

def is_complete_tree(root):
    if not root:
        return True
    queue = deque([root])
    found_empty = False
    while queue:
        node = queue.popleft()
        if not node:
            found_empty = True
        else:
            if found_empty:  # 空节点后又出现非空节点
                return False
            queue.append(node.left)
            queue.append(node.right)
    return True
```

**复杂度**：时间O(n)，空间O(w)

### 2.14 BM28 二叉树最大路径和
**问题**：找最大路径和（任意节点到任意节点）

**思路**：后序遍历，计算经过当前节点的最大路径
- 每个节点计算以该节点为根的子树中的最大路径贡献
- 最大路径 = max(左贡献, 0) + max(右贡献, 0) + 节点值

**代码**：
```python
def max_path_sum(root):
    self.max_sum = float('-inf')

    def dfs(node):
        if not node:
            return 0
        left = max(dfs(node.left), 0)  # 左子树最大贡献
        right = max(dfs(node.right), 0)  # 右子树最大贡献
        self.max_sum = max(self.max_sum, left + right + node.val)
        return max(left, right) + node.val

    dfs(root)
    return self.max_sum
```

**复杂度**：时间O(n)，空间O(h)

### 2.18 BM32 按之字形顺序打印二叉树

**思路**：层序遍历 + 奇偶层判断
- 使用队列进行层序遍历
- 奇数层从左到右，偶数层从右到左
- 可用双端队列或单端队列+反转

**代码**：
```python
from collections import deque

def zigzag_level_order(root):
    if not root:
        return []
    result = []
    queue = deque([root])
    left_to_right = True
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        if not left_to_right:
            level = level[::-1]
        result.append(level)
        left_to_right = not left_to_right
    return result
```

### 3.1 BM119 全排列
**问题**：返回数组的所有排列

**思路**：回溯法（深度优先搜索）
- 选择 + 递归 + 回溯的标准模式
- used数组标记已使用的元素

**代码**：
```python
def permute(nums):
    n = len(nums)
    result = []
    used = [False] * n
    path = []

    def backtrack():
        if len(path) == n:
            result.append(path[:])
            return
        for i in range(n):
            if not used[i]:
                used[i] = True
                path.append(nums[i])
                backtrack()
                path.pop()
                used[i] = False

    backtrack()
    return result
```

**复杂度**：时间O(n!)，空间O(n)

### 3.2 BM120 全排列II
**问题**：有重复元素的全排列

**思路**：排序 + 去重 + 回溯
- 先对数组排序，使相同元素相邻
- 去重关键：跳过相同元素的重复选择
- 通过used[i-1]判断相同元素的前一个是否被使用来去重

**代码**：
```python
def permute_unique(nums):

    result = []

    path = []

    def backtrack():
        if len(path) == n:
            result.append(path[:])
            return
        for i in range(n):
            if used[i]:
                continue
            if i > 0 and nums[i] == nums[i-1] and not used[i-1]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack()
            path.pop()
            used[i] = False

    backtrack()
    return result
```

**复杂度**：时间O(n!)，空间O(n)

### 3.3 BM121 组合总和
**问题**：找出所有和为目标值的组合

**思路**：回溯法
- 每个元素可以重复使用，所以递归时从当前位置继续
- 当remaining为0时找到有效组合
- 当remaining为负时提前终止

**代码**：
```python
def combination_sum(candidates, target):
    result = []

    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(path[:])
            return
        if remaining < 0:
            return
        for i in range(start, len(candidates)):
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])
            path.pop()

    backtrack(0, [], target)
    return result
```

**复杂度**：时间O(n^t)，空间O(t)，t为目标值

- 右括号数量不能超过左括号（保持有效性）
- 当字符串长度为2n时找到一个有效组合

**代码**：
```python
def generate_parentheses(n):
    result = []

    def backtrack(s, left, right):
        if len(s) == 2 * n:
            result.append(s)
            return
        if left < n:
            backtrack(s + '(', left + 1, right)

    return result
```

### 3.6 BM124 岛屿数量
**问题**：计算岛屿数量

**思路**：DFS或BFS遍历
- 遍历所有格子，遇到岛屿（'1'）时进行DFS/BFS将其所有相连的陆地标记为已访问
- 每找到一片新的岛屿，计数加一

**代码**：
```python
def num_islands(grid):
    if not grid:
        return 0
    count = 0
    m, n = len(grid), len(grid[0])

    def dfs(i, j):
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == '0':
            return
        grid[i][j] = '0'
        dfs(i + 1, j)
        dfs(i - 1, j)
        dfs(i, j + 1)
        dfs(i, j - 1)

    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                count += 1
                dfs(i, j)
    return count
```

### 3.7 BM125 矩阵最长递增路径
**问题**：矩阵中最长递增路径长度

**思路**：DFS + 记忆化
- 从每个格子出发进行DFS，遇到递增路径时继续扩展
- 使用记忆化避免重复计算

**代码**：
```python
def longest_increasing_path(matrix):
    if not matrix:
        return 0
    m, n = len(matrix), len(matrix[0])
    memo = [[0] * n for _ in range(m)]

    def dfs(i, j):
        if memo[i][j]:
            return memo[i][j]
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        max_len = 1
        for di, dj in directions:
            ni, nj = i + di, j + dj
            if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
                max_len = max(max_len, dfs(ni, nj) + 1)
        memo[i][j] = max_len
        return max_len

    return max(dfs(i, j) for i in range(m) for j in range(n))
```

**复杂度**：时间O(m*n)，空间O(m*n)

### 4.9 BM46 最长公共子序列

```python
        dp[i][0] = i

        dp[0][j] = j

    for i in range(1, m + 1):

                dp[i][j] = dp[i-1][j-1]
```

- DP：dp[i]表示以nums[i]结尾的最长递增子序列长度
- 二分优化：维护一个tails数组，tails[i]表示长度为i+1的递增子序列的最小结尾值

**代码**：
```python
def length_of_lis(nums):
    if not nums:
        return 0
    dp = [1] * len(nums)
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

import bisect

def length_of_lis_binary(nums):
    tails = []
    for num in nums:
        pos = bisect.bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    return len(tails)
```

**代码**：
```python
class MyQueue:
    def __init__(self):
        self.stack_in = []
        self.stack_out = []

    def push(self, x):
        self.stack_in.append(x)

    def pop(self):
        self._transfer()
        return self.stack_out.pop() if self.stack_out else None

    def peek(self):
        self._transfer()
        return self.stack_out[-1] if self.stack_out else None

    def empty(self):
        return not self.stack_in and not self.stack_out

    def _transfer(self):
        if not self.stack_out:
            while self.stack_in:
                self.stack_out.append(self.stack_in.pop())
```

### 5.7 BM55 滑动窗口的最大值

- 移除超出窗口范围的元素

**代码**：
```python
from collections import deque

def max_sliding_window(nums, k):
    if not nums or k == 0:
        return []
    result = []
    queue = deque()

    for i in range(len(nums)):
        while queue and nums[queue[-1]] <= nums[i]:
            queue.pop()  # 移除比当前元素小的元素
        queue.append(i)

        if queue[0] <= i - k:  # 移除超出窗口的元素
            queue.popleft()

        if i >= k - 1:
            result.append(nums[queue[0]])
    return result
```

```python
        return []
```

```python
    window = {}

        need[c] = need.get(c, 0) + 1

    left = right = 0
    match = 0

        c = s[right]
        if c in need:
            window[c] = window.get(c, 0) + 1
            if window[c] == need[c]:
                match += 1
        right += 1

            if match == len(need):
                result.append(left)

                    match -= 1
                window[c] -= 1
            left += 1
```

```python
def three_sum(nums):

    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i-1]:
            continue
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total == 0:
                result.append([nums[i], nums[left], nums[right]])

                right -= 1
                while left < right and nums[left] == nums[left-1]:
                    left += 1
```

- 每次移动较小那边的指针，计算能接的雨水量

```python
def trap(height):
    if not height:
        return 0
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    result = 0

    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                result += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                result += right_max - height[right]
            right -= 1
    return result
```

```python
def longest_palindrome(s):
    if not s:
        return ""
    start, end = 0, 0

    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return left + 1, right - 1

    for i in range(len(s)):
        left1, right1 = expand(i, i)
        left2, right2 = expand(i, i + 1)
        if right1 - left1 > end - start:
            start, end = left1, right1
        if right2 - left2 > end - start:
            start, end = left2, right2
```

### 8.1 BM73 数组中的逆序对
**问题**：数组中的逆序对数量

**思路**：归并排序中统计
- 在归并排序的合并过程中统计逆序对
- 左半部分元素大于右半部分元素时构成逆序对

**代码**：

```python
def inverse_pairs(nums):
    if not nums:
        return 0
    self.count = 0
    self.merge_sort(nums, 0, len(nums) - 1)
    return self.count

def merge_sort(self, nums, left, right):
    if left >= right:
        return
    mid = (left + right) // 2
    self.merge_sort(nums, left, mid)
    self.merge_sort(nums, mid + 1, right)
    self.merge(nums, left, mid, right)

def merge(self, nums, left, mid, right):
    temp = []
    i, j = left, mid + 1
    while i <= mid and j <= right:
        if nums[i] <= nums[j]:
            temp.append(nums[i])
            i += 1
        else:
            self.count += (mid - i + 1)  # 统计逆序对
            temp.append(nums[j])
            j += 1
    while i <= mid:
        temp.append(nums[i])
        i += 1
    while j <= right:
        temp.append(nums[j])
        j += 1
    for i in range(len(temp)):
        nums[left + i] = temp[i]
```

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:

        elif arr[mid] < target:
```

### 12.1 BM91 N皇后问题
**问题**：在N×N棋盘上放置N个皇后，互相不攻击

**思路**：回溯 + 位置有效性判断
- 按行放置，每行选择一个位置
- 判断该位置是否与已放置的皇后冲突
- 冲突条件：同列、同主对角线、同副对角线

**代码**：
```python
def solve_n_queens(n):
    result = []

    def backtrack(row, path):
        if row == n:
            result.append(path[:])
            return
        for col in range(n):
            if is_valid(row, col, path):
                path.append(col)
                backtrack(row + 1, path)
                path.pop()

    def is_valid(row, col, path):
        for r, c in enumerate(path):
            if c == col or abs(r - row) == abs(c - col):
                return False
        return True

    backtrack(0, [])
    return result
```

**复杂度**：时间O(N!)，空间O(N)

### 12.2 BM92 矩阵最长递增路径
**问题**：矩阵中最长递增路径长度

**思路**：DFS + 记忆化
- 从每个格子出发DFS
- 使用记忆化避免重复计算

**代码**：
```python
def longest_increasing_path(matrix):
    if not matrix:
        return 0
    m, n = len(matrix), len(matrix[0])
    memo = [[0] * n for _ in range(m)]

    def dfs(i, j):
        if memo[i][j]:
            return memo[i][j]
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        max_len = 1
        for di, dj in directions:
            ni, nj = i + di, j + dj
            if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
                max_len = max(max_len, dfs(ni, nj) + 1)
        memo[i][j] = max_len
        return max_len

    return max(dfs(i, j) for i in range(m) for j in range(n))
```

**复杂度**：时间O(m*n)，空间O(m*n)

### 13.2 BM94 数据流中的中位数

**思路**：大顶堆 + 小顶堆
- 大顶堆存较小的一半，小顶堆存较大的一半
- 保持两个堆大小平衡，中位数在堆顶

**代码**：
```python
import heapq

class MedianFinder:
    def __init__(self):
        self.small = []
        self.large = []

    def add_num(self, num):
        heapq.heappush(self.small, -num)
        heapq.heappush(self.large, -heapq.heappop(self.small))
        if len(self.small) < len(self.large):
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def find_median(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
```

### 15.2 BM99 最小覆盖子串
**问题**：找到包含目标所有字符的最小子串

**思路**：滑动窗口 + 哈希表计数
- 扩大右边界，直到窗口包含所有目标字符
- 收缩左边界，尝试优化结果

**代码**：
```python
def min_window(s, t):
    if not s or not t:
        return ""
    from collections import Counter
    need = Counter(t)
    window = {}
    left, right = 0, 0
    valid = 0
    min_len = float('inf')
    min_start = 0

    while right < len(s):
        c = s[right]
        right += 1
        if c in need:
            window[c] = window.get(c, 0) + 1
            if window[c] == need[c]:
                valid += 1

        while valid == len(need):
            if right - left < min_len:
                min_len = right - left
                min_start = left
            d = s[left]
            left += 1
            if d in need:
                if window[d] == need[d]:
                    valid -= 1
                window[d] -= 1
    return s[min_start:min_start + min_len] if min_len != float('inf') else ""
```

**复杂度**：时间O(n)，空间O(1)

**思路**：贪心 + 两遍遍历
- 从左到右遍历，满足右边比左边大
- 从右到左遍历，满足左边比右边大
- 取两遍遍历的最大值

**代码**：
```python
def candy(ratings):
    if not ratings:
        return 0
    n = len(ratings)
    candies = [1] * n

    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1

    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)

    return sum(candies)
```

**复杂度**：时间O(n)，空间O(n)

- 堆顶即为最早结束的活动

**代码**：
```python
import heapq

def min_主持人(nums):
    if not nums:
        return 0
    nums.sort()
    heap = [nums[0][1]]
    count = 1
    for i in range(1, len(nums)):
        if nums[i][0] >= heap[0]:
            heapq.heapreplace(heap, nums[i][1])
        else:
            heapq.heappush(heap, nums[i][1])
            count += 1
    return count
```

### 16.4 BM105 螺旋矩阵
**问题**：按顺时针螺旋顺序输出矩阵元素

**思路**：模拟
- 按层遍历，每层四条边
- 收缩边界

**代码**：
```python
def spiral_order(matrix):
    if not matrix:
        return []
    result = []
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for j in range(left, right + 1):
            result.append(matrix[top][j])
        top += 1
        for i in range(top, bottom + 1):
            result.append(matrix[i][right])
        right -= 1
        if top <= bottom:
            for j in range(right, left - 1, -1):
                result.append(matrix[bottom][j])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1
    return result
```

**复杂度**：时间O(m*n)，空间O(1)

### 17.1 BM107 最长公共子串
**问题**：两个字符串的最长公共子串

**思路**：二维DP
- dp[i][j]表示以str1[i]和str2[j]结尾的最长公共子串
- 如果str1[i]==str2[j]，dp[i][j]=dp[i-1][j-1]+1

**代码**：
```python
def longest_common_substring(str1, str2):
    m, n = len(str1), len(str2)
    dp = [[0] * (n + 1) for _ in range(2)]
    max_len = 0
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if str1[i-1] == str2[j-1]:
                dp[i % 2][j] = dp[(i-1) % 2][j-1] + 1
                max_len = max(max_len, dp[i % 2][j])
            else:
                dp[i % 2][j] = 0
    return max_len
```

**复杂度**：时间O(m*n)，空间O(min(m,n))

### 17.2 BM108 把数字翻译成字符串
**问题**：数字转化为字母的方案数

**思路**：DP
- dp[i]表示以第i位结尾的方案数
- 转移方程：dp[i] = dp[i-1] + dp[i-2]（当i-1和i位组成的数在10-26之间）

**代码**：
```python
def solve(num):
    s = str(num)
    if not s:
        return 0
    n = len(s)
    dp = [0] * (n + 1)
    dp[0] = 1
    dp[1] = 1 if s[0] != '0' else 0
    for i in range(2, n + 1):
        if s[i-1] != '0':
            dp[i] += dp[i-1]
        if s[i-2:i] >= '10' and s[i-2:i] <= '26':
            dp[i] += dp[i-2]
    return dp[n]
```

**复杂度**：时间O(n)，空间O(1)

```python
def rob(nums):
```

```python
def max_profit(prices):
    if not prices:
        return 0
    buy1 = sell1 = -prices[0]
    buy2 = sell2 = -prices[0]
    for price in prices[1:]:
        buy1 = max(buy1, -price)

    return sell2
```

### 17.8 BM114 数字字符串转化成IP地址
**问题**：将数字字符串所有可能的IP地址

**思路**：回溯
- 每段1-3位，不能有前导0（除0本身）
- 每段值在0-255之间

**代码**：
```python
def restore_ip_addresses(s):
    result = []

    def backtrack(start, path):
        if len(path) == 4 and start == len(s):
            result.append('.'.join(path))
            return
        if len(path) == 4:
            return
        for length in range(1, 4):
            if start + length > len(s):
                return
            segment = s[start:start+length]
            if (len(segment) > 1 and segment[0] == '0') or int(segment) > 255:
                continue
            path.append(segment)
            backtrack(start + length, path)
            path.pop()

    backtrack(0, [])
    return result
```

**复杂度**：时间O(1)，空间O(1)

### 17.9 BM115 正则表达式匹配
**问题**：实现正则表达式匹配（. 和 *）

**思路**：DP
- dp[i][j]表示s[:i]与p[:j]的匹配结果
- 转移方程考虑*的两种情况

**代码**：
```python
def is_match(s, p):
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True
    for j in range(2, n + 1):
        if p[j-1] == '*':
            dp[0][j] = dp[0][j-2]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j-1] == '*':
                dp[i][j] = dp[i][j-2]
                if p[j-2] in ('.', s[i-1]):
                    dp[i][j] |= dp[i-1][j]
            elif p[j-1] in ('.', s[i-1]):
                dp[i][j] = dp[i-1][j-1]
    return dp[m][n]
```

**复杂度**：时间O(m*n)，空间O(m*n)

### 18.1 BM116 设计LRU缓存结构
**问题**：实现最近最少使用缓存

**思路**：哈希表 + 双向链表
- 哈希表：O(1)查找
- 双向链表：维护访问顺序

**代码**：
```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```

**复杂度**：时间O(1)，空间O(capacity)

### 18.2 BM117 设计LFU缓存结构
**问题**：实现最不经常使用缓存

**思路**：哈希表 + 双向链表
- 多个频率链表，每个频率维护访问顺序
- 哈希表：key到节点的映射

**代码**：
```python
class LFUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.min_freq = 0
        self.cache = {}
        self.freq_map = {}

    def get(self, key):
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._update(node)
        return node.value

    def put(self, key, value):
        if self.capacity == 0:
            return
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._update(node)
        else:
            if len(self.cache) >= self.capacity:
                self._remove_min_freq()
            node = Node(key, value, 1)
            self.cache[key] = node
            self._add_to_freq(node)
            self.min_freq = 1

    def _update(self, node):
        old_freq = node.freq
        self.freq_map[old_freq].remove(node)
        if not self.freq_map[old_freq]:
            del self.freq_map[old_freq]
            if self.min_freq == old_freq:
                self.min_freq += 1
        node.freq += 1
        self._add_to_freq(node)

    def _remove_min_freq(self):
        node = self.freq_map[self.min_freq].pop()
        del self.cache[node.key]

    def _add_to_freq(self, node):
        if node.freq not in self.freq_map:
            self.freq_map[node.freq] = LinkedList()
        self.freq_map[node.freq].add(node)
```

**复杂度**：时间O(1)，空间O(capacity)
