# 高性能

## 性能指标

- **QPS**（Queries Per Second）：每秒查询数
- **TPS**（Transactions Per Second）：每秒事务数
- **RT**（Response Time）：响应时间，P50/P95/P99
- **吞吐量**：单位时间处理的数据量
- **并发数**：系统同时处理的请求数

关系：`QPS = 并发数 / 平均RT`

## 高性能读

### 读写分离

```
写请求 → 主库
读请求 → 从库1 / 从库2 / 从库3
主库 → binlog → 从库
```

- 延迟问题：半同步复制 / 并行复制
- 路由：中间件（MyCat/ShardingSphere）/ 代码层

### 缓存

- 本地缓存（进程内）+ 分布式缓存（Redis）
- 多级缓存减少回源
- 详见 [缓存.md](./缓存.md)

### CQRS

命令查询职责分离：

```
写操作 → 写模型（关系DB）→ 事件 → 读模型（ES/Redis）
读操作 → 读模型
```

- 读写模型独立扩展
- 最终一致性
- 适用：读远大于写、复杂查询场景

### 预计算

- 定时任务预生成页面/数据
- 列表页、排行榜等高并发读场景
- 数据变更时触发异步更新

## 高性能写

### 异步化

```
同步：请求 → 处理 → 返回（阻塞等待）
异步：请求 → 消息队列 → 返回 → 异步处理
```

- 消息队列削峰填谷
- 适用于非实时性要求场景

### 批量与合并

```python
def batch_insert(items):
    db.execute(insert_query, items)

def batch_write():
    buffer = []
    for item in stream:
        buffer.append(item)
        if len(buffer) >= 1000:
            db.batch_insert(buffer)
            buffer.clear()
```

### 分库分表

- **水平分表**：按分表键（用户ID）哈希/范围分片
- **垂直分库**：按业务拆分数据库
- 中间件：ShardingSphere / Vitess

### 写聚合

- 多次写合并为一次写
- 计数器：Redis INCR → 定期落DB
- 点赞数：内存聚合 → 批量持久化

## 数据库优化

### 索引优化

- 覆盖索引：查询字段全在索引中，无需回表
- 联合索引：最左前缀原则
- 索引下推（ICP）：在存储引擎层过滤
- 避免索引失效：函数、隐式转换、OR、LIKE 前缀%

### 查询优化

- 避免SELECT *，只查需要的字段
- 分页优化：游标分页替代 OFFSET
- 子查询改JOIN
- 大事务拆小事务

```sql
SELECT * FROM orders WHERE id > 10000 LIMIT 20;
```

### 连接池

- 预创建连接，避免频繁建连
- HikariCP（Java）/ SQLAlchemy pool（Python）
- 合理配置：max_size、min_idle、timeout

## 接口优化

### 串行改并行

```python
import asyncio

async def get_user_detail(user_id):
    user, orders, profile = await asyncio.gather(
        get_user(user_id),
        get_orders(user_id),
        get_profile(user_id),
    )
    return {**user, "orders": orders, "profile": profile}
```

### 池化

- 连接池：数据库、Redis、HTTP
- 线程池/协程池：控制并发度
- 对象池：减少GC压力

### 数据压缩

- HTTP gzip/brotli
- Protobuf 替代 JSON（更小更快）
- Redis msgpack 替代 JSON

## 网络优化

- **长连接**：减少TCP握手开销
- **连接复用**：HTTP Keep-Alive / HTTP/2 多路复用
- **CDN**：静态资源就近访问
- **DNS 优化**：预解析、缓存、HttpDNS

## 性能调优流程

```
1. 建立基准 → 2. 压测定位瓶颈 → 3. 分析优化 → 4. 验证效果 → 5. 循环
```

### 压测工具

- wrk / ab / hey：HTTP 压测
- JMeter / Locust：场景压测
- sysbench：数据库压测

### 火焰图

- CPU 火焰图：分析函数耗时
- 内存火焰图：分析内存分配
- 工具：perf / py-spy / Go pprof
