# 高可用

## 衡量高可用

- 可用性 = （总时间 - 停机时间）/ 总时间 * 100%
- MTTR (Mean Time To Repair) 平均修复时间
- MTBF (Mean Time Between Failures) 平均故障间隔时间

| 可用性 | 年停机时间 | 等级 |
|--------|-----------|------|
| 99% | 3.65天 | 2个9 |
| 99.9% | 8.76小时 | 3个9 |
| 99.99% | 52.6分钟 | 4个9 |
| 99.999% | 5.26分钟 | 5个9 |

## 重试

### 重试策略

- **指数退避**：1s → 2s → 4s → 8s → ...
- **抖动（Jitter）**：退避时间加随机值，避免惊群
- **最大重试次数**：防止无限重试
- **幂等性**：重试必须保证操作幂等

```python
import time, random

def retry_with_backoff(func, max_retries=3, base_delay=1):
    for attempt in range(max_retries + 1):
        try:
            return func()
        except Exception as e:
            if attempt == max_retries:
                raise
            delay = base_delay * (2 ** attempt) + random.uniform(0, 1)
            time.sleep(delay)
```

## 熔断

### 状态机

```
Closed → Open → Half-Open → Closed/Open
```

- **Closed**：正常状态，请求通过，统计失败率
- **Open**：熔断状态，请求直接拒绝/走降级逻辑
- **Half-Open**：半开状态，放行少量请求探测，成功则恢复

### 配置参数

- 错误率阈值（如 50%）
- 时间窗口（如 10秒内）
- 最小请求数（如 20次）
- 熔断持续时间（如 30秒）
- 半开探测数（如 5次）

## 隔离

### 线程池隔离

- 每个依赖分配独立线程池
- 一个依赖耗尽不影响其他
- 缺点：线程切换开销

### 信号量隔离

- 计数器控制并发数
- 无线程切换开销
- 适用于本地调用

### 舱壁模式

- 按业务/租户/区域物理隔离
- 故障不扩散，爆炸半径可控

## 降级

### 降级策略

| 策略 | 说明 | 场景 |
|------|------|------|
| 返回默认值 | 返回预设值 | 推荐系统不可用 |
| 返回缓存数据 | 返回上次缓存 | 实时数据不可用 |
| 简化逻辑 | 跳过非核心步骤 | 下单跳过推荐 |
| 关闭功能 | 前端隐藏入口 | 非核心功能 |
| 限流排队 | 排队等待 | 流量突增 |

### 降级开关

- 配置中心控制降级开关
- 分级降级：P0 → P1 → P2
- 自动降级 + 手动降级

## 超时控制

### 超时分类

- **连接超时**：建立连接的超时时间
- **读超时**：等待响应数据的超时时间
- **写超时**：发送数据的超时时间
- **总超时**：整个请求的超时时间

### 超时设置原则

- 上游超时 > 下游超时之和（留余量）
- 设置合理的重试次数
- 超时传播：请求超时随调用链传递

## 限流

### 算法

| 算法 | 特点 | 问题 |
|------|------|------|
| 固定窗口 | 简单 | 窗口边界突发 |
| 滑动窗口 | 平滑 | 实现复杂 |
| 漏桶 | 匀速处理 | 无法应对突发 |
| 令牌桶 | 允许突发 | 实现稍复杂 |

### 分布式限流

- Redis + Lua 脚本实现滑动窗口
- 网关层限流（Nginx / APISIX）
- 自适应限流：根据系统负载动态调整

## 容灾

### 同城双活

- 同城两个机房同时提供服务
- 数据同步延迟低（< 1ms）
- 一个机房故障，DNS 切换

### 异地多活

- 多个城市部署，每个城市可独立提供服务
- 数据同步：同步复制 / 异步复制
- 两地三中心：同域双活 + 异域冷备

### 故障转移

- 主从切换：Keepalived / Redis Sentinel
- 自动摘除故障节点
- 健康检查：主动探测 + 被动探测

## SLA/SLO/SLI

- **SLA**（Service Level Agreement）：服务等级协议，对外承诺
- **SLO**（Service Level Objective）：服务等级目标，内部目标
- **SLI**（Service Level Indicator）：服务等级指标，量化度量

示例：
- SLA：99.9% 可用性
- SLO：P99 延迟 < 200ms
- SLI：实际 P99 延迟 = 150ms
