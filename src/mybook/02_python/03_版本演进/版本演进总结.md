# Python 版本演进总结

## Python 3.6 (2016-12)

### f-string 格式化

```python
name = "Alice"
age = 30
print(f"{name} is {age} years old")
print(f"{'hello':>10}")
print(f"{3.14159:.2f}")
print(f"{2**10 = }")
```

### 类型注解

```python
from typing import List, Dict, Optional

def greet(name: str) -> str:
    return f"Hello, {name}"

def process(items: List[int]) -> Dict[str, int]:
    return {str(i): i for i in items}

def find_user(uid: int) -> Optional[dict]:
    if uid > 0:
        return {"id": uid}
    return None
```

### 异步生成器与推导式

```python
async def agen():
    for i in range(5):
        await asyncio.sleep(0.1)
        yield i

result = [i async for i in agen()]
```

### 其他特性

- 变量注解语法：`x: int = 5`
- `secrets` 模块：安全随机数
- `dict` 保持插入顺序（CPython 实现细节）
- `os.path` 新增 `Path` 类似功能

## Python 3.7 (2018-06)

### dataclasses

```python
from dataclasses import dataclass, field

@dataclass
class Point:
    x: float
    y: float
    z: float = 0.0

    def distance(self) -> float:
        return (self.x**2 + self.y**2 + self.z**2) ** 0.5

@dataclass
class Config:
    host: str = "localhost"
    port: int = 8080
    tags: list = field(default_factory=list)

p = Point(3, 4)
print(p)
print(p.distance())
```

### `__future__` 注解

```python
from __future__ import annotations

class Node:
    def __init__(self, value: int, next: Node | None = None):
        self.value = value
        self.next = next
```

### 其他特性

- `breakpoint()` 内置调试函数
- `dict` 保证插入顺序（语言规范）
- `asyncio.run()` 简化异步入口

## Python 3.10 (2021-10)

### 模式匹配 (match-case)

```python
def handle_command(cmd):
    match cmd.split():
        case ["quit"]:
            return "Goodbye"
        case ["go", direction]:
            return f"Going {direction}"
        case ["pick", "up", item]:
            return f"Picked up {item}"
        case ["look"]:
            return "Looking around"
        case _:
            return "Unknown command"

def classify(point):
    match point:
        case (0, 0):
            return "Origin"
        case (0, y):
            return f"Y-axis at {y}"
        case (x, 0):
            return f"X-axis at {x}"
        case (x, y) if x == y:
            return f"Diagonal at {x}"
        case (x, y):
            return f"Point at ({x}, {y})"
```

### 联合类型语法


### 其他特性

- `zip(strict=True)` 严格模式

## Python 3.11 (2022-10)

### 异常组与 except*

```python
def validate(data):
    errors = []
    if not data.get("name"):
        errors.append(ValueError("name required"))
    if not data.get("email"):
        errors.append(ValueError("email required"))
    if not data.get("age"):
        errors.append(TypeError("age required"))
    if errors:
        raise ExceptionGroup("validation", errors)

try:
    validate({})
except* ValueError as eg:
    print(f"ValueErrors: {eg.exceptions}")
except* TypeError as eg:
    print(f"TypeErrors: {eg.exceptions}")
```

### Self 类型

```python
from typing import Self

class Builder:
    def set_name(self, name: str) -> Self:
        self.name = name
        return self

    def set_age(self, age: int) -> Self:
        self.age = age
        return self
```

### 性能提升

- CPython 3.11 比 3.10 快 10-60%（平均 25%）
- 专门化自适应解释器（PEP 659）
- 零开销异常处理

### 其他特性

- `tomllib` 内置 TOML 解析
- `TaskGroup` 异步任务组
- 更详细的错误回溯

## Python 3.12 (2023-10)

```python
from typing import Sized

def first[T](items: list[T]) -> T:
    return items[0]

def filter[T](items: list[T], pred: callable) -> list[T]:
    return [x for x in items if pred(x)]

class Stack[T]:
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()

type Vector = list[float]
type Matrix = list[Vector]
```

## 迁移建议

### 最低版本选择

| 目标场景 | 推荐最低版本 | 原因 |
|----------|-------------|------|
| 新项目 | 3.11+ | 性能提升 + 现代语法 |
| 库开发 | 3.9+ | 内置泛型广泛支持 |
| 长期维护 | 3.10+ | match-case + 联合类型 |
| 实验项目 | 3.13+ | 自由线程 + JIT |

```bash
pyupgrade --py311-plus my_module.py

pip install ruff
ruff check --target-version py311 my_module.py
```
