# 日志库

Python 第三方日志库汇总。

## Loguru

最流行的替代 logging 的库，开箱即用。

```python
from loguru import logger

logger.add("app.log", rotation="10 MB", retention="7 days")
logger.info("应用启动")
logger.error("发生错误: {}", error_msg)

@logger.catch
def risky_function():
    raise ValueError("oops")
```

### 核心特性

- 无需配置即可使用
- 自动彩色输出
- 支持文件轮转（按大小/时间）
- 异常自动捕获（`@logger.catch`）
- 结构化日志（`logger.bind(user="alice")`）

## Structlog

结构化日志，适合 JSON 输出。

```python
import structlog

structlog.configure(
    processors=[structlog.processors.JSONRenderer()]
)
log = structlog.get_logger()
log.info("user_login", user_id=123, ip="1.2.3.4")
```

## 标准库 logging

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    handlers=[logging.FileHandler("app.log"), logging.StreamHandler()]
)
logger = logging.getLogger(__name__)
```

## 选型

| 库 | 适用场景 |
|----|----------|
| Loguru | 中小项目，快速开发 |
| Structlog | 微服务，需要 JSON 日志 |
| logging | 标准库，无需额外依赖 |
