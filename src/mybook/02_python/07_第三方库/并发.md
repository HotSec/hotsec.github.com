# Python 并发库

Python 协程与并发编程的第三方库汇总。

## Greenlet

轻量级协程库，提供显式的上下文切换。

```python
from greenlet import greenlet

def task1():
    print("task1 start")
    g2.switch()
    print("task1 end")

def task2():
    print("task2 start")
    g1.switch()
    print("task2 end")

g1 = greenlet(task1)
g2 = greenlet(task2)
g1.switch()
```

## Eventlet

基于 greenlet 的并发网络库，内置事件循环。

```python
import eventlet
from eventlet.green import urllib2

urls = ["http://example.com"] * 10
pool = eventlet.GreenPool()

def fetch(url):
    return urllib2.urlopen(url).read()

results = pool.imap(fetch, urls)
```

## Gevent

最流行的 Python 协程并发框架。

```python
import gevent
from gevent import monkey
monkey.patch_all()  # 必须在其他导入之前

import requests

def fetch(url):
    print(f"Fetching {url}")
    return requests.get(url).status_code

urls = ["https://httpbin.org/delay/1"] * 5
jobs = [gevent.spawn(fetch, url) for url in urls]
gevent.joinall(jobs)
```

### 核心特性

- 基于 libev/libuv 的事件循环
- 基于 greenlet 的轻量级执行单元
- `monkey.patch_all()` 使标准库协程化
- 协程化的 socket / ssl / dns / time
- 内置 WSGI 服务器
- 支持 Queue / Event / Semaphore 等同步原语

### 猴子补丁原理

```python
# monkey.patch_all() 替换标准库为协程版本
import socket
from gevent import socket as gevent_socket
socket.socket = gevent_socket.socket  # 类似操作
```

## 对比

| 特性 | Gevent | Eventlet | Greenlet |
|------|--------|----------|----------|
| 事件循环 | libev/libuv | 内置 | 无 |
| 猴子补丁 | ✅ | ✅ | ❌ |
| WSGI 服务器 | ✅ | ✅ | ❌ |
| 生态 | 丰富 | 中等 | 底层 |
