# Python 微服务架构

## 设计原则

1. **单一职责**：每个服务只负责一个业务领域
2. **服务自治**：服务独立开发、部署、扩展
3. **分布式设计**：服务间通过网络通信，需处理网络不可靠
4. **自动化**：CI/CD 流水线，自动化测试与部署

## 服务发现

| 工具 | 特点 | Python 客户端 |
|------|------|---------------|
| Consul | 健康检查 + KV 存储 | `python-consul` |
| Eureka | Netflix 出品，AP 模型 | `py-eureka-client` |
| etcd | CP 模型，强一致性 | `etcd3` |
| ZooKeeper | CP 模型，成熟稳定 | `kazoo` |

```python
import consul

c = consul.Consul(host="localhost")
c.agent.service.register(
    name="user-service",
    service_id="user-1",
    address="192.168.1.10",
    port=8000,
    check=consul.Check.http("http://192.168.1.10:8000/health", "10s")
)

index, services = c.health.service("user-service", passing=True)
```

## 分布式追踪

Jaeger / OpenTelemetry 实现请求链路追踪。

```python
from opentelemetry import trace
from opentelemetry.exporter.jaeger import JaegerExporter

trace.set_tracer_provider(TracerProvider())
jaeger = JaegerExporter(agent_host_name="localhost", agent_port=6831)
trace.get_tracer_provider().add_span_processor(BatchSpanProcessor(jaeger))

tracer = trace.get_tracer(__name__)
with tracer.start_as_current_span("user-login"):
    # 业务逻辑
    pass
```

## 容错与高可用

### 熔断器

```python
from pybreaker import CircuitBreaker

breaker = CircuitBreaker(fail_max=5, reset_timeout=60)

@breaker
def call_remote_service():
    return requests.get("http://other-service/api")
```

### 重试

```python
from tenacity import retry, stop_after_attempt, wait_exponential

@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=1, max=10))
def call_with_retry():
    return requests.get("http://other-service/api")
```

## CI/CD

```yaml
# .github/workflows/deploy.yml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker build -t user-service .
      - run: docker push registry/user-service:latest
      - run: kubectl rollout restart deployment/user-service
```
