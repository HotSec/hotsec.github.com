# 反爬虫措施

## 常见反爬手段

### User-Agent 检测

检测请求头中的 User-Agent，拒绝非浏览器请求。

```python
from flask import request, abort

@app.before_request
def check_ua():
    ua = request.headers.get("User-Agent", "")
    if "python" in ua.lower() or not ua:
        abort(403)
```

### IP 限制

基于 IP 的访问频率限制。

```python
from collections import defaultdict
import time

class RateLimiter:
    def __init__(self, max_requests=60, window=60):
        self.max_requests = max_requests
        self.window = window
        self.requests = defaultdict(list)

    def is_allowed(self, ip: str) -> bool:
        now = time.time()
        self.requests[ip] = [t for t in self.requests[ip] if now - t < self.window]
        if len(self.requests[ip]) >= self.max_requests:
            return False
        self.requests[ip].append(now)
        return True
```

### Session 访问限制

限制单个会话的访问频率和总量。

### Spider Trap（蜜罐）

在页面中放置隐藏链接（`display:none`），正常用户不会访问，爬虫会抓取。

```html
<a href="/trap" style="display:none">hidden</a>
```

访问该链接的 IP 直接加入黑名单。

### 验证码

| 类型 | 说明 |
|------|------|
| 图形验证码 | 传统方式，OCR 可破解 |
| 滑块验证码 | 拖动滑块，行为检测 |
| 点选验证码 | 点击指定文字/图片 |
| 无感验证 | 基于行为分析，用户无感知 |

### 数据动态加载

- AJAX 异步加载数据
- WebSocket 推送
- 前端渲染（Vue/React），爬虫只能拿到空壳

### 数据加密

- JS 加密：前端对参数加密，后端解密
- 字体文件映射：自定义字体，HTML 中是乱码，渲染后正常显示

```css
@font-face {
    font-family: 'custom';
    src: url('/static/custom.woff');
}
.price { font-family: 'custom'; }
```

### 非可视区域遮挡

将真实数据放在可视区域外，爬虫直接解析 HTML 会拿到错误数据。

## 爬虫对抗手段

| 反爬手段 | 对抗方式 |
|----------|----------|
| UA 检测 | 伪造 UA 头 |
| IP 限制 | 代理 IP 池 |
| 验证码 | 打码平台 / OCR 识别 |
| 动态加载 | Selenium / Playwright 模拟浏览器 |
| JS 加密 | 分析 JS 逻辑，还原加密算法 |
| 字体映射 | OCR 识别渲染结果 |

## robots.txt

遵守 robots.txt 是爬虫的基本礼仪：

```
User-agent: *
Disallow: /admin/
Disallow: /api/
Crawl-delay: 10
```
