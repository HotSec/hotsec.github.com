# 大模型开发流程

---

## 一、整体流程

```
需求分析 → 数据准备 → 模型选型 → Prompt 工程 → 应用开发 → 评估测试 → 部署上线 → 监控迭代
```

## 二、需求分析

### 2.1 任务分类

| 任务类型 | 说明 | 推荐方案 |
|----------|------|----------|
| 文本生成 | 写作、摘要、翻译 | 直接调用 LLM |
| 问答系统 | 知识问答 | RAG |
| 对话系统 | 多轮对话 | LLM + Memory |
| 数据提取 | 信息抽取 | Prompt + JSON 输出 |
| 代码生成 | 编程辅助 | LLM + 工具 |
| Agent | 自主决策 | LLM + Tools |

### 2.2 关键决策

| 决策点 | 选项 | 考量 |
|--------|------|------|
| 自训 vs 调用 | 自训练 / 微调 / API | 成本、数据量、延迟 |
| 开源 vs 闭源 | GPT-4 / Claude / Qwen / DeepSeek | 隐私、成本、能力 |
| 部署方式 | 云 API / 本地 / 私有化 | 数据安全、延迟、成本 |

```python
# 数据清洗
def clean_text(text: str) -> str:
    text = re.sub(r'\s+', ' ', text)        # 合并空白
    text = re.sub(r'[^\S\n]+', ' ', text)   # 合并空格（保留换行）
    text = text.strip()
    return text

# 数据去重
def deduplicate(data: list[str], threshold: float = 0.95) -> list[str]:
    seen = []
    result = []
    for item in data:
        emb = embed(item)
        if all(cosine_similarity(emb, s) < threshold for s in seen):
            seen.append(emb)
            result.append(item)
    return result

# 数据质量过滤
def filter_quality(qa_pairs: list[dict]) -> list[dict]:
    return [
        qa for qa in qa_pairs
        if len(qa["question"]) > 10
        and len(qa["answer"]) > 20
        and qa["answer"] not in qa["question"]
    ]
```

## 六、评估

### 6.1 自动评估

```python
# LLM-as-Judge
JUDGE_PROMPT = """请评估以下回答的质量。

问题：{question}
参考答案：{reference}
待评估回答：{answer}

评分标准（1-5分）：
1. 准确性：回答是否正确
2. 完整性：是否涵盖所有要点
3. 相关性：是否切题

输出JSON：{"accuracy": 1-5, "completeness": 1-5, "relevance": 1-5, "overall": 1-5}"""
```

### 6.2 评估指标

| 指标 | 说明 | 方法 |
|------|------|------|
| 准确率 | 回答是否正确 | 人工/LLM Judge |
| 忠实度 | 是否基于上下文 | RAGAS faithfulness |
| 相关性 | 是否切题 | RAGAS answer_relevancy |
| 延迟 | 响应时间 | P50/P95/P99 |
| 成本 | Token 消耗 | 每次调用费用 |

```python
from fastapi.responses import StreamingResponse

@app.post("/chat/stream")
async def chat_stream(request: ChatRequest):
    async def generate():
        async for chunk in llm.astream(prompt):

        yield "data: [DONE]\n\n"
    return StreamingResponse(generate(), media_type="text/event-stream")
```

## 九、成本优化

| 策略 | 效果 | 实现方式 |
|------|------|----------|
| 缓存 | 减少 30-50% 调用 | Redis 缓存相似问题 |
| 小模型路由 | 降低 60% 成本 | 简单问题用小模型 |
| Prompt 压缩 | 减少 20-30% Token | 去除冗余上下文 |
| 批量处理 | 降低延迟 | 非实时场景批量调用 |
| 流式输出 | 提升体验 | SSE 流式返回 |
