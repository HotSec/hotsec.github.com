
# OpenClaw 源码分析总结

## 1. 整体架构

OpenClaw 是一个高度模块化、本地优先的 AI 助手框架，主要由以下几个层次组成：

```
┌─────────────────────────────────────────┐
│  User Interfaces   │
│  (CLI, UI, Mobile apps │
└─────────────────────────────────────────┘
               ↕
┌─────────────────────────────────────────┐
│  Gateway (HTTP/WebSocket)   │
│  (src/gateway)      │
└─────────────────────────────────────────┘
               ↕
┌─────────────────────────────────────────┐
│  Agent Runtime (src/agents)      │
│  (Sessions, Skills, Tools)   │
└─────────────────────────────────────────┘
               ↕
┌─────────────────────────────────────────┐
│  Channels & Plugins       │
│  (Telegram/Discord/etc │
└─────────────────────────────────────────┘
               ↕
┌─────────────────────────────────────────┐
│  Models & Providers          │
└─────────────────────────────────────────┘
```

## 2. 技术栈

- 语言：TypeScript
- Runtime：Node.js 22.19+ / 24
- Package Manager：pnpm
- Web Server：内置（可能是 polka 或类似轻量框架）
- WebSocket：内置
- Configuration：JSON5
- UI：可能是 Vite-based

## 3. 设计亮点

### 3.1 Local-First 本地优先设计
 - 完全本地运行，默认无数据外发
 - 配置文件本地存储
 - 会话本地持久化
 - 技能本地加载

### 3.2 插件系统
- Plugin-SDK 接口清晰
- Channel 插件机制
- Provider 插件机制
- Skills 技能系统

### 3.3 安全模型
- 配对机制（Pairing），防止滥用
- 沙箱模式运行
- 安全配置

### 3.4 可扩展性
- MCP 协议支持
- 多模型支持
- 多渠道支持

## 6. 学习 OpenClaw 的建议路径

1. 从 README.md 和 onboarding 了解基本功能
2. 从 src/entry.ts 和 openclaw.mjs 了解入口
3. 看 src/cli/ 了解 CLI
4. 看 src/config/ 了解配置
5. 看 src/gateway/ 了解核心服务
6. **深入理解核心智能体** (看 06_ 文件)
7. 看 src/agents/pi-embedded-runner/ 了解运行时
8. 看 src/agents/pi-tools.ts 了解工具系统
9. 看 src/channels/ 了解渠道
10. 看 extensions/ 了解插件

## 7. 总结

OpenClaw 是一个设计非常优秀的本地 AI 助手项目，从架构到细节都有很多值得学习的地方，比如：
- 模块化设计和插件 SDK
- 强大且安全的工具策略系统
- 本地优先理念
- 渠道抽象
- 丰富的功能集（语音/Canvas/skills/子代理/沙箱）
