
# OpenClaw 项目概览

## 1. 简介

**OpenClaw** 是一个开源的个人 AI 助手网关平台，由 Peter Steinberger 和社区共同开发。它允许你在自己的设备上运行一个个人 AI 助手，支持多种消息平台（WhatsApp、Telegram、Discord、Slack 等），并提供强大的工具、技能和可扩展性。

## 2. 核心特点

- **本地优先**: 所有数据和配置存储在本地，确保隐私安全
- **多平台支持**: macOS、iOS、Android 都有配套应用
- **多渠道接入**: 支持 20+ 种消息平台（WhatsApp、Telegram、Discord、Slack 等）
- **技能系统**: 支持加载和管理技能（Skills）扩展功能
- **MCP 协议**: 支持 Model Context Protocol，增强工具调用能力
- **插件架构**: 可通过插件扩展功能
- **语音支持**: 语音唤醒和语音对话（TTS/STT）
- **Canvas 界面**: 可视化 Canvas 支持，展示丰富内容
- **定时任务**: 内置 cron 定时任务系统
- **安全性**: 配对机制和安全策略

## 3. 项目结构

```
openclaw/
├── apps/                 # 移动端/桌面端应用
│   ├── android/         # Android 应用
│   ├── ios/             # iOS 应用
│   ├── macos/           # macOS 应用
│   └── swabble/         # Swabble 应用
├── docs/                # 文档
├── extensions/          # 官方扩展/插件
├── skills/              # 内置技能
├── src/                 # 核心源代码
│   ├── acp/            # Agent Control Protocol
│   ├── agents/         # 智能体核心
│   ├── channels/       # 渠道处理
│   ├── cli/            # 命令行工具
│   ├── commands/       # CLI 命令实现
│   ├── config/         # 配置管理
│   ├── cron/           # 定时任务
│   ├── daemon/         # 守护进程
│   ├── gateway/        # 网关服务
│   ├── hooks/          # 钩子系统
│   ├── infra/          # 基础设施
│   ├── logging/        # 日志系统
│   └── plugin-sdk/     # 插件 SDK
├── ui/                  # 控制界面（Web）
├── package.json
└── pnpm-workspace.yaml
```

## 4. 关键模块说明

| 模块 | 位置 | 功能说明 |
|------|------|---------|
| Gateway | `src/gateway/` | 核心网关服务，提供 HTTP/WS API、控制界面 |
| Agents | `src/agents/` | 智能体运行环境、工具调用、会话管理 |
| CLI | `src/cli/` | 命令行工具，用于配置和管理 |
| Config | `src/config/` | 配置文件管理和验证 |
| Channels | `src/channels/` | 各种消息渠道的适配层 |
| Hooks | `src/hooks/` | 钩子系统，支持扩展 |
| Plugin SDK | `src/plugin-sdk/` | 插件开发 SDK |
| Cron | `src/cron/` | 定时任务管理 |
