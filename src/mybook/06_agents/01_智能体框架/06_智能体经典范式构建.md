# 智能体经典范式构建

智能体范式是组织智能体"思考"与"行动"的核心方式。本章将深入探讨 ReAct、Plan-and-Solve、Reflection 三种最具代表性的范式，并提供完整的实现代码。

---

## 一、为什么需要经典范式

在 LLM 驱动的智能体领域，存在两种极端：
- **纯思考型**：如 Chain-of-Thought，能进行复杂逻辑推理，但无法与外部世界交互
- **纯行动型**：直接输出动作，但缺乏规划和纠错能力

经典范式将两者结合，实现了推理与行动的协同。

---

## 二、ReAct（Reasoning + Acting）

### 2.1 ReAct 的核心思想

ReAct 由 Shunyu Yao 于 2022 年提出，其核心是模仿人类解决问题的方式，将**推理**与**行动**显式地结合起来，形成一个"思考-行动-观察"的循环。

```
Thought → Action → Observation → Thought → ... → Finish
```

**核心要素**：
- **Thought（思考）**：智能体的"内心独白"，分析当前情况、分解任务、制定下一步计划
- **Action（行动）**：智能体决定采取的具体动作，通常是调用外部工具
- **Observation（观察）**：执行 Action 后从外部工具返回的结果

### 2.2 ReAct 的工作流程

在每个时间步 t：

```math
\left(th_t, a_t\right) = \pi\left(q, (a_1, o_1), \dots, (a_{t-1}, o_{t-1})\right)
```

```math
o_t = T(a_t)
```

其中，π 是大语言模型策略，T 是环境中的工具。

### 2.3 基础 LLM 客户端实现

```python
import os
from openai import OpenAI
from dotenv import load_dotenv
from typing import List, Dict

load_dotenv()

class HelloAgentsLLM:
    """为 HelloAgents 定制的 LLM 客户端
    """
    def __init__(self, model: str = None, api_key: str = None, base_url: str = None):
        self.model = model or os.getenv("LLM_MODEL_ID")
        self.api_key = api_key or os.getenv("LLM_API_KEY")
        self.base_url = base_url or os.getenv("LLM_BASE_URL")
        
        self.client = OpenAI(
            api_key=self.api_key,
            base_url=self.base_url
        )

    def think(self, messages: List[Dict[str, str]], temperature: float = 0) -> str:
        response = self.client.chat.completions.create(
            model=self.model,
            messages=messages,
            temperature=temperature
        )
        return response.choices[0].message.content
```

### 2.4 工具系统实现

一个良好定义的工具应包含三个核心要素：
1. **名称**：简洁唯一的标识符
2. **描述**：清晰的自然语言描述，说明工具用途
3. **执行逻辑**：真正执行任务的函数

```python
from serpapi import SerpApiClient

def search(query: str) -> str:
    """基于 SerpApi 的网页搜索引擎工具"""
    print(f"🔍 正在搜索: {query}")
    try:
        api_key = os.getenv("SERPAPI_API_KEY")
        params = {
            "engine": "google",
            "q": query,
            "api_key": api_key,
            "gl": "cn",
            "hl": "zh-cn",
        }
        client = SerpApiClient(params)
        results = client.get_dict()
        
        if "answer_box" in results and "answer" in results["answer_box"]:
            return results["answer_box"]["answer"]
        if "organic_results" in results:
            return "\n\n".join([
                f"[{i+1}] {res.get('title', '')}\n{res.get('snippet', '')}"
                for i, res in enumerate(results["organic_results"][:3])
            ])
        return f"未找到关于 '{query}' 的信息"
    except Exception as e:
        return f"搜索时发生错误: {e}"

class ToolExecutor:
    def __init__(self):
        self.tools = {}
    
    def register_tool(self, name: str, description: str, func: callable):
        self.tools[name] = {"description": description, "func": func}
    
    def execute(self, name: str, *args, **kwargs):
        if name not in self.tools:
            return f"错误：未知工具 '{name}'"
        return self.tools[name]["func"](*args, **kwargs)
    
    def get_description(self):
        return "\n".join([
            f"- {name}: {info['description']}"
            for name, info in self.tools.items()
        ])
```

### 2.5 ReAct Agent 完整实现

```python
import re

class ReActAgent:
    def __init__(self, llm: HelloAgentsLLM, tool_executor: ToolExecutor):
        self.llm = llm
        self.tool_executor = tool_executor
        self.max_steps = 10
        self.system_prompt = """你是一个能够使用工具解决问题的智能助手。

你必须严格遵循以下格式：
Thought: <你的思考过程>
Action: <工具名>[<参数>]
Observation: <工具返回的结果>
... (重复 Thought/Action/Observation 直到你有足够信息回答问题)
Thought: 我现在有足够的信息回答问题
Action: Finish[<最终答案>]

可用工具：
{tools}
"""

    def run(self, question: str) -> str:
        history = []
        step = 0
        
        while step < self.max_steps:
            step += 1
            
            messages = self._build_messages(question, history)
            response = self.llm.think(messages)
            
            thought, action = self._parse_response(response)
            
            if action.startswith("Finish["):
                final_answer = action[7:-1]
                return final_answer
            
            tool_name, tool_args = self._parse_action(action)
            observation = self.tool_executor.execute(tool_name, tool_args)
            
            history.append((thought, action, observation))
            print(f"\n🤔 思考: {thought}")
            print(f"🛠️ 行动: {action}")
            print(f"👁️ 观察: {observation}\n")
        
        return "抱歉，我未能在规定步骤内解决问题。"
    
    def _build_messages(self, question: str, history):
        tools_desc = self.tool_executor.get_description()
        system_prompt = self.system_prompt.format(tools=tools_desc)
        
        messages = [{"role": "system", "content": system_prompt}]
        
        history_text = ""
        for thought, action, obs in history:
            history_text += f"Thought: {thought}\nAction: {action}\nObservation: {obs}\n"
        
        user_content = f"{history_text}Question: {question}\n\n开始！"
        messages.append({"role": "user", "content": user_content})
        
        return messages
    
    def _parse_response(self, response: str):
        thought_match = re.search(r"Thought:\s*(.+?)(?:\n|$)", response)
        action_match = re.search(r"Action:\s*(.+?)(?:\n|$)", response)
        
        thought = thought_match.group(1).strip() if thought_match else ""
        action = action_match.group(1).strip() if action_match else ""
        
        return thought, action
    
    def _parse_action(self, action: str):
        match = re.match(r"(\w+)\[(.+)\]", action)
        if match:
            return match.group(1), match.group(2).strip()
        return action, ""
```

## 三、Plan-and-Solve

### 3.1 Plan-and-Solve 的核心思想

Plan-and-Solve 范式的核心是"三思而后行"：先制定完整的计划，再严格执行。

```
1. Plan（计划阶段）：制定详细的行动计划
2. Execute（执行阶段）：逐步执行计划
```

这种方式适用于：
- 需要严谨规划的任务
- 多步骤复杂任务
- 需要协调多个工具的任务

### 3.2 Plan-and-Solve Agent 实现

```python
class PlanAndSolveAgent:
    def __init__(self, llm: HelloAgentsLLM, tool_executor: ToolExecutor):
        self.llm = llm
        self.tool_executor = tool_executor
        self.plan_prompt = """你是一个擅长制定计划的智能助手。

请为以下问题制定一个详细的执行计划，使用工具。

问题：{question}

可用工具：
{tools}

请以 JSON 格式返回计划：
{{
    "plan": [
        "步骤 1：...",
        "步骤 2：...",
        "步骤 3：..."
    ]
}}
"""
        self.solve_prompt = """你是一个擅长执行计划的智能助手。

当前计划：
{plan}

当前步骤：{current_step}

请执行当前步骤，使用工具或推理。

问题：{question}
"""

可用工具：
{tools}

历史记录：
{history}
"""

    def run(self, question: str) -> str:
        # 阶段 1：制定计划
        plan = self._make_plan(question)
        print(f"📋 计划：\n{plan}")
        
        # 阶段 2：执行计划
        result = self._execute_plan(question, plan)
        return result
    
    def _make_plan(self, question: str):
        tools_desc = self.tool_executor.get_description()
        prompt = self.plan_prompt.format(
            question=question, tools=tools_desc
        )
        
        response = self.llm.think([{"role": "user", "content": prompt}])
        
        import json
        try:
            plan_data = json.loads(response)
            return plan_data.get("plan", [])
        except:
            # 如果 JSON 解析失败，尝试提取步骤
            steps = re.findall(r"步骤\s*\d+[：:.]\s*(.+)", response)
            return steps if steps else [response]
    
    def _execute_plan(self, question: str, plan: list):
        history = []
        
        for i, step in enumerate(plan):
            print(f"\n📍 执行步骤 {i+1}: {step}")
            
            tools_desc = self.tool_executor.get_description()
            prompt = self.solve_prompt.format(
                plan="\n".join([f"{j+1}. {s}" for j, s in enumerate(plan)]),
                current_step=f"{i+1}. {step}",
                question=question,
                tools=tools_desc,
                history="\n".join(history)
            )
            
            response = self.llm.think([{"role": "user", "content": prompt}])
            
            if "Action:" in response:
                thought, action = self._parse_response(response)
                if action.startswith("Finish["):
                    return action[7:-1]
                
                tool_name, tool_args = self._parse_action(action)
                observation = self.tool_executor.execute(tool_name, tool_args)
                history.append(f"步骤 {i+1}: {step} - 结果：{observation}")
            else:
                history.append(f"步骤 {i+1}: {step} - {response}")
        
        # 汇总结果
        summary_prompt = f"根据以下执行记录，总结最终答案：\n\n" + "\n".join(history)
        final_answer = self.llm.think([{"role": "user", "content": summary_prompt}])
        return final_answer
    
    def _parse_response(self, response: str):
        thought_match = re.search(r"Thought:\s*(.+?)(?:\n|$)", response)
        action_match = re.search(r"Action:\s*(.+?)(?:\n|$)", response)
        
        thought = thought_match.group(1).strip() if thought_match else ""
        action = action_match.group(1).strip() if action_match else ""
        
        return thought, action
    
    def _parse_action(self, action: str):
        match = re.match(r"(\w+)\[(.+)\]", action)
        if match:
            return match.group(1), match.group(2).strip()
        return action, ""
```

## 四、Reflection

### 4.1 Reflection 的核心思想

Reflection 范式赋予智能体"反思"能力，通过自我批判和修正来优化结果。

```
1. Generate（生成）：生成初步答案
2. Reflect（反思）：批判和反思
3. Improve（改进）：根据反思改进
```

### 4.2 Reflection Agent 实现

```python
class ReflectionAgent:
    def __init__(self, llm: HelloAgentsLLM, tool_executor: ToolExecutor):
        self.llm = llm
        self.tool_executor = tool_executor
        self.max_iterations = 3
        self.generate_prompt = """你是一个解决问题的智能助手。

问题：{question}
可用工具：{tools}

请使用 ReAct 范式解决问题。
"""
        self.reflect_prompt = """你是一个严格的评论家。请批评以下答案，指出问题并提供改进建议。

问题：{question}
当前答案：{answer}
执行历史：
{history}

请以 JSON 格式返回：
{{
    "criticisms": ["批评点 1", "批评点 2", ...],
    "suggestions": ["改进建议 1", "改进建议 2", ...]
}}
"""
        self.improve_prompt = """你是一个改进答案的智能助手。

原始问题：{question}
原始答案：{answer}
批评意见：{criticisms}
改进建议：{suggestions}
可用工具：{tools}

请根据批评和建议，使用 ReAct 范式改进答案。
"""

    def run(self, question: str) -> str:
        current_answer = None
        history = []
        
        for iteration in range(self.max_iterations):
            print(f"\n🔄 迭代 {iteration + 1}/{self.max_iterations}")
            
            # 生成答案
            if current_answer is None:
                current_answer = self._generate(question, history)
            else:
                current_answer = self._improve(question, current_answer, history)
            
            # 反思
            criticisms, suggestions = self._reflect(question, current_answer, history)
            
            if not criticisms:
                print("✅ 无批评，停止迭代")
                break
            
            history.append((current_answer, criticisms, suggestions))
            
            print(f"📝 批评：{criticisms}")
            print(f"💡 建议：{suggestions}")
        
        return current_answer
    
    def _generate(self, question: str, history: list):
        tools_desc = self.tool_executor.get_description()
        prompt = self.generate_prompt.format(
            question=question, tools=tools_desc
        )
        
        # 使用 ReAct 生成答案
        react_agent = ReActAgent(self.llm, self.tool_executor)
        return react_agent.run(question)
    
    def _reflect(self, question: str, answer: str, history: list):
        history_text = "\n".join([
            f"迭代 {i+1}: {a}\n批评：{c}\n建议：{s}"
            for i, (a, c, s) in enumerate(history)
        ])
        
        prompt = self.reflect_prompt.format(
            question=question, answer=answer, history=history_text
        )
        
        response = self.llm.think([{"role": "user", "content": prompt}])
        
        import json
        try:
            data = json.loads(response)
            return data.get("criticisms", []), data.get("suggestions", [])
        except:
            return [], []
    
    def _improve(self, question: str, answer: str, history: list):
        criticisms = "\n".join([c for _, c, _ in history[-1]]) if history else ""
        suggestions = "\n".join([s for _, _, s in history[-1]]) if history else ""
        
        tools_desc = self.tool_executor.get_description()
        prompt = self.improve_prompt.format(
            question=question, answer=answer,
            criticisms=criticisms, suggestions=suggestions,
            tools=tools_desc
        )
        
        return self.llm.think([{"role": "user", "content": prompt}])
```

## 五、三种范式对比

| 范式 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| **ReAct** | 动态调整、灵活 | 可能陷入死循环 | 需要快速反馈的任务 |
| **Plan-and-Solve** | 结构清晰、易于追踪 | 计划可能不完善 | 需要严谨规划的任务 |
| **Reflection** | 自我优化、质量高 | 计算成本高 | 需要高质量输出的任务 |
