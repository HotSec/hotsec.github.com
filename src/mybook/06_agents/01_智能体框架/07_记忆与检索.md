# 记忆与检索

记忆是智能体的核心能力之一，使智能体能够从历史经验中学习，积累长期知识。本章将深入探讨智能体的记忆系统以及 RAG（检索增强生成）技术。

---

## 一、为什么智能体需要记忆系统

没有记忆的智能体就像得了"失忆症"的人，尽管可能在单个任务上表现良好，但无法：
- **学习经验**：无法从过往的错误或成功中学习
- **保持一致性**：在长时间对话中无法保持一致的人设和回答
- **利用上下文**：无法利用之前的对话信息
- **积累知识**：无法长期保存和使用新获取的知识

---

## 二、记忆系统的分类

### 2.1 按持续时间和用途分类

| 记忆类型 | 人类类比 | 功能 | 存储位置 | 特点 |
|----------|----------|------|----------|------|
| **工作记忆（Working Memory）** | 短期记忆 | 处理当前任务的临时信息 | 上下文窗口 | 容量有限，快速访问 |
| **情景记忆（Episodic Memory）** | 自传式记忆 | 存储个人经历和事件 | 向量数据库 | 可检索，长期保存 |
| **语义记忆（Semantic Memory）** | 事实性知识 | 存储客观知识和概念 | 图数据库/知识图谱 | 结构化，可推理 |
| **感知记忆（Perceptual Memory）** | 感官印象 | 存储多模态感知信息 | 特征数据库 | 视觉、听觉等 |

### 2.2 HelloAgents 记忆系统架构

```
HelloAgents 记忆系统
├── WorkingMemory（工作记忆）
│   └── 在当前上下文中的消息历史
├── EpisodicMemory（情景记忆）
│   └── Qdrant 向量存储 + 时间戳、元数据
├── SemanticMemory（语义记忆）
│   └── Neo4j 图数据库 + 实体、关系
└── PerceptualMemory（感知记忆）
    └── 多模态特征存储（扩展支持）
```

## 三、工作记忆（Working Memory）

### 3.1 工作记忆的核心功能

工作记忆是智能体在执行单个任务时直接使用的记忆，通常直接体现在上下文窗口中。

```python
from typing import List, Dict

class WorkingMemory:
    """工作记忆：管理当前对话/任务的上下文"""
    
    def __init__(self, max_tokens: int = 8000):
        self.messages: List[Dict] = []
        self.max_tokens = max_tokens
    
    def add_message(self, role: str, content: str):
        """添加一条消息到工作记忆"""
        self.messages.append({
            "role": role,
            "content": content
        })
    
    def get_context(self) -> List[Dict]:
        """获取当前上下文（自动裁剪避免溢出）"""
        # 简单实现：保留最近的消息
        # 实际应用中需要估算 token 数量并智能裁剪
        return self.messages[-20:]  # 保留最近 20 条
    
    def clear(self):
        """清空工作记忆"""
        self.messages = []
```

### 3.2 工作记忆的限制与挑战

- **上下文窗口有限**：无法无限扩展上下文
- **注意力稀释**：过长的上下文会导致模型注意力分散
- **敏感信息问题**：敏感信息一直在上下文中存在

## 四、情景记忆（Episodic Memory）

### 4.1 情景记忆的核心思想

情景记忆记录智能体的"个人经历"，通常使用向量数据库实现：
1. 将记忆嵌入为向量
2. 存储在向量数据库中
3. 检索时通过相似度搜索找到相关记忆

### 4.2 基于 Qdrant 的情景记忆实现

```python
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams, PointStruct
import uuid
from typing import List, Dict, Any

class EpisodicMemory:
    """情景记忆：使用 Qdrant 存储和检索"""
    
    def __init__(
        self, 
        collection_name: str = "agent_episodes",
        vector_size: int = 1024
    ):
        self.client = QdrantClient(":memory:")
        self.collection_name = collection_name
        self.vector_size = vector_size
        
        # 创建集合
        self.client.create_collection(
            collection_name=self.collection_name,
            vectors_config=VectorParams(
                size=vector_size,
                distance=Distance.COSINE
            )
        )
    
    def store(
        self, 
        text: str, 
        embedding: List[float], 
        metadata: Dict[str, Any] = None
    ):
        """存储一条记忆"""
        point_id = str(uuid.uuid4())
        metadata = metadata or {}
        metadata["text"] = text
        
        self.client.upsert(
            collection_name=self.collection_name,
            points=[PointStruct(
                id=point_id,
                vector=embedding,
                payload=metadata
            )]
        )
        return point_id
    
    def retrieve(
        self, 
        query_embedding: List[float], 
        top_k: int = 5
    ) -> List[Dict]:
        """检索相关记忆"""
        results = self.client.search(
            collection_name=self.collection_name,
            query_vector=query_embedding,
            limit=top_k
        )
        
        return [
            {
                "text": hit.payload["text"],
                "score": hit.score,
                "metadata": {k: v for k, v in hit.payload.items() if k != "text"}
            }
            for hit in results
        ]
```

### 4.3 流式检索思考（Reflection-in-Stream）

在流式响应中插入思考过程，构建更细粒度的记忆记录：

```python
import re

class StreamingEpisodicMemory(EpisodicMemory):
    """支持流式思考的情景记忆"""
    
    def process_streaming_thought(self, text: str) -> List[str]:
        """从流式文本中提取思考片段"""
        # 提取 <thought> 标签内容
        thoughts = re.findall(r'<thought>(.*?)</thought>', text, re.DOTALL)
        
        # 或者提取推理标记
        reasoning_steps = re.findall(r'(\d+\.\s.+?)(?=\n\d+\.|\n\n|$)', text, re.DOTALL)
        
        return thoughts + reasoning_steps
    
    def store_thoughts(self, thoughts: List[str], llm_client):
        """存储思考片段"""
        for thought in thoughts:
            embedding = llm_client.get_embedding(thought)
            self.store(
                text=thought,
                embedding=embedding,
                metadata={"type": "streaming_thought"}
            )
```

## 五、语义记忆（Semantic Memory）

### 5.1 语义记忆的核心思想

语义记忆存储结构化的知识，使用图数据库（如 Neo4j）表示：
- **实体（Nodes）**：人、事、物、概念
- **关系（Edges）**：实体之间的关联
- **属性（Properties）**：实体和关系的属性

### 5.2 基于 Neo4j 的语义记忆实现

```python
from neo4j import GraphDatabase
from typing import List, Dict, Any

class SemanticMemory:
    """语义记忆：使用 Neo4j 图数据库"""
    
    def __init__(self, uri: str = "bolt://localhost:7687", user: str = "neo4j", password: str = "password"):
        self.driver = GraphDatabase.driver(uri, auth=(user, password))
    
    def close(self):
        self.driver.close()
    
    def add_entity(self, name: str, entity_type: str, properties: Dict[str, Any] = None):
        """添加实体"""
        properties = properties or {}
        with self.driver.session() as session:
            session.run(
                f"CREATE (e:{entity_type} {{name: $name}}) SET e += $properties",
                name=name, properties=properties
            )
    
    def add_relation(self, from_entity: str, relation: str, to_entity: str, properties: Dict[str, Any] = None):
        """添加关系"""
        properties = properties or {}
        with self.driver.session() as session:
            session.run(
                f"""
                MATCH (a {{name: $from}}), (b {{name: $to}})
                CREATE (a)-[r:{relation}]->(b)
                SET r += $properties
                """,
                from_entity=from_entity,
                to_entity=to_entity,
                properties=properties
            )
    
    def query(self, query: str, **kwargs) -> List[Dict]:
        """执行 Cypher 查询"""
        with self.driver.session() as session:
            result = session.run(query, **kwargs)
            return [dict(record) for record in result]
    
    def get_related(self, entity: str, relation: str = None) -> List[Dict]:
        """获取相关实体"""
        if relation:
            return self.query(
                f"MATCH (a {{name: $name}})-[r:{relation}]->(b) RETURN b.name as name, type(r) as relation",
                name=entity
            )
        else:
            return self.query(
                f"MATCH (a {{name: $name}})-[r]->(b) RETURN b.name as name, type(r) as relation",
                name=entity
            )
```

### 5.3 知识抽取的自动构建

使用 LLM 从对话中自动抽取知识：

```python
class KnowledgeExtractor:
    """自动知识抽取器"""
    
    def __init__(self, llm_client, semantic_memory: SemanticMemory):
        self.llm = llm_client
        self.semantic_memory = semantic_memory
        self.extraction_prompt = """从以下文本中提取知识图谱信息。

文本：
{text}

请以 JSON 格式返回：
{{
    "entities": [
        {{"name": "实体名", "type": "类型", "properties": {{"属性": "值"}}}}
    ],
    "relations": [
        {{"from": "源实体", "relation": "关系类型", "to": "目标实体", "properties": {{"属性": "值"}}}}
    ]
}}

只返回 JSON，不要有其他文字。
"""
    
    def extract_and_store(self, text: str):
        """从文本中抽取知识并存入语义记忆"""
        prompt = self.extraction_prompt.format(text=text)
        response = self.llm.think([{"role": "user", "content": prompt}])
        
        import json
        try:
            data = json.loads(response)
            
            # 存储实体
            for entity in data.get("entities", []):
                self.semantic_memory.add_entity(
                    name=entity["name"],
                    entity_type=entity.get("type", "Entity"),
                    properties=entity.get("properties", {})
                )
            
            # 存储关系
            for rel in data.get("relations", []):
                self.semantic_memory.add_relation(
                    from_entity=rel["from"],
                    relation=rel["relation"],
                    to_entity=rel["to"],
                    properties=rel.get("properties", {})
                )
                
            return True
        except Exception as e:
            print(f"知识抽取失败: {e}")
            return False
```

## 六、RAG（检索增强生成）系统

### 6.1 RAG 的核心架构

```
用户查询 → 向量化 → 向量检索 → 相关文档 → 提示词组装 → LLM 生成 → 答案
```

### 6.2 完整的 RAG 系统实现

```python
import os
from typing import List, Dict, Any
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams, PointStruct
from llama_index.core import SimpleDirectoryReader, VectorStoreIndex, StorageContext
from llama_index.vector_stores.qdrant import QdrantVectorStore

class RAGSystem:
    """完整的 RAG 系统"""
    
    def __init__(
        self,
        llm_client,
        collection_name: str = "rag_documents",
        vector_size: int = 1024
    ):
        self.llm = llm_client
        self.vector_size = vector_size
        
        # 初始化 Qdrant
        self.qdrant_client = QdrantClient(":memory:")
        self.vector_store = QdrantVectorStore(
            client=self.qdrant_client,
            collection_name=collection_name
        )
        
        # 创建集合
        self.qdrant_client.create_collection(
            collection_name=collection_name,
            vectors_config=VectorParams(
                size=vector_size,
                distance=Distance.COSINE
            )
        )
        
        self.storage_context = StorageContext.from_defaults(
            vector_store=self.vector_store
        )
        self.index = None
    
    def ingest_documents(self, directory: str):
        """读取并索引文档"""
        print(f"📚 正在读取目录: {directory}")
        documents = SimpleDirectoryReader(directory).load_data()
        print(f"✅ 读取到 {len(documents)} 个文档")
        
        # 创建索引（简化版）
        # 实际应用中需要使用正确的 embedding 模型
        self._build_index(documents)
        
    def _build_index(self, documents):
        """构建索引"""
        # 这里简化处理，实际使用 LlamaIndex 或 LangChain
        # 存储文档到 Qdrant
        for doc in documents:
            embedding = self.llm.get_embedding(doc.text)
            
            # 生成 UUID（简化）
            import uuid
            point_id = str(uuid.uuid4())
            
            self.qdrant_client.upsert(
                collection_name="rag_documents",
                points=[PointStruct(
                    id=point_id,
                    vector=embedding,
                    payload={"text": doc.text, "metadata": doc.metadata}
                )]
            )
    
    def query(self, question: str, top_k: int = 3) -> str:
        """使用 RAG 回答问题"""
        # 1. 获取查询嵌入
        query_embedding = self.llm.get_embedding(question)
        
        # 2. 检索相关文档
        results = self.qdrant_client.search(
            collection_name="rag_documents",
            query_vector=query_embedding,
            limit=top_k
        )
        
        # 3. 构建上下文
        context = "\n\n".join([
            f"文档 {i+1}:\n{hit.payload['text']}"
            for i, hit in enumerate(results)
        ])
        
        # 4. 组装提示词
        system_prompt = """你是一个基于检索的问答助手。

请根据以下上下文回答问题。如果上下文中没有答案，请如实告知。

上下文：
{context}
"""
        
        prompt = system_prompt.format(context=context)
        
        messages = [
            {"role": "system", "content": prompt},
            {"role": "user", "content": question}
        ]
        
        # 5. 生成答案
        return self.llm.think(messages)
```

### 6.3 RAG 优化技术

#### HyDE（Hypothetical Document Embedding）

先生成假设文档，再基于假设文档进行检索：

```python
def hyde_query(rag_system: RAGSystem, question: str, llm_client) -> str:
    """使用 HyDE 优化查询"""
    # 1. 生成假设文档
    hyde_prompt = """请写一篇关于以下问题的简短文档：{question}"""
    
    hypothetical_doc = llm_client.think([
        {"role": "user", "content": hyde_prompt.format(question=question)}
    ])
    
    # 2. 使用假设文档查询
    query_text = question + "\n\n" + hypothetical_doc
    
    return rag_system.query(query_text)
```

#### 多查询生成（Multi-Query Generation）

生成多个查询变体，分别检索后合并结果：

```python
def multi_query_rag(rag_system: RAGSystem, question: str, llm_client) -> str:
    """多查询 RAG"""
    # 生成多个查询变体
    generation_prompt = """为以下问题生成 3 个不同的搜索查询变体：

问题：{question}

每行一个查询。
"""
    
    response = llm_client.think([
        {"role": "user", "content": generation_prompt.format(question=question)}
    ])
    
    queries = [q.strip() for q in response.split("\n") if q.strip()]
    queries = [question] + queries  # 包含原始查询
    
    # 分别检索并收集结果（简化实现）
    # 实际应用中需要去重和重新排序
    return rag_system.query(question)
```
