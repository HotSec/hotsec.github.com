# RHCA红帽认证架构师

## 一、红帽认证体系概述

红帽认证是由 Red Hat 公司推出的 Linux 专业技能认证体系，是业内公认含金量最高的 Linux 认证之一。

### 1.1 认证金字塔

| 级别 | 认证名称 | 英文全称 | 定位 |
|------|----------|----------|------|
| 初级 | **RHCSA** | Red Hat Certified System Administrator | Linux系统管理员 |
| 中级 | **RHCE** | Red Hat Certified Engineer | Linux工程师 |
| 高级 | **RHCA** | Red Hat Certified Architect | 红帽认证架构师 |

> 💡 注意：RHCSA 考试已整合到 RHCE 考试中，考生需在一天内完成 RHCSA 和 RHCE 两部分。

### 1.2 认证特点

- **全实操考试**：没有选择题，所有题目都是真实环境下的动手操作
- **闭卷考试**：不能查阅任何资料
- **必须通过授权培训机构报名**：个人无法直接报名
- **基于 Red Hat Enterprise Linux（RHEL）** 环境

---

## 二、RHCA 认证概述

### 2.1 什么是 RHCA

**RHCA（Red Hat Certified Architect）** 是红帽最高级别的认证，代表持证人在 Linux 系统架构和企业级开源解决方案方面具备专家级能力。

### 2.2 前置要求

- 必须先获得 **RHCE**（红帽认证工程师）
- 在此基础之上再通过 **5门** 额外的专家级认证考试
- 5门考试必须保持有效状态

### 2.3 两条认证路径

| 路径 | 说明 |
|------|------|
| **红帽基础架构认证架构师** | 偏向系统管理、基础架构、自动化运维 |
| **红帽企业应用认证架构师** | 偏向应用开发、云原生、微服务 |

可以同时选择两条路径，也可以混合选择。

## 四、重点科目知识点

### 4.1 EX342 — Linux 故障排除专家

**核心技能：**

| 模块 | 内容 |
|------|------|
| 引导过程 | GRUB2 修复、内核参数、initramfs 重建、救援模式 |
| systemd | 服务管理、target、journal 日志分析 |
| 文件系统 | fsck、xfs_repair、LVM 恢复、挂载问题 |
| 内核 | 内核崩溃（Kdump）分析、/proc、/sys 排查 |
| 网络 | 网卡驱动、路由表、防火墙、DNS 排查 |
| 存储 | iSCSI、NFS、多路径问题 |
| SELinux | SELinux 导致的服务启动失败排查 |

**常见排错场景：**
- 服务器无法启动 → GRUB/initramfs/fstab 修复
- 服务启动失败 → SELinux 标签/配置文件/依赖
- 磁盘满 → find 大文件、inode 耗尽
- 网络不通 → firewalld/SELinux/网卡配置

### 4.2 EX442 — Linux 性能调优专家

**核心技能：**

| 模块 | 工具/方法 |
|------|-----------|
| CPU 调优 | `tuned` 配置文件、CPU 亲和性、IRQ 均衡、NUMA |
| 内存调优 | 大页（HugePages）、透明大页、swap、内存回收 |
| IO 调优 | I/O 调度器（mq-deadline/kyber/bfq）、LVM 条带、文件系统 |
| 网络调优 | 缓冲区大小、TCP 参数、中断合并 |
| 性能分析 | `perf`、火焰图、`vmstat`、`iostat`、`pidstat` |
| 容量规划 | 资源监控基线、趋势分析、扩容决策 |
| 虚拟化调优 | CPU pinning、NUMA 绑定、virtio 优化 |

### 4.3 EX436 — 高可用集群专家

**Pacemaker + Corosync 架构：**

```
┌─────────────────────────────────┐
│        Pacemaker (资源管理器)     │
│  ┌─────────┐  ┌─────────┐      │
│  │ 资源代理 │  │ 约束规则 │      │
│  └─────────┘  └─────────┘      │
├─────────────────────────────────┤
│      Corosync (消息层)          │
├─────────────────────────────────┤
│        集群节点通信              │
└─────────────────────────────────┘
```

**核心组件：**

| 组件 | 作用 |
|------|------|
| Corosync | 集群成员管理、心跳消息、Quorum |
| Pacemaker | 资源管理、启动/停止/监控/迁移 |
| Fencing（STONITH） | 隔离故障节点，防止脑裂 |
| pcs/pcsd | 集群命令行管理工具 |

**关键概念：**
- 资源（Resource）：IP、文件系统、服务、虚拟机
- 约束（Constraint）：Colocation（共存）、Order（顺序）、Location（位置）
- 故障转移（Failover）：自动检测故障 → Fencing → 资源迁移到备用节点
- 法定票数（Quorum）：超过半数节点存活才能做决策
- 双活、主备、N+M 架构设计

### 4.4 EX415 — Linux 安全专家

**核心模块：**

| 模块 | 内容 |
|------|------|
| SELinux | 策略管理、布尔值、上下文标签、audit2allow、自定义模块 |
| 系统审计 | auditd 配置、审计规则、ausearch/aureport 分析 |
| SCAP | OpenSCAP 安全扫描、STIG 基线、安全合规检查 |
| USBGuard | USB 设备白名单/黑名单控制 |
| NBD/Clevis/Tang | 网络绑定磁盘加密、Clevis 自动解密 |
| 防火墙 | firewalld 高级规则、富规则、区域管理 |
| 系统加固 | 内核参数安全、最小权限、文件完整性（AIDE） |

### 4.5 EX280 — OpenShift 管理员

**核心技能：**

| 模块 | 内容 |
|------|------|
| 集群管理 | 安装、升级、节点管理、etcd 备份恢复 |
| 多租户 | Project、RBAC、Security Context Constraints（SCC） |
| 网络 | SDN、NetworkPolicy、Router/Ingress、Service |
| 存储 | PV/PVC、StorageClass、CSI 驱动 |
| Operator | OperatorHub、Operator Lifecycle Manager（OLM） |
| 监控 | Prometheus、Grafana、Alertmanager 集成 |
| 安全 | 镜像签名、Quay 镜像仓库、证书管理 |

### 4.6 EX374 — Ansible 自动化平台开发专家

**核心技能：**

| 模块 | 内容 |
|------|------|
| 高级 Playbook | 循环、条件、变量、include/import、role |
| 执行环境 | 自动化执行环境构建、容器化 Ansible |
| 自动化内容浏览器 | ansible-navigator 使用 |
| 自动化控制器 | Ansible Automation Platform（AAP/Tower） |
| Jinja2 模板 | 高级模板语法、过滤器 |
| 错误处理 | block/rescue/always、滚动更新 |

## 五、考试形式与流程

### 5.1 考试基本信息

| 项目 | 说明 |
|------|------|
| 考试形式 | **全程实操**，无选择题 |
| 考试时长 | 每门 3-4 小时不等 |
| 考试方式 | 远程监考或考场机考 |
| 及格分数 | 一般为 210/300 分（70%） |
| 考试环境 | RHEL 虚拟机，通过 SSH 操作 |
| 报名方式 | 必须通过红帽授权培训机构 |

### 5.2 考试流程

```
RHCE 认证
    ↓
选择 5 门 RHCA 科目
    ↓
逐门报考（建议每门间隔 2-3 个月备考）
    ↓
全部通过后自动获得 RHCA 证书
```

### 5.3 考试注意事项

- 每门考试独立计分，可以补考
- 考试题目是真实环境配置，不是理论问答
- 只要结果正确即可得分，不限制具体方法
- 远程考试需要：摄像头、安静环境、身份证件
- 考试中不能用手机、不能查阅资料、不能使用 AI 工具

## 六、有效期与重认证

### 6.1 有效期

| 项目 | 说明 |
|------|------|
| 单科成绩有效期 | **3 年** |
| RHCA 证书有效期 | **3 年** |
| 所有 5 门保持有效 | 任何一门过期 → RHCA 失效 |

### 6.2 重认证方式

- 在 3 年有效期内，重新通过任意 5 门中的过期科目
- 或通过新的科目替代过期科目
- RHCE 也必须保持有效状态

### 6.3 证书查询

[红帽认证验证平台](https://www.redhat.com/rhtapps/certification/verify/)

## 七、备考建议

### 7.1 推荐备考路线

```
第一阶段：打好基础（RHCE）
├── RHCSA 系统管理基础
├── RHCE Ansible 自动化
└── 日常工作中积累经验

第二阶段：选择方向
├── 运维架构方向 → EX342 + EX436 + EX442
├── 云原生方向 → EX280 + EX374 + EX342
└── 安全方向 → EX415 + EX342 + EX436

第三阶段：逐门攻克（每门 2-3 个月）
├── 官方培训或自学教材
├── 搭建实验环境反复练习
└── 模拟考试
```

### 7.2 备考资源

| 资源 | 说明 |
|------|------|
| 红帽官方培训 | 红帽授权培训机构面授/直播课程 |
| Red Hat Learning Subscription | 红帽在线学习订阅（含实验环境） |
| 官方文档 | docs.redhat.com 各产品文档 |
| 实验环境 | 自建 KVM 虚拟机或云主机练习 |
| rhcsa/rhce 练习 | 基础打牢再冲 RHCA |

### 7.3 经验之谈

- **不要同时冲 5 门**：每门都需要大量动手练习，合理安排节奏
- **搭建自己的实验环境**：KVM 虚拟化搭建多节点集群，反复练习
- **重点突破 EX342**：故障排除是所有方向的基础，建议首先攻克
- **善用 man 和 --help**：考试环境中可以使用
- **考试时先通读所有题目**：先做简单题，最后攻克难题
