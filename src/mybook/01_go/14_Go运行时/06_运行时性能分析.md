# Go 运行时性能分析

> 主要参考：《Go语言高级编程（第2版）》第4.6节 — 柴树杉、曹春晖 著

Go 运行时提供了丰富的性能分析工具，帮助开发者诊断和优化程序性能。本文介绍运行时层面的性能分析方法，包括 CPU 分析、内存分析、Goroutine 分析、阻塞分析等。

---

## 一、pprof 工具

### 1.1 pprof 简介

pprof 是 Go 标准的性能分析工具，支持多种分析类型：

| 分析类型 | 描述 | 开销 |
|---------|------|------|
| **CPU** | CPU 使用分析 | ~1-5% |
| **Heap** | 堆内存分配分析 | 低 |
| **Goroutine** | Goroutine 栈分析 | 低 |
| **Block** | 阻塞分析 | 需显式启用 |
| **Mutex** | 互斥锁竞争分析 | 需显式启用 |
| **ThreadCreate** | 线程创建分析 | 低 |

### 1.2 HTTP 端点

```go
import (
    "net/http"
    _ "net/http/pprof"
)

func main() {
    go func() {
        http.ListenAndServe(":6060", nil)
    }()
    
    // 程序逻辑
}
```

访问端点：
- `/debug/pprof/` - pprof 首页
- `/debug/pprof/profile?seconds=30` - CPU profile
- `/debug/pprof/heap` - 堆内存分析
- `/debug/pprof/goroutine` - Goroutine 分析
- `/debug/pprof/block` - 阻塞分析
- `/debug/pprof/mutex` - 互斥锁分析

### 1.3 命令行分析

```bash
# 下载 CPU profile
curl -o cpu.prof http://localhost:6060/debug/pprof/profile?seconds=30

# 分析
go tool pprof cpu.prof

# 交互式命令
(pprof) top10
(pprof) list functionName
(pprof) web

# 下载堆内存分析
curl -o heap.prof http://localhost:6060/debug/pprof/heap
go tool pprof heap.prof
```

### 1.4 代码集成

```go
import (
    "os"
    "runtime/pprof"
)

func main() {
    // CPU 分析
    f, _ := os.Create("cpu.prof")
    pprof.StartCPUProfile(f)
    defer pprof.StopCPUProfile()
    
    // 程序逻辑
    run()
    
    // 堆内存分析
    f2, _ := os.Create("heap.prof")
    pprof.Lookup("heap").WriteTo(f2, 0)
    
    // Goroutine 分析
    f3, _ := os.Create("goroutine.prof")
    pprof.Lookup("goroutine").WriteTo(f3, 0)
}
```

## 二、CPU 分析

### 2.1 工作原理

CPU 分析使用采样方法：
1. 每 10ms 中断一次（默认）
2. 记录当前正在执行的函数
3. 统计各函数的采样次数
4. 计算函数的 CPU 占用比例

### 2.2 分析示例

```go
func main() {
    f, _ := os.Create("cpu.prof")
    pprof.StartCPUProfile(f)
    defer pprof.StopCPUProfile()
    
    // 模拟 CPU 密集型任务
    for i := 0; i < 4; i++ {
        go func() {
            for {
                _ = calculate(10000)
            }
        }()
    }
    
    time.Sleep(10 * time.Second)
}

func calculate(n int) int {
    result := 0
    for i := 0; i < n; i++ {
        result += i
    }
    return result
}
```

```bash
go tool pprof cpu.prof
```

## 三、内存分析

### 3.1 内存分析类型

| 类型 | 描述 |
|------|------|
| **allocs** | 所有内存分配（含已释放） |
| **heap** | 存活对象的内存分配 |
| **inuse_objects** | 正在使用的对象数量 |
| **inuse_space** | 正在使用的内存大小 |
| **alloc_objects** | 分配过的对象总数 |
| **alloc_space** | 分配过的内存总量 |

### 3.2 分析示例

```go
func main() {
    // 启用内存分析
    f, _ := os.Create("mem.prof")
    defer f.Close()
    
    // 分配内存
    var data [][]byte
    for i := 0; i < 1000; i++ {
        data = append(data, make([]byte, 1024*1024)) // 1MB
    }
    
    // 释放部分内存
    data = data[:500]
    runtime.GC()
    
    // 写入内存分析
    pprof.Lookup("heap").WriteTo(f, 0)
}
```

## 四、Goroutine 分析

### 4.1 Goroutine 栈分析

```go
func main() {
    // 启动多个 goroutine
    for i := 0; i < 100; i++ {
        go worker(i)
    }
    
    // 等待
    time.Sleep(10 * time.Second)
    
    // 获取 goroutine 分析
    f, _ := os.Create("goroutine.prof")
    pprof.Lookup("goroutine").WriteTo(f, 0)
}

func worker(id int) {
    for {
        time.Sleep(time.Second)
    }
}
```

```bash
go tool pprof goroutine.prof

(pprof) top10
Showing nodes accounting for 100, 100% of 100 total
      flat  flat%   sum%        cum   cum%
       100   100%   100%        100   100%  time.Sleep
         0     0%   100%        100   100%  main.worker
         0     0%   100%        100   100%  runtime.main
```

### 4.2 Goroutine 泄漏检测

```go
// 检测 goroutine 泄漏
func detectLeak() {
    before := runtime.NumGoroutine()
    
    // 执行测试
    runTest()
    
    after := runtime.NumGoroutine()
    
    if after > before+10 {
        fmt.Printf("Possible goroutine leak: before=%d, after=%d\n", before, after)
    }
}
```

## 五、阻塞分析

### 5.1 启用阻塞分析

```go
import "runtime"

func init() {
    // 设置采样率（1 = 100%）
    runtime.SetBlockProfileRate(1)
}
```

### 5.2 分析示例

```go
func main() {
    runtime.SetBlockProfileRate(1)
    
    var mu sync.Mutex
    var wg sync.WaitGroup
    
    for i := 0; i < 10; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            mu.Lock()
            time.Sleep(100 * time.Millisecond)
            mu.Unlock()
        }()
    }
    
    wg.Wait()
    
    // 获取阻塞分析
    f, _ := os.Create("block.prof")
    pprof.Lookup("block").WriteTo(f, 0)
}
```

```bash
go tool pprof block.prof

(pprof) top10
Showing nodes accounting for 450ms, 100% of 450ms total
      flat  flat%   sum%        cum   cum%
    450ms   100%   100%     450ms   100%  sync.(*Mutex).Lock
         0     0%   100%     450ms   100%  main.main.func1
```

## 六、互斥锁分析

### 6.1 启用互斥锁分析

```go
import "runtime"

func init() {
    // 设置采样率（1 = 100%）
    runtime.SetMutexProfileFraction(1)
}
```

### 6.2 分析示例

```go
func main() {
    runtime.SetMutexProfileFraction(1)
    
    var mu sync.Mutex
    var wg sync.WaitGroup
    
    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for j := 0; j < 1000; j++ {
                mu.Lock()
                _ = j
                mu.Unlock()
            }
        }()
    }
    
    wg.Wait()
    
    // 获取互斥锁分析
    f, _ := os.Create("mutex.prof")
    pprof.Lookup("mutex").WriteTo(f, 0)
}
```

## 七、trace 工具

### 7.1 trace 简介

trace 提供更细粒度的执行追踪：
- Goroutine 调度
- GC 活动
- 系统调用
- 网络事件
- 用户事件

### 7.2 使用方法

```go
import (
    "os"
    "runtime/trace"
)

func main() {
    f, _ := os.Create("trace.out")
    trace.Start(f)
    defer trace.Stop()
    
    // 程序逻辑
    run()
}
```

```bash
# 查看 trace
go tool trace trace.out

# 浏览器打开
# http://127.0.0.1:端口
```

### 7.4 用户事件

```go
func main() {
    f, _ := os.Create("trace.out")
    trace.Start(f)
    defer trace.Stop()
    
    // 记录用户事件
    ctx := context.Background()
    trace.Log(ctx, "category", "message")

    defer task.End()
    
    region := trace.StartRegion(ctx, "myRegion")
    // 执行操作
    region.End()
}
```

## 八、GODEBUG 环境变量

### 8.1 常用选项

```bash
# GC 追踪
GODEBUG=gctrace=1 ./program

# 调度器追踪
GODEBUG=schedtrace=1000 ./program

# 内存分配追踪
GODEBUG=allocfreetrace=1 ./program

# 禁用 GC
GODEBUG=gcstop=1 ./program

# 打印竞争检测详情
GODEBUG=racelimit=10 go run -race main.go
```

### 8.2 gctrace 输出

```bash
GODEBUG=gctrace=1 ./program

# 输出示例
gc 1 @0.003s 2%: 0.018+0.52+0.023 ms clock, 0.14+0.11/0.98/0.49+0.18 ms cpu, 4->4->0 MB, 5 MB goal, 8 P
```

字段解释：
- `gc 1`: GC 次数
- `@0.003s`: 程序启动后的时间
- `2%`: GC CPU 占比
- `0.018+0.52+0.023 ms`: STW 时间
- `4->4->0 MB`: GC 前后堆大小
- `5 MB goal`: 目标堆大小
- `8 P`: P 的数量

### 8.3 schedtrace 输出

```bash
GODEBUG=schedtrace=1000 ./program

# 输出示例
SCHED 1000ms: gomaxprocs=8 idleprocs=0 threads=10 spinningthreads=1 idlethreads=3 runqueue=0 [0 0 0 0 0 0 0 0]
```

字段解释：
- `gomaxprocs`: P 的数量
- `idleprocs`: 空闲 P 的数量
- `threads`: M 的数量
- `spinningthreads`: 自旋 M 的数量
- `idlethreads`: 空闲 M 的数量
- `runqueue`: 全局队列长度
- `[...]`: 各 P 的本地队列长度

### 10.2 常见优化技巧

```go

        return new(MyStruct)
    },

    return MyStruct{} // 值类型
}

// 4. 批量处理

    // 批量处理减少函数调用开销
```
