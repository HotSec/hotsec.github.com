# 反射基础

反射是 Go 提供的在运行时检查类型信息的能力，通过 `reflect` 包实现。

---

## 一、反射三定律

### 1.1 从接口值到反射对象

```go
var x int = 42
v := reflect.ValueOf(x)
t := reflect.TypeOf(x)

fmt.Println("type:", t)
fmt.Println("value:", v)
```

### 1.2 从反射对象到接口值

```go
v := reflect.ValueOf(42)
i := v.Interface()
n := i.(int)
```

### 1.3 要修改反射对象，值必须可设置

```go
x := 42
v := reflect.ValueOf(&x).Elem()
v.SetInt(100)
fmt.Println(x)
```

## 二、reflect.Type

### 2.1 获取类型信息

```go
t := reflect.TypeOf(3.14)

fmt.Println("name:", t.Name())
fmt.Println("kind:", t.Kind())
fmt.Println("size:", t.Size())
fmt.Println("pkgPath:", t.PkgPath())
```

### 2.2 Kind 枚举

```go
const (
    Invalid Kind = iota
    Bool
    Int
    Int8
    Int16
    Int32
    Int64

    Uint8

    Float64
    Complex64
    Complex128
    Array
    Chan
    Func

    Pointer

    String

    UnsafePointer
)
```

### 2.3 结构体字段操作

```go
type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

t := reflect.TypeOf(User{})

for i := 0; i < t.NumField(); i++ {
    f := t.Field(i)
    fmt.Printf("field %d: name=%s, type=%v, tag=%v\n",
        i, f.Name, f.Type, f.Tag.Get("json"))
}
```

## 三、reflect.Value

### 3.1 获取值

```go
v := reflect.ValueOf(42)

fmt.Println("int:", v.Int())
fmt.Println("interface:", v.Interface())

fmt.Println("string:", v.String())
fmt.Println("bool:", v.Bool())
```

### 3.2 修改值

```go
x := 42
v := reflect.ValueOf(&x).Elem()

if v.CanSet() {
    v.SetInt(100)
}
```

- 必须传入指针才能修改
- 使用 `Elem()` 解引用
- 使用 `CanSet()` 检查是否可设置

### 3.3 创建新值

```go
t := reflect.TypeOf(42)
v := reflect.New(t)
v.Elem().SetInt(100)
n := v.Elem().Interface().(int)
```

## 四、结构体操作

### 4.1 遍历字段

```go
type User struct {
    Name string
    Age  int
}

u := User{Name: "Alice", Age: 30}
v := reflect.ValueOf(u)

for i := 0; i < v.NumField(); i++ {
    field := v.Field(i)
    fmt.Printf("field %d: %v\n", i, field.Interface())
}
```

### 4.2 调用方法

```go
type Calculator struct{}

func (c Calculator) Add(a, b int) int {
    return a + b
}

c := Calculator{}
v := reflect.ValueOf(c)
m := v.MethodByName("Add")

args := []reflect.Value{
    reflect.ValueOf(1),
    reflect.ValueOf(2),
}
result := m.Call(args)
fmt.Println(result[0].Int())
```

## 五、常见应用场景

### 5.1 结构体转 Map

```go
func StructToMap(obj any) map[string]any {
    result := make(map[string]any)
    v := reflect.ValueOf(obj)
    t := v.Type()

    for i := 0; i < v.NumField(); i++ {
        field := t.Field(i)
        if field.IsExported() {
            result[field.Name] = v.Field(i).Interface()
        }
    }
    return result
}
```

### 5.2 深拷贝

```go
func DeepCopy(src any) any {
    v := reflect.ValueOf(src)
    if v.Kind() == reflect.Ptr {
        v = v.Elem()
    }

    copy := reflect.New(v.Type()).Elem()
    copy.Set(v)
    return copy.Interface()
}
```

### 5.3 动态调用函数

```go
func Call(fn any, args ...any) []any {
    v := reflect.ValueOf(fn)
    in := make([]reflect.Value, len(args))
    for i, arg := range args {
        in[i] = reflect.ValueOf(arg)
    }
    out := v.Call(in)
    result := make([]any, len(out))
    for i, o := range out {
        result[i] = o.Interface()
    }
    return result
}
```

## 六、性能注意事项

- 反射比直接代码慢 10-100 倍
- 避免在热路径使用反射
- 可以使用代码生成替代反射（如 `stringer`, `json-iterator`）
- 缓存反射结果

```go
var fieldIndex int
var once sync.Once

func getFieldIndex(t reflect.Type) int {
    once.Do(func() {
        for i := 0; i < t.NumField(); i++ {
            if t.Field(i).Name == "Target" {
                fieldIndex = i
                break
            }
        }
    })
    return fieldIndex
}
```
