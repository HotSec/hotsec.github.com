# 方法与结构体

## 一、结构体

### 1.1 自定义类型与类型别名

```go
type MyInt int64

type MyIntAlias = int64

var a MyInt = 100
var b MyIntAlias = 200

fmt.Printf("a type: %T\n", a)
fmt.Printf("b type: %T\n", b)
```

- `type NewType OldType`：自定义新类型
- `type Alias = OldType`：类型别名，只是另一个名字

### 1.2 结构体定义

```go
type Student struct {
    Name string
    Age  int
}

type Address struct {
    Province string
    City     string
}
```

### 1.3 实例化

```go
// 基本实例化
var s1 Student
s1.Name = "Go"
s1.Age = 18

// new 实例化（返回指针）
s2 := new(Student)
s2.Name = "Go"

// 键值对初始化
s3 := Student{
    Name: "Go",
    Age:  18,
}

// 值列表初始化（必须按字段顺序）
s4 := Student{"Go", 18}

// 指针初始化
s5 := &Student{
    Name: "Go",
    Age:  18,
}
```

### 1.4 构造函数

```go
func NewStudent(name string, age int) *Student {
    return &Student{
        Name: name,
        Age:  age,
    }
}

s := NewStudent("Go", 18)
```

- Go 没有构造函数，使用 `NewXxx` 函数约定
- 返回指针避免结构体拷贝

### 1.5 匿名字段（嵌入）

```go
type Person struct {
    Name string
    Age  int
}

type Student struct {
    Person
    School string
}

s := Student{
    Person: Person{
        Name: "Go",
        Age:  18,
    },
    School: "MIT",
}

fmt.Println(s.Name)
fmt.Println(s.Person.Name)
```

- 匿名字段实现了类似继承的效果
- 可以直接访问嵌入字段的属性和方法
- 字段名冲突时需要显式指定

### 1.6 嵌套结构体

```go
type Address struct {
    Province string
    City     string
}

type User struct {
    Name    string
    Address Address
}

u := User{
    Name: "Go",
    Address: Address{
        Province: "Beijing",
        City:     "Beijing",
    },
}
fmt.Println(u.Address.City)
```

### 1.7 JSON 序列化与 Tag

```go
type Student struct {
    ID     int    `json:"id"`
    Name   string `json:"name"`
    Age    int    `json:"age,omitempty"`
    Gender string `json:"gender"`
    Email  string `json:"email,omitempty"`
}

s := Student{
    ID:     1,
    Name:   "Go",
    Age:    18,
    Gender: "male",
}

data, _ := json.Marshal(s)
fmt.Println(string(data))

var s2 Student
json.Unmarshal(data, &s2)
fmt.Println(s2)
```

- `json:"name"` 指定 JSON 字段名
- `omitempty` 省略零值字段
- `-` 忽略字段
- 结构体字段必须大写开头才能被 JSON 包访问

## 二、方法

### 2.1 方法定义

```go
type Student struct {
    Name string
    Age  int
}

func (s Student) SayHello() string {
    return fmt.Sprintf("Hello, I'm %s", s.Name)
}

func (s *Student) SetAge(age int) {
    s.Age = age
}
```

- 方法是带接收者的函数
- 接收者写在 `func` 和方法名之间

### 2.2 值接收者 vs 指针接收者

```go
func (s Student) GetValue() int {
    return s.Age
}

func (s *Student) SetValue(age int) {
    s.Age = age
}
```

| 特性 | 值接收者 | 指针接收者 |
|------|----------|------------|
| 修改原始对象 | 否 | 是 |
| 拷贝开销 | 复制整个结构体 | 复制指针 |
| 调用方式 | 值和指针均可 | 值和指针均可 |
| 适用场景 | 小对象/只读 | 大对象/需修改 |

- 建议统一使用指针接收者
- Go 会自动进行值和指针的转换

### 2.3 任意类型添加方法

```go
type MyInt int

func (m MyInt) IsPositive() bool {
    return m > 0
}

type MySlice []int

func (s MySlice) Sum() int {
    total := 0
    for _, v := range s {
        total += v
    }
    return total
}
```

- 基于自定义类型添加方法
- 不能给其他包的类型添加方法

### 2.4 方法继承与重写

```go
type Animal struct {
    Name string
}

func (a Animal) Speak() string {
    return a.Name + " speaks"
}

type Dog struct {
    Animal
    Breed string
}

func (d Dog) Speak() string {
    return d.Name + " barks"
}

d := Dog{Animal: Animal{Name: "Rex"}, Breed: "Labrador"}
fmt.Println(d.Speak())
fmt.Println(d.Animal.Speak())
```

- 嵌入结构体的方法会被继承
- 外层方法会覆盖内层同名方法
- 可通过显式指定访问被覆盖的方法
