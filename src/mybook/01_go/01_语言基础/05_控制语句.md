# 语句

## 一、变量与常量

### 1.1 标识符与关键字

- 标识符：由字母、数字、`_` 组成，且不能以数字开头
- 25 个关键字：`break`/`case`/`chan`/`const`/`continue`/`default`/`defer`/`else`/`fallthrough`/`for`/`func`/`go`/`goto`/`if`/`import`/`interface`/`map`/`package`/`range`/`return`/`select`/`struct`/`switch`/`type`/`var`
- 37 个保留字：内建常量/类型/函数

### 1.2 变量声明

```go
// 标准声明
var name string
var age int

// 批量声明
var (
    name   string
    age    int
    isOk   bool
)

// 初始化
var name string = "Go"
var age int = 18

// 类型推导
var name = "Go"
var age = 18

// 短变量声明（只能在函数内使用）
name := "Go"
age := 18

// 匿名变量
x, _ := getValue()
```

- 函数外必须使用 `var`/`const`/`func` 等关键字
- `:=` 只能在函数体内使用
- 变量声明后必须使用，否则编译错误
- 同一作用域内不能重复声明

### 1.3 常量与 iota

```go
const pi = 3.1415
const e = 2.7182

const (
    pi = 3.1415
    e  = 2.7182
)

// 批量声明时省略值则和上一行相同
const (
    n1 = 100
    n2
    n3
)

// iota 常量计数器
const (
    a1 = iota // 0
    a2        // 1
    a3        // 2
    a4        // 3
)

// _ 跳过某些值
const (
    b1 = iota // 0
    b2        // 1
    _         // 2 (跳过)
    b3        // 3
)

// iota 声明中间插队
const (
    c1 = iota // 0
    c2 = 100  // 100
    c3 = iota // 2
    c4        // 3
)

// 多个 iota 定义在一行
const (
    d1, d2 = iota + 1, iota + 2 // 1, 2
    d3, d4 = iota + 1, iota + 2 // 2, 3
)

// 定义数量级
const (
    _  = iota
    KB = 1 << (10 * iota) // 1 << 10 = 1024
    MB                    // 1 << 20
    GB                    // 1 << 30
    TB                    // 1 << 40
    PB                    // 1 << 50
)
```

## 三、流程控制

### 3.1 if else

```go
if condition {
    // ...
} else if condition2 {
    // ...
} else {
    // ...
}

// if 特殊写法：在条件前执行语句
if err := doSomething(); err != nil {
    fmt.Println("error:", err)
}
```

- 条件不需要括号
- 大括号必须与 if/else 在同一行
- if 前可添加执行语句，用分号分隔

### 3.2 for

```go
// 基本循环
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// 省略初始语句
i := 0
for ; i < 10; i++ {
    fmt.Println(i)
}

// 省略初始和增量语句（类似 while）
for i < 10 {
    fmt.Println(i)
    i++
}

// 无限循环
for {
    // ...
}

// for range
for i, v := range "hello" {
    fmt.Printf("index: %d, value: %c\n", i, v)
}

for k, v := range map[string]int{"go": 1} {
    fmt.Println(k, v)
}
```

- Go 只有 `for` 循环，没有 `while`/`do-while`
- `for range` 可遍历 slice/map/string/channel

### 3.3 switch

```go
finger := 3
switch finger {
case 1:
    fmt.Println("大拇指")
case 2:
    fmt.Println("食指")
case 3:
    fmt.Println("中指")
default:
    fmt.Println("无效")
}

// 一个 case 多个值
switch n := 7; n {
case 1, 3, 5, 7, 9:
    fmt.Println("奇数")
case 2, 4, 6, 8, 10:
    fmt.Println("偶数")
}

// case 使用表达式
age := 30
switch {
case age < 18:
    fmt.Println("未成年")
case age >= 18 && age < 60:
    fmt.Println("成年")
default:
    fmt.Println("老年")
}

// fallthrough 穿透
switch n := 1; n {
case 1:
    fmt.Println("1")
    fallthrough
case 2:
    fmt.Println("2")
}
```

- Go 的 switch 默认不穿透（不需要 break）
- `fallthrough` 可强制穿透到下一个 case
- case 可使用表达式，switch 不带条件时等价于 `switch true`

### 3.4 goto / break / continue

```go
// goto 跳转到标签
goto label
// ...
label:
    fmt.Println("here")

// break 跳出循环，可指定标签跳出外层循环
outer:
for i := 0; i < 5; i++ {
    for j := 0; j < 5; j++ {
        if j == 3 {
            break outer
        }
    }
}

// continue 跳过当前迭代
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue
    }
    fmt.Println(i)
}
```

### 3.5 range over func（自定义迭代器）⭐ Go 1.23+

Go 1.23 引入了 `range over func`，允许使用 `for range` 遍历函数返回的迭代器。

#### 基本概念

```go
// iter 包定义的迭代器类型
type Seq[V any] func(yield func(V) bool)
type Seq2[K, V any] func(yield func(K, V) bool)
```

- `yield` 函数：每次迭代调用，返回 `false` 表示停止迭代
- `Seq`：单值迭代器
- `Seq2`：键值对迭代器

#### 简单迭代器

```go
// 遍历整数序列
func Ints(n int) func(yield func(int) bool) {
    return func(yield func(int) bool) {
        for i := 0; i < n; i++ {
            if !yield(i) {
                return
            }
        }
    }
}

for i := range Ints(5) {
    fmt.Println(i)
}
```

#### 反向迭代

```go
func Backward[E any](s []E) func(yield func(int, E) bool) {
    return func(yield func(int, E) bool) {
        for i := len(s) - 1; i >= 0; i-- {
            if !yield(i, s[i]) {
                return
            }
        }
    }
}

s := []string{"a", "b", "c"}
for i, v := range Backward(s) {
    fmt.Printf("%d: %s\n", i, v)
}
```

#### 过滤迭代器

```go
func Filter[E any](s []E, pred func(E) bool) func(yield func(E) bool) {
    return func(yield func(E) bool) {
        for _, v := range s {
            if pred(v) && !yield(v) {
                return
            }
        }
    }
}

nums := []int{1, 2, 3, 4, 5, 6}
for v := range Filter(nums, func(n int) bool { return n%2 == 0 }) {
    fmt.Println(v)
}
```

#### 链式迭代器

```go
func Map[E, R any](s []E, f func(E) R) func(yield func(R) bool) {
    return func(yield func(R) bool) {
        for _, v := range s {
            if !yield(f(v)) {
                return
            }
        }
    }
}

nums := []int{1, 2, 3}
for v := range Map(nums, func(n int) int { return n * 2 }) {
    fmt.Println(v)
}
```

#### 文件行迭代器

```go
func Lines(filename string) func(yield func(string) bool) error {
    return func(yield func(string) bool) error {
        f, err := os.Open(filename)
        if err != nil {
            return err
        }
        defer f.Close()
        
        scanner := bufio.NewScanner(f)
        for scanner.Scan() {
            if !yield(scanner.Text()) {
                return nil
            }
        }
        return scanner.Err()
    }
}

for line := range Lines("test.txt") {
    fmt.Println(line)
}
```

#### 树遍历迭代器

```go
type Tree[E any] struct {
    Val   E
    Left  *Tree[E]
    Right *Tree[E]
}

func InOrder[E any](t *Tree[E]) func(yield func(E) bool) {
    return func(yield func(E) bool) {
        var walk func(t *Tree[E]) bool
        walk = func(t *Tree[E]) bool {
            if t == nil {
                return true
            }
            return walk(t.Left) && yield(t.Val) && walk(t.Right)
        }
        walk(t)
    }
}

for v := range InOrder(root) {
    fmt.Println(v)
}
```

#### 提前退出

```go
func FindFirst[E any](s []E, pred func(E) bool) (E, bool) {
    for v := range Filter(s, pred) {
        return v, true
    }
    var zero E
    return zero, false
}
```

#### Pull 模式（主动拉取）

```go
import "iter"

func ToSlice[E any](seq iter.Seq[E]) []E {
    var s []E
    for v := range seq {
        s = append(s, v)
    }
    return s
}

// 使用 iter.Pull 主动拉取
func Collect[E any](seq iter.Seq[E]) ([]E, error) {
    next, stop := iter.Pull(seq)
    defer stop()
    
    var s []E
    for {
        v, ok := next()
        if !ok {
            return s, nil
        }
        s = append(s, v)
    }
}
```

#### 注意事项

1. **yield 返回 false 时必须立即返回**：避免继续迭代
2. **资源清理**：使用 `defer` 确保资源释放
3. **性能**：迭代器有函数调用开销，热点代码慎用
4. **版本要求**：需要 Go 1.23+

### 3.6 循环变量语义调整（loopvar）⭐ Go 1.22+

Go 1.22 修复了 `for` 循环变量的作用域问题，每次迭代创建新变量。

#### 旧版本问题（Go 1.21 及之前）

```go
// 问题代码：循环变量复用
var prints []func()
for i := 0; i < 3; i++ {
    prints = append(prints, func() { fmt.Println(i) })
}
for _, f := range prints {
    f()
}
// Go 1.21: 输出 3, 3, 3（全部是最后一个值）
// Go 1.22+: 输出 0, 1, 2（正确）
```

#### 闭包陷阱修复

```go
// 旧版本需要手动复制
for i := 0; i < 3; i++ {
    i := i // 必须复制
    go func() {
        fmt.Println(i)
    }()
}

// Go 1.22+ 直接使用
for i := 0; i < 3; i++ {
    go func() {
        fmt.Println(i) // 每个 goroutine 捕获不同的 i
    }()
}
```

#### for range 同样适用

```go
// Go 1.21 及之前
for _, v := range []int{1, 2, 3} {
    go func() {
        fmt.Println(v) // 可能全部打印 3
    }()
}

// Go 1.22+
for _, v := range []int{1, 2, 3} {
    go func() {
        fmt.Println(v) // 正确打印 1, 2, 3
    }()
}
```

#### 迁移指南

```go
// 依赖旧行为的代码（罕见）
func oldBehavior() {
    var saves []int
    for i := 0; i < 3; i++ {
        saves = append(saves, i)
    }
    fmt.Println(saves) // [0 1 2] 行为不变
}

// 如果确实需要共享变量
func sharedVariable() {
    var shared int
    for i := 0; i < 3; i++ {
        shared = i
        fmt.Println(shared) // 每次迭代更新 shared
    }
}
```

#### 版本兼容性

```bash
# 强制使用旧语义（不推荐）
GOEXPERIMENT=noloopvar go build

# 检查受影响的代码
go vet -loopclosure ./...
```

#### 最佳实践

1. **新代码**：直接使用 Go 1.22+ 语义，无需手动复制变量
2. **旧代码迁移**：移除不必要的 `v := v` 复制语句
3. **测试**：运行测试确保行为正确
4. **代码审查**：检查依赖旧行为的代码（极少见）

## 四、defer

### 4.1 基本用法

```go
func main() {
    defer fmt.Println("world")
    fmt.Println("hello")
}
// 输出：
// hello
// world
```

### 4.2 多个 defer

```go
func main() {
    defer fmt.Println("1")
    defer fmt.Println("2")
    defer fmt.Println("3")
}
// 输出：3, 2, 1（LIFO 后进先出）
```

### 4.3 defer 执行时机

```go
func a() {
    fmt.Println("start a")
    defer fmt.Println("defer a")
    b()
    fmt.Println("end a")
}

func b() {
    fmt.Println("b")
}

// 输出：
// start a
// b
// end a
// defer a
```

- defer 在函数返回前执行，不是在作用域结束时

### 4.4 defer 参数预计算

```go
func main() {
    i := 0
    defer fmt.Println(i) // 0，参数在 defer 声明时计算
    i++
    fmt.Println(i) // 1
}
```

### 4.5 defer 修改命名返回值

```go
func f() (n int) {
    defer func() {
        n++ // 修改命名返回值
    }()
    return 1 // 实际返回 2
}
```

### 4.6 defer 性能

```go
// 在循环中使用 defer 可能导致资源延迟释放
func bad() {
    for i := 0; i < 1000; i++ {
        f, _ := os.Open("file.txt")
        defer f.Close() // 所有文件在函数结束时才关闭
    }
}

// 正确做法：在循环体内处理
func good() {
    for i := 0; i < 1000; i++ {
        func() {
            f, _ := os.Open("file.txt")
            defer f.Close() // 每次迭代结束后关闭
        }()
    }
}
```

## 五、panic 和 recover

### 5.1 panic

```go
func main() {
    fmt.Println("start")
    panic("something wrong")
    fmt.Println("end") // 不会执行
}
```

- `panic` 会立即停止当前函数执行
- 依次执行当前函数的 defer
- 沿调用栈向上传播

### 5.2 recover

```go
func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("recovered:", r)
        }
    }()
    
    panic("panic here")
    fmt.Println("after panic") // 不会执行
}
```

- `recover` 必须在 defer 中调用才有效
- 用于捕获 panic，让程序继续运行

### 5.3 panic/recover 模式

```go
func safeOperation() (err error) {
    defer func() {
        if r := recover(); r != nil {
            err = fmt.Errorf("panic: %v", r)
        }
    }()
    
    riskyOperation()
    return nil
}
```

## 六、select

### 6.1 基本用法

```go
select {
case v := <-ch1:
    fmt.Println("ch1:", v)
case v := <-ch2:
    fmt.Println("ch2:", v)
case ch3 <- 42:
    fmt.Println("sent to ch3")
default:
    fmt.Println("no activity")
}
```

- 多路复用，随机选择一个就绪的 case
- `default` 用于非阻塞操作

### 6.2 超时控制

```go
select {
case v := <-ch:
    fmt.Println(v)
case <-time.After(time.Second):
    fmt.Println("timeout")
}
```

### 6.3 非阻塞接收

```go
select {
case v := <-ch:
    fmt.Println(v)
default:
    fmt.Println("no value")
}
```
