# 接口

接口类型定义了一组方法的集合，如果某个自定义类型为这些方法提供了具体的实现，则该自定义类型就实现了该接口。Go 的接口是**隐式实现**的，不需要 `implements` 关键字。

---

## 一、接口定义

### 1.1 基本定义

```go
type Speaker interface {
    Speak() string
}

type Dog struct{ Name string }

func (d Dog) Speak() string { return d.Name + ": Woof!" }

var s Speaker = Dog{Name: "Rex"}
fmt.Println(s.Speak())
```

### 1.2 空接口

```go
var x interface{} = 42
var y any = "hello"

func Print(v any) {
    fmt.Println(v)
}
```

- `interface{}` 和 `any` 完全等价（Go 1.18+）
- 空接口可以接受任意类型的值

### 1.3 接口组合

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

type ReadWriter interface {
    Reader
    Writer
}
```

## 二、接口实现规则

### 2.1 隐式实现

```go
type Writer interface {
    Write(p []byte) (n int, err error)
}

type BufferedWriter struct{}

func (b *BufferedWriter) Write(p []byte) (n int, err error) {
    return len(p), nil
}

var w Writer = &BufferedWriter{}
```

- 只要实现了接口的所有方法，就自动实现了该接口
- 不需要显式声明 `implements`

### 2.2 值接收者 vs 指针接收者

```go
type Animal interface {
    Speak() string
}

type Cat struct{ Name string }

func (c Cat) Speak() string { return c.Name + ": Meow" }

type Dog struct{ Name string }

func (d *Dog) Speak() string { return d.Name + ": Woof" }

var a1 Animal = Cat{Name: "Kitty"}
var a2 Animal = &Cat{Name: "Kitty"}
var a3 Animal = &Dog{Name: "Rex"}
var a4 Animal = Dog{Name: "Rex"}
```

| 接收者类型 | 值类型实现接口 | 指针类型实现接口 |
|-----------|--------------|----------------|
| 值接收者 | ✅ | ✅ |
| 指针接收者 | ❌ | ✅ |

## 三、类型断言

### 3.1 基本断言

```go
var i interface{} = "hello"

s := i.(string)
fmt.Println(s)

n := i.(int)
```

### 3.2 安全断言（comma-ok 模式）

```go
var i interface{} = "hello"

if s, ok := i.(string); ok {
    fmt.Println("string:", s)
} else {
    fmt.Println("not a string")
}
```

### 3.3 类型 switch

```go
func classify(i interface{}) string {
    switch v := i.(type) {
    case int:
        return fmt.Sprintf("int: %d", v)
    case string:
        return fmt.Sprintf("string: %s", v)
    case bool:
        return fmt.Sprintf("bool: %t", v)
    case []int:
        return fmt.Sprintf("[]int: %v", v)
    case nil:
        return "nil"
    default:
        return fmt.Sprintf("unknown: %T", v)
    }
}
```

## 四、接口类型转换

```go
var (
    a io.ReadCloser = (*os.File)(f)
    b io.Reader     = a
    c io.Closer     = a
    d io.Reader     = c.(io.Reader)
)
```

- 子接口可隐式转换为父接口
- 父接口转子接口需要类型断言

## 五、nil 接口陷阱

### 5.1 nil 接口 vs nil 值

```go
type MyError struct{ msg string }
func (e *MyError) Error() string { return e.msg }

func getError() error {
    var err *MyError
    return err
}

func main() {
    err := getError()
    fmt.Println(err == nil)
}
```

原因：接口值 = `(type, data)`，`getError()` 返回的是 `(*MyError, nil)`，type 不为 nil，所以整个接口不为 nil。

### 5.2 正确做法

```go
func getError() error {
    return nil
}

func getError2() error {
    var err error
    return err
}
```

## 六、接口底层实现

### 6.1 eface（空接口）

```go
type eface struct {
    _type *_type
    data  unsafe.Pointer
}
```

### 6.2 iface（有方法的接口）

```go
type iface struct {
    tab  *itab
    data unsafe.Pointer
}

type itab struct {
    inter *interfacetype
    _type *_type
    fun   [1]uintptr
}
```

- 空接口 `interface{}` 使用 `eface`，只记录类型和数据
- 非空接口使用 `iface`，通过 `itab` 记录接口方法表

## 七、接口比较

```go
var a interface{} = 42
var b interface{} = 42
fmt.Println(a == b)

var c interface{} = []int{1, 2, 3}
var d interface{} = []int{1, 2, 3}
fmt.Println(c == d)
```

- 接口值可比较当且仅当其底层类型可比较
- slice、map、function 不可比较，会导致 panic

## 八、接口设计原则

### 8.1 小接口

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}
```

- Go 社区推崇"小接口"：1-3 个方法最佳
- 通过组合构建大接口

### 8.2 接口应该在使用方定义

```go
type Store interface {
    Get(key string) (string, error)
}

type Service struct {
    store Store
}
```

- 接口由消费方定义，不是提供方
- 避免返回接口，返回具体类型

### 8.3 接口优势

- 隐藏实现细节
- 解耦模块间依赖
- 便于单元测试（Mock）
- 实现多态

## 九、常见接口模式

### 9.1 策略模式

```go
type SortStrategy interface {
    Sort(data []int)
}

type BubbleSort struct{}
func (s BubbleSort) Sort(data []int) { /* ... */ }

type QuickSort struct{}
func (s QuickSort) Sort(data []int) { /* ... */ }

type Sorter struct {
    strategy SortStrategy
}

func (s *Sorter) SetStrategy(strategy SortStrategy) {
    s.strategy = strategy
}
```

### 9.2 装饰器模式

```go
type Handler interface {
    Handle(ctx *Context)
}

type LoggingHandler struct {
    next Handler
}

func (h *LoggingHandler) Handle(ctx *Context) {
    log.Println("before")
    h.next.Handle(ctx)
    log.Println("after")
}
```
