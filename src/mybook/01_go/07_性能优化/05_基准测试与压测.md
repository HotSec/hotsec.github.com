# 基准测试与压测

基准测试用于衡量代码性能，压测用于验证系统承载能力。

---

## 一、Go 基准测试

### 1.1 编写基准测试

```go
func BenchmarkAdd(b *testing.B) {
    for i := 0; i < b.N; i++ {
        Add(1, 2)
    }
}
```

### 1.2 运行基准测试

```bash
go test -bench=. -benchmem
```

输出示例：

```
BenchmarkAdd-8    1000000000    0.256 ns/op    0 B/op    0 allocs/op
```

### 1.3 常用参数

```bash
go test -bench=. -benchtime=5s
go test -bench=. -count=5
go test -bench=. -cpu=1,2,4
go test -bench=. -run=^$
```

## 二、基准测试进阶

### 2.1 重置计时器

```go
func BenchmarkHeavy(b *testing.B) {
    setup()
    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        process()
    }
}
```

### 2.2 并行基准测试

```go
func BenchmarkParallel(b *testing.B) {
    b.RunParallel(func(pb *testing.PB) {
        for pb.Next() {
            process()
        }
    })
}
```

### 2.3 子基准测试

```go
func BenchmarkJSON(b *testing.B) {
    b.Run("Marshal", func(b *testing.B) {
        for i := 0; i < b.N; i++ {
            json.Marshal(data)
        }
    })
    b.Run("Unmarshal", func(b *testing.B) {
        for i := 0; i < b.N; i++ {
            json.Unmarshal(raw, &data)
        }
    })
}
```

### 2.4 内存分配分析

```go
func BenchmarkAllocs(b *testing.B) {
    b.ReportAllocs()
    for i := 0; i < b.N; i++ {
        _ = make([]byte, 1024)
    }
}
```

## 三、压测工具

### 3.1 wrk

```bash
wrk -t12 -c400 -d30s http://localhost:8080/api
```

参数说明：
- `-t` 线程数
- `-c` 连接数
- `-d` 持续时间

### 3.2 hey

```bash
hey -n 10000 -c 100 http://localhost:8080/api
```

参数说明：
- `-n` 总请求数
- `-c` 并发数

### 3.3 vegeta

```bash
echo "GET http://localhost:8080/api" | vegeta attack -duration=30s -rate=100 | vegeta report
```

### 3.4 ab (Apache Bench)

```bash
ab -n 10000 -c 100 http://localhost:8080/api
```

## 四、压测指标

### 4.1 QPS/TPS

- QPS：每秒查询数
- TPS：每秒事务数

### 4.2 延迟

- P50：50% 请求的延迟
- P90：90% 请求的延迟
- P99：99% 请求的延迟

### 4.3 错误率

- 失败请求占比
- 5xx 错误率

### 4.4 资源使用

- CPU 使用率
- 内存使用率
- 连接数

## 六、Go 压测示例

### 6.1 HTTP 服务压测

```go
func BenchmarkHTTP(b *testing.B) {
    ts := httptest.NewServer(http.HandlerFunc(handler))
    defer ts.Close()

    b.ResetTimer()
    b.RunParallel(func(pb *testing.PB) {
        client := &http.Client{}
        for pb.Next() {
            resp, _ := client.Get(ts.URL)
            resp.Body.Close()
        }
    })
}
```

### 6.2 数据库压测

```go
func BenchmarkDB(b *testing.B) {
    db, _ := sql.Open("mysql", dsn)
    defer db.Close()

    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        var result int
        db.QueryRow("SELECT 1").Scan(&result)
    }
}
```

## 七、性能对比

### 7.1 benchstat

```bash
go install golang.org/x/perf/cmd/benchstat@latest

go test -bench=. -count=10 > old.txt
go test -bench=. -count=10 > new.txt

benchstat old.txt new.txt
```

输出示例：

```
name    old time/op  new time/op  delta
Add     2.45ns ± 1%  2.48ns ± 2%  +1.2%
```

## 八、注意事项

1. **预热**：压测前先预热系统
2. **隔离**：压测环境与生产隔离
3. **监控**：压测时监控系统资源
4. **逐步加压**：避免瞬间高压
5. **多次测试**：取平均值减少误差
