# 编译器优化实践

> 参考：《Go语言高级编程（第2版）》第5章

理解编译器优化有助于编写更高效的 Go 代码。本章介绍常见的编译器优化技术和如何利用这些优化。

---

## 一、内联优化

### 1.1 内联决策

编译器根据函数的"复杂度"决定是否内联：

```go
func add(a, b int) int {
    return a + b
}

func complexFunc(data []int) int {
    var total int
    for _, v := range data {
        total += v
    }
    return total
}
```

查看内联决策：

```bash
go build -gcflags="-m=2" main.go
```

输出：
```
./main.go:3:6: can inline add with cost 4 as: func(int, int) int { return a + b }
./main.go:7:6: cannot inline complexFunc: function too complex: cost 83 exceeds budget 80
```

### 1.2 内联预算

```go
const (
    inlineBudget = 80
)

func (n *Node) inlineCost() int {
    cost := 0
    
    switch n.Op {
    case OLITERAL:
        cost = 1
    case ONAME:
        cost = 1
    case OADD, OSUB, OMUL, ODIV:
        cost = 1 + n.Left.inlineCost() + n.Right.inlineCost()
    case OCALL:
        cost = 10 + inlineCost(n.List)
    case OFOR, OIF:
        cost = 20 + inlineCost(n.Body)
    }
    
    return cost
}
```

### 1.3 控制内联

```go
//go:noinline
func noInline() int {
    return 42
}

//go:inline
func forceInline() int {
    return 42
}
```

### 1.4 内联优化示例

```go
package main

func add(a, b int) int {
    return a + b
}

func compute() int {
    return add(1, 2) + add(3, 4)
}

func main() {
    println(compute())
}
```

优化后等价于：

```go
func compute() int {
    return 1 + 2 + 3 + 4
}

func main() {
    println(10)
}
```

## 二、逃逸分析优化

### 2.1 减少堆分配

```go
func bad() *Point {
    p := Point{X: 1, Y: 2}
    return &p
}

func good() Point {
    return Point{X: 1, Y: 2}
}
```

### 2.2 接口逃逸

```go
func bad(x int) interface{} {
    return x
}

func good(x int) int {
    return x
}
```

### 2.3 切片逃逸

```go
func bad() []int {
    s := make([]int, 100)
    return s
}

func good(s []int) {
    for i := range s {
        s[i] = i
    }
}
```

### 2.4 查看逃逸分析

```bash
go build -gcflags="-m -m" main.go 2>&1 | grep escape
```

## 三、边界检查消除

### 3.1 BCE 原理

```go
func sum(s []int) int {
    total := 0
    for i := 0; i < len(s); i++ {
        total += s[i]
    }
    return total
}
```

编译器知道 `i < len(s)`，所以 `s[i]` 不会越界。

### 3.2 BCE 示例

```go
func bceExample(s []int) {
    _ = s[0]
    _ = s[1]
    _ = s[2]
}

func noBCE(s []int) {
    _ = s[0]
    _ = s[2]
    _ = s[1]
}
```

查看 BCE：

```bash
go build -gcflags="-d=ssa/check_bce/debug=1" main.go
```

### 3.3 帮助编译器

```go
func process(s []int) {
    if len(s) < 10 {
        return
    }
    
    for i := 0; i < 10; i++ {
        s[i] = i
    }
}
```

## 四、死代码消除

### 4.1 常量条件

```go
func dce() {
    const debug = false
    
    if debug {
        println("debug mode")
    }
}
```

编译器会完全移除 `if` 块。

### 4.2 未使用变量

```go
func dce2() int {
    x := 1
    y := 2
    return x
}
```

`y` 会被完全移除。

### 4.3 未使用函数

```go
func unused() int {
    return 42
}

func main() {
    println("hello")
}
```

`unused` 不会出现在最终二进制中。

## 五、循环优化

### 5.1 循环不变量外提

```go
func process(data []int, scale int) int {
    total := 0
    for i := range data {
        total += data[i] * scale * scale
    }
    return total
}
```

优化后：

```go
func process(data []int, scale int) int {
    total := 0
    scale2 := scale * scale
    for i := range data {
        total += data[i] * scale2
    }
    return total
}
```

### 5.2 强度削减

```go
func strength() int {
    x := 10
    y := x * 2
    z := x * 8
    return y + z
}
```

优化后：

```go
func strength() int {
    x := 10
    y := x << 1
    z := x << 3
    return y + z
}
```

### 5.3 循环展开

```go
func sum(s []int) int {
    total := 0
    for i := 0; i < len(s); i++ {
        total += s[i]
    }
    return total
}
```

编译器可能展开为：

```go
func sum(s []int) int {
    total := 0
    for i := 0; i < len(s)-3; i += 4 {
        total += s[i] + s[i+1] + s[i+2] + s[i+3]
    }
    for i := len(s) - len(s)%4; i < len(s); i++ {
        total += s[i]
    }
    return total
}
```

## 六、函数调用优化

### 6.1 尾调用优化

Go 不保证尾调用优化，但可以手动优化：

```go
func factorial(n int) int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n-1)
}

func factorialTail(n, acc int) int {
    if n <= 1 {
        return acc
    }
    return factorialTail(n-1, n*acc)
}
```

### 6.2 函数参数优化

```go
func bad(s []int) {
    process(s)
}

func process(s []int) {
    for i := range s {
        s[i] = i
    }
}

func good(s []int) {
    process(&s[0], len(s))
}

func process(ptr *int, len int) {
    for i := 0; i < len; i++ {
        *(*int)(unsafe.Pointer(uintptr(unsafe.Pointer(ptr)) + uintptr(i)*8)) = i
    }
}
```

## 七、内存布局优化

### 7.1 结构体字段对齐

```go
type Bad struct {
    a bool
    b int64
    c bool
    d int32
}

type Good struct {
    b int64
    d int32
    a bool
    c bool
}
```

`Bad`: 32 字节
`Good`: 16 字节

### 7.2 热点字段前置

```go
type Data struct {
    hotField  int
    coldField [1024]byte
}
```

热点字段在前，提高缓存命中率。

### 7.3 False Sharing 避免

```go
type Bad struct {
    a int64
    b int64
}

type Good struct {
    a     int64
    _pad  [7]int64
    b     int64
}
```

## 十、优化最佳实践

### 10.1 优化原则

1. **先测量，后优化**：使用 benchmark 确定瓶颈
2. **理解编译器**：知道编译器能做什么
3. **保持简单**：简单代码更容易被优化
4. **避免过早优化**：可读性优先
5. **验证优化效果**：每次优化后都要测量

### 10.2 常见优化模式

```go
// 1. 减少分配
var buf bytes.Buffer
buf.WriteString("hello")
buf.WriteString("world")
s := buf.String()

// 2. 预分配
s := make([]int, 0, 100)
for i := 0; i < 100; i++ {
    s = append(s, i)
}

// 3. 复用对象
var pool = sync.Pool{
    New: func() interface{} {
        return new(Buffer)
    },
}

buf := pool.Get().(*Buffer)
defer pool.Put(buf)

// 4. 批量处理
func batch(items []Item) {
    for i := 0; i < len(items); i += batchSize {
        end := i + batchSize
        if end > len(items) {
            end = len(items)
        }
        processBatch(items[i:end])
    }
}
```

### 10.3 避免反模式

```go
// 反模式1：频繁字符串拼接
s := ""
for i := 0; i < n; i++ {
    s += strconv.Itoa(i)
}

// 正确：使用 strings.Builder
var sb strings.Builder
for i := 0; i < n; i++ {
    sb.WriteString(strconv.Itoa(i))
}
s := sb.String()

// 反模式2：频繁类型断言
for _, v := range items {
    if s, ok := v.(string); ok {
        process(s)
    }
}

// 正确：类型开关
for _, v := range items {
    switch v := v.(type) {
    case string:
        process(v)
    }
}
```

## 十一、总结

编译器优化是提升 Go 程序性能的重要手段：

1. **内联优化**：减少函数调用开销
2. **逃逸分析**：减少堆分配
3. **边界检查消除**：减少运行时检查
4. **死代码消除**：减小二进制体积
5. **循环优化**：提升循环性能
6. **内存布局优化**：提高缓存效率
