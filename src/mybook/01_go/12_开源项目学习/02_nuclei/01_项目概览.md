
# Nuclei 项目概览

## 1. 简介

[Nuclei](https://github.com/projectdiscovery/nuclei) 是由 [ProjectDiscovery](https://github.com/projectdiscovery) 团队开发的一款现代化、高性能的漏洞扫描器，使用 Go 语言编写。它基于 **YAML 模板驱动**的设计理念，通过简单易用的模板语言实现漏洞检测。

## 2. 主要特点

- **模板驱动**: 所有漏洞检测逻辑都封装在 YAML 模板中
- **多协议支持**: 支持 HTTP、DNS、TCP、SSL/TLS、WebSocket、Headless、JavaScript、File、Code 等协议
- **社区驱动**: 拥有庞大的社区维护的模板库
- **高性能**: 双层并发、请求聚类、缓存等技术优化
- **可扩展**: 提供 SDK 可嵌入到其他应用中

## 3. 项目结构

```
nuclei/
├── cmd/                   # 命令行工具入口
│   └── nuclei/
│       └── main.go       # 主程序入口
├── lib/                   # 公开 SDK
│   └── sdk.go            # SDK API
├── internal/              # 内部包
│   └── runner/           # 运行器实现
│       └── runner.go
├── pkg/                   # 核心库
│   ├── catalog/          # 模板目录管理
│   ├── core/             # 核心引擎
│   ├── protocols/        # 协议实现
│   ├── templates/        # 模板处理
│   ├── operators/        # 匹配/提取算子
│   └── ...
└── go.mod                # Go 模块定义
```
