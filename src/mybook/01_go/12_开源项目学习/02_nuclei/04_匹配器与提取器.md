
# Nuclei 匹配器与提取器

## 1. Matchers 匹配器

### 1.1 Matcher 结构

[Matcher](file:///Volumes/SN740/code/notebook/third/nuclei/pkg/operators/matchers/matchers.go) 是判断漏洞是否存在的核心组件：

```go
type Matcher struct {
	// 类型
	Type MatcherTypeHolder `yaml:"type" json:"type"`

	// 条件
	Condition string `yaml:"condition,omitempty" json:"condition,omitempty"`

	// 匹配位置
	Part string `yaml:"part,omitempty" json:"part,omitempty"`

	// 反向匹配
	Negative bool `yaml:"negative,omitempty" json:"negative,omitempty"`

	// 名称
	Name string `yaml:"name,omitempty" json:"name,omitempty"`

	// 各种匹配器字段
	Status  []int    `yaml:"status,omitempty" json:"status,omitempty"`
	Size    []int    `yaml:"size,omitempty" json:"size,omitempty"`
	Words   []string `yaml:"words,omitempty" json:"words,omitempty"`
	Regex   []string `yaml:"regex,omitempty" json:"regex,omitempty"`
	Binary  []string `yaml:"binary,omitempty" json:"binary,omitempty"`
	DSL     []string `yaml:"dsl,omitempty" json:"dsl,omitempty"`
	XPath   []string `yaml:"xpath,omitempty" json:"xpath,omitempty"`
	Encoding string  `yaml:"encoding,omitempty" json:"encoding,omitempty"`
	CaseInsensitive bool `yaml:"case-insensitive,omitempty" json:"case-insensitive,omitempty"`
	MatchAll bool `yaml:"match-all,omitempty" json:"match-all,omitempty"`
	Internal bool `yaml:"internal,omitempty" json:"internal,omitempty"`

	// 编译后缓存
	condition ConditionType
	matcherType MatcherType
	binaryDecoded []string
	regexCompiled []*regexp.Regexp
	dslCompiled   []*govaluate.EvaluableExpression
}
```

### 1.2 支持的匹配器类型

| 类型 | 说明 | 示例 |
|----|----|------|
| **word** | 单词匹配 | `word: ["error", "fail"]` |
| **regex** | 正则匹配 | `regex: ["token=([a-f0-9]+)"]` |
| **status** | 状态码匹配 | `status: [200, 302]` |
| **size** | 响应大小匹配 | `size: [1024, 2048]` |
| **binary** | 二进制模式匹配 | `binary: ["48545450"]` |
| **dsl** | 表达式语言匹配 | `dsl: ["status_code == 200 && contains(body, \"admin\")"]` |
| **xpath** | XPath 匹配 | `xpath: ["/html/body/div"]` |

### 1.3 匹配条件

支持两种匹配条件：

- **AND**: 所有子匹配都满足（默认）
- **OR**: 任意子匹配满足

```yaml
matchers:
  - type: word
    words:
      - "admin"
      - "password"
    condition: or  # 任意一个满足即可
```

### 1.4 匹配器执行

[Execute](file:///Volumes/SN740/code/notebook/third/nuclei/pkg/operators/operators.go) 方法执行匹配：

```go
func (operators *Operators) Execute(data map[string]interface{}, matchFunc MatchFunc, extractFunc ExtractFunc, debug bool) (*Result, bool) {
	results := &Result{}
	matched := true
	var finalMatch bool

	// 执行匹配
	if len(operators.Matchers) > 0 {
		matches := make(map[string]struct{})
		for _, matcher := range operators.Matchers {
			m, values := matchFunc(data, matcher)
			matched = matched && m

			if m {
				finalMatch = true
				for k := range values {
					matches[k] = struct{}{}
				}
				// 记录匹配
				results.Matches = append(results.Matches, matcher)
				for k := range values {
					results.MatchedValues = append(results.MatchedValues, k)
				}
			}
		}

		// 应用条件
		switch operators.MatchersCondition {
		case ANDCondition:
			matched = true
			for _, matcher := range operators.Matchers {
				if !matcher.Match(data, matchFunc) {
					matched = false
					break
				}
			}
		case ORCondition:
			matched = false
			for _, matcher := range operators.Matchers {
				if matcher.Match(data, matchFunc) {
					matched = true
					break
				}
			}
		}
	}

	// 执行提取
	if len(operators.Extractors) > 0 {
		for _, extractor := range operators.Extractors {
			values := extractFunc(data, extractor)
			for k, v := range values {
				results.Extracts[k] = v
			}
		}
	}

	return results, matched
}
```

## 2. Extractors 提取器

### 2.1 Extractor 结构

[Extractor](file:///Volumes/SN740/code/notebook/third/nuclei/pkg/operators/extractors/extractors.go) 用于从响应中提取信息：

```go
type Extractor struct {
	Name string `yaml:"name,omitempty" json:"name,omitempty"`
	Type ExtractorTypeHolder `json:"type" yaml:"type"`
	extractorType ExtractorType

	// 正则提取
	Regex []string `yaml:"regex,omitempty" json:"regex,omitempty"`
	RegexGroup int `yaml:"group,omitempty" json:"group,omitempty"`
	regexCompiled []*regexp.Regexp

	// Key-Value 提取
	KVal []string `yaml:"kval,omitempty" json:"kval,omitempty"`

	// JSON 提取 (jq 语法)
	JSON []string `yaml:"json,omitempty" json:"json,omitempty"`
	jsonCompiled []*gojq.Code

	// XPath 提取
	XPath []string `yaml:"xpath,omitempty" json:"xpath,omitempty"`
	Attribute string `yaml:"attribute,omitempty" json:"attribute,omitempty"`

	// DSL 提取
	DSL []string `yaml:"dsl,omitempty" json:"dsl,omitempty"`
	dslCompiled []*govaluate.EvaluableExpression

	Part string `yaml:"part,omitempty" json:"part,omitempty"`
	Internal bool `yaml:"internal,omitempty" json:"internal,omitempty"`
	CaseInsensitive bool `yaml:"case-insensitive,omitempty" json:"case-insensitive,omitempty"`
}
```

### 2.2 支持的提取器类型

| 类型 | 说明 | 示例 |
|----|----|------|
| **regex** | 正则提取 | `regex: ["token=([a-f0-9]+)"]` |
| **kval** | Key-Value 提取 | `kval: ["Set-Cookie", "X-API-Key"]` |
| **json** | JSON jq 表达式提取 | `json: [".token", ".user.id"]` |
| **xpath** | XPath 提取 | `xpath: ["//a/@href"]` |
| **dsl** | DSL 表达式提取 | `dsl: ["body"]` |

### 2.3 提取器示例

```yaml
extractors:
  - type: regex
    name: token
    part: body
    regex:
      - "token=([a-f0-9]{32})"
  - type: json
    name: user-id
    part: body
    json:
      - ".user.id"
```

## 3. DSL 表达式语言

### 3.1 可用变量

Nuclei 提供的 DSL 支持多种变量访问：

| 变量 | 说明 |
|----|------|
| `status_code` | HTTP 状态码 |
| `body` | 响应体 |
| `header` | 响应头（单值） |
| `all_headers` | 所有响应头 |
| `content_length` | 内容长度 |
| `duration` | 请求耗时 |
| `ip` | 目标 IP |
| `host` | 目标主机名 |
| ... | 更多... |

### 3.2 可用函数

| 函数 | 说明 |
|----|------|
| `contains(str, substr)` | 检查包含 |
| `starts_with(str, prefix)` | 检查前缀 |
| `ends_with(str, suffix)` | 检查后缀 |
| `regex(pattern, str)` | 正则匹配 |
| `len(str)` | 获取长度 |
| `tolower(str)` | 转小写 |
| `toupper(str)` | 转大写 |
| `trim(str)` | 去除空白 |
| ... | 更多... |

### 3.3 DSL 示例

```yaml
matchers:
  - type: dsl
    dsl:
      - "status_code == 200 && contains(body, \"admin\")"
      - "contains(tolower(all_headers), \"x-powered-by\")"
```

## 4. 组合使用

### 4.1 匹配器与提取器结合

```yaml
http:
  - method: GET
    path:
      - "{{BaseURL}}/login"
    matchers:
      - type: word
        words:
          - "Login"
        part: body
    extractors:
      - type: regex
        name: csrf-token
        part: body
        regex:
          - "name=\"csrf\" value=\"([a-f0-9]+)\""
```

### 4.2 多匹配器组合

```yaml
matchers:
  - type: status
    status:
      - 200
  - type: word
    words:
      - "admin panel"
    condition: and  # 两个条件都要满足
```

## 5. 内部匹配器

使用 `internal: true` 的匹配器不会在输出中显示，但可以用作流程控制：

```yaml
matchers:
  - type: word
    name: check-step1
    words:
      - "step1 ok"
    internal: true  # 不显示在输出中
```

## 6. 小结

Nuclei 的 Operators 设计特点：

1. **丰富的匹配器**: 支持 7 种类型的匹配器，覆盖大多数场景
2. **灵活的提取器**: 支持从多种格式（文本、JSON、HTML）提取信息
3. **DSL 表达式**: 提供强大的条件组合和数据处理能力
4. **组合机制**: MatchersCondition（AND/OR）支持复杂逻辑组合
5. **内部标记**: 支持不输出到结果的内部匹配器用于流程控制
