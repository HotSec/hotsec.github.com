# 监控面板

开源监控面板工具汇总。

## Pika

基于 Go 的轻量级监控面板。

- 支持自定义指标采集
- Web 界面展示
- 告警通知

## Nezha（哪吒监控）

开源服务器监控面板，支持多服务器管理。

```bash
# 安装面板端
curl -L https://raw.githubusercontent.com/naiba/nezha/master/script/install.sh -o nezha.sh
chmod +x nezha.sh && ./nezha.sh install_panel

# 安装 Agent
./nezha.sh install_agent --server <面板IP>:<gRPC端口> --password <密钥>
```

### 核心功能

- 服务器状态监控（CPU/内存/磁盘/网络/负载）
- 多服务器集中管理
- 在线率监控与告警
- 流量统计
- 支持 Telegram/DingTalk/WeChat 通知

## Uptime Kuma

开源服务在线率监控。

```bash
docker run -d --name uptime-kuma -p 3001:3001 louislam/uptime-kuma
```

### 功能

- HTTP(s) / TCP / Ping / DNS 监控
- 多种通知方式
- 状态页面
- 多语言支持
