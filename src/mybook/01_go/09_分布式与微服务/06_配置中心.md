# 配置中心

配置中心用于集中管理分布式系统的配置，支持动态更新。

---

## 一、配置中心功能

- 配置集中存储
- 动态配置更新
- 配置版本管理
- 多环境支持
- 配置加密

---

## 二、etcd 配置中心

### 2.1 存储配置

```go
import "go.etcd.io/etcd/client/v3"

func SaveConfig(client *clientv3.Client, key, value string) error {
    _, err := client.Put(context.Background(), key, value)
    return err
}

func GetConfig(client *clientv3.Client, key string) (string, error) {
    resp, err := client.Get(context.Background(), key)
    if err != nil {
        return "", err
    }
    if len(resp.Kvs) == 0 {
        return "", errors.New("config not found")
    }
    return string(resp.Kvs[0].Value), nil
}
```

### 2.2 监听配置变化

```go
func WatchConfig(client *clientv3.Client, key string, onChange func(value string)) {
    watchChan := client.Watch(context.Background(), key)
    for resp := range watchChan {
        for _, ev := range resp.Events {
            onChange(string(ev.Kv.Value))
        }
    }
}
```

### 2.3 配置结构

```go
type Config struct {
    Database DatabaseConfig `json:"database"`
    Redis    RedisConfig    `json:"redis"`
    Server   ServerConfig   `json:"server"`
}

func LoadConfig(client *clientv3.Client, key string) (*Config, error) {
    value, err := GetConfig(client, key)
    if err != nil {
        return nil, err
    }
    var cfg Config
    if err := json.Unmarshal([]byte(value), &cfg); err != nil {
        return nil, err
    }
    return &cfg, nil
}
```

## 三、Nacos 配置中心

### 3.1 客户端初始化

```go
import "github.com/nacos-group/nacos-sdk-go/clients/config_client"

func NewNacosClient() (config_client.IConfigClient, error) {
    return clients.NewConfigClient(vo.NacosClientParam{
        ServerConfigs: []constant.ServerConfig{
            {IpAddr: "127.0.0.1", Port: 8848},
        },
    })
}
```

### 3.2 获取配置

```go
func GetNacosConfig(client config_client.IConfigClient, dataID, group string) (string, error) {
    return client.GetConfig(vo.ConfigParam{
        DataId: dataID,
        Group:  group,
    })
}
```

### 3.3 监听配置

```go
func ListenConfig(client config_client.IConfigClient, dataID, group string, onChange func(content string)) {
    client.ListenConfig(vo.ConfigParam{
        DataId: dataID,
        Group:  group,
        OnChange: func(namespace, group, dataID, data string) {
            onChange(data)
        },
    })
}
```

## 四、Apollo 配置中心

### 4.1 客户端初始化

```go
import "github.com/apolloconfig/agollo/v4"

func InitApollo() {
    c := &config.AppConfig{
        AppID:          "myapp",
        Cluster:        "default",
        IP:             "http://localhost:8080",
        NamespaceName:  "application",
    }
    agollo.SetConfig(c)
    agollo.Start()
}
```

### 4.2 获取配置

```go
func GetApolloConfig(key string) string {
    return agollo.GetStringValue(key, "default")
}
```

### 4.3 监听配置

```go
func ListenApolloConfig(namespace string, onChange func()) {
    agollo.AddChangeListener(&config.ChangeListener{
        OnChange: func(changeEvent *storage.ChangeEvent) {
            onChange()
        },
    })
}
```

## 五、配置热更新

### 5.1 配置管理器

```go
type ConfigManager struct {
    mu     sync.RWMutex
    config *Config
}

func (m *ConfigManager) Get() *Config {
    m.mu.RLock()
    defer m.mu.RUnlock()
    return m.config
}

func (m *ConfigManager) Update(newConfig *Config) {
    m.mu.Lock()
    defer m.mu.Unlock()
    m.config = newConfig
}
```

### 5.2 使用示例

```go
var configMgr = &ConfigManager{}

func init() {
    go WatchConfig(etcdClient, "/config/app", func(value string) {
        var cfg Config
        json.Unmarshal([]byte(value), &cfg)
        configMgr.Update(&cfg)
    })
}

func handler(w http.ResponseWriter, r *http.Request) {
    cfg := configMgr.Get()
}
```
