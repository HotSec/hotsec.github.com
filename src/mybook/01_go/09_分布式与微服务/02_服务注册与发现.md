# 服务注册与发现

服务注册与发现是微服务架构的核心组件，用于动态管理服务实例。

---

## 一、基本概念

### 1.1 服务注册

服务启动时向注册中心注册自己的信息：
- 服务名称
- IP 地址
- 端口号
- 元数据

### 1.2 服务发现

服务消费者从注册中心获取服务提供者的地址列表。

### 1.3 健康检查

注册中心定期检查服务实例的健康状态，剔除不健康的实例。

---

## 二、常见注册中心

| 注册中心 | 特点 |
|---------|------|
| etcd | 强一致性，K8s 默认 |

## 三、etcd 服务注册发现

### 3.1 服务注册

```go
import (
    "go.etcd.io/etcd/client/v3"
    "go.etcd.io/etcd/client/v3/concurrency"
)

func Register(etcdClient *clientv3.Client, serviceName, addr string, ttl int64) error {
    session, err := concurrency.NewSession(etcdClient,
        concurrency.WithTTL(int(ttl)))
    if err != nil {
        return err
    }

    key := fmt.Sprintf("/services/%s/%s", serviceName, addr)
    _, err = etcdClient.Put(context.Background(), key, addr,
        clientv3.WithLease(session.Lease()))
    return err
}
```

### 3.2 服务发现

```go
func Discover(etcdClient *clientv3.Client, serviceName string) ([]string, error) {
    prefix := fmt.Sprintf("/services/%s/", serviceName)
    resp, err := etcdClient.Get(context.Background(), prefix,
        clientv3.WithPrefix())
    if err != nil {
        return nil, err
    }

    var addrs []string
    for _, kv := range resp.Kvs {
        addrs = append(addrs, string(kv.Value))
    }
    return addrs, nil
}
```

### 3.3 Watch 变化

```go
func Watch(etcdClient *clientv3.Client, serviceName string) {
    prefix := fmt.Sprintf("/services/%s/", serviceName)
    watchChan := etcdClient.Watch(context.Background(), prefix,
        clientv3.WithPrefix())

    for resp := range watchChan {
        for _, ev := range resp.Events {
            switch ev.Type {
            case clientv3.EventTypePut:
                fmt.Printf("Service added: %s\n", ev.Kv.Value)
            case clientv3.EventTypeDelete:
                fmt.Printf("Service removed: %s\n", ev.Kv.Key)
            }
        }
    }
}
```

## 四、Consul 服务注册发现

### 4.1 服务注册

```go
import "github.com/hashicorp/consul/api"

func Register(consulAddr, serviceName, serviceAddr string, port int) error {
    config := api.DefaultConfig()
    config.Address = consulAddr
    client, err := api.NewClient(config)
    if err != nil {
        return err
    }

    registration := &api.AgentServiceRegistration{
        ID:      fmt.Sprintf("%s-%s", serviceName, serviceAddr),
        Name:    serviceName,
        Address: serviceAddr,
        Port:    port,
        Check: &api.AgentServiceCheck{
            HTTP:     fmt.Sprintf("http://%s:%d/health", serviceAddr, port),
            Interval: "10s",
            Timeout:  "5s",
        },
    }

    return client.Agent().ServiceRegister(registration)
}
```

### 4.2 服务发现

```go
func Discover(consulAddr, serviceName string) ([]string, error) {
    config := api.DefaultConfig()
    config.Address = consulAddr
    client, err := api.NewClient(config)
    if err != nil {
        return nil, err
    }

    services, _, err := client.Health().Service(serviceName, "", true, nil)
    if err != nil {
        return nil, err
    }

    var addrs []string
    for _, service := range services {
        addr := fmt.Sprintf("%s:%d", service.Service.Address, service.Service.Port)
        addrs = append(addrs, addr)
    }
    return addrs, nil
}
```

## 五、gRPC 服务发现集成

### 5.1 自定义 Resolver

```go
import (
    "google.golang.org/grpc"
    "google.golang.org/grpc/resolver"
)

type etcdResolver struct {
    client *clientv3.Client
    target resolver.Target
    cc     resolver.ClientConn
}

func (r *etcdResolver) ResolveNow(resolver.ResolveNowOptions) {}

func (r *etcdResolver) Close() {}

func (r *etcdResolver) start() {
    prefix := fmt.Sprintf("/services/%s/", r.target.Endpoint())
    resp, _ := r.client.Get(context.Background(), prefix, clientv3.WithPrefix())

    var addrs []resolver.Address
    for _, kv := range resp.Kvs {
        addrs = append(addrs, resolver.Address{Addr: string(kv.Value)})
    }
    r.cc.UpdateState(resolver.State{Addresses: addrs})

    go r.watch(prefix)
}

func (r *etcdResolver) watch(prefix string) {
    watchChan := r.client.Watch(context.Background(), prefix, clientv3.WithPrefix())
    for resp := range watchChan {
        var addrs []resolver.Address
        for _, ev := range resp.Events {
            if ev.Type == clientv3.EventTypePut {
                addrs = append(addrs, resolver.Address{Addr: string(ev.Kv.Value)})
            }
        }
        if len(addrs) > 0 {
            r.cc.UpdateState(resolver.State{Addresses: addrs})
        }
    }
}
```
