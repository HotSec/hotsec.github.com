# 交叉编译与构建优化

Go 支持轻松交叉编译到不同平台，并提供多种构建优化手段。

---

## 一、交叉编译

### 1.1 基本命令

```bash
GOOS=linux GOARCH=amd64 go build -o app_linux
GOOS=windows GOARCH=amd64 go build -o app.exe
GOOS=darwin GOARCH=arm64 go build -o app_mac
```

### 1.2 常见平台组合

| GOOS | GOARCH | 说明 |
|------|--------|------|
| linux | amd64 | Linux 64位 |
| linux | arm64 | Linux ARM64 |
| windows | amd64 | Windows 64位 |
| darwin | amd64 | macOS Intel |
| darwin | arm64 | macOS Apple Silicon |

### 1.3 查看支持的平台

```bash
go tool dist list
```

## 二、CGO 交叉编译

### 2.1 禁用 CGO

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build
```

- 禁用 CGO 可简化交叉编译
- 生成静态链接二进制

### 2.2 使用 CGO 交叉编译

```bash
CC=x86_64-linux-musl-gcc CGO_ENABLED=1 GOOS=linux GOARCH=amd64 go build
```

- 需要对应平台的 C 编译器
- 使用 musl 可生成静态二进制

## 三、构建优化

### 3.1 减小二进制大小

```bash
go build -ldflags="-s -w" -o app
```

- `-s`：去除符号表
- `-w`：去除 DWARF 调试信息

### 3.2 UPX 压缩

```bash
upx --best app
```

- 进一步压缩二进制
- 启动时解压，略微影响启动速度

### 3.3 构建模式

```bash
go build -buildmode=exe
go build -buildmode=c-shared -o lib.so
go build -buildmode=plugin -o plugin.so
```

### 3.4 修剪未使用代码

```bash
go build -trimpath
```

- 去除文件系统路径信息
- 使构建可复现

## 五、构建信息注入

### 5.1 注入版本信息

```bash
go build -ldflags="-X main.Version=1.0.0 -X main.BuildTime=$(date +%Y-%m-%d)"
```

```go
var (
    Version   string
    BuildTime string
)

func main() {
    fmt.Printf("Version: %s, Built: %s\n", Version, BuildTime)
}
```

### 5.2 完整构建脚本

```bash
#!/bin/bash

VERSION=$(git describe --tags --always)
BUILD_TIME=$(date -u '+%Y-%m-%d_%H:%M:%S')
GIT_COMMIT=$(git rev-parse --short HEAD)

LDFLAGS="-s -w \
    -X main.Version=${VERSION} \
    -X main.BuildTime=${BUILD_TIME} \
    -X main.GitCommit=${GIT_COMMIT}"

go build -trimpath -ldflags="${LDFLAGS}" -o app
```

## 六、多平台构建

### 6.1 Makefile

```makefile
BINARY_NAME=myapp
VERSION=$(shell git describe --tags --always)

build:
	go build -o $(BINARY_NAME)

build-linux:
	GOOS=linux GOARCH=amd64 go build -o $(BINARY_NAME)-linux

build-windows:
	GOOS=windows GOARCH=amd64 go build -o $(BINARY_NAME).exe

build-darwin:
	GOOS=darwin GOARCH=arm64 go build -o $(BINARY_NAME)-darwin

build-all: build-linux build-windows build-darwin

docker-build:
	docker build -t $(BINARY_NAME):$(VERSION) .

clean:
	go clean
	rm -f $(BINARY_NAME)*
```

### 6.2 Goreleaser

```yaml
project_name: myapp

builds:
  - env:
      - CGO_ENABLED=0
    goos:
      - linux
      - windows
      - darwin
    goarch:
      - amd64
      - arm64
    ldflags:
      - -s -w -X main.Version={{.Version}}

archives:
  - format: tar.gz
    name_template: "{{ .ProjectName }}_{{ .Version }}_{{ .Os }}_{{ .Arch }}"
```

## 七、Docker 多阶段构建

```dockerfile
FROM golang:1.21-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o app

FROM alpine:latest

RUN apk --no-cache add ca-certificates
WORKDIR /root/

COPY --from=builder /app/app .
COPY --from=builder /app/config ./config

EXPOSE 8080
CMD ["./app"]
```
