# 常见安全漏洞与防护

Web 应用常见的安全漏洞及 Go 语言中的防护措施。

---

## 一、SQL 注入

### 1.1 漏洞示例

```go
func getUser(db *sql.DB, username string) (*User, error) {
    query := fmt.Sprintf("SELECT * FROM users WHERE username = '%s'", username)
    rows, _ := db.Query(query)
}
```

攻击输入：`' OR '1'='1`

### 1.2 防护措施

```go
func getUser(db *sql.DB, username string) (*User, error) {
    query := "SELECT * FROM users WHERE username = ?"
    rows, _ := db.Query(query, username)
}
```

- 使用参数化查询
- 使用 ORM（GORM 自动转义）

## 二、XSS（跨站脚本攻击）

### 2.1 漏洞示例

```go
func handler(w http.ResponseWriter, r *http.Request) {
    name := r.URL.Query().Get("name")
    fmt.Fprintf(w, "Hello, %s!", name)
}
```

攻击输入：`<script>alert('XSS')</script>`

### 2.2 防护措施

```go
import "html"

func handler(w http.ResponseWriter, r *http.Request) {
    name := r.URL.Query().Get("name")
    fmt.Fprintf(w, "Hello, %s!", html.EscapeString(name))
}
```

- 使用 `html.EscapeString` 转义
- 设置 Content-Security-Policy 头

```go
w.Header().Set("Content-Security-Policy", "default-src 'self'")
```

## 三、CSRF（跨站请求伪造）

### 3.1 防护措施

```go
import "github.com/utrack/gin-csrf"

func main() {
    r := gin.Default()
    r.Use(csrf.Middleware(csrf.Options{
        Secret: "csrf-secret",
        ErrorFunc: func(c *gin.Context) {
            c.String(400, "CSRF token mismatch")
            c.Abort()
        },
    }))

    r.POST("/transfer", func(c *gin.Context) {
        c.String(200, "OK")
    })
}
```

- 使用 CSRF Token
- 验证 Referer 头
- SameSite Cookie 属性

```go
http.SetCookie(w, &http.Cookie{
    Name:     "session",
    Value:    token,
    SameSite: http.SameSiteStrictMode,
})
```

## 四、命令注入

### 4.1 漏洞示例

```go
func listFiles(dir string) ([]byte, error) {
    cmd := exec.Command("ls", dir)
    return cmd.Output()
}
```

攻击输入：`; rm -rf /`

### 4.2 防护措施

```go
func listFiles(dir string) ([]byte, error) {
    dir = filepath.Clean(dir)
    if !strings.HasPrefix(dir, "/safe/dir/") {
        return nil, errors.New("invalid path")
    }
    cmd := exec.Command("ls", dir)
    return cmd.Output()
}
```

- 验证输入
- 使用白名单
- 避免拼接命令

## 五、路径遍历

### 5.1 漏洞示例

```go
func readFile(filename string) ([]byte, error) {
    return os.ReadFile("/app/files/" + filename)
}
```

攻击输入：`../../../etc/passwd`

### 5.2 防护措施

```go
func readFile(filename string) ([]byte, error) {
    baseDir := "/app/files/"
    fullPath := filepath.Join(baseDir, filename)
    fullPath = filepath.Clean(fullPath)

    if !strings.HasPrefix(fullPath, baseDir) {
        return nil, errors.New("invalid path")
    }

    return os.ReadFile(fullPath)
}
```

## 六、敏感信息泄露

### 6.1 常见问题

- 错误信息包含敏感数据
- 日志记录敏感信息
- 配置文件明文存储

### 6.2 防护措施

```go
func handler(w http.ResponseWriter, r *http.Request) {
    err := doSomething()
    if err != nil {
        log.Printf("Error: %v", err)
        http.Error(w, "Internal Server Error", 500)
    }
}
```

- 错误信息不暴露细节
- 敏感数据加密存储
- 使用环境变量存储密钥

## 七、不安全的反序列化

### 7.1 漏洞示例

```go
import "encoding/json"

func process(data []byte) {
    var v any
    json.Unmarshal(data, &v)
}
```

### 7.2 防护措施

```go
type Request struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

func process(data []byte) error {
    var req Request
    if err := json.Unmarshal(data, &req); err != nil {
        return err
    }
    return nil
}
```

- 使用强类型结构体
- 验证输入数据

## 八、安全头设置

```go
func SecurityHeaders(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        w.Header().Set("X-Content-Type-Options", "nosniff")
        w.Header().Set("X-Frame-Options", "DENY")
        w.Header().Set("X-XSS-Protection", "1; mode=block")
        w.Header().Set("Strict-Transport-Security", "max-age=31536000; includeSubDomains")
        w.Header().Set("Content-Security-Policy", "default-src 'self'")
        next.ServeHTTP(w, r)
    })
}
```
