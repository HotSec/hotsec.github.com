# 监控系统集成

## Pika Monitor

基于 Prometheus + Grafana 的监控方案。

### 架构

```
应用 → Prometheus（采集） → Grafana（展示） → Alertmanager（告警）
```

### 核心指标

| 类型 | 指标 |
|------|------|
| 系统 | CPU / 内存 / 磁盘 / 网络 |
| 应用 | QPS / 延迟 / 错误率 / 并发数 |
| 业务 | 订单量 / 注册数 / 支付成功率 |
| 中间件 | Redis / MySQL / Kafka 状态 |

### Prometheus 配置

```yaml
scrape_configs:
  - job_name: "app"
    static_configs:
      - targets: ["localhost:8080"]
```

### Grafana 面板

- RED 方法：Rate（请求速率）/ Errors（错误率）/ Duration（延迟）
- USE 方法：Utilization（利用率）/ Saturation（饱和度）/ Errors（错误）
- 黄金信号：延迟 / 流量 / 错误 / 饱和度

### 告警规则

```yaml
groups:
  - name: app_alerts
    rules:
      - alert: HighErrorRate
        expr: rate(http_errors_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
```
