# 信息系统架构

## 面向服务架构（SOA）

### 核心概念

- 服务：自包含、自描述的业务功能单元
- 服务契约：接口定义（WSDL/IDL）
- 松耦合：服务间依赖最小化
- 可组合：服务可编排为业务流程

### ESB（企业服务总线）

- 消息路由与转换
- 协议适配
- 消息增强
- 服务编排

### EDA（事件驱动架构）

- 事件生产者 → 事件通道 → 事件消费者
- 异步解耦
- 事件溯源（Event Sourcing）

## 层次式架构

### 表现层

- UI 渲染
- 用户交互
- 输入验证

### 业务层

- 业务逻辑
- 业务规则
- 工作流编排

### 数据访问层

- ORM / 数据映射
- 事务管理
- 缓存策略

## 物联网架构

### 感知层

- 传感器：温度/湿度/光照/加速度
- 执行器：继电器/电机/阀门
- 通信协议：ZigBee / BLE / LoRa / NB-IoT

### 网络层

- 网关：协议转换、数据聚合
- MQTT：轻量级发布/订阅消息协议
  - QoS 0：至多一次
  - QoS 1：至少一次
  - QoS 2：恰好一次
- CoAP：受限应用协议

### 平台层

- 设备管理：注册/认证/监控/OTA
- 数据处理：流式/批处理
- 规则引擎：事件触发动作

### 应用层

- 可视化大屏
- 报警通知
- 数据分析

### 边缘计算

- 本地数据处理，降低延迟
- 断网自治
- 边云协同

## 大型网站系统架构实例

- 淘宝：微服务 + 中台 + 单元化架构
- 微信：SET 模型 + 异地多活
- Netflix：微服务 + Chaos Engineering

## C/S 与 B/S 架构

| 特性 | C/S（客户端/服务器） | B/S（浏览器/服务器） |
|------|---------------------|---------------------|
| 客户端 | 需安装专用客户端 | 浏览器即可 |
| 更新 | 需客户端升级 | 服务端更新即可 |
| 性能 | 高（本地计算） | 受网络影响 |
| 跨平台 | 需适配多平台 | 天然跨平台 |
| 安全 | 相对安全 | 需更多防护 |

## 中台架构

### 技术中台

- 通用技术能力沉淀：认证、支付、消息、搜索
- 避免重复造轮子

### 数据中台

- 统一数据标准与口径
- 数据资产化管理
- 数据服务化（OneService）

### 业务中台

- 用户中心、商品中心、订单中心
- 标准化业务能力，前台快速组合

## 中间件

| 中间件 | 作用 | 典型产品 |
|--------|------|----------|
| 消息队列 | 异步解耦、削峰 | Kafka / RabbitMQ |
| 缓存 | 加速读取 | Redis / Memcached |
| 搜索 | 全文检索 | ElasticSearch |
| 配置中心 | 动态配置 | Nacos / Apollo |
| 注册中心 | 服务发现 | etcd / Consul |
| 网关 | 统一入口 | Nginx / APISIX |
| 任务调度 | 定时/分布式任务 | XXL-Job / Elastic-Job |
