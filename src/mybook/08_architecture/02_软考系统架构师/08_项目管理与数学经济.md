## 二、项目立项与可行性分析

### 2.1 经济评价指标

| 指标 | 公式 | 判断标准 | 说明 |
|------|------|----------|------|
| NPV净现值 | $NPV = \sum_{t=0}^{n}\frac{CI_t - CO_t}{(1+i)^t}$ | NPV ≥ 0 可行 | 考虑资金时间价值，越大越好 |
| IRR内部收益率 | 使NPV=0的折现率 | IRR ≥ 基准收益率 可行 | 反映项目内在盈利能力 |
| ROI投资回报率 | $ROI = \frac{总收益 - 总成本}{总成本} \times 100\%$ | ROI越高越好 | 静态指标，未考虑时间价值 |
| 静态投资回收期 | 累计净现金流量首次≥0的年份 | ≤ 基准回收期 可行 | 不考虑时间价值 |
| 动态投资回收期 | 累计折现净现金流量首次≥0的年份 | ≤ 基准回收期 可行 | 考虑时间价值 |

### 2.2 资金时间价值计算

| 类型 | 公式 | 用途 |
|------|------|------|
| 复利终值 | $F = P(1+i)^n$ | 现值求终值 |
| 复利现值 | $P = F(1+i)^{-n}$ | 终值求现值 |
| 年金终值 | $F = A\frac{(1+i)^n - 1}{i}$ | 等额年金求终值 |
| 年金现值 | $P = A\frac{1-(1+i)^{-n}}{i}$ | 等额年金求现值 |

## 四、进度管理

### 4.1 活动排序（四种依赖关系）

| 关系 | 含义 | 示例 |
|------|------|------|
| FS（完成-开始） | 前序完成，后续开始 | 编码完成→测试开始 |
| FF（完成-完成） | 前序完成，后续完成 | 文档编写完成→评审完成 |
| SS（开始-开始） | 前序开始，后续开始 | 基础施工开始→上部施工开始 |
| SF（开始-完成） | 前序开始，后续完成 | 新系统上线→旧系统停用 |

### 4.2 关键路径法（CPM）

- 关键路径：总时差为零（或最小）的路径，决定项目最短工期
- 总时差（TF）= LS - ES = LF - EF
- 自由时差（FF）= min(ES后续) - EF
- 关键路径上活动：ES=LS，EF=LF，总时差=0

| 参数 | 含义 |
|------|------|
| ES | 最早开始时间 |
| EF | 最早完成时间（EF = ES + 工期） |
| LS | 最迟开始时间 |
| LF | 最迟完成时间（LS = LF - 工期） |

### 4.3 PERT三点估算

$$T_E = \frac{T_O + 4T_M + T_T}{6}$$

$$\sigma = \frac{T_T - T_O}{6}$$

| 符号 | 含义 |
|------|------|
| $T_O$ | 乐观时间 |
| $T_M$ | 最可能时间 |
| $T_T$ | 悲观时间 |
| $T_E$ | 期望时间 |
| $\sigma$ | 标准差 |

## 五、成本管理

### 5.1 挣值分析（EVA）核心公式

| 指标 | 公式 | 含义 | 判断标准 |
|------|------|------|----------|
| PV | 计划价值 | 截至某时点计划完成工作的预算 | 基准 |
| EV | 挣值 | 截至某时点实际完成工作的预算 | 实际进度 |
| AC | 实际成本 | 截至某时点实际花费 | 实际花费 |
| SV | EV - PV | 进度偏差 | >0 进度超前 |
| CV | EV - AC | 成本偏差 | >0 成本节约 |
| SPI | EV / PV | 进度绩效指数 | >1 进度超前 |
| CPI | EV / AC | 成本绩效指数 | >1 成本节约 |

### 5.2 预测指标

| 指标 | 公式 | 含义 |
|------|------|------|
| BAC | 完工预算 | 项目总预算 |
| EAC（典型偏差） | BAC / CPI | 假设偏差持续 |
| EAC（非典型偏差） | AC + (BAC - EV) | 假设偏差不持续 |
| ETC | EAC - AC | 完工尚需估算 |
| TCPI | (BAC - EV) / (BAC - AC) | 完工绩效指数 |

### 5.3 成本估算方法

| 方法 | 特点 | 适用场景 |
|------|------|----------|
| 类比估算 | 自上而下，基于历史数据，精度低 | 项目早期 |
| 参数估算 | 基于统计关系模型，精度中等 | 有历史参数时 |
| 自下而上估算 | 逐项汇总，精度高但耗时 | WBS已明确时 |
| 三点估算 | 考虑不确定性 | 风险较高时 |

## 十、运筹学

### 10.1 线性规划

- 标准形式：求目标函数 max/min，满足约束条件（等式/不等式）
- 单纯形法：从可行域顶点逐步迭代寻优
  - 基本可行解 → 最优性检验 → 换基迭代
  - 最优性判断：所有检验数 ≤ 0（求max时）
- 对偶理论：
  - 原问题与对偶问题互为对偶
  - 弱对偶性：对偶问题目标值是原问题上/下界
  - 强对偶性：若原问题有最优解，对偶问题也有最优解且目标值相等
  - 对偶单纯形法：保持最优性，逐步满足可行性

### 10.2 运输问题

- 供需平衡运输问题：总供给 = 总需求
- 初始解方法：最小元素法、伏格尔法（Vogel）
- 最优性检验：闭回路法、位势法
- 调运方案改进：闭回路调整

### 10.3 指派问题（匈牙利法）

- 目标：n个人分配n项任务，总成本最小
- 匈牙利法步骤：
  1. 行变换：每行减去该行最小元素
  2. 列变换：每列减去该列最小元素
  3. 找独立零元素，若个数为n则得最优解
  4. 否则用最小直线覆盖所有零元素，调整矩阵重复步骤3

## 十一、图论

### 11.1 最小生成树

| 算法 | 策略 | 时间复杂度 | 适用 |
|------|------|------------|------|
| Prim | 从顶点扩展，选最近邻接边 | O(V²) | 稠密图 |
| Kruskal | 按边权排序，依次选不构成回路的边 | O(E log E) | 稀疏图 |

### 11.2 最短路径

| 算法 | 类型 | 特点 | 时间复杂度 |
|------|------|------|------------|
| Dijkstra | 单源最短路径 | 不支持负权边 | O(V²)或O(E+V log V) |
| Floyd | 所有顶点对最短路径 | 支持负权边（无负权回路） | O(V³) |
| Bellman-Ford | 单源最短路径 | 支持负权边，可检测负权回路 | O(VE) |

### 11.3 最大流与最小割

- 最大流最小割定理：最大流量 = 最小割容量
- Ford-Fulkerson方法：通过增广路径逐步增加流量
- 割：将顶点集分为S和T两部分，割容量 = 从S到T的边容量之和

### 11.4 关键路径（图论视角）

- AOE网：顶点表示事件，边表示活动
- 关键活动：最早开始时间 = 最迟开始时间的活动
- 关键路径：由关键活动组成的路径，长度为项目最短工期

## 十二、排队论

### 12.1 基本模型

| 模型 | 含义 | 到达 | 服务 | 服务台 |
|------|------|------|------|--------|
| M/M/1 | 单服务台排队 | 泊松 | 指数 | 1 |
| M/M/c | 多服务台排队 | 泊松 | 指数 | c |

### 12.2 M/M/1 关键公式

| 指标 | 公式 |
|------|------|
| 系统利用率 | $\rho = \lambda / \mu$ |
| 系统中平均顾客数 | $L_s = \rho / (1 - \rho)$ |
| 队列中平均等待顾客数 | $L_q = \rho^2 / (1 - \rho)$ |
| 系统中平均逗留时间 | $W_s = 1 / (\mu - \lambda)$ |
| 队列中平均等待时间 | $W_q = \rho / (\mu - \lambda)$ |

- $\lambda$：到达率，$\mu$：服务率
- 稳态条件：$\rho = \lambda / \mu < 1$

### 12.3 M/M/c 关键公式

| 指标 | 公式 |
|------|------|
| 系统利用率 | $\rho = \lambda / (c\mu)$ |
| 无顾客概率 | $P_0$ 由公式计算 |
| 队列中平均等待数 | $L_q = P_0 \frac{(c\rho)^c \rho}{c!(1-\rho)^2}$ |

- 稳态条件：$\rho = \lambda / (c\mu) < 1$

## 十三、概率与统计

### 13.1 条件概率与贝叶斯公式

| 公式 | 表达式 |
|------|--------|
| 条件概率 | $P(A|B) = P(AB) / P(B)$ |
| 全概率公式 | $P(B) = \sum P(B|A_i)P(A_i)$ |
| 贝叶斯公式 | $P(A_i|B) = \frac{P(B|A_i)P(A_i)}{\sum P(B|A_j)P(A_j)}$ |

### 13.2 正态分布

- 概率密度：$f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$
- 标准正态分布：$\mu=0, \sigma=1$

| 区间 | 概率 |
|------|------|
| $\mu \pm 1\sigma$ | 68.27% |
| $\mu \pm 2\sigma$ | 95.45% |
| $\mu \pm 3\sigma$ | 99.73% |

### 13.3 期望与方差

| 指标 | 离散型 | 连续型 |
|------|--------|--------|
| 期望 | $E(X) = \sum x_i p_i$ | $E(X) = \int xf(x)dx$ |
| 方差 | $D(X) = E(X^2) - [E(X)]^2$ | $D(X) = E(X^2) - [E(X)]^2$ |
| 标准差 | $\sigma = \sqrt{D(X)}$ | $\sigma = \sqrt{D(X)}$ |

## 十五、系统可靠性

### 15.1 可靠度计算

| 模型 | 可靠度公式 | 说明 |
|------|------------|------|
| 串联系统 | $R = \prod_{i=1}^{n} R_i$ | 任一失效则系统失效 |
| 并联系统 | $R = 1 - \prod_{i=1}^{n}(1 - R_i)$ | 全部失效系统才失效 |
| 混联系统 | 先局部后整体 | 分解为串并联子结构 |

### 15.2 可靠性指标关系

| 指标 | 含义 | 关系 |
|------|------|------|
| MTBF | 平均无故障时间（两次故障间） | MTBF = MTTF + MTTR |
| MTTF | 平均故障前时间（不可修复） | 不可修复系统的寿命 |
| MTTR | 平均修复时间 | 故障到恢复的时间 |
| 失效率 $\lambda$ | 单位时间故障概率 | MTBF = 1/$\lambda$（指数分布） |

### 15.3 浴盆曲线

| 阶段 | 特征 | 原因 |
|------|------|------|
| 早期故障期 | 失效率递减 | 制造缺陷、工艺问题 |
| 偶然故障期 | 失效率恒定（最低） | 随机因素 |
| 耗损故障期 | 失效率递增 | 老化、磨损 |

## 十八、关键路径法CPM详解

### 18.1 正推法（计算ES/EF）

- 起始活动ES=0
- EF = ES + 工期
- 后续活动ES = max(所有前序活动EF)
- 从左向右依次计算

### 18.2 逆推法（计算LS/LF）

- 终点活动LF = 项目总工期
- LS = LF - 工期
- 前序活动LF = min(所有后续活动LS)
- 从右向左依次计算

### 18.3 浮动时间

| 类型 | 公式 | 含义 |
|------|------|------|
| 总浮动时间TF | TF = LS - ES = LF - EF | 活动可延迟而不影响项目总工期的最大时间 |
| 自由浮动时间FF | FF = min(ES后继) - EF | 活动可延迟而不影响任何后续活动最早开始的时间 |

### 18.4 关键路径判定

- 关键路径上所有活动TF=0
- 关键路径是项目最短工期
- 一个项目可能有多条关键路径
- 关键路径上的活动不能延迟

### 18.5 计算示例

某项目活动如下：

| 活动 | 前序 | 工期 |
|------|------|------|
| A | — | 3 |
| B | — | 2 |
| C | A | 4 |
| D | A,B | 3 |
| E | C,D | 2 |

正推结果：

| 活动 | ES | EF |
|------|----|----|
| A | 0 | 3 |
| B | 0 | 2 |
| C | 3 | 7 |
| D | 3 | 6 |
| E | 7 | 9 |

逆推结果：

| 活动 | LS | LF | TF |
|------|----|----|-----|
| A | 0 | 3 | 0 |
| B | 1 | 3 | 1 |
| C | 3 | 7 | 0 |
| D | 4 | 7 | 1 |
| E | 7 | 9 | 0 |

关键路径：A→C→E，总工期=9

1. 行变换：每行各元素减去该行最小元素
2. 列变换：每列各元素减去该列最小元素
3. 找独立零元素（每行每列最多一个），若个数=n则得最优解
4. 否则用最少直线覆盖所有零元素
5. 找未被覆盖元素中的最小值，未覆盖行减去该值，交叉列加上该值
6. 重复步骤3~5直到找到n个独立零元素

## 二十二、图论补充

### 22.1 AOE网关键概念

| 概念 | 含义 |
|------|------|
| 事件最早发生时间Ve | 从源点到该事件的最长路径长度 |
| 事件最迟发生时间Vl | 不影响总工期的前提下事件最迟发生时间 |
| 活动最早开始时间e | 活动弧尾事件的Ve |
| 活动最迟开始时间l | 活动弧头事件的Vl减去活动持续时间 |

### 22.2 AOE网计算步骤

**正推求Ve：**

- 源点Ve=0
- Ve(j) = max{Ve(i) + dut(i,j)}，其中i是j的所有前序事件

**逆推求Vl：**

- 汇点Vl = Ve（汇点最早发生时间=最迟发生时间=总工期）
- Vl(i) = min{Vl(j) - dut(i,j)}，其中j是i的所有后续事件

**计算活动时间：**

- e(i→j) = Ve(i)
- l(i→j) = Vl(j) - dut(i,j)

### 22.3 关键活动与关键路径

- 关键活动：l = e 的活动（最迟开始时间=最早开始时间，无机动时间）
- 关键路径：由关键活动组成的路径
- 总工期 = 汇点的Ve
- 活动机动时间 = l - e

### 22.4 计算示例

某AOE网：

| 活动 | 前序事件 | 后续事件 | 持续时间 |
|------|----------|----------|----------|
| a1 | V1 | V2 | 3 |
| a2 | V1 | V3 | 2 |
| a3 | V2 | V4 | 4 |
| a4 | V3 | V4 | 3 |
| a5 | V4 | V5 | 2 |

Ve计算：Ve(V1)=0, Ve(V2)=3, Ve(V3)=2, Ve(V4)=7, Ve(V5)=9

Vl计算：Vl(V5)=9, Vl(V4)=7, Vl(V3)=4, Vl(V2)=3, Vl(V1)=0

| 活动 | e | l | l-e | 是否关键 |
|------|---|---|-----|----------|
| a1 | 0 | 0 | 0 | 是 |
| a2 | 0 | 2 | 2 | 否 |
| a3 | 3 | 3 | 0 | 是 |
| a4 | 2 | 4 | 2 | 否 |
| a5 | 7 | 7 | 0 | 是 |

关键路径：V1→V2→V4→V5（a1→a3→a5），总工期=9

## 二十三、系统可靠性补充

### 23.1 表决系统（k/n系统）

- n个部件中至少k个正常工作，系统才正常
- 各部件可靠度均为R时：

$$R_{k/n} = \sum_{i=k}^{n} C(n,i) R^i (1-R)^{n-i}$$

- 常见特例：3/2表决系统（三取二），至少2个正常则系统正常

$$R_{2/3} = C(3,2)R^2(1-R) + C(3,3)R^3 = 3R^2(1-R) + R^3 = 3R^2 - 2R^3$$

### 23.2 冷备系统

- 一个部件工作，其余部件不工作不老化
- 工作部件故障时，切换到备用部件
- n个相同部件冷备系统可靠度：

$$R(t) = e^{-\lambda t} \sum_{i=0}^{n-1} \frac{(\lambda t)^i}{i!}$$

- 冷备系统可靠度高于热备（备用部件不损耗）

### 23.3 热备系统

- 所有部件同时工作，但只需部分部件正常即可
- 等同于并联系统
- n个相同部件热备系统可靠度：

$$R(t) = 1 - (1 - e^{-\lambda t})^n$$

### 23.4 冷备vs热备对比

| 对比项 | 冷备系统 | 热备系统 |
|--------|----------|----------|
| 备用部件状态 | 不工作 | 同时工作 |
| 备用部件损耗 | 无损耗 | 有损耗 |
| 切换时间 | 需要切换时间 | 无需切换 |
| 可靠度 | 更高 | 较低 |
| 响应速度 | 较慢（需切换） | 即时 |

## 二十四、决策论补充

### 24.1 决策树画法

1. 绘制决策点（方框□），引出方案分支
2. 绘制机会点（圆圈○），引出状态分支，标注概率
3. 在状态分支末端标注收益值
4. 从右向左计算各机会点期望值
5. 在决策点选择期望值最大的方案
6. 剪掉非最优方案（标记//）

### 24.2 贝叶斯决策

- 利用贝叶斯公式，根据新的观测信息修正先验概率
- 步骤：
  1. 确定先验概率P(Si)
  2. 确定条件概率P(X|Si)（在状态Si下观测到X的概率）
  3. 用贝叶斯公式计算后验概率P(Si|X)
  4. 基于后验概率计算各方案期望收益
  5. 选择期望收益最大的方案

$$P(S_i|X) = \frac{P(X|S_i) \cdot P(S_i)}{\sum_j P(X|S_j) \cdot P(S_j)}$$

### 24.3 多目标决策

| 方法 | 说明 |
|------|------|
| 加权求和法 | 各目标乘以权重后求和，权重之和=1 |
| 理想点法 | 找各目标最优值构成理想点，选距理想点最近的方案 |
| 层次分析法（AHP） | 构建层次结构，两两比较判断矩阵，计算权重 |
| 目标规划法 | 设定各目标期望值，最小化偏差 |
| 劣解淘汰法 | 淘汰被支配的方案，保留Pareto最优解 |
