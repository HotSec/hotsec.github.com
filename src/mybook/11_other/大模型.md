# 大模型

## LangChain 生态

6 大核心组件：

- **Model I/O**：LLM / Chat Model / Prompt Template / Output Parser
- **Data Connection**：Document Loader / Text Splitter / Embedding / Vector Store / Retriever
- **Chains**：Sequential / Router / Transform / LLMChain
- **Memory**：Buffer / Summary / Conversation Buffer Window / Entity
- **Agents**：ReAct / OpenAI Functions / Plan-and-Execute / Self-Ask
- **Callbacks**：Tracing / Logging / Streaming

子项目：langchain-core / langchain-community / langgraph / langserve / LangSmith

## 开发流程

1. 确定目标（解决什么问题）
2. 设计功能（RAG/对话/生成/分析）
3. 搭建架构（数据流/模型选择/部署方案）
4. 建向量数据库（文档切分/Embedding/索引）
5. Prompt Engineering（模板设计/Few-shot/CoT）
6. 验证迭代（Bad Case 分析/指标评估）
7. 前后端搭建（API/界面/集成）
8. 体验优化（延迟/成本/准确性）

## RAG vs 微调

| 维度 | RAG | 微调 |
|------|-----|------|
| 知识更新 | 低成本，更新数据库 | 高成本，需重新训练 |
| 可解释性 | 强（可追溯来源） | 弱 |
| 幻觉控制 | 较好（基于检索内容） | 一般 |
| 定制风格 | 有限 | 强 |
| 计算成本 | 低 | 高 |
| 适用场景 | 知识密集型问答 | 风格/行为定制 |

## 提示词工程

- 设计原则：清晰/具体/分步/给出示例
- 迭代优化：测试→分析 Bad Case→改进模板
- Chain-of-Thought（CoT）：分步推理
- Few-shot：提供示例引导输出格式
- 自我一致性：多次采样取多数

## 推理部署

- **Ollama**：本地部署，`ollama run llama3`
- **vLLM**：高吞吐推理服务，PagedAttention，连续批处理
- **Tensor-Parallel**：多 GPU 并行推理
- **量化**：AWQ / GPTQ / GGUF，降低显存需求

## 工具

- **LiteLLM**：统一多模型 API，100+ 模型，路由/负载均衡/故障转移
- **Continue**：IDE 插件，代码补全+对话
- **Tabby**：自托管代码补全服务

## 评估体系

- **RAGAS**：Faithfulness / Answer Relevancy / Context Precision / Context Recall
- **LLM-as-Judge**：用强模型评估弱模型输出
- **人工评估**：准确性/相关性/流畅性/幻觉率

## Agent 框架

### LangGraph

- 基于图的状态机，构建复杂 Agent 工作流
- 支持循环、分支、并行
- 状态持久化与断点续跑

### CrewAI

- 多 Agent 协作框架
- 角色定义 + 任务分配 + 协作流程

### AutoGen

- 微软开源，多 Agent 对话
- 支持人机协作

### OpenAI Assistants API

- 官方托管 Agent 服务
- 内置 Code Interpreter / File Search / Function Calling

## Function Calling

```python
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "获取指定城市的天气",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "城市名"}
            },
            "required": ["city"]
        }
    }
}]

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "北京天气怎么样"}],
    tools=tools,
)
```

## 成本优化

- 缓存：语义缓存 / 精确缓存
- 路由：简单问题用小模型，复杂问题用大模型
- 量化：GGUF / AWQ / GPTQ 降低推理成本
- 批处理：合并请求降低 API 调用次数
