# Lua 协程

Lua 协程（Coroutine）是协作式多任务的非抢占式线程，由程序员控制切换时机。

## 基础操作

```lua
local co = coroutine.create(function(a, b)
    print("co received:", a, b)
    local c = coroutine.yield(a + b)
    print("co resumed with:", c)
    return c * 2
end)

local ok, val = coroutine.resume(co, 1, 2)
print("first resume:", val)     -- 3

local ok, val = coroutine.resume(co, 10)
print("second resume:", val)    -- 20
```

## 协程状态

| 状态 | 说明 |
|------|------|
| suspended | 挂起，刚创建或 yield 后 |
| running | 正在执行 |
| normal | 恢复了其他协程 |
| dead | 执行完毕或出错 |

```lua
coroutine.status(co)
```

## 核心函数

| 函数 | 说明 |
|------|------|
| `create(f)` | 创建协程，返回 thread 类型 |
| `resume(co, ...)` | 恢复协程，传递参数 |
| `yield(...)` | 挂起协程，返回值给 resume |
| `wrap(f)` | 创建协程，返回可调用函数 |
| `status(co)` | 获取协程状态 |
| `running()` | 获取当前运行的协程 |

## wrap 简化

```lua
local fib = coroutine.wrap(function()
    local a, b = 0, 1
    while true do
        coroutine.yield(a)
        a, b = b, a + b
    end
end)

for i = 1, 10 do
    print(fib())
end
```

## 生产者-消费者

```lua
function producer()
    return coroutine.create(function()
        while true do
            local item = io.read()
            if not item then return end
            coroutine.yield(item)
        end
    end)
end

function consumer(prod)
    while true do
        local _, item = coroutine.resume(prod)
        if not item then break end
        print("consumed:", item)
    end
end

consumer(producer())
```

## 迭代器

```lua
function range(n)
    return coroutine.wrap(function()
        for i = 1, n do
            coroutine.yield(i)
        end
    end)
end

for v in range(5) do
    print(v)
end
```

## 协程与异步

### 异步回调转同步风格

```lua
local function async_read(fd, callback)
    -- 模拟异步读取
    set_timeout(100, function()
        callback("data from " .. fd)
    end)
end

local function sync_read(fd)
    local co = coroutine.running()
    async_read(fd, function(data)
        coroutine.resume(co, data)
    end)
    return coroutine.yield()
end

local data = sync_read("file.txt")
print(data)
```

### OpenResty 中的协程

```nginx
location /api {
    content_by_lua_block {
        local co = ngx.thread.spawn(function()
            local res = ngx.location.capture("/backend")
            return res.body
        end)

        local ok, body = ngx.thread.wait(co)
        ngx.say(body)
    }
}
```

## 错误处理

```lua
local co = coroutine.create(function()
    error("something wrong")
end)

local ok, msg = coroutine.resume(co)
if not ok then
    print("coroutine error:", msg)
end
```

## 协程 vs 线程

| 特性 | 协程 | 线程 |
|------|------|------|
| 调度 | 协作式（程序员控制） | 抢占式（OS调度） |
| 切换开销 | 极低（无上下文切换） | 较高（内核态切换） |
| 并发 | 并发非并行 | 真正并行 |
| 共享状态 | 无需锁 | 需要同步机制 |
| 栈大小 | 按需增长 | 固定大小（通常8MB） |
