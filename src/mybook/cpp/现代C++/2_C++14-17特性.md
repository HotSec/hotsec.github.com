# C++14/17 特性

---

## 一、C++14 特性

### 1.1 泛型 Lambda

```cpp
auto add = [](auto a, auto b) {
    return a + b;
};

add(3, 5);                    // int
add(1.5, 2.5);                // double
add(std::string("a"), std::string("b")); // string
```

### 1.2 Lambda 初始化捕获

```cpp
auto ptr = std::make_unique<int>(42);
auto f = [p = std::move(ptr)]() { return *p; };

// 捕获表达式结果
auto gen = [i = 0]() mutable { return i++; };
```

### 1.3 返回类型推导

```cpp
auto add(int a, int b) {
    return a + b; // 自动推导为 int
}

auto getContainer() {
    return std::vector<int>{1, 2, 3};
}
```

### 1.4 std::make_unique

```cpp
auto p = std::make_unique<int>(42);
auto arr = std::make_unique<int[]>(10);
```

### 1.5 [[deprecated]] 属性

```cpp
[[deprecated("use newFunc() instead")]]
void oldFunc() {}

void newFunc() {}
```

### 1.6 二进制字面量与分隔符

```cpp
int bin = 0b1010'1100;       // 二进制
int hex = 0xFF'FF'FF'FF;     // 分隔符
int dec = 1'000'000;         // 百万
```

## 二、C++17 特性

### 2.1 结构化绑定 ⭐⭐⭐

```cpp
// pair
auto [key, value] = *m.begin();

// tuple
auto [x, y, z] = std::make_tuple(1, 2.0, "hello");

// struct
struct Point { double x, y; };
auto [x, y] = Point{3.14, 2.71};

// 数组
int arr[] = {1, 2, 3};
auto [a, b, c] = arr;

// map 遍历
for (auto& [key, value] : myMap) {
    std::cout << key << ": " << value << "\n";
}
```

### 2.2 if constexpr ⭐⭐⭐

```cpp
template<typename T>
auto length(const T& val) {
    if constexpr (std::is_integral_v<T>) {
        return val;
    } else {
        return val.size();
    }
}

length(42);            // 42
length(std::string("hello")); // 5
```

### 2.3 std::optional

```cpp
#include <optional>

std::optional<int> findUser(const std::string& name) {
    if (auto it = users.find(name); it != users.end()) {
        return it->second;
    }
    return std::nullopt;
}

auto result = findUser("alice");
if (result) {
    std::cout << result.value() << "\n";
}
std::cout << result.value_or(-1) << "\n";
```

### 2.4 std::variant

```cpp
#include <variant>

using Value = std::variant<int, double, std::string>;

Value v = 42;
v = 3.14;
v = "hello";

// 访问
std::visit([](auto&& arg) {
    std::cout << arg << "\n";
}, v);

// 获取值
if (auto pval = std::get_if<int>(&v)) {
    std::cout << *pval << "\n";
}
```

### 2.5 std::any

```cpp
#include <any>

std::any a = 42;
a = 3.14;
a = std::string("hello");

// 获取值
if (auto p = std::any_cast<int>(&a)) {
    std::cout << *p << "\n";
}

try {
    auto val = std::any_cast<double>(a);
} catch (const std::bad_any_cast& e) {
    std::cout << "wrong type\n";
}
```

### 2.6 std::string_view

```cpp
#include <string_view>

// 不拷贝字符串，只持有指针和长度
void print(std::string_view sv) {
    std::cout << sv << "\n";
}

std::string s = "hello";
print(s);             // string → string_view
print("world");       // const char* → string_view
print(s.substr(0, 3)); // 子串视图

// ⚠️ 注意悬空引用
std::string_view danger() {
    std::string s = "temporary";
    return s; // ❌ 悬空！s 析构后 sv 无效
}
```

### 2.7 std::filesystem

```cpp
#include <filesystem>
namespace fs = std::filesystem;

// 路径操作
fs::path p = "/usr/local/bin/app";
p.filename();    // "app"
p.parent_path(); // "/usr/local/bin"
p.extension();   // ""

// 文件操作
fs::exists("/tmp/test.txt");
fs::create_directories("/tmp/a/b/c");
fs::copy_file(src, dst, fs::copy_options::overwrite_existing);
fs::remove("/tmp/test.txt");

// 遍历目录
for (auto& entry : fs::directory_iterator("/tmp")) {
    std::cout << entry.path() << "\n";
}

// 递归遍历
for (auto& entry : fs::recursive_directory_iterator("/tmp")) {
    if (entry.is_regular_file()) {
        std::cout << entry.file_size() << " " << entry.path() << "\n";
    }
}
```

### 2.8 if/switch 初始化

```cpp
// if 初始化
if (auto it = m.find(key); it != m.end()) {
    std::cout << it->second << "\n";
}

// switch 初始化
switch (auto val = getValue(); val) {
    case 1: break;
    case 2: break;
}
```

### 2.9 折叠表达式

```cpp
// 一元右折叠
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);
}
sum(1, 2, 3, 4, 5); // 15

// 一元左折叠
template<typename... Args>
auto product(Args... args) {
    return (... * args);
}

// 打印
template<typename... Args>
void print(Args... args) {
    ((std::cout << args << " "), ...);
    std::cout << "\n";
}
```

### 2.10 并行 STL

```cpp
#include <execution>

std::vector<int> v(1'000'000);

// 并行排序
std::sort(std::execution::par, v.begin(), v.end());

// 并行遍历
std::for_each(std::execution::par, v.begin(), v.end(), [](int& x) {
    x *= 2;
});

// 并行规约
auto sum = std::reduce(std::execution::par, v.begin(), v.end(), 0);

// 执行策略
// std::execution::seq     - 顺序执行
// std::execution::par     - 并行执行
// std::execution::par_unseq - 并行+向量化
```
