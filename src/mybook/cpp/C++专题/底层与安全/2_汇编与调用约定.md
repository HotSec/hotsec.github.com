# 汇编与调用约定

## 内联汇编

### GCC 内联汇编

```cpp
int a = 10, b = 20, result;
asm ("addl %1, %2"
     : "=r" (result)
     : "r" (a), "0" (b));
```

格式：`asm(汇编模板 : 输出操作数 : 输入操作数 : 修改寄存器)`

### 常见 x86-64 指令

| 指令 | 说明 |
|------|------|
| mov | 数据传送 |
| push/pop | 栈操作 |
| add/sub/imul | 算术运算 |
| and/or/xor | 位运算 |
| cmp/test | 比较/测试 |
| jmp/je/jne/jl/jg | 跳转 |
| call/ret | 函数调用/返回 |

## 调用约定

### cdecl（C 默认）

- 参数从右到左压栈
- 调用者清理栈
- 返回值在 eax/rax

### stdcall（Windows API）

- 参数从右到左压栈
- 被调用者清理栈
- 函数名修饰：`_func@N`

### fastcall

- 前两个参数通过 ecx/edx 传递
- 其余参数压栈
- 被调用者清理栈

### x86-64 System V ABI（Linux/macOS）

- 整数参数：rdi/rsi/rdx/rcx/r8/r9
- 浮点参数：xmm0-xmm7
- 返回值：rax（整数）/ xmm0（浮点）
- 调用者保存：rax/rcx/rdx/rsi/rdi/r8-r11
- 被调用者保存：rbx/rbp/r12-r15

### x86-64 Microsoft ABI（Windows）

- 整数参数：rcx/rdx/r8/r9
- 浮点参数：xmm0-xmm3
- 调用者预留 32 字节影子空间

## 函数名修饰规则

### C 编译器

- cdecl：`_func`
- stdcall：`_func@N`（N 为参数字节数）

### C++ 编译器（Name Mangling）

```cpp
int foo(int)       → _Z3fooi
int foo(double)    → _Z3food
void bar(int,int)  → _Z3barii
```

- 解修饰：`c++filt _Z3fooi` → `foo(int)`
- C 链接：`extern "C"` 禁用修饰
