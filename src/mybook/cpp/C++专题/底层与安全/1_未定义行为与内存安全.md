# 未定义行为与内存安全

## 常见未定义行为（UB）

### 悬空指针（Dangling Pointer）

```cpp
int* p = new int(42);
delete p;
*p = 10;
```

释放后访问，行为未定义。

### 越界访问

```cpp
int arr[5];
arr[10] = 0;
```

### 有符号整数溢出

```cpp
int x = INT_MAX;
x += 1;
```

### 空指针解引用

```cpp
int* p = nullptr;
*p = 42;
```

### 数据竞争

```cpp
int counter = 0;
// 线程1: counter++;
// 线程2: counter++;  // 无同步，UB
```

### 未初始化变量

```cpp
int x;
std::cout << x;
```

## 消毒器（Sanitizers）

### ASan（Address Sanitizer）

检测：堆/栈/全局缓冲区溢出、悬空指针、双重释放

```bash
g++ -fsanitize=address -g program.cpp
```

### MSan（Memory Sanitizer）

检测：未初始化内存读取

```bash
g++ -fsanitize=memory -g program.cpp
```

### TSan（Thread Sanitizer）

检测：数据竞争

```bash
g++ -fsanitize=thread -g program.cpp
```

### UBSan（Undefined Behavior Sanitizer）

检测：整数溢出、空指针、类型违规等

```bash
g++ -fsanitize=undefined -g program.cpp
```

## RAII 原则与所有权语义

- 每个资源有且仅有一个所有者
- 所有权通过 `std::unique_ptr` 转移（move）
- 共享所有权通过 `std::shared_ptr` + 引用计数
- 析构函数保证资源释放，即使异常发生

## 内存映射文件

### mmap（Linux/macOS）

```cpp
#include <sys/mman.h>

int fd = open("file.dat", O_RDONLY);
void* addr = mmap(nullptr, length, PROT_READ, MAP_PRIVATE, fd, 0);
// 使用 addr ...
munmap(addr, length);
close(fd);
```

### CreateFileMapping（Windows）

```cpp
HANDLE hFile = CreateFile(L"file.dat", GENERIC_READ, ...);
HANDLE hMap = CreateFileMapping(hFile, nullptr, PAGE_READONLY, 0, 0, nullptr);
void* addr = MapViewOfFile(hMap, FILE_MAP_READ, 0, 0, 0);
// 使用 addr ...
UnmapViewOfFile(addr);
CloseHandle(hMap);
CloseHandle(hFile);
```
