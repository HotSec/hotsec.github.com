# C++11 核心特性

---

## 一、auto 类型推导

### 1.1 基本用法

```cpp
auto x = 42;          // int
auto pi = 3.14;       // double
auto name = "hello";  // const char*
auto s = std::string("hello"); // std::string

// 迭代器
std::map<std::string, int> m;
for (auto it = m.begin(); it != m.end(); ++it) {
    // it: std::map<std::string, int>::iterator
}

// 范围 for
for (auto& [key, val] : m) {
    // C++17 结构化绑定
}
```

### 1.2 auto 与引用/const

```cpp
int x = 42;
auto a = x;       // int (拷贝)
auto& b = x;      // int& (引用)
const auto& c = x; // const int&
auto&& d = x;     // int& (万能引用)

// auto 推导规则与模板参数推导相同
```

### 1.3 返回类型推导

```cpp
// C++11 尾置返回类型
auto add(int a, int b) -> int {
    return a + b;
}

// C++14 自动推导
auto add(int a, int b) {
    return a + b;
}
```

## 二、Lambda 表达式

### 2.1 基本语法

```cpp
[capture](parameters) -> return_type { body }

auto add = [](int a, int b) -> int {
    return a + b;
};
add(3, 5); // 8

// 自动推导返回类型
auto multiply = [](int a, int b) {
    return a * b;
};
```

### 2.2 捕获列表

| 捕获方式 | 说明 |
|----------|------|
| `[]` | 不捕获 |
| `[=]` | 按值捕获所有变量 |
| `[&]` | 按引用捕获所有变量 |
| `[x]` | 按值捕获 x |
| `[&x]` | 按引用捕获 x |
| `[=, &x]` | 按值捕获所有，x 按引用 |
| `[&, x]` | 按引用捕获所有，x 按值 |
| `[this]` | 捕获 this 指针 |

```cpp
int a = 10, b = 20;

auto f1 = [a, b]() { return a + b; };       // 按值
auto f2 = [&a, &b]() { a++; b++; };         // 按引用
auto f3 = [=]() { return a * b; };          // 全部按值
auto f4 = [&]() { a++; b++; };              // 全部按引用
auto f5 = [=, &a]() { a += b; };            // b 按值，a 按引用
```

### 2.3 初始化捕获 (C++14)

```cpp
auto ptr = std::make_unique<int>(42);
auto f = [p = std::move(ptr)]() { return *p; };
```

### 2.4 泛型 Lambda (C++14)

```cpp
auto add = [](auto a, auto b) {
    return a + b;
};
add(3, 5);       // int
add(1.5, 2.5);   // double
add(std::string("hello"), std::string(" world"));
```

### 2.5 STL 中使用 Lambda

```cpp
std::vector<int> v = {5, 2, 8, 1, 9, 3};

// 排序
std::sort(v.begin(), v.end(), [](int a, int b) {
    return a > b; // 降序
});

// 查找
auto it = std::find_if(v.begin(), v.end(), [](int x) {
    return x > 5;
});

// 遍历
std::for_each(v.begin(), v.end(), [](int x) {
    std::cout << x << " ";
});

// 删除
v.erase(std::remove_if(v.begin(), v.end(), [](int x) {
    return x < 3;
}), v.end());
```

## 三、移动语义

### 3.1 左值与右值

```cpp
int x = 42;    // x 是左值，42 是右值
int& lr = x;   // 左值引用
int&& rr = 42; // 右值引用

// 左值：有名字，可取地址
// 右值：无名字，不可取地址（临时对象、字面量）
```

### 3.2 移动构造与移动赋值

```cpp
class String {
    char* data_;
    size_t size_;
public:
    // 普通构造
    String(const char* s) : size_(strlen(s)) {
        data_ = new char[size_ + 1];
        strcpy(data_, s);
    }

    // 拷贝构造（深拷贝）
    String(const String& other) : size_(other.size_) {
        data_ = new char[size_ + 1];
        strcpy(data_, other.data_);
    }

    // 移动构造（浅拷贝 + 置空源对象）
    String(String&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    // 拷贝赋值
    String& operator=(const String& other) {
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = new char[size_ + 1];
            strcpy(data_, other.data_);
        }
        return *this;
    }

    // 移动赋值
    String& operator=(String&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    ~String() { delete[] data_; }
};
```

### 3.3 std::move

```cpp
std::string s1 = "hello";
std::string s2 = std::move(s1); // s1 变为空，s2 获得资源

// std::move 不移动任何东西，只是将左值转为右值引用
// 实际移动发生在移动构造/赋值函数中
```

### 3.4 std::forward 完美转发

```cpp
template<typename T, typename Arg>
auto make_unique(Arg&& arg) {
    return std::unique_ptr<T>(new T(std::forward<Arg>(arg)));
}

// std::forward 保持值的类别（左值/右值）
// Arg 为左值引用时 → 转发为左值
// Arg 为右值引用时 → 转发为右值
```

## 四、智能指针

### 4.1 unique_ptr

```cpp
// 独占所有权，不可拷贝
auto p1 = std::make_unique<int>(42);
// auto p2 = p1;              // ❌ 不可拷贝
auto p3 = std::move(p1);     // ✅ 可移动

// 数组
auto arr = std::make_unique<int[]>(10);
arr[0] = 42;

// 自定义删除器
auto deleter = [](FILE* f) { fclose(f); };
std::unique_ptr<FILE, decltype(deleter)> fp(fopen("a.txt", "r"), deleter);
```

### 4.2 shared_ptr

```cpp
// 共享所有权，引用计数
auto p1 = std::make_shared<int>(42);
auto p2 = p1; // 引用计数 = 2

std::cout << p1.use_count(); // 2

// 循环引用问题
struct Node {
    std::shared_ptr<Node> next;
    ~Node() { std::cout << "destroyed\n"; }
};

auto a = std::make_shared<Node>();
auto b = std::make_shared<Node>();
a->next = b; // 循环引用，内存泄漏！
b->next = a;
```

### 4.3 weak_ptr

```cpp
// 打破循环引用
struct Node {
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev; // 弱引用，不增加引用计数
    ~Node() { std::cout << "destroyed\n"; }
};

auto a = std::make_shared<Node>();
auto b = std::make_shared<Node>();
a->next = b;
b->prev = a; // ✅ 无循环引用

// 使用 weak_ptr
if (auto sp = b->prev.lock()) {
    // 成功获取 shared_ptr
}
```

## 五、右值引用与移动语义总结

| 操作 | 拷贝语义 | 移动语义 |
|------|----------|----------|
| 构造 | `T(const T&)` | `T(T&&)` |
| 赋值 | `T& operator=(const T&)` | `T& operator=(T&&)` |
| 触发 | 拷贝时 | `std::move` 时 |
| 开销 | 深拷贝 | 浅拷贝+置空 |

## 六、其他 C++11 特性

### 6.1 range-based for

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

for (auto& x : v) {
    x *= 2; // 修改元素
}

for (const auto& x : v) {
    std::cout << x << " "; // 只读
}
```

### 6.2 nullptr

```cpp
void f(int);
void f(void*);

f(NULL);    // 二义性：调用 f(int)?
f(nullptr); // 明确：调用 f(void*)
```

### 6.3 constexpr

```cpp
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

constexpr int x = factorial(5); // 编译期计算 = 120
```

### 6.4 初始化列表

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};
std::map<std::string, int> m = {
    {"alice", 25},
    {"bob", 30}
};
```

### 6.5 可变参数模板

```cpp
template<typename... Args>
void print(Args... args) {
    (std::cout << ... << args) << '\n'; // C++17 折叠表达式
}

print(1, "hello", 3.14, 'x');
```

### 6.6 enum class

```cpp
enum class Color { Red, Green, Blue };
enum class Size { Small, Medium, Large };

Color c = Color::Red;
// int x = c; // ❌ 不可隐式转换
int x = static_cast<int>(c); // ✅ 显式转换
```

### 6.7 override 与 final

```cpp
class Base {
public:
    virtual void foo() = 0;
    virtual void bar() final; // 不可再覆盖
};

class Derived : public Base {
public:
    void foo() override; // 显式标记覆盖
    // void bar() override; // ❌ bar 是 final
};

class Final final : public Derived {
    // 不可再继承
};
```

### 6.8 std::function 与 std::bind

```cpp
#include <functional>

std::function<int(int, int)> add = [](int a, int b) {
    return a + b;
};

// std::bind
auto add5 = std::bind(add, std::placeholders::_1, 5);
add5(3); // 8

// C++14 推荐：lambda 替代 bind
auto add5_lambda = [add](int a) { return add(a, 5); };
```
