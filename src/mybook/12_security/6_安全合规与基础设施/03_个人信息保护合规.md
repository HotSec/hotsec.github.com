# 个人信息保护合规

## 中国个人信息保护法律体系

### 三法并行格局

| 法律 | 全称 | 施行日期 | 核心定位 |
|------|------|----------|----------|
| 网安法 | 《中华人民共和国网络安全法》 | 2017-06-01 | 网络运行安全、网络安全等级保护、关键信息基础设施 |
| 个保法 | 《中华人民共和国个人信息保护法》 | 2021-11-01 | 个人信息处理全生命周期权利义务 |
| 数安法 | 《中华人民共和国数据安全法》 | 2021-09-01 | 数据分类分级、数据安全审查、数据跨境 |

### 法律层级关系

```
法律
├── 网安法 — 网络安全基座
├── 个保法 — 个人信息保护专法
└── 数安法 — 数据安全基座
    ↓
行政法规
├── 《网络数据安全管理条例》
├── 《关键信息基础设施安全保护条例》
└── 《数据出境安全评估办法》
    ↓
部门规章与规范性文件
├── 《个人信息安全规范》(GB/T 35273)
├── 《App违法违规收集使用个人信息行为认定方法》
└── 《个人信息保护影响评估指南》(GB/T 39335)
    ↓
行业标准
├── 《信息安全技术 个人信息安全工程指南》
└── 《移动互联网应用程序(App)收集使用个人信息备案要求》
```

### 三法交叉适用

| 场景 | 主要适用 | 辅助适用 |
|------|----------|----------|
| 个人信息跨境传输 | 个保法 | 网安法、数安法 |
| 关键信息基础设施运营者数据处理 | 网安法 | 个保法、数安法 |
| 重要数据出境 | 数安法 | 网安法 |
| App个人信息收集 | 个保法 | 网安法 |

## 个人信息保护法核心要点

### 适用范围

| 维度 | 内容 |
|------|------|
| 域内适用 | 在中国境内处理自然人个人信息 |
| 域外适用 | 境外处理中国境内自然人个人信息，且符合以下情形之一：以向境内自然人提供产品或服务为目的；分析评估境内自然人的行为；法律行政法规规定的其他情形 |
| 豁免情形 | 自然人因个人或家庭事务处理个人信息；匿名化处理后的信息展示 |

### 个人信息定义与分类

```
个人信息
├── 一般个人信息
│   以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息
│   不包括匿名化处理后的信息
│
└── 敏感个人信息
    一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害
    或者人身、财产安全受到危害的个人信息
```

| 类别 | 示例 |
|------|------|
| 一般个人信息 | 姓名、联系方式、地址、账号、浏览记录 |
| 敏感个人信息 | 生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹、不满14周岁未成年人信息 |

### 处理合法性基础

个保法第13条规定了七项合法性基础：

| 序号 | 合法性基础 | 典型场景 |
|------|-----------|----------|
| 1 | 取得个人同意 | App收集用户位置信息 |
| 2 | 订立或履行合同所必需 | 电商配送需收货地址 |
| 3 | 履行法定职责或法定义务 | 税务机关依法收集纳税信息 |
| 4 | 应对突发公共卫生事件 | 疫情期间流行病学调查 |
| 5 | 保护自然人生命健康和财产安全所必需 | 紧急救援定位 |
| 6 | 为公共利益实施新闻报道等合理处理 | 新闻报道中不可避免出现个人信息 |
| 7 | 处理已合法公开的个人信息 | 处理政府公开数据 |

### 知情同意

```
知情同意要求
├── 知情
│   ├── 处理者身份与联系方式
│   ├── 处理目的与处理方式
│   ├── 处理的个人信息种类
│   ├── 保存期限
│   ├── 向第三方提供的情形
│   └── 个人行使权利的方式和程序
│
├── 同意
│   ├── 自愿作出
│   ├── 明确作出
│   ├── 可撤回（撤回不影响此前处理效力）
│   └── 不得以不同意为由拒绝提供基本功能
│
└── 单独同意（特殊场景）
    ├── 处理敏感个人信息
    ├── 向第三方提供个人信息
    ├── 个人信息出境
    └── 公开处理的个人信息
```

### 最小必要原则

| 维度 | 要求 |
|------|------|
| 收集类型 | 与处理目的直接相关，不得过度收集 |
| 收集频率 | 仅在实现目的所必需的最低频率内收集 |
| 收集精度 | 在合理范围内达到处理目的所需最低精度 |
| 使用范围 | 不得超出处理目的使用 |
| 存储期限 | 实现目的所必需的最短时间 |

### 目的限制原则

- 个人信息处理应当具有明确合理的目的
- 不得以默认授权、强制捆绑等方式获取同意
- 变更处理目的需重新取得同意
- 委托处理不得超出原处理目的

### 存储限制原则

- 存储期限应为实现处理目的所必要的最短时间
- 超出存储期限应删除或匿名化处理
- 法律行政法规另有规定的从其规定
- 存储地点应在境内（满足出境条件的除外）

### 跨境传输规则

```
个人信息出境条件（满足其一即可）
├── 安全评估
│   ├── 关键信息基础设施运营者
│   ├── 处理个人信息达到国家网信部门规定数量
│   └── 累计向境外提供个人信息达到规定数量
│
├── 标准合同
│   └── 未达到安全评估门槛的，与境外接收方订立标准合同
│
└── 个人信息保护认证
    └── 经专业机构认证符合保护要求

额外要求
├── 向个人告知境外接收方信息
├── 取得个人单独同意
├── 进行个人信息保护影响评估
└── 保存相关记录至少3年
```

### 个人权利

| 权利 | 内容 | 行使方式 |
|------|------|----------|
| 知情权 | 了解个人信息处理规则 | 隐私政策、告知书 |
| 决定权 | 拒绝或撤回同意 | 设置开关、客服渠道 |
| 查阅复制权 | 查询、复制其个人信息 | 数据导出、自助查询 |
| 更正补充权 | 请求更正、补充不准确信息 | 编辑功能、申诉渠道 |
| 删除权 | 请求删除其个人信息 | 账号注销、数据删除 |
| 可携带权 | 请求将个人信息转移至其指定的处理者 | 数据导出标准格式 |
| 解释说明权 | 要求对个人信息处理规则进行解释说明 | 客服、FAQ |
| 自动化决策拒绝权 | 拒绝仅通过自动化决策方式作出的决定 | 人工审核请求 |

### 个人信息保护影响评估（DPIA）

**应当开展DPIA的场景：**

- 处理敏感个人信息
- 利用个人信息进行自动化决策
- 委托处理、向第三方提供或公开个人信息
- 向境外提供个人信息
- 其他对个人权益有重大影响的处理活动

**DPIA内容：**

| 评估项 | 内容 |
|--------|------|
| 合法性基础 | 处理活动是否具有合法性基础 |
| 必要性评估 | 对个人权益的影响程度与处理目的必要性 |
| 安全风险 | 泄露、篡改、丢失的风险 |
| 保护措施 | 技术措施与管理措施的有效性 |

### 个人信息保护负责人（DPO）

**应当设置DPO的条件：**

- 处理个人信息达到国家网信部门规定数量
- 处理敏感个人信息
- 法律行政法规规定的其他情形

**DPO职责：**

- 对个人信息处理活动进行监督
- 采取必要措施保护个人信息权益
- 公开联系方式并报送履行个人信息保护职责的部门

## 敏感个人信息处理规则

### 敏感个人信息类别

| 类别 | 具体内容 | 典型场景 |
|------|----------|----------|
| 生物识别 | 人脸、指纹、声纹、虹膜、步态 | 人脸支付、门禁系统 |
| 宗教信仰 | 宗教信仰信息、宗教活动参与 | 宗教App、社区管理 |
| 特定身份 | 民族、种族、政治观点、工会成员 | 人事管理、背景调查 |
| 医疗健康 | 病历、健康检查数据、用药记录 | 互联网医疗、健康监测 |
| 金融账户 | 银行账号、信贷信息、征信信息 | 金融App、支付平台 |
| 行踪轨迹 | GPS定位、出行记录、住宿记录 | 打车App、酒店预订 |
| 不满14周岁未成年人 | 儿童全部个人信息 | 儿童教育App、游戏防沉迷 |

### 处理敏感信息额外要求

```
处理敏感个人信息
├── 具有特定的目的和充分的必要性
├── 取得个人的单独同意（书面同意为推荐做法）
├── 处理不满14周岁未成年人信息须取得监护人同意
├── 开展个人信息保护影响评估
├── 向个人告知处理敏感信息的必要性及影响
└── 采取严格的保护措施
```

### 不满14周岁未成年人信息保护

- 应当取得未成年人父母或其他监护人同意
- 应当制定专门的个人信息处理规则
- 不得强制未成年人提供非必要信息
- 游戏防沉迷系统收集信息应遵循最小必要

## 数据出境合规路径

### 三条路径对比

| 维度 | 安全评估 | 标准合同 | 个人信息保护认证 |
|------|----------|----------|------------------|
| 适用主体 | CIIO / 大量数据处理者 | 中小规模处理者 | 跨国公司内部传输 |
| 评估方式 | 国家网信部门评估 | 自评估+合同备案 | 第三方机构认证 |
| 触发门槛 | 处理100万人以上 / 年累计出境10万人以上 / 含1万人以上敏感信息 | 未达安全评估门槛 | 自愿选择 |
| 办理周期 | 45-60个工作日 | 合同生效后10个工作日内备案 | 视认证机构而定 |
| 有效期 | 2年 | 3年或合同期满 | 认证周期 |
| 成本 | 较高 | 较低 | 中等 |

### 安全评估流程

```
申报准备
├── 自评估报告
├── 数据出境合同
├── 数据出境风险自评估
└── 证明材料

    ↓

省级网信部门初审

    ↓

国家网信部门评估

    ↓

评估结果
├── 通过 → 可开展数据出境活动
└── 未通过 → 不得出境，可补充材料重新申报
```

### 标准合同备案

```
签订标准合同
├── 使用网信办发布的标准合同模板
├── 合同核心条款不得修改
└── 可增加补充条款

    ↓

开展个人信息保护影响评估

    ↓

合同生效之日起10个工作日内备案
├── 向省级网信部门备案
└── 提交合同+影响评估报告
```

## App合规要求

### 收集使用规则

| 要求 | 内容 |
|------|------|
| 最小必要 | 仅收集与业务功能相关的信息 |
| 知情同意 | 收集前明示目的、方式、范围 |
| 单独同意 | 敏感信息需取得单独同意 |
| 禁止强制 | 不得因用户拒绝非必要收集拒绝提供基本服务 |
| 禁止捆绑 | 不得将多项业务功能捆绑同意 |
| 及时删除 | 用户注销账号后及时删除或匿名化 |

### 权限最小化

```
权限管理要求
├── 申请时机
│   ├── 仅在使用相关功能时申请
│   └── 不得提前或默认申请
│
├── 权限范围
│   ├── 选择最小权限集
│   ├── 精确定位 vs 粗略定位
│   └── 读取 vs 读写
│
├── 用户控制
│   ├── 支持逐项授权
│   ├── 支持随时撤回
│   └── 拒绝后不得频繁弹窗
│
└── 后台行为
    ├── 前台服务告知
    ├── 后台访问需用户可知
    └── 不得后台静默收集
```

### SDK管理

| 要求 | 内容 |
|------|------|
| 接入审查 | 评估SDK安全性、合规性、必要性 |
| 最小集成 | 仅集成业务必需SDK |
| 信息披露 | 在隐私政策中列明SDK名称、目的、信息类型 |
| 权限管控 | SDK不得自行申请权限，由宿主App管控 |
| 版本管理 | 及时更新SDK版本修复安全漏洞 |
| 退出机制 | 提供SDK退出/数据删除途径 |

### 隐私政策

```
隐私政策必备内容
├── 处理者基本信息
│   ├── 公司名称、注册地址
│   └── 个人信息保护负责人联系方式
│
├── 个人信息处理规则
│   ├── 收集目的、方式、范围
│   ├── 存储地点与期限
│   ├── 共享、转让、公开披露
│   └── 境外提供情况
│
├── 个人权利行使
│   ├── 查阅、复制、更正、删除
│   ├── 撤回同意
│   ├── 账号注销
│   └── 可携带权
│
├── 第三方SDK信息
│
├── 未成年人保护条款
│
└── 隐私政策更新机制
```

## 与GDPR对比

| 维度 | 中国个保法 | GDPR |
|------|-----------|------|
| 适用范围 | 境内+境外处理中国自然人信息 | 境内+境外处理欧盟数据主体信息 |
| 合法性基础 | 7项（含单独同意） | 6项（含合法利益） |
| 同意标准 | 明确同意+单独同意（敏感信息） | 自由、明确、知情、不含糊 |
| 敏感信息类别 | 7类（含不满14周岁未成年人） | 9类（含种族、政治、基因等） |
| 儿童保护 | 不满14周岁需监护人同意 | 16周岁（成员国可降至13周岁） |
| 数据主体权利 | 7项（含可携带权） | 8项（含被遗忘权） |
| 删除权 | 有条件删除 | 被遗忘权（范围更广） |
| 可携带权 | 有（请求转移至指定处理者） | 有（结构化通用格式） |
| 自动化决策 | 有权拒绝 | 有权拒绝+有权要求人工介入 |
| DPO要求 | 达到规定数量或处理敏感信息 | 核心活动涉及大规模定期系统监控或敏感信息 |
| DPIA | 5类场景 | 高风险处理活动 |
| 跨境传输 | 安全评估/标准合同/认证 | 充分性认定/标准合同/BCR/认证 |
| 违规处罚 | 最高5000万元或上一年度营业额5% | 最高2000万欧元或全球营业额4% |
| 监管机构 | 国家网信部门+各行业主管部门 | 各成员国数据保护机构+EDPB |

### 关键差异解读

```
同意机制差异
├── 个保法
│   ├── 强调"单独同意"（敏感/出境/第三方提供）
│   └── 不得以不同意为由拒绝提供基本功能
│
└── GDPR
    ├── 强调"自由作出"（不得捆绑服务）
    └── 合法利益可作为处理基础（个保法无此条款）

跨境传输差异
├── 个保法
│   ├── 以安全评估为主导
│   └── 量化门槛触发强制评估
│
└── GDPR
    ├── 以充分性认定为主导
    └── 无量化门槛，基于风险判断

处罚机制差异
├── 个保法
│   ├── 罚款+责令改正+吊销许可
│   └── 直接责任人员罚款10-100万元
│
└── GDPR
    ├── 分级罚款（2%/4%）
    └── 暂时或确定性限制处理
```
