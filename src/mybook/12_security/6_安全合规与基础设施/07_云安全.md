# 云安全

---

## 一、云安全概述

### 1.1 共享责任模型

云安全的核心原则是**共享责任模型（Shared Responsibility Model）**，即云厂商和客户共同承担安全责任：

| 责任方 | 负责内容 | 示例 |
|--------|----------|------|
| 云厂商 | 云本身的安全（Security of the Cloud） | 物理数据中心、硬件设施、虚拟化层、网络基础设施 |
| 客户 | 云中的安全（Security in the Cloud） | 数据加密、访问控制、应用安全、操作系统补丁 |

```
┌─────────────────────────────────────────────────┐
│                  共享责任模型                      │
├──────────────────┬──────────────────────────────┤
│   云厂商负责      │   客户负责                     │
├──────────────────┼──────────────────────────────┤
│ 物理安全          │ 数据分类与加密                  │
│ 基础设施硬件      │ 身份与访问管理                  │
│ 虚拟化层          │ 操作系统补丁                    │
│ 网络基础设施      │ 应用安全                        │
│ 全球网络          │ 网络防火墙配置                  │
│ 可用区/区域       │ 客户数据保护                    │
└──────────────────┴──────────────────────────────┘
```

### 1.2 云安全关键特性

| 特性 | 描述 |
|------|------|
| 弹性 | 资源按需伸缩，安全策略需动态适配 |
| 资源池化 | 多租户共享底层资源，需强隔离机制 |
| 按需自助 | 用户可自主创建资源，需自动化安全管控 |
| 可计量服务 | 资源使用可追踪，便于安全审计 |
| 广泛网络访问 | 任何位置可访问，增大攻击面 |

## 二、云服务模型与安全职责划分

### 2.1 IaaS / PaaS / SaaS 安全职责对比

| 安全控制项 | 本地部署 | IaaS | PaaS | SaaS |
|-----------|---------|------|------|------|
| 物理安全 | 客户 | 云厂商 | 云厂商 | 云厂商 |
| 网络控制 | 客户 | 客户 | 共享 | 云厂商 |
| 操作系统 | 客户 | 客户 | 云厂商 | 云厂商 |
| 中间件/运行时 | 客户 | 客户 | 云厂商 | 云厂商 |
| 应用程序 | 客户 | 客户 | 客户 | 共享 |
| 数据 | 客户 | 客户 | 客户 | 客户 |
| 身份与访问 | 客户 | 客户 | 共享 | 共享 |

### 2.2 各模型安全关注点

**IaaS（基础设施即服务）**

- 虚拟机操作系统加固与补丁管理
- 网络安全组与访问控制列表配置
- 磁盘加密与快照安全
- 虚拟网络隔离与流量控制

**PaaS（平台即服务）**

- 应用代码安全与依赖管理
- API 密钥与连接字符串保护
- 运行时环境配置安全
- 服务间通信加密

**SaaS（软件即服务）**

- 数据所有权与可移植性
- 集成接口安全
- 用户权限与角色管理
- 数据驻留与合规要求

## 三、云安全威胁

### 3.1 MITRE ATT&CK Cloud 矩阵

| 战术阶段 | 云相关技术 |
|----------|-----------|
| 初始访问 | 云账号滥用、钓鱼获取凭证、利用公开API |
| 执行 | 云API调用、Lambda函数执行、容器命令 |
| 持久化 | 创建后门账号、修改IAM策略、持久化Lambda |
| 权限提升 | IAM权限提升、角色链攻击、AssumeRole滥用 |
| 防御规避 | 禁用日志、删除CloudTrail、加密数据销毁 |
| 凭证访问 | 元数据服务窃取、Secrets Manager读取、S3桶枚举 |
| 发现 | 云资产枚举、网络扫描、权限探测 |
| 横向移动 | 跨VPC访问、角色切换、跨账号渗透 |
| 数据窃取 | S3数据外泄、快照导出、API批量下载 |

### 3.2 OWASP Cloud Top 10

| 排名 | 威胁 | 描述 |
|------|------|------|
| 1 | 不安全的身份与访问管理 | 默认权限过大、缺乏MFA、凭证泄露 |
| 2 | 不安全的接口与API | 缺乏认证、注入攻击、速率限制缺失 |
| 3 | 数据泄露 | 存储桶公开、加密缺失、传输不安全 |
| 4 | 配置错误 | 默认配置未修改、权限过宽、日志未启用 |
| 5 | 账户劫持 | 凭证窃取、钓鱼攻击、Token重用 |
| 6 | 恶意内部人员 | 权限滥用、数据窃取、后门植入 |
| 7 | 不安全的服务集成 | 第三方API风险、供应链攻击 |
| 8 | 缺乏可见性 | 影子IT、资源失控、盲区 |
| 9 | 拒绝服务 | 资源耗尽、账单攻击 |
| 10 | 共享技术漏洞 | 虚拟化逃逸、多租户隔离失败 |

### 3.3 常见云安全威胁详解

**数据泄露**

- 公开存储桶（S3/OSS/Blob 未授权访问）
- 数据库暴露在公网（RDS/MongoDB 无认证）
- 快照/备份未加密被窃取
- 日志中包含敏感信息

**配置错误**

- 安全组放通 0.0.0.0/0
- 存储桶 ACL 设为 public-read
- 管理端口（22/3389/3306）对公网开放
- 云函数环境变量硬编码密钥

**身份滥用**

- Root/Admin 账号日常使用
- IAM 策略授予 `*:*` 权限
- 长期访问密钥未轮换
- 服务账号权限过大

**不安全接口**

- API 缺乏认证与授权
- 无速率限制导致暴力破解
- GraphQL 过度查询暴露数据
- Webhook 未验证来源

**账户劫持**

- 凭证泄露（代码仓库、钓鱼）
- Token 未设置过期时间
- 缺少多因素认证（MFA）
- 会话固定攻击

## 四、云基础设施安全

### 4.1 VPC 网络隔离

```
┌──────────────────────────────────────────────────────┐
│                      VPC (10.0.0.0/16)               │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────┐ │
│  │ 公有子网      │  │ 私有子网      │  │ 数据库子网  │ │
│  │ 10.0.1.0/24  │  │ 10.0.2.0/24  │  │10.0.3.0/24 │ │
│  │              │  │              │  │            │ │
│  │ ALB/NAT GW   │  │ 应用服务器    │  │ RDS/Redis  │ │
│  │ Bastion      │  │ 容器集群      │  │            │ │
│  └──────┬───────┘  └──────┬───────┘  └─────┬──────┘ │
│         │                 │                 │        │
│         └─────────────────┴─────────────────┘        │
│                    安全组/NACL                         │
└──────────────────────────────────────────────────────┘
```

| 网络组件 | 功能 | 特点 |
|---------|------|------|
| VPC | 虚拟私有云，逻辑隔离网络 | 自定义网段、子网划分 |
| 子网 | VPC 内的网络分段 | 公有/私有/数据库子网 |
| Internet Gateway | VPC 与互联网的网关 | 公有子网必需 |
| NAT Gateway | 私有子网访问互联网 | 仅出站，不暴露私有资源 |
| VPC Peering | VPC 间互联 | 跨账号/跨区域 |
| Transit Gateway | 集中式网络枢纽 | 大规模多VPC互联 |
| PrivateLink | 私有端点访问服务 | 不经互联网 |

### 4.2 安全组与 NACL

| 对比项 | 安全组（Security Group） | NACL（网络ACL） |
|--------|------------------------|----------------|
| 层级 | 实例级（ENI） | 子网级 |
| 状态 | 有状态（自动放行返回流量） | 无状态（需显式放行双向） |
| 规则 | 仅允许规则 | 允许和拒绝规则 |
| 评估顺序 | 全部规则评估后合并 | 按编号顺序评估，命中即停 |
| 应用 | 绑定到实例/ENI | 自动应用于子网内所有实例 |

**安全组最佳实践**

- 最小化入站规则，仅开放必要端口和来源IP
- 禁止 0.0.0.0/0 访问管理端口（22/3389/3306）
- 使用安全组引用替代 IP 地址（SG → SG）
- 分层设计：ALB-SG → App-SG → DB-SG

### 4.3 WAF（Web 应用防火墙）

| 防护类型 | 描述 |
|---------|------|
| SQL 注入 | 检测并阻断 SQL 注入攻击 |
| XSS | 跨站脚本攻击防护 |
| CC 攻击 | 频率限制、防爬虫 |
| 规则引擎 | 自定义匹配规则（IP/URI/Header/Body） |
| 托管规则组 | OWASP Top 10、已知漏洞防护 |
| Bot 控制 | 机器人流量识别与管理 |
| IP 信誉 | 已知恶意 IP 自动拦截 |

### 4.4 DDoS 防护

| 防护层级 | 措施 |
|---------|------|
| L3/L4（网络层/传输层） | 流量清洗、Anycast 网络、SYN Cookie |
| L7（应用层） | WAF 速率限制、CAPTCHA 挑战、请求过滤 |
| 全局防护 | CDN 分散流量、Shield/DDoS 高防服务 |
| 架构层面 | 自动伸缩、多区域部署、降级策略 |

### 4.5 密钥管理

| 服务 | 功能 | 适用场景 |
|------|------|---------|
| KMS（密钥管理服务） | 密钥创建/轮换/审计 | 应用数据加密、信封加密 |
| HSM（硬件安全模块） | 专用硬件密钥存储 | 高合规要求、密钥隔离 |
| Secrets Manager | 密码/Token 轮换管理 | 数据库凭证、API密钥 |
| Parameter Store | 配置参数存储 | 非敏感配置、轻量密钥 |

**信封加密（Envelope Encryption）流程**

```
1. 应用请求 KMS 生成数据密钥（DEK）
2. KMS 返回：明文 DEK + 用 CMK 加密的 DEK
3. 应用用明文 DEK 加密数据
4. 存储加密数据 + 加密后的 DEK
5. 解密时：用 CMK 解密 DEK → 用 DEK 解密数据
```

## 五、云身份与访问管理

### 5.1 IAM 核心概念

| 概念 | 描述 |
|------|------|
| 用户（User） | 代表人员或应用程序的身份 |
| 组（Group） | 用户的集合，便于批量授权 |
| 角色（Role） | 临时身份，可被实体 Assume |
| 策略（Policy） | 权限的声明文档（JSON） |
| 服务账号 | 代表服务/工作负载的身份 |

### 5.2 IAM 策略结构

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject",
        "s3:PutObject"
      ],
      "Resource": "arn:aws:s3:::my-bucket/*",
      "Condition": {
        "IpAddress": {
          "aws:SourceIp": ["10.0.0.0/8"]
        },
        "StringEquals": {
          "s3:x-amz-server-side-encryption": "aws:kms"
        }
      }
    }
  ]
}
```

### 5.3 临时凭证与角色切换

| 机制 | 描述 | 有效期 |
|------|------|--------|
| AssumeRole | 获取角色的临时凭证 | 15分钟-12小时 |
| STS | 安全令牌服务 | 可配置 |
| 实例元数据 | EC2自动获取角色凭证 | 自动轮换 |
| OIDC 联合 | 外部身份提供商 | 可配置 |
| Web Identity | 社交账号登录 | 可配置 |

### 5.4 跨账号访问

```
┌──────────────┐     AssumeRole     ┌──────────────┐
│  账号 A       │ ──────────────────→ │  账号 B       │
│  (源账号)     │ ←────────────────── │  (目标账号)   │
│              │    临时凭证          │  信任策略      │
└──────────────┘                     └──────────────┘
```

**跨账号访问配置要点**

- 目标账号配置信任策略，允许源账号 ARN
- 源账号用户/角色具有 `sts:AssumeRole` 权限
- 使用外部 ID 防止混淆代理人攻击
- 临时凭证自动过期，无需长期密钥

## 六、云数据安全

### 6.1 加密体系

| 加密类型 | 描述 | 实现方式 |
|---------|------|---------|
| 传输加密（In Transit） | 数据在网络传输中加密 | TLS 1.2+/mTLS |
| 存储加密（At Rest） | 数据在存储介质上加密 | AES-256/服务端加密 |
| 使用加密（In Use） | 数据在计算过程中加密 | 机密计算/TEE/同态加密 |

### 6.2 信封加密详解

```
┌──────────────────────────────────────────────┐
│              信封加密架构                       │
│                                              │
│  CMK（客户主密钥）── KMS/HSM 管理             │
│       │                                      │
│       ├── 加密 ──→ DEK₁（数据密钥1）          │
│       │              │                       │
│       │              ├── 明文：加密数据        │
│       │              └── 密文：存储备用        │
│       │                                      │
│       └── 加密 ──→ DEK₂（数据密钥2）          │
│                      │                       │
│                      ├── 明文：加密数据        │
│                      └── 密文：存储备用        │
└──────────────────────────────────────────────┘
```

**信封加密优势**

- CMK 不直接加密数据，减少 KMS 调用
- DEK 可独立轮换，不影响 CMK
- 加密操作在客户端完成，KMS 仅管理密钥
- 支持跨服务/跨区域数据加密

### 6.3 客户管理密钥（CMK）

| 密钥类型 | 管理方 | 轮换 | 审计 | 控制权 |
|---------|--------|------|------|--------|
| 云厂商管理密钥 | 云厂商 | 自动 | 有限 | 低 |
| 客户管理密钥（CMK） | 客户 | 可配置（年度） | 完整 | 高 |
| 外部导入密钥 | 客户 | 手动 | 完整 | 最高 |
| HSM 密钥 | 客户 | 可配置 | 完整 | 最高 |

### 6.4 数据分类

| 分类级别 | 描述 | 加密要求 | 访问控制 |
|---------|------|---------|---------|
| 公开 | 可对外公开 | 可选 | 无限制 |
| 内部 | 仅内部使用 | 推荐 | 内部用户 |
| 机密 | 敏感业务数据 | 必须 | 授权用户 |
| 绝密 | 核心敏感数据 | 必须+CMK | 严格授权+审计 |

### 6.5 数据生命周期

```
创建 → 存储 → 使用 → 共享 → 归档 → 销毁
 │      │      │      │      │      │
加密    分类    DLP    权限   冷存储  彻底删除
标签    加密    脱敏    审计   保留策略 安全擦除
```

## 八、云安全态势管理（CSPM）

### 8.1 CSPM 核心能力

| 能力 | 描述 |
|------|------|
| 配置审计 | 自动检查云资源配置是否符合安全基线 |
| 合规基线 | 对照 CIS/NIST/等保等标准评估 |
| 漂移检测 | 发现配置偏离基线的变更 |
| 自动修复 | 对不合规配置自动或半自动修复 |
| 可视化 | 安全态势仪表盘、风险热力图 |
| 优先级排序 | 基于风险评分排列修复顺序 |

### 8.2 CSPM 工作流程

```
资源发现 → 配置采集 → 规则评估 → 风险评分 → 告警/修复 → 持续监控
```

## 九、云工作负载保护（CWPP）

### 9.1 CWPP 定义

云工作负载保护平台（Cloud Workload Protection Platform）为运行在任何基础设施上的工作负载提供统一安全保护，覆盖物理机、虚拟机、容器和无服务器。

### 9.2 CWPP 能力矩阵

| 能力 | 虚拟机 | 容器 | 无服务器 |
|------|--------|------|---------|
| 漏洞管理 | ✅ | ✅ | ✅ |
| 运行时保护 | ✅ | ✅ | ❌（无Agent） |
| 文件完整性 | ✅ | ✅ | ❌ |
| 系统调用监控 | ✅ | ✅ | ❌ |
| 网络微隔离 | ✅ | ✅ | ❌ |
| 合规基线 | ✅ | ✅ | ✅ |
| 镜像扫描 | ❌ | ✅ | ✅ |

### 9.3 CWPP 与 CSPM 对比

| 对比项 | CSPM | CWPP |
|--------|------|------|
| 关注点 | 云控制平面配置 | 工作负载运行时安全 |
| 保护对象 | 云服务资源配置 | VM/容器/无服务器 |
| 检测方式 | API 调用审计 | Agent/eBPF 监控 |
| 典型场景 | 存储桶公开、安全组过宽 | 异常进程、容器逃逸 |

## 十、多云与混合云安全策略

### 10.1 多云安全挑战

## 十三、云安全最佳实践

### 13.1 最小权限原则

- 默认拒绝，按需授权
- 使用角色和策略而非长期密钥
- 定期审查和清理未使用权限
- 实施 Just-In-Time（JIT）访问
- 禁用 Root/Admin 日常使用

### 13.2 加密默认

- 所有存储启用服务端加密
- 所有传输使用 TLS 1.2+
- 敏感数据使用 CMK
- 密钥启用自动轮换
- 数据库启用透明数据加密（TDE）

### 13.3 网络分段

- VPC 隔离不同环境（开发/测试/生产）
- 子网分层（公有/私有/数据库）
- 安全组最小化入站规则
- 使用 PrivateLink/PrivateEndpoint 避免公网暴露
- 实施微分段（Micro-segmentation）

### 13.4 日志审计

- 启用全量操作日志（CloudTrail/ActionTrail）
- 启用网络流量日志（VPC Flow Log）
- 启用数据访问日志（S3 Access Log）
- 日志发送至独立账号存储
- 日志接入 SIEM 实时分析
- 设置关键操作告警（IAM变更/安全组修改/密钥使用）

### 13.5 自动化响应

- 安全事件自动检测与告警
- 自动阻断高危操作（公开存储桶/开放安全组）
- 自动修复已知配置错误
- 自动隔离受感染实例
- 自动触发取证流程
- 使用 EventBridge/EventGrid 事件驱动响应

### 13.6 灾难恢复

| 策略 | RPO | RTO | 成本 |
|------|-----|-----|------|
| 备份与恢复 | 小时级 | 小时级 | 低 |
| Pilot Light | 分钟级 | 分钟级 | 中 |
| 温备 | 秒级 | 分钟级 | 中高 |
| 多活 | 接近零 | 接近零 | 高 |

**灾难恢复关键措施**

- 跨区域/跨云数据复制
- 基础设施即代码（IaC）快速重建
- 定期演练恢复流程
- 自动化故障切换
- 备份数据加密与验证
