# 告警处理与关联分析

## 告警生命周期

```
原始事件 → 告警生成 → 去重 → 聚合 → 降噪 → 关联 → 溯源 → 处置 → 复盘
```

### 各阶段说明

| 阶段 | 描述 | 关键技术 |
|------|------|---------|
| 告警生成 | 检测引擎产生原始告警 | 规则匹配、阈值触发、模型推理 |
| 去重 | 消除重复告警 | 哈希去重、时间窗口去重 |
| 聚合 | 合并相似告警 | 聚类算法、分组策略 |
| 降噪 | 过滤低价值告警 | 白名单、置信度评分、上下文过滤 |
| 关联 | 建立告警间联系 | 时序关联、因果关联、资产关联 |
| 溯源 | 追踪攻击源头和路径 | 攻击链还原、ATT&CK映射 |
| 处置 | 执行响应动作 | 封禁、隔离、通知 |
| 复盘 | 优化检测规则 | 规则调优、误报分析 |

## 告警去重

### 去重策略

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| 精确去重 | 相同五元组+规则ID+时间窗口 | 同源同目标重复告警 |
| 模糊去重 | 相同规则ID+源IP/目标IP | 扫描类告警 |
| 语义去重 | 相同攻击类型+目标资产 | 不同规则触发同一攻击 |

### 去重实现

```go
type AlertKey struct {
    RuleID    string
    SrcIP     string
    DstIP     string
    DstPort   int
    TimeBlock int64
}

func Dedup(alerts []Alert) []Alert {
    seen := make(map[AlertKey]bool)
    result := make([]Alert, 0, len(alerts))
    for _, a := range alerts {
        key := AlertKey{
            RuleID:    a.RuleID,
            SrcIP:     a.SrcIP,
            DstIP:     a.DstIP,
            DstPort:   a.DstPort,
            TimeBlock: a.Timestamp / 300,
        }
        if !seen[key] {
            seen[key] = true
            result = append(result, a)
        }
    }
    return result
}
```

## 告警聚合

### 聚合维度

| 维度 | 示例 |
|------|------|
| 按攻击源 | 同一源IP触发的所有告警 |
| 按攻击目标 | 同一目标IP/资产的所有告警 |
| 按攻击类型 | 同类攻击（如所有SQL注入告警） |
| 按时间窗口 | 5分钟/1小时内的相关告警 |
| 按攻击阶段 | 同一攻击链上的告警 |

### 聚合算法

#### 基于规则的聚合

```go
type AggregationRule struct {
    GroupBy    []string
    TimeWindow time.Duration
    Threshold  int
}

func Aggregate(alerts []Alert, rule AggregationRule) []AlertGroup {
    groups := make(map[string]*AlertGroup)
    for _, a := range alerts {
        key := a.GroupKey(rule.GroupBy)
        if g, ok := groups[key]; ok && a.Timestamp-g.LastSeen < rule.TimeWindow.Milliseconds() {
            g.Add(a)
        } else {
            groups[key] = &AlertGroup{Alerts: []Alert{a}}
        }
    }
    return filterGroups(groups, rule.Threshold)
}
```

#### 基于聚类的聚合

- DBSCAN：基于密度的聚类，无需预设簇数
- 层次聚类：构建告警间的层次关系
- 图聚类：将告警构建为图，发现社区结构

## 告警降噪

### 降噪方法

| 方法 | 描述 | 效果 |
|------|------|------|
| 白名单过滤 | 已知安全IP/行为的告警直接过滤 | 减少已知误报 |
| 资产上下文 | 结合资产信息判断告警价值 | 过滤无目标资产的告警 |
| 置信度评分 | 对告警打分，低分告警降级 | 优先处理高置信度告警 |
| 基线对比 | 与历史正常行为对比 | 过滤正常业务触发的告警 |
| 告警疲劳控制 | 同类告警频率限制 | 防止告警风暴 |

### 置信度评分模型

```
置信度 = w1×规则可信度 + w2×资产重要性 + w3×威胁情报匹配 + w4×历史准确率
```

| 因子 | 说明 |
|------|------|
| 规则可信度 | 规则的精确度和覆盖率 |
| 资产重要性 | 目标资产的业务价值 |
| 威胁情报匹配 | 源IP/域名/Hash是否在情报库中 |
| 历史准确率 | 该规则/源的历史告警准确率 |

## 关联分析

### 关联类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 时序关联 | 时间先后顺序的事件关联 | 扫描→入侵→横向移动 |
| 因果关联 | 攻击行为间的因果关系 | 漏洞利用→Webshell→C2通信 |
| 资产关联 | 同一资产上的多源告警 | 同一服务器上的IDS+EDR告警 |
| 实体关联 | 同一攻击者/受害者的关联 | 同一源IP对不同目标的攻击 |
| 情报关联 | 与威胁情报的匹配 | 源IP在恶意IP库中 |

### 关联规则示例

```yaml
rule: lateral_movement_detection
description: 检测横向移动行为
correlation:
  - event: smb_connection
    group_by: src_ip
    threshold: 10
    time_window: 5m
  - event: rdp_login
    group_by: src_ip
    threshold: 5
    time_window: 10m
  condition: smb_connection AND rdp_login
  action: escalate
```

### 攻击链还原

基于 ATT&CK 框架将离散告警映射到攻击阶段：

```
初始访问 → 执行 → 持久化 → 提权 → 防御规避 → 凭据访问 → 横向移动 → 数据窃取 → 命令控制
  │          │        │        │        │          │          │          │          │
鱼叉邮件  PowerShell  计划任务  Token   进程注入   Mimikatz   PsExec    DNS隧道   HTTP C2
恶意附件   WMI      注册表    UAC绕过  日志清除   Hash传递   RDP      ICMP隧道   HTTPS
漏洞利用   Cmd      服务创建  SUID    禁用AV    密码喷洒   SSH      隐蔽信道   Domain前端
```
