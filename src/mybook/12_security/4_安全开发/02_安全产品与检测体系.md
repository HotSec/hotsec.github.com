## IDS / IPS

### 概念

| 类型 | 全称 | 特点 |
|------|------|------|
| IDS | Intrusion Detection System | 检测并告警，不阻断 |
| IPS | Intrusion Prevention System | 检测并自动阻断 |

### 检测方法

| 方法 | 原理 | 优缺点 |
|------|------|--------|
| 签名检测 | 模式匹配已知攻击特征 | 准确率高，但无法检测未知攻击 |
| 异常检测 | 基线比对，偏离即告警 | 可发现未知威胁，但误报率高 |
| 行为分析 | 分析行为模式和关联关系 | 适合APT检测，计算开销大 |

### Suricata

高性能开源 IDS/IPS/NSM 引擎。

#### 核心特性

- 多线程架构，支持高流量环境
- 同时支持 IDS 和 IPS 模式
- 支持 EVE JSON 输出格式
- 支持 Lua 脚本自定义检测逻辑
- 支持协议解析、文件提取、TLS指纹

#### 规则语法

```
alert http $EXTERNAL_NET any -> $HOME_NET any (
    msg:"ET WEB_SERVER SQL Injection Attempt";
    flow:established,to_server;
    content:"UNION"; nocase;
    content:"SELECT"; nocase;
    pcre:"/union\s+select/i";
    sid:1000001; rev:1;
)
```

#### 规则关键字段

| 字段 | 描述 |
|------|------|
| alert/drop/pass | 动作：告警/丢弃/放行 |
| protocol | 协议：tcp/udp/icmp/http/dns/tls/smb |
| src/dst | 源/目标地址和端口 |
| msg | 告警消息 |
| content | 内容匹配 |
| pcre | 正则表达式匹配 |
| flow | 流方向控制 |
| sid:rev | 规则ID和版本 |

### Snort

最经典的开源 IDS/IPS，规则生态丰富。

#### 与 Suricata 对比

| 维度 | Snort | Suricata |
|------|-------|----------|
| 架构 | 单线程 | 多线程 |
| 性能 | 中等 | 高 |
| 规则兼容 | 原生 | 兼容Snort规则 |
| 输出格式 | 统一2格式 | EVE JSON |
| 社区 | 老牌成熟 | 活跃增长 |

## NDR

### 概念

NDR（Network Detection and Response）是新一代网络安全产品，融合了传统 IDS、流量分析和自动化响应能力。

### 核心能力

| 能力 | 描述 |
|------|------|
| 全流量可见性 | 对网络东西向和南北向流量全面监控 |
| 高级威胁检测 | 结合规则、行为分析、ML模型 |
| 自动化响应 | 与防火墙/EDR联动，自动阻断 |
| 回溯分析 | 存储历史流量PCAP，支持回溯调查 |
| 实体分析 | 对主机、用户、资产进行画像 |

### NDR vs IDS

| 维度 | IDS | NDR |
|------|-----|-----|
| 检测方式 | 签名为主 | 签名+行为+ML |
| 响应能力 | 仅告警 | 告警+响应 |
| 分析深度 | 单包/单会话 | 关联分析+实体画像 |
| 回溯能力 | 无 | 有（PCAP存储） |
| 误报处理 | 人工分析 | 自动降噪 |

## Zeek（原 Bro）

### 概述

Zeek 是强大的网络分析框架，侧重于网络行为的深度观察和日志记录，而非签名检测。

### 核心特性

- 事件驱动的脚本语言
- 丰富的协议解析器（50+协议）
- 结构化日志输出
- 文件提取和哈希计算
- 可扩展的分析框架

### 日志类型

| 日志 | 描述 |
|------|------|
| conn.log | 连接日志（五元组、字节、持续时间） |
| http.log | HTTP请求/响应详情 |
| dns.log | DNS查询和响应 |
| ssl.log | TLS/SSL连接信息 |
| files.log | 文件传输信息 |
| weird.log | 异常协议行为 |
| notice.log | Zeek检测到的值得注意的事件 |

### Zeek 脚本示例

```zeek
event http_request(c: connection, method: string, original_URI: string, unescaped_URI: string, version: string) {
    if (method == "POST" && /sqlmap/ in original_URI) {
        NOTICE([$note=WeirdActivity,
                $msg=fmt("SQLMap detected from %s", c$id$orig_h),
                $conn=c]);
    }
}
```

### Suricata + Zeek 组合

| 组件 | 职责 |
|------|------|
| Suricata | 签名检测、IPS阻断、快速告警 |
| Zeek | 深度协议分析、行为日志、异常检测 |

两者互补：Suricata 擅长已知威胁的精确匹配，Zeek 擅长行为观察和异常发现。

## Arkime（原 Moloch）

### 概述

Arkime 是开源的全流量捕获、索引和检索系统，提供PCAP存储和搜索能力。

### 核心特性

- 高性能PCAP捕获和存储
- 基于Elasticsearch的会话索引
- Web界面浏览和搜索PCAP
- 支持SPI（Session Profile Information）数据
- 可与Suricata/Zeek集成

### 数据流

```
网络流量 → Arkime Capture → PCAP存储 + SPI数据 → Elasticsearch索引 → Web界面查询
```

### 典型部署

```
          ┌─────────────┐
  流量 ──→│ Arkime Capture│──→ PCAP文件(磁盘)
          └──────┬──────┘
                 │ SPI数据
                 ▼
          ┌─────────────┐
          │Elasticsearch │
          └──────┬──────┘
                 │
                 ▼
          ┌─────────────┐
          │  Arkime Viewer│──→ Web UI
          └─────────────┘
```

## SOC / SIEM

### SOC（安全运营中心）

| 职能 | 描述 |
|------|------|
| 监控 | 7×24 实时安全事件监控 |
| 分析 | 告警研判、威胁分析、溯源 |
| 响应 | 事件处置、应急响应 |
| 优化 | 规则调优、误报治理 |

### SIEM（安全信息与事件管理）

| 功能 | 描述 |
|------|------|
| 日志采集 | Agent/Syslog/API 多源采集 |
| 归一化 | 统一日志格式和字段 |
| 关联分析 | 跨源事件关联和规则匹配 |
| 告警 | 基于规则和阈值的告警 |
| 可视化 | 仪表盘、报表、搜索 |

### 常见SIEM平台

| 平台 | 类型 | 特点 |
|------|------|------|
| Splunk | 商业 | 功能全面，生态丰富 |
| ELK Stack | 开源 | Elasticsearch+Logstash+Kibana |
| QRadar | 商业 | IBM，AI辅助分析 |
| Wazuh | 开源 | OSSEC衍生，HIDS+SIEM |

## Nuclei

### 概述

基于模板的快速漏洞扫描器，用于主动安全检测。

### 核心特性

- YAML模板定义检测逻辑
- 支持多协议（HTTP/TCP/DNS/SSL/Code）
- 并发扫描，速度快
- 社区模板库持续更新

### 模板结构

```yaml
id: cve-2021-44228-log4j

info:
  name: Log4j RCE
  severity: critical
  description: Apache Log4j2 远程代码执行漏洞

http:
  - method: GET
    path:
      - "{{BaseURL}}"
    headers:
      X-Api-Version: "${jndi:ldap://{{interactsh-url}}}"
    matchers:
      - type: word
        part: interactsh_protocol
        words:
          - "dns"
          - "http"
```

| 主动漏洞扫描 | Nuclei |
| 流量回溯分析 | Arkime |
