# AI在安全中的应用

## 概述

AI/ML 技术在网络安全中的应用日益广泛，主要解决传统规则检测无法覆盖的未知威胁和海量告警处理问题。

### 应用领域

| 领域 | 任务 | 常用算法 |
|------|------|---------|
| 恶意流量识别 | 区分正常与恶意网络流量 | 随机森林、XGBoost、DNN |
| DGA检测 | 识别算法生成的域名 | LSTM、CNN、字符级模型 |
| 异常行为检测 | 发现偏离基线的异常行为 | 自编码器、Isolation Forest |
| 告警降噪 | 过滤误报、优先级排序 | 分类模型、排序模型 |
| 敏感信息识别 | 文本中的敏感数据识别 | NER（命名实体识别） |
| 恶意软件分类 | 文件和行为分类 | 多特征融合模型 |

## 恶意流量识别

### 特征工程

| 特征类别 | 具体特征 |
|---------|---------|
| 统计特征 | 包数、字节数、持续时间、包间隔统计量 |
| 协议特征 | DNS查询类型分布、HTTP方法分布、TLS版本和套件 |
| 行为特征 | 连接频率、目标多样性、通信规律性 |
| 载荷特征 | 熵值、n-gram分布、可打印字符比例 |

### 模型选择

| 模型 | 优势 | 劣势 |
|------|------|------|
| 随机森林 | 特征重要性可解释，训练快 | 特征工程依赖重 |
| XGBoost | 精度高，处理不平衡数据好 | 超参调优复杂 |
| DNN | 自动特征提取 | 需大量数据，可解释性差 |
| 1D-CNN | 捕获局部模式（如载荷模式） | 需要原始数据 |

## DGA 检测

### DGA 域名特征

| 特征 | 正常域名 | DGA域名 |
|------|---------|---------|
| 可读性 | 有语义 | 无意义字符组合 |
| 长度 | 短-中等 | 偏长 |
| 熵值 | 低-中 | 高 |
| 辅音比例 | 低 | 高 |
| n-gram分布 | 符合语言模型 | 异常 |

### 检测方法

#### 基于规则/统计

```python
def dga_score(domain):
    score = 0
    labels = domain.split('.')
    for label in labels:
        if len(label) > 10:
            score += 1
        if entropy(label) > 3.5:
            score += 2
        if consonant_ratio(label) > 0.7:
            score += 1
        if digit_ratio(label) > 0.3:
            score += 1
    return score
```

#### 基于深度学习

```
输入：域名字符序列 → Embedding → BiLSTM/CNN → Dense → Sigmoid（DGA概率）
```

- 字符级输入，无需手动特征工程
- BiLSTM 捕获双向上下文
- 可区分不同 DGA 家族

## 异常行为检测

### 检测方法

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| 统计基线 | 计算历史均值/方差，偏离即异常 | 流量速率、连接频率 |
| 自编码器 | 重构误差大的为异常 | 高维行为特征 |
| Isolation Forest | 异常点更容易被孤立 | 多维特征异常检测 |
| LOF | 局部密度异常 | 局部异常模式 |
| 时间序列模型 | ARIMA/Prophet预测偏差 | 时序行为分析 |

### 用户实体行为分析（UEBA）

```
数据采集 → 特征提取 → 基线建模 → 异常评分 → 告警 → 调查
```

| 分析维度 | 特征 |
|---------|------|
| 登录行为 | 时间、地点、设备、频率 |
| 网络行为 | 访问目标、流量模式、协议使用 |
| 文件操作 | 访问频率、文件类型、操作类型 |
| 权限使用 | 特权操作、越权访问 |

## 告警降噪中的ML

### 分类模型

将告警分为：真实威胁 / 误报 / 不确定

| 特征 | 描述 |
|------|------|
| 规则特征 | 规则ID、规则类别、历史准确率 |
| 网络特征 | 源/目标IP信誉、地理位置、ASN |
| 资产特征 | 资产类型、重要性、暴露面 |
| 上下文特征 | 同期告警数、关联告警数、时间特征 |

### 排序模型

对告警按威胁程度排序，优先处理高威胁告警：

```
排序分 = f(告警严重度, 资产价值, 情报匹配度, 历史准确率, 关联强度)
```

```
                    ┌─────┴─────┐

```

### 关键工程问题

| 问题 | 解决方案 |
|------|---------|
| 推理延迟 | 批量推理、模型量化、ONNX Runtime |
| 特征一致性 | 训练和推理共享特征计算逻辑 |
| 模型更新 | A/B测试、灰度发布、回滚机制 |
| 数据漂移 | 监控特征分布、定期重训练 |
| 冷启动 | 规则兜底、迁移学习 |

### Go 调用推理服务

```go
func InferMaliciousTraffic(features FlowFeatures) (float64, error) {
    conn, _ := grpc.Dial("ml-service:50051", grpc.WithInsecure())
    client := pb.NewInferenceServiceClient(conn)

    req := &pb.InferenceRequest{
        ModelName: "malicious_traffic",
        Features:  features.ToProto(),
    }

    resp, err := client.Predict(context.Background(), req)
    if err != nil {
        return 0, err
    }
    return resp.GetScore(), nil
}
```
