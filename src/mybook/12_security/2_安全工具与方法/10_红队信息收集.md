# 红队信息收集实战指南

信息收集是红队攻防演练中最重要也最耗时的阶段。根据初始信息类型（域名/IP/公司名称），采用不同的收集路线。

---

## 一、域名信息收集

### 1.1 CDN判断

| 方法 | 操作 | 判断依据 |
|------|------|----------|
| Ping域名 | `ping target.com` | 返回域名很长或含cdn/ali/tencent字段 |
| Nslookup | `nslookup target.com` | 一个域名对应多个IP |
| 超级Ping | https://ping.chinaz.com/ | 多地Ping返回不同IP |
| 多地Ping | https://www.itdog.cn/ping | 不同地区返回不同IP |

### 1.2 绕过CDN获取真实IP

| 方法 | 原理 | 工具/网站 |
|------|------|----------|
| 多地Ping对比 | 不同地区解析出相同IP即为真实IP | itdog.cn、chinaz.com |
| 子域名查询 | CDN费用高，通常只对主站做加速 | 360quake `domain:"target.com"`、fofa `domain="target.com"` |
| DNS历史记录 | CDN启用前的DNS记录可能暴露真实IP | dnsdb.io、微步在线 x.threatbook.cn、Netcraft、viewdns.info、ipip.net |
| DNSDB查询 | 查询DNS绑定历史 | https://dnsdb.io/zh-cn/ 输入 `target.com type:A` |
| SecurityTrails | 历史数据查看原始IP | securitytrails.com |
| MX记录 | 邮件服务器若与Web同IP则暴露 | nslookup -type=MX |
| SSL证书搜索 | 443端口暴露SSL证书关联IP | Censys IPv4搜索 |
| SSL SHA1指纹 | 证书指纹搜索关联主机 | Censys `SHA1 fingerprint` |
| 网站漏洞 | phpinfo泄露/XSS/SSRF/命令执行 | — |
| 邮件订阅 | 网站发邮件含真实IP | 查看邮件源码 |
| F5 LTM解码 | Set-Cookie中BIGipServer值解码 | 十进制→十六进制→逆序→十进制 |

**F5 LTM解码示例：**

```
Set-Cookie: BIGipServerpool_8.29_8030=487098378.24095.0000

487098378 → 十六进制 1d08880a → 逆序取4位 0a.88.08.1d → 十进制 10.136.8.29
```

### 1.3 子域名收集

**搜索引擎：**

```
site:target.com          # Google搜索子域
intitle:公司名称          # 按标题搜索
```

**资产测绘：**

```
fofa:    domain="target.com" / host="target.com" / icon_hash="hash值"
hunter:  domain.suffix="target.com"
360quake: domain:"target.com"
```

**在线工具：**

| 工具 | 网址 |
|------|------|
| phpinfo.me | https://phpinfo.me/domain/ |
| t1h2ua | https://www.t1h2ua.cn/tools/ |
| ip138 | https://site.ip138.com/target.com/domain.htm |
| 站长之家 | http://tool.chinaz.com/ |

**子域名爆破工具：**

| 工具 | 特点 |
|------|------|
| SubDomainBrute | 高性能爆破，支持泛解析检查 |
| Sublist3r | 字典强大，爆破率高 |
| OneForAll | 证书透明度收集（censys/certspotter/crtsh/entrust/google/spyse） |

### 1.4 隐藏域名Hosts碰撞

原理：很多站点禁止IP直接访问，需绑定Host才能正常请求。域名删除A记录但反代配置未更新时，可通过IP+域名配对碰撞发现隐藏资产。

**碰撞所需字典：**
- 目标域名列表
- 目标相关IP段（历史解析IP：site.ip138.com、ipchaxun.com）

**方法：** 遍历 IP+域名 组合发送HTTP请求，对比title和响应包大小

## 二、IP信息收集

### 2.1 IP反查域名

| 工具 | 用法 |
|------|------|
| SearchMap | 集域名解析/IP反查/WHOIS/CDN检测/端口扫描/目录扫描/子域名挖掘 |
| ip-adress.com | http://www.ip-adress.com/reverse_ip |
| 7c.com | http://www.7c.com/ |
| fofa | `ip="1.1.1.1/24"` C段搜索 |
| ip138 | https://site.ip138.com/ |

### 2.2 Nmap扫描

| 命令 | 用途 |
|------|------|
| `nmap -sn -PE -n 192.168.1.1/24 -oX out.xml` | C段主机发现 |
| `nmap -sS -Pn -p 3389 152.136.248.0/24` | 定向端口扫描 |
| `nmap -sS -Pn -p 1-65535 -n IP` | 全端口扫描 |
| `nmap -sS -sV -p 1-65535 -n IP` | 端口+服务版本扫描 |

### 2.3 旁站查询

旁站：同一服务器上的其他域名

| 工具 | 网址 |
|------|------|
| 查旁站 | https://chapangzhan.com/ |
| webscan | https://webscan.cc/（每日更新大量站点） |

### 2.4 端口扫描工具对比

| 工具 | 特点 |
|------|------|
| Nmap | 最流行，扫描准确率高，功能全面 |
| Masscan | 速度比Nmap快10倍，适合快速扫描 |
| fofa | 资产测绘，覆盖面广 |

**Nmap常用参数：**

| 参数 | 说明 |
|------|------|
| `-sS` | SYN半开扫描，速度快 |
| `-sT` | TCP全连接扫描 |
| `-sV` | 服务版本检测 |
| `-O` | 操作系统识别（需root） |
| `-Pn` | 跳过主机发现 |
| `-A` | 全面扫描（OS+版本+脚本+路由） |

## 三、公司名称信息收集

### 3.1 企业信息查询

| 平台 | 网址 | 特色 |
|------|------|------|
| 爱企查 | https://aiqicha.baidu.com/ | 百度旗下，查域名/手机号/子公司 |
| 天眼查 | https://www.tianyancha.com/ | 企业关系图谱 |
| 小蓝本 | https://sou.xiaolanben.com/pc | 查APP/商标/媒体信息最佳 |

**关键信息点：**
- 更多网址：手机号、其他域名、子公司
- 股权穿透：持股50%以上的子公司可作为攻击目标
- 知识产权：软件著作权、产品信息、微信小程序、APP
- 供应商：技术支持信息可扩展攻击面

### 3.2 供应商攻击

通过fofa搜索使用某供应商产品的网站：

```
body="北京三易拓科技有限公司"
```

从供应商入手攻击目标。

### 3.3 ICP备案查询

```
https://beian.miit.gov.cn/#/Integrated/index
```

通过备案号反查公司信息。

### 3.4 GitHub泄露

| 搜索语法 | 用途 |
|----------|------|
| `site:Github.com smtp @qq.com` | 邮箱密码泄露 |
| `site:Github.com smtp @target.com` | 目标公司邮箱 |
| `site:Github.com sa password` | 数据库密码 |
| `site:Github.com root password` | root密码 |
| `site:Github.com inurl:sql` | SQL文件 |
| `site:Github.com 密码` | 中文密码泄露 |
| `site:Github.com 内部` | 内部文档 |

### 3.5 Google产品手册

搜索目标公司产品使用手册，可能泄露默认账号密码。

## 五、信息收集路线图

```
初始信息
  ├── 域名 → CDN判断 → 绕过CDN获取真实IP
  │       → 子域名收集 → 扩大资产范围
  │       → Hosts碰撞 → 发现隐藏资产
  ├── IP  → 反查域名 → 扩大域名范围
  │       → C段扫描 → 发现同网段资产
  │       → 旁站查询 → 发现同服务器站点
  │       → 端口扫描 → 发现开放服务
  └── 公司名称 → 企业查询 → 子公司/域名/APP/小程序
              → 供应商 → 从供应链入手
              → ICP备案 → 反查关联信息
              → GitHub泄露 → 凭证/源码/内部文档
              → 产品手册 → 默认账号密码

网站深入
  → 指纹识别 → 中间件/框架/脚本语言
  → 目录扫描 → 敏感文件/备份/配置
  → JS收集 → URL/子域名/敏感信息
  → WAF探测 → 防御设备识别
```
