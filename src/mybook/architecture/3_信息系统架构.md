# 信息系统架构

## 面向服务架构（SOA）

### 核心概念

- 服务：自包含、自描述的业务功能单元
- 服务契约：接口定义（WSDL/IDL）
- 松耦合：服务间依赖最小化
- 可组合：服务可编排为业务流程

### ESB（企业服务总线）

- 消息路由与转换
- 协议适配
- 消息增强
- 服务编排

### EDA（事件驱动架构）

- 事件生产者 → 事件通道 → 事件消费者
- 异步解耦
- 事件溯源（Event Sourcing）

## 层次式架构

### 表现层

- UI 渲染
- 用户交互
- 输入验证

### 业务层

- 业务逻辑
- 业务规则
- 工作流编排

### 数据访问层

- ORM / 数据映射
- 事务管理
- 缓存策略

## 物联网架构

### 感知层

- 传感器：温度/湿度/光照/加速度
- 执行器：继电器/电机/阀门
- 通信协议：ZigBee / BLE / LoRa / NB-IoT

### 网络层

- 网关：协议转换、数据聚合
- MQTT：轻量级发布/订阅消息协议
  - QoS 0：至多一次
  - QoS 1：至少一次
  - QoS 2：恰好一次
- CoAP：受限应用协议

### 平台层

- 设备管理：注册/认证/监控/OTA
- 数据处理：流式/批处理
- 规则引擎：事件触发动作

### 应用层

- 可视化大屏
- 报警通知
- 数据分析

### 边缘计算

- 本地数据处理，降低延迟
- 断网自治
- 边云协同

## 大型网站系统架构实例

- 淘宝：微服务 + 中台 + 单元化架构
- 微信：SET 模型 + 异地多活
- Netflix：微服务 + Chaos Engineering
