# 虚拟化技术

## 虚拟化概述

### 类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 全虚拟化 | 模拟完整硬件 | VMware, KVM, Hyper-V |
| 半虚拟化 | Guest 修改内核配合 | Xen PV |
| 硬件辅助虚拟化 | CPU 硬件支持 | Intel VT-x, AMD-V |
| 容器虚拟化 | OS 级隔离 | Docker, LXC, Podman |
| 桌面虚拟化 | 远程桌面 | VDI, RDP |

### 全虚拟化 vs 容器

| 特性 | 全虚拟化 | 容器 |
|------|----------|------|
| 隔离级别 | 硬件级 | 进程级 |
| 内核 | 独立内核 | 共享宿主内核 |
| 启动速度 | 分钟级 | 秒级 |
| 资源开销 | 高（需模拟硬件） | 低（共享内核） |
| 镜像大小 | GB 级 | MB 级 |
| 安全性 | 强隔离 | 相对较弱 |
| 密度 | 低 | 高 |

## KVM

### 架构

```
┌──────────────────────────────┐
│        Guest User Space      │
│  ┌───────┐  ┌───────┐       │
│  │ App A │  │ App B │       │
│  └───┬───┘  └───┬───┘       │
│  ┌───┴──────────┴───┐       │
│  │   Guest Kernel    │       │
│  └────────┬──────────┘       │
├───────────┼──────────────────┤
│     virtio / QEMU           │
├───────────┼──────────────────┤
│        KVM Module           │
│  (ioctl /dev/kvm)           │
├───────────┼──────────────────┤
│     Host Linux Kernel       │
│  ┌────────┴──────────┐      │
│  │   Hardware (VT-x)  │      │
│  └────────────────────┘      │
└──────────────────────────────┘
```

### virt-install

```bash
virt-install \
  --name vm1 \
  --ram 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/vm1.qcow2,size=20 \
  --os-variant ubuntu22.04 \
  --network bridge=virbr0 \
  --graphics none \
  --location 'http://archive.ubuntu.com/ubuntu/dists/jammy/main/installer-amd64/' \
  --extra-args 'console=ttyS0,115200n8'
```

## Vagrant

### 基础配置

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/jammy64"

  config.vm.network "forwarded_port", guest: 80, host: 8080
  config.vm.network "private_network", ip: "192.168.33.10"

  config.vm.synced_folder "./src", "/home/vagrant/src"

  config.vm.provider "virtualbox" do |vb|
    vb.memory = "2048"
    vb.cpus = 2
    vb.name = "dev-vm"
  end

  config.vm.provision "shell", inline: <<-SHELL
    apt-get update
    apt-get install -y nginx docker.io
    systemctl enable nginx docker
  SHELL
end
```

### 多机配置

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/jammy64"

  config.vm.define "master" do |master|
    master.vm.network "private_network", ip: "192.168.33.10"
    master.vm.provider "virtualbox" do |vb|
      vb.memory = "4096"
      vb.cpus = 2
    end
    master.vm.provision "shell", inline: <<-SHELL
      apt-get update && apt-get install -y docker.io
    SHELL
  end

  config.vm.define "worker1" do |worker|
    worker.vm.network "private_network", ip: "192.168.33.11"
    worker.vm.provider "virtualbox" do |vb|
      vb.memory = "2048"
      vb.cpus = 1
    end
  end

  config.vm.define "worker2" do |worker|
    worker.vm.network "private_network", ip: "192.168.33.12"
    worker.vm.provider "virtualbox" do |vb|
      vb.memory = "2048"
      vb.cpus = 1
    end
  end
end
```

## 容器虚拟化深入

### Namespace

| Namespace | 隔离内容 |
|-----------|----------|
| PID | 进程 ID |
| NET | 网络栈 |
| IPC | 进程间通信 |
| MNT | 文件系统挂载 |
| UTS | 主机名 |
| USER | 用户/组 ID |
| CGROUP | Cgroup 根目录 |

```bash
ls -la /proc/$$/ns
unshare --pid --fork --mount-proc /bin/bash
unshare --net /bin/bash
nsenter -t <pid> -n ip addr
```

### Cgroups

| 子系统 | 功能 |
|--------|------|
| cpu | CPU 时间限制 |
| cpuset | CPU 核绑定 |
| memory | 内存限制 |
| blkio | 块设备 IO 限制 |
| pids | 进程数限制 |
| devices | 设备访问控制 |

```bash
ls /sys/fs/cgroup/
cat /sys/fs/cgroup/memory/docker/<container_id>/memory.limit_in_bytes
cat /sys/fs/cgroup/cpu/docker/<container_id>/cpu.cfs_quota_us
```

### Union File System

```
Container Layer (读写)
    ↓
Image Layer 3 (只读)
    ↓
Image Layer 2 (只读)
    ↓
Image Layer 1 (只读)
```

- **Copy-on-Write**：修改文件时从下层复制到容器层
- **overlay2**：Docker 默认存储驱动
- **分层复用**：相同层只存储一份

### Proxmox VE

```bash
qm create 100 --name "vm-ubuntu" --memory 2048 --cores 2 \
    --net0 virtio,bridge=vmbr0 \
    --scsi0 local-lvm:vm-100-disk-0,size=20G

qm start 100
qm stop 100
qm snapshot 100 snap-before-update
qm listsnapshot 100

pct create 200 local-lvm:vztmpl/ubuntu-22.04-standard_22.04-1_amd64.tar.zst \
    --hostname "ct-ubuntu" --memory 1024 --cores 1 \
    --net0 name=eth0,bridge=vmbr0,ip=dhcp

pct start 200
pct enter 200
```
