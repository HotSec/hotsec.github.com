# Go 设计模式

## 一、函数选项模式（Functional Options）

### 1.1 问题

```go
type Server struct {
    host    string
    port    int
    timeout time.Duration
    tls     bool
}

func NewServer(host string, port int, timeout time.Duration, tls bool) *Server {
    return &Server{host: host, port: port, timeout: timeout, tls: tls}
}
```

问题：参数多时调用不清晰，扩展需要改签名。

### 1.2 解决方案

```go
type Option func(*Server)

func WithPort(port int) Option {
    return func(s *Server) {
        s.port = port
    }
}

func WithTimeout(timeout time.Duration) Option {
    return func(s *Server) {
        s.timeout = timeout
    }
}

func WithTLS() Option {
    return func(s *Server) {
        s.tls = true
    }
}

func NewServer(host string, opts ...Option) *Server {
    s := &Server{
        host: host,
        port: 8080,
    }
    for _, opt := range opts {
        opt(s)
    }
    return s
}
```

### 1.3 使用

```go
s1 := NewServer("localhost")
s2 := NewServer("localhost", WithPort(9090), WithTLS())
s3 := NewServer("localhost", WithTimeout(30*time.Second), WithPort(8080))
```

- 默认值在构造函数中设置
- 选项可按任意顺序组合
- 新增选项不需要改签名

## 二、单例模式

### 2.1 sync.Once

```go
var (
    instance *Database
    once     sync.Once
)

func GetDatabase() *Database {
    once.Do(func() {
        instance = &Database{
            conn: connectDB(),
        }
    })
    return instance
}
```

- `sync.Once` 保证只执行一次
- 并发安全
- 常用于全局配置/连接池/日志实例

## 三、工厂模式

```go
type Storage interface {
    Save(data []byte) error
    Load(key string) ([]byte, error)
}

func NewStorage(storageType string) (Storage, error) {
    switch storageType {
    case "redis":
        return NewRedisStorage(), nil
    case "mysql":
        return NewMySQLStorage(), nil
    case "file":
        return NewFileStorage(), nil
    default:
        return nil, fmt.Errorf("unknown storage type: %s", storageType)
    }
}
```

## 四、策略模式

```go
type SortStrategy interface {
    Sort(data []int)
}

type BubbleSort struct{}
func (s BubbleSort) Sort(data []int) { /* ... */ }

type QuickSort struct{}
func (s QuickSort) Sort(data []int) { /* ... */ }

type Sorter struct {
    strategy SortStrategy
}

func (s *Sorter) SetStrategy(strategy SortStrategy) {
    s.strategy = strategy
}

func (s *Sorter) Sort(data []int) {
    s.strategy.Sort(data)
}
```

## 五、装饰器模式

```go
type Handler interface {
    Handle(ctx context.Context, req Request) (Response, error)
}

type LoggingDecorator struct {
    next   Handler
    logger *zap.Logger
}

func (d *LoggingDecorator) Handle(ctx context.Context, req Request) (Response, error) {
    start := time.Now()
    resp, err := d.next.Handle(ctx, req)
    d.logger.Info("request", zap.Duration("duration", time.Since(start)), zap.Error(err))
    return resp, err
}
```

## 六、构建者模式

```go
type Request struct {
    Method  string
    URL     string
    Headers map[string]string
    Body    []byte
    Timeout time.Duration
}

type RequestBuilder struct {
    request Request
}

func NewRequestBuilder(method, url string) *RequestBuilder {
    return &RequestBuilder{
        request: Request{
            Method:  method,
            URL:     url,
            Headers: make(map[string]string),
        },
    }
}

func (b *RequestBuilder) WithHeader(key, value string) *RequestBuilder {
    b.request.Headers[key] = value
    return b
}

func (b *RequestBuilder) WithBody(body []byte) *RequestBuilder {
    b.request.Body = body
    return b
}

func (b *RequestBuilder) WithTimeout(timeout time.Duration) *RequestBuilder {
    b.request.Timeout = timeout
    return b
}

func (b *RequestBuilder) Build() *Request {
    return &b.request
}

req := NewRequestBuilder("GET", "http://example.com").
    WithHeader("Authorization", "Bearer token").
    WithTimeout(5 * time.Second).
    Build()
```
