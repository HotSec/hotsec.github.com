# 错误和异常

- Go语言基于错误值比较的错误处理方式，而不是基于异常捕获的方式
- 必须显示地进行错误检查

- error接口

  - ```go
    type error interface {
        Error() string
    }
    ```

- syscall.Errno
  - ```go
    package main
    
    import (
        "fmt"
        "os"
        "syscall"
    )
    
    func main() {
        // 尝试打开不存在的文件
        file, err := os.Open("/path/to/nonexistent/file")
        if err != nil {
            // 检查是否是系统调用错误
            if errno, ok := err.(syscall.Errno); ok {
                fmt.Printf("系统调用错误码: %d\n", errno)
                fmt.Printf("错误描述: %v\n", errno)
                
                switch errno {
                case syscall.ENOENT:
                    fmt.Println("文件或目录不存在")
                case syscall.EACCES:
                    fmt.Println("权限不足")
                case syscall.EIO:
                    fmt.Println("I/O 错误")
                default:
                    fmt.Println("其他系统调用错误")
                }
            } else {
                fmt.Printf("非系统调用错误: %v\n", err)
            }
        } else {
            file.Close()
        }
    }
    ```
- err.Error()
  - ```go
    // 错误写法 - 可能导致 panic
    // msg := err.Error()  // 如果 err 是 nil 会 panic
    
    // 正确写法
    if err != nil {
        msg := err.Error()
        // 处理错误
    }
    ```
- panic
  - 触发 panic 后，当前函数的后续代码立即停止执行。
  - 从触发点开始，逐层向上 “解栈”（unwind），执行每层函数中已声明的 defer 语句（按 defer 声明的逆序执行）。
  - 如果全程没有 recover 捕获，程序会终止，并打印 panic 信息和完整的调用栈。

  - ```go
    panic("a problem")
    ```

- recover：捕获 panic 并恢复执行
    - 定义：recover 是内置函数，唯一作用是捕获当前 goroutine 中的 panic，阻止程序崩溃，并让 goroutine 恢复正常执行。
    - 核心规则（必记）：
        - recover 必须在 defer 函数中调用 才有效（直接调用或在非 defer 函数中调用会返回 nil）。
        - 调用后返回值：捕获到 panic 时，返回 panic 传递的错误值；无 panic 时，返回 nil。
        - 捕获效果：仅恢复当前 goroutine 的执行，不会影响其他 goroutine；触发 panic 的函数内，panic 之后的代码仍不会执行，仅上层函数可继续运行。

  - ```go
        defer func() {
            if r := recover(); r != nil {
                switch x := r.(type) {
                case string:
                    err = errors.New(x)
                case error:
                    err = x
                default:
                    err = fmt.Errorf("Unknown panic: %v", r)
                }
            }
        }()

        panic("TODO")
    }

    ```
