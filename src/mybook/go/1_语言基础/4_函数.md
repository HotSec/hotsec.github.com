# 函数

## 一、函数定义

```go
func Add(a, b int) int {
    return a + b
}

func Swap(a, b int) (int, int) {
    return b, a
}

func Find(m map[int]int, key int) (value int, ok bool) {
    value, ok = m[key]
    return
}
```

- 多返回值：Go 函数支持多返回值
- 命名返回值：可在返回值列表中命名，return 时自动返回
- 参数类型简写：连续同类型参数可省略前面的类型声明

### 1.1 可变参数

```go
func Sum(a int, more ...int) int {
    for _, v := range more {
        a += v
    }
    return a
}

func Print(a ...interface{}) {
    fmt.Println(a...)
}

func main() {
    var a = []interface{}{123, "abc"}
    Print(a...)
    Print(a)
}
```

- `...int` 表示可变参数，函数内为 `[]int` 切片
- 可变参数必须放在参数列表最后
- 传切片时需用 `slice...` 展开

## 二、函数进阶

### 2.1 变量作用域

```go
var x int = 100 // 全局变量

func foo() {
    var x int = 200 // 局部变量，遮蔽全局变量
    fmt.Println(x)
}
```

- 全局变量：函数外定义，整个包内可见
- 局部变量：函数内定义，仅在函数内可见
- 内层可遮蔽外层同名变量

### 2.2 函数类型与变量

```go
type Calculation func(int, int) int

func Add(a, b int) int { return a + b }
func Sub(a, b int) int { return a - b }

var c Calculation = Add
fmt.Println(c(10, 5))

c = Sub
fmt.Println(c(10, 5))
```

- 函数也是一种类型，可以赋值给变量
- 函数类型可作为参数和返回值

### 2.3 高阶函数

```go
func apply(a, b int, op func(int, int) int) int {
    return op(a, b)
}

result := apply(10, 5, Add)

func multiplier(factor int) func(int) int {
    return func(x int) int {
        return x * factor
    }
}

double := multiplier(2)
fmt.Println(double(5))
```

- 函数作为参数：回调模式
- 函数作为返回值：工厂模式/闭包

### 2.4 匿名函数与闭包

```go
// 匿名函数
add := func(a, b int) int {
    return a + b
}
fmt.Println(add(1, 2))

// 立即执行
func() {
    fmt.Println("hello")
}()

// 闭包：函数捕获了外部局部变量
func adder() func(int) int {
    var x int
    return func(delta int) int {
        x += delta
        return x
    }
}

f := adder()
fmt.Println(f(10))
fmt.Println(f(20))
fmt.Println(f(30))
```

- 闭包捕获的是变量的引用，不是值
- 闭包常用于：状态封装/延迟执行/回调

### 2.5 defer 详解

```go
func main() {
    fmt.Println("start")
    defer fmt.Println("1")
    defer fmt.Println("2")
    defer fmt.Println("3")
    fmt.Println("end")
}
// 输出: start end 3 2 1
```

- defer 执行顺序：后进先出（LIFO）
- defer 参数在声明时就确定了

```go
func main() {
    x := 10
    defer fmt.Println("defer x =", x)
    x = 20
    fmt.Println("x =", x)
}
// 输出: x = 20  defer x = 10
```

**defer 执行时机**：
1. 设置返回值
2. 执行 defer 语句
3. 真正返回

```go
func f1() int {
    x := 5
    defer func() { x++ }()
    return x
}

func f2() (x int) {
    defer func() { x++ }()
    return 5
}

func f3() (y int) {
    x := 5
    defer func() { x++ }()
    return x
}
```

**defer 使用场景**：
- 释放资源（文件句柄/数据库连接/锁）
- recover 捕获 panic

## 三、内置函数

| 函数 | 说明 |
|------|------|
| `len(v)` | 返回长度（string/slice/map/channel/array） |
| `cap(v)` | 返回容量（slice/channel/array） |
| `append(slice, elems...)` | 追加元素到切片 |
| `copy(dst, src)` | 复制切片 |
| `delete(m, key)` | 删除 map 中的键 |
| `new(Type)` | 分配零值内存，返回指针 |
| `make(Type, size...)` | 初始化 slice/map/channel |
| `close(ch)` | 关闭 channel |
| `panic(v)` | 触发 panic |
| `recover()` | 捕获 panic |
| `print/println` | 内置打印（调试用） |

### 3.1 panic 与 recover

```go
func mustPanic() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("recovered:", r)
        }
    }()
    panic("something went wrong")
}
```

- `panic` 触发运行时错误，程序退出
- `recover` 在 defer 中捕获 panic
- recover 必须在 defer 函数中直接调用才有效

## 四、递归

```go
func factorial(n int) int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n-1)
}

func fibonacci(n int) int {
    if n <= 1 {
        return n
    }
    return fibonacci(n-1) + fibonacci(n-2)
}
```

### 4.1 分金币问题

```go
func distributeGold(gold []int) (left, right int) {
    if len(gold) == 0 {
        return 0, 0
    }
    if len(gold) == 1 {
        return gold[0], 0
    }
    if gold[0] >= gold[len(gold)-1] {
        left += gold[0]
        l, r := distributeGold(gold[1:])
        right += l
        left += r
    } else {
        left += gold[len(gold)-1]
        l, r := distributeGold(gold[:len(gold)-1])
        right += l
        left += r
    }
    return
}
```
