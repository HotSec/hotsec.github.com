# 语句

## 一、变量与常量

### 1.1 标识符与关键字

- 标识符：由字母、数字、`_` 组成，且不能以数字开头
- 25 个关键字：`break`/`case`/`chan`/`const`/`continue`/`default`/`defer`/`else`/`fallthrough`/`for`/`func`/`go`/`goto`/`if`/`import`/`interface`/`map`/`package`/`range`/`return`/`select`/`struct`/`switch`/`type`/`var`
- 37 个保留字：内建常量/类型/函数

### 1.2 变量声明

```go
// 标准声明
var name string
var age int

// 批量声明
var (
    name   string
    age    int
    isOk   bool
)

// 初始化
var name string = "Go"
var age int = 18

// 类型推导
var name = "Go"
var age = 18

// 短变量声明（只能在函数内使用）
name := "Go"
age := 18

// 匿名变量
x, _ := getValue()
```

- 函数外必须使用 `var`/`const`/`func` 等关键字
- `:=` 只能在函数体内使用
- 变量声明后必须使用，否则编译错误
- 同一作用域内不能重复声明

### 1.3 常量与 iota

```go
const pi = 3.1415
const e = 2.7182

const (
    pi = 3.1415
    e  = 2.7182
)

// 批量声明时省略值则和上一行相同
const (
    n1 = 100
    n2
    n3
)

// iota 常量计数器
const (
    a1 = iota // 0
    a2        // 1
    a3        // 2
    a4        // 3
)

// _ 跳过某些值
const (
    b1 = iota // 0
    b2        // 1
    _         // 2 (跳过)
    b3        // 3
)

// iota 声明中间插队
const (
    c1 = iota // 0
    c2 = 100  // 100
    c3 = iota // 2
    c4        // 3
)

// 多个 iota 定义在一行
const (
    d1, d2 = iota + 1, iota + 2 // 1, 2
    d3, d4 = iota + 1, iota + 2 // 2, 3
)

// 定义数量级
const (
    _  = iota
    KB = 1 << (10 * iota) // 1 << 10 = 1024
    MB                    // 1 << 20
    GB                    // 1 << 30
    TB                    // 1 << 40
    PB                    // 1 << 50
)
```

## 二、运算符

### 2.1 算术运算符

| 运算符 | 描述 |
|--------|------|
| `+` | 相加 |
| `-` | 相减 |
| `*` | 相乘 |
| `/` | 相除（整数除法向下取整） |
| `%` | 取余 |
| `++` | 自增（语句，不是表达式） |
| `--` | 自减（语句，不是表达式） |

```go
a := 10
b := 3
fmt.Println(a / b)
fmt.Println(a % b)
a++
a--
```

- `++` 和 `--` 在 Go 中是语句而非表达式，不能写在表达式内
- `a = b++` 是非法的

### 2.2 关系运算符

| 运算符 | 描述 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

### 2.3 逻辑运算符

| 运算符 | 描述 |
|--------|------|
| `&&` | 逻辑与（短路） |
| `\|\|` | 逻辑或（短路） |
| `!` | 逻辑非 |

### 2.4 位运算符

| 运算符 | 描述 |
|--------|------|
| `&` | 按位与 |
| `\|` | 按位或 |
| `^` | 按位异或 |
| `&^` | 位清除（AND NOT） |
| `<<` | 左移 |
| `>>` | 右移 |

### 2.5 赋值运算符

| 运算符 | 描述 |
|--------|------|
| `=` | 赋值 |
| `+=` `/=` `-=` `*=` `%=` | 算术赋值 |
| `<<=` `>>=` `&=` `\|=` `^=` `&^=` | 位运算赋值 |

### 2.6 运算符优先级

由高到低：`*` `/` `%` → `+` `-` → `==` `!=` `<` `<=` `>` `>=` → `&&` → `||`

## 三、流程控制

### 3.1 if else

```go
if condition {
    // ...
} else if condition2 {
    // ...
} else {
    // ...
}

// if 特殊写法：在条件前执行语句
if err := doSomething(); err != nil {
    fmt.Println("error:", err)
}
```

- 条件不需要括号
- 大括号必须与 if/else 在同一行
- if 前可添加执行语句，用分号分隔

### 3.2 for

```go
// 基本循环
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// 省略初始语句
i := 0
for ; i < 10; i++ {
    fmt.Println(i)
}

// 省略初始和增量语句（类似 while）
for i < 10 {
    fmt.Println(i)
    i++
}

// 无限循环
for {
    // ...
}

// for range
for i, v := range "hello" {
    fmt.Printf("index: %d, value: %c\n", i, v)
}

for k, v := range map[string]int{"go": 1} {
    fmt.Println(k, v)
}
```

- Go 只有 `for` 循环，没有 `while`/`do-while`
- `for range` 可遍历 slice/map/string/channel

### 3.3 switch

```go
finger := 3
switch finger {
case 1:
    fmt.Println("大拇指")
case 2:
    fmt.Println("食指")
case 3:
    fmt.Println("中指")
default:
    fmt.Println("无效")
}

// 一个 case 多个值
switch n := 7; n {
case 1, 3, 5, 7, 9:
    fmt.Println("奇数")
case 2, 4, 6, 8, 10:
    fmt.Println("偶数")
}

// case 使用表达式
age := 30
switch {
case age < 18:
    fmt.Println("未成年")
case age >= 18 && age < 60:
    fmt.Println("成年")
default:
    fmt.Println("老年")
}

// fallthrough 穿透
switch n := 1; n {
case 1:
    fmt.Println("1")
    fallthrough
case 2:
    fmt.Println("2")
}
```

- Go 的 switch 默认不穿透（不需要 break）
- `fallthrough` 可强制穿透到下一个 case
- case 可使用表达式，switch 不带条件时等价于 `switch true`

### 3.4 goto / break / continue

```go
// goto 跳转到标签
goto label
// ...
label:
    fmt.Println("here")

// break 跳出循环，可指定标签跳出外层循环
outer:
for i := 0; i < 5; i++ {
    for j := 0; j < 5; j++ {
        if j == 3 {
            break outer
        }
    }
}

// continue 跳过当前迭代
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue
    }
    fmt.Println(i)
}
```
