# Go 泛型

---

## 一、泛型理念

在定义函数、类型或接口时，不预先指定具体类型，而在使用时再指定。类似 C++ 模板、Java 泛型、Rust 泛型。

### 1.1 为什么需要泛型

```go
// ❌ 没有泛型时：每种类型写一个函数
func AddInt(a, b int) int           { return a + b }
func AddFloat(a, b float64) float64 { return a + b }
func AddString(a, b string) string  { return a + b }

// ✅ 泛型：一个函数适用所有类型
func Add[T Number](a, b T) T { return a + b }
```

## 二、泛型函数

### 2.1 基本语法

```go
func FuncName[T TypeConstraint](param T) T {
    // ...
}
```

### 2.2 示例

```go
func Map[T any, U any](s []T, f func(T) U) []U {
    result := make([]U, len(s))
    for i, v := range s {
        result[i] = f(v)
    }
    return result
}

nums := []int{1, 2, 3}
strs := Map(nums, func(n int) string { return fmt.Sprintf("num:%d", n) })
// ["num:1", "num:2", "num:3"]
```

### 2.3 多类型参数

```go
func Pair[K comparable, V any](key K, value V) map[K]V {
    return map[K]V{key: value}
}

m := Pair("name", "Alice")  // map[string]string
m2 := Pair(1, true)          // map[int]bool
```

## 三、泛型类型

### 3.1 泛型结构体

```go
type Stack[T any] struct {
    items []T
}

func (s *Stack[T]) Push(v T) {
    s.items = append(s.items, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.items) == 0 {
        var zero T
        return zero, false
    }
    v := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return v, true
}

func (s *Stack[T]) Len() int {
    return len(s.items)
}

// 使用
intStack := Stack[int]{}
intStack.Push(42)
v, ok := intStack.Pop() // 42, true

strStack := Stack[string]{}
strStack.Push("hello")
```

### 3.2 泛型切片

```go
type SortedSlice[T constraints.Ordered] []T

func (s SortedSlice[T]) Contains(v T) bool {
    idx := sort.Search(len(s), func(i int) bool { return s[i] >= v })
    return idx < len(s) && s[idx] == v
}
```

### 3.3 泛型 Map

```go
type Map[K comparable, V any] map[K]V

func (m Map[K, V]) GetOrDefault(key K, defaultVal V) V {
    if v, ok := m[key]; ok {
        return v
    }
    return defaultVal
}
```

## 四、类型约束

### 4.1 内置约束

```go
// any = interface{} — 无约束
func Print[T any](v T) { fmt.Println(v) }

// comparable — 可比较 (==, !=)
func Contains[T comparable](s []T, v T) bool {
    for _, e := range s {
        if e == v { return true }
    }
    return false
}
```

### 4.2 联合类型约束

```go
type Number interface {
    int | int8 | int16 | int32 | int64 |
    float32 | float64
}

func Sum[T Number](nums []T) T {
    var total T
    for _, n := range nums {
        total += n
    }
    return total
}
```

### 4.3 行为约束

```go
type Stringer interface {
    String() string
}

func Join[T Stringer](items []T, sep string) string {
    strs := make([]string, len(items))
    for i, item := range items {
        strs[i] = item.String()
    }
    return strings.Join(strs, sep)
}
```

### 4.4 混合约束

```go
type Integer interface {
    ~int | ~int8 | ~int16 | ~int32 | ~int64
}

// ~ 表示底层类型，允许自定义类型
type MyInt int // 也满足 Integer 约束
```

### 4.5 constraints 包

```go
import "golang.org/x/exp/constraints"

// constraints.Signed    — 所有有符号整数
// constraints.Unsigned  — 所有无符号整数
// constraints.Integer   — 所有整数
// constraints.Float     — 所有浮点数
// constraints.Complex   — 所有复数
// constraints.Ordered   — 可排序类型 (~< ~<= ~> ~>=)
```

## 五、泛型接口

```go
type Container[T any] interface {
    Add(item T)
    Get(index int) (T, bool)
    Size() int
}

type List[T any] struct {
    items []T
}

func (l *List[T]) Add(item T)      { l.items = append(l.items, item) }
func (l *List[T]) Get(i int) (T, bool) {
    if i < 0 || i >= len(l.items) {
        var zero T
        return zero, false
    }
    return l.items[i], true
}
func (l *List[T]) Size() int { return len(l.items) }

var c Container[string] = &List[string]{}
c.Add("hello")
```

## 六、泛型与反射

### 6.1 泛型 vs 反射

| 维度 | 泛型 | 反射 |
|------|------|------|
| 类型安全 | 编译期检查 | 运行时检查 |
| 性能 | 无额外开销 | 有运行时开销 |
| 灵活性 | 编译期确定 | 运行时动态 |
| 适用场景 | 类型已知的通用逻辑 | 类型未知的动态处理 |

### 6.2 何时用泛型、何时用反射

```go
// ✅ 泛型：类型在编译期可知
func Filter[T any](s []T, pred func(T) bool) []T { ... }

// ✅ 反射：类型在运行时才可知（如 JSON 解析）
func Unmarshal(data []byte, v interface{}) error { ... }

// ✅ 泛型替代反射的常见场景
func Must[T any](v T, err error) T {
    if err != nil { panic(err) }
    return v
}
```

## 七、标准库泛型容器 (Go 1.21+)

### 7.1 slices

```go
import "slices"

nums := []int{3, 1, 4, 1, 5, 9}

slices.Sort(nums)
slices.Contains(nums, 4)     // true
slices.Index(nums, 1)        // 1
slices.Insert(nums, 2, 99)   // 在索引2插入99
slices.Delete(nums, 1, 3)    // 删除索引1-2
slices.Reverse(nums)
slices.Min(nums)              // 1
slices.Max(nums)              // 9
slices.Clone(nums)            // 浅拷贝
slices.Compact(nums)          // 去除连续重复
```

### 7.2 maps

```go
import "maps"

m := map[string]int{"a": 1, "b": 2, "c": 3}

keys := maps.Keys(m)          // []string{"a","b","c"}
vals := maps.Values(m)        // []int{1,2,3}
clone := maps.Clone(m)        // 浅拷贝
maps.DeleteFunc(m, func(k string, v int) bool { return v < 2 })
```

### 7.3 cmp

```go
import "cmp"

cmp.Or("", "default")         // "default" — 返回第一个非零值
cmp.Compare(3, 5)             // -1
cmp.Less(3, 5)                // true
```

## 八、泛型实战模式

### 8.1 类型安全的 Channel 多路复用

```go
func FanIn[T any](channels ...<-chan T) <-chan T {
    out := make(chan T)
    var wg sync.WaitGroup
    for _, ch := range channels {
        wg.Add(1)
        go func(c <-chan T) {
            defer wg.Done()
            for v := range c { out <- v }
        }(ch)
    }
    go func() { wg.Wait(); close(out) }()
    return out
}
```

### 8.2 泛型 Set

```go
type Set[T comparable] map[T]struct{}

func NewSet[T comparable](items ...T) Set[T] {
    s := make(Set[T])
    for _, item := range items { s.Add(item) }
    return s
}

func (s Set[T]) Add(item T)          { s[item] = struct{}{} }
func (s Set[T]) Remove(item T)       { delete(s, item) }
func (s Set[T]) Contains(item T) bool { _, ok := s[item]; return ok }
func (s Set[T]) Len() int             { return len(s) }

func (s Set[T]) Union(other Set[T]) Set[T] {
    result := make(Set[T])
    for k := range s { result.Add(k) }
    for k := range other { result.Add(k) }
    return result
}
```

### 8.3 泛型选项模式

```go
type Option[T any] func(*T)

func Apply[T any](v *T, opts ...Option[T]) {
    for _, opt := range opts { opt(v) }
}

type Server struct {
    Port int
    Host string
}

WithPort := func(port int) Option[Server] {
    return func(s *Server) { s.Port = port }
}

s := &Server{Host: "localhost"}
Apply(s, WithPort(8080))
```
