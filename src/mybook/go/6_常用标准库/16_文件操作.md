# 文件操作（os / io）

## 一、打开与关闭

```go
file, err := os.Open("test.txt")
if err != nil {
    fmt.Println("open error:", err)
    return
}
defer file.Close()
```

## 二、读取文件

### 2.1 Read

```go
file, _ := os.Open("test.txt")
defer file.Close()

var buf = make([]byte, 128)
n, err := file.Read(buf)
if err != nil {
    fmt.Println("read error:", err)
    return
}
fmt.Println(string(buf[:n]))
```

### 2.2 ReadFile

```go
content, err := os.ReadFile("test.txt")
if err != nil {
    fmt.Println("read error:", err)
    return
}
fmt.Println(string(content))
```

### 2.3 bufio 按行读取

```go
file, _ := os.Open("test.txt")
defer file.Close()

scanner := bufio.NewScanner(file)
for scanner.Scan() {
    fmt.Println(scanner.Text())
}
if err := scanner.Err(); err != nil {
    fmt.Println("scanner error:", err)
}
```

## 三、写入文件

### 3.1 Create & Write

```go
file, _ := os.Create("test.txt")
defer file.Close()

file.WriteString("hello\n")
file.Write([]byte("world\n"))
```

### 3.2 WriteFile

```go
err := os.WriteFile("test.txt", []byte("hello world\n"), 0644)
if err != nil {
    fmt.Println("write error:", err)
}
```

### 3.3 OpenFile 追加写入

```go
file, _ := os.OpenFile("test.txt", os.O_APPEND|os.O_WRONLY|os.O_CREATE, 0644)
defer file.Close()
file.WriteString("appended line\n")
```

| 标志 | 说明 |
|------|------|
| `os.O_RDONLY` | 只读 |
| `os.O_WRONLY` | 只写 |
| `os.O_RDWR` | 读写 |
| `os.O_APPEND` | 追加 |
| `os.O_CREATE` | 不存在则创建 |
| `os.O_TRUNC` | 清空文件 |

## 四、文件信息

```go
info, _ := os.Stat("test.txt")
fmt.Println(info.Name())
fmt.Println(info.Size())
fmt.Println(info.IsDir())
fmt.Println(info.Mode())
fmt.Println(info.ModTime())
```

## 五、目录操作

```go
os.Mkdir("dir1", 0755)
os.MkdirAll("dir1/dir2/dir3", 0755)

os.Remove("file.txt")
os.RemoveAll("dir1")

entries, _ := os.ReadDir(".")
for _, entry := range entries {
    fmt.Println(entry.Name(), entry.IsDir())
}

filepath.Walk(".", func(path string, info os.FileInfo, err error) error {
    fmt.Println(path)
    return nil
})
```

## 六、临时文件

```go
dir, _ := os.MkdirTemp("", "myapp")
defer os.RemoveAll(dir)

f, _ := os.CreateTemp(dir, "tmp-*.txt")
f.WriteString("temporary content")
fmt.Println(f.Name())
f.Close()
```

## 七、io 工具

```go
r := strings.NewReader("hello world")
data, _ := io.ReadAll(r)
fmt.Println(string(data))

src := strings.NewReader("hello")
dst := &bytes.Buffer{}
io.Copy(dst, src)
fmt.Println(dst.String())
```
