## 一、编码层面优化

### 1. 字符串处理
```go
// ❌ 避免：频繁字符串拼接
s := ""
for i := 0; i < n; i++ {
    s += str  // 每次都分配新内存
}

// ✅ 推荐：strings.Builder
var builder strings.Builder
builder.Grow(n * len(str))  // 预分配
for i := 0; i < n; i++ {
    builder.WriteString(str)
}
result := builder.String()
```

### 2. 切片预分配
```go
// ❌ 避免动态扩容
var result []int
for i := 0; i < n; i++ {
    result = append(result, i)  // 可能多次扩容
}

// ✅ 预分配容量
result := make([]int, 0, n)
for i := 0; i < n; i++ {
    result = append(result, i)
}
```

### 3. Map 预分配
```go
m := make(map[string]int, expectedSize)  // 预估大小
```

### 4. 减少内存分配
```go
// ❌ 每次分配
func process() []byte {
    return make([]byte, 1024)
}

// ✅ 使用 sync.Pool 复用
var bufPool = sync.Pool{
    New: func() interface{} {
        return make([]byte, 1024)
    },
}

func process() []byte {
    buf := bufPool.Get().([]byte)
    defer bufPool.Put(buf)
    // 使用 buf...
    return buf
}
```

### 5. 避免逃逸到堆
```go
// ❌ 逃逸：返回局部变量指针
func newInt() *int {
    i := 10
    return &i  // 逃逸到堆
}

// ✅ 直接返回值
func newInt() int {
    return 10  // 栈分配
}
```

## 二、并发优化

### 1. 并发处理独立任务
```go
func fetchData() (*User, *Order, *Product) {
    var wg sync.WaitGroup
    var user User
    var order Order
    var product Product
    
    wg.Add(3)
    go func() {
        defer wg.Done()
        user = getUser()
    }()
    go func() {
        defer wg.Done()
        order = getOrder()
    }()
    go func() {
        defer wg.Done()
        product = getProduct()
    }()
    wg.Wait()
    
    return &user, &order, &product
}
```

### 2. 使用 errgroup
```go
import "golang.org/x/sync/errgroup"

func fetchData() error {
    g, ctx := errgroup.WithContext(context.Background())
    
    g.Go(func() error { return fetchUser(ctx) })
    g.Go(func() error { return fetchOrder(ctx) })
    
    return g.Wait()  // 任一失败立即返回
}
```

### 3. Worker Pool（工作池）
```go
func workerPool(jobs <-chan Task, results chan<- Result, workers int) {
    var wg sync.WaitGroup
    for i := 0; i < workers; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for job := range jobs {
                results <- process(job)
            }
        }()
    }
    wg.Wait()
}
```

## 三、数据库优化

### 1. 连接池配置
```go
db, _ := sql.Open("mysql", dsn)
db.SetMaxOpenConns(100)     // 最大连接数
db.SetMaxIdleConns(10)      // 最大空闲连接
db.SetConnMaxLifetime(time.Hour)      // 连接最大存活时间
db.SetConnMaxIdleTime(time.Minute * 10) // 空闲连接超时
```

### 2. 批量操作
```go
// ❌ 循环单条插入
for _, item := range items {
    db.Exec("INSERT INTO t VALUES (?)", item)
}

// ✅ 批量插入
tx, _ := db.Begin()
stmt, _ := tx.Prepare("INSERT INTO t VALUES (?)")
for _, item := range items {
    stmt.Exec(item)
}
stmt.Close()
tx.Commit()
```

### 3. 查询优化
- 只查询需要的字段，避免 `SELECT *`
- 合理使用索引
- 避免 N+1 查询

## 六、JSON 优化

### 1. 使用 json-iterator
```go
import jsoniter "github.com/json-iterator/go"

var json = jsoniter.ConfigCompatibleWithStandardLibrary
// API 完全兼容，性能提升 2-3x
```

### 2. 流式处理大 JSON
```go
decoder := json.NewDecoder(file)
for {
    var item Item
    if err := decoder.Decode(&item); err == io.EOF {
        break
    }
    // 处理 item
}
```
