## 一、编码层面优化

### 1.1 字符串拼接

```go
// ❌ 低效：每次拼接分配新内存
s := ""
for i := 0; i < 10000; i++ {
    s += "hello"
}

// ✅ 高效：strings.Builder
var builder strings.Builder
builder.Grow(50000) // 预分配
for i := 0; i < 10000; i++ {
    builder.WriteString("hello")
}
result := builder.String()
```

### 1.2 切片预分配

```go
// ❌ 动态扩容
var result []int
for i := 0; i < 10000; i++ {
    result = append(result, i)
}

// ✅ 预分配容量
result := make([]int, 0, 10000)
for i := 0; i < 10000; i++ {
    result = append(result, i)
}
```

### 1.3 Map 预分配

```go
// ❌ 动态扩容
m := make(map[string]int)
for i := 0; i < 10000; i++ {
    m[fmt.Sprintf("key%d", i)] = i
}

// ✅ 预分配
m := make(map[string]int, 10000)
```

### 1.4 对象复用 sync.Pool

```go
var bufPool = sync.Pool{
    New: func() interface{} {
        return make([]byte, 1024)
    },
}

func processData() []byte {
    buf := bufPool.Get().([]byte)
    defer bufPool.Put(buf)

    // 使用 buf 处理数据
    return append([]byte(nil), buf...)
}
```

### 1.5 避免逃逸到堆

```go
// ❌ 逃逸：返回局部变量指针
func newUser() *User {
    u := User{Name: "test"}
    return &u // 逃逸到堆
}

// ✅ 直接返回值
func newUser() User {
    return User{Name: "test"} // 栈分配
}

// ❌ 逃逸：接口赋值
func process(v interface{}) {} // 任何值传入都会逃逸

// ✅ 使用泛型避免接口
func process[T any](v T) {}
```

### 1.6 减少反射

```go
// ❌ 反射：性能差
func toJSON(v interface{}) string {
    b, _ := json.Marshal(v)
    return string(b)
}

// ✅ 实现 MarshalJSON
func (u User) MarshalJSON() ([]byte, error) {
    return []byte(fmt.Sprintf(`{"name":"%s"}`, u.Name)), nil
}

// ✅ 使用 json-iterator
import jsoniter "github.com/json-iterator/go"

var json = jsoniter.ConfigCompatibleWithStandardLibrary
```

## 二、并发优化

### 2.1 并发处理独立任务

```go
// ❌ 串行
func fetchData() (*User, *Order, *Product) {
    user := getUser()      // 100ms
    order := getOrder()    // 150ms
    product := getProduct() // 200ms
    return &user, &order, &product
}

// ✅ 并发
func fetchData() (*User, *Order, *Product) {
    var wg sync.WaitGroup
    var user User
    var order Order
    var product Product

    wg.Add(3)
    go func() { defer wg.Done(); user = getUser() }()
    go func() { defer wg.Done(); order = getOrder() }()
    go func() { defer wg.Done(); product = getProduct() }()
    wg.Wait()

    return &user, &order, &product
}
```

### 2.2 errgroup 并发

```go
import "golang.org/x/sync/errgroup"

func fetchData(ctx context.Context) (*User, *Order, error) {
    g, ctx := errgroup.WithContext(ctx)

    var user User
    var order Order

    g.Go(func() error {
        var err error
        user, err = getUser(ctx)
        return err
    })

    g.Go(func() error {
        var err error
        order, err = getOrder(ctx)
        return err
    })

    if err := g.Wait(); err != nil {
        return nil, nil, err
    }
    return &user, &order, nil
}
```

### 2.3 singleflight 防击穿

```go
import "golang.org/x/sync/singleflight"

var sf singleflight.Group

func getUserByID(id string) (*User, error) {
    v, err, _ := sf.Do(id, func() (interface{}, error) {
        return fetchUserFromDB(id)
    })
    if err != nil {
        return nil, err
    }
    return v.(*User), nil
}
```

## 三、数据库优化

### 3.1 连接池配置

```go
db, err := sql.Open("mysql", dsn)
if err != nil {
    log.Fatal(err)
}

db.SetMaxOpenConns(100)       // 最大连接数
db.SetMaxIdleConns(20)        // 最大空闲连接
db.SetConnMaxLifetime(time.Hour)     // 连接最大存活时间
db.SetConnMaxIdleTime(30 * time.Minute) // 空闲连接最大存活时间
```

### 3.2 批量操作

```go
// ❌ 逐条插入
for _, user := range users {
    db.Exec("INSERT INTO users (name) VALUES (?)", user.Name)
}

// ✅ 批量插入
values := make([]string, 0, len(users))
args := make([]interface{}, 0, len(users))
for _, user := range users {
    values = append(values, "(?)")
    args = append(args, user.Name)
}
query := fmt.Sprintf("INSERT INTO users (name) VALUES %s", strings.Join(values, ","))
db.Exec(query, args...)
```

### 3.3 查询优化

```go
// ❌ 查询不需要的字段
rows, _ := db.Query("SELECT * FROM users WHERE age > 18")

// ✅ 只查询需要的字段
rows, _ := db.Query("SELECT id, name FROM users WHERE age > 18")

// ✅ 使用 LIMIT
rows, _ := db.Query("SELECT id, name FROM users WHERE age > 18 LIMIT 100")
```

## 四、缓存优化

### 4.1 多级缓存

```go
type Cache struct {
    local  *freecache.Cache  // 本地缓存
    redis  *redis.Client     // 分布式缓存
}

func (c *Cache) Get(ctx context.Context, key string) (string, error) {
    // L1: 本地缓存
    if val, err := c.local.Get([]byte(key)); err == nil {
        return string(val), nil
    }

    // L2: Redis
    val, err := c.redis.Get(ctx, key).Result()
    if err != nil {
        return "", err
    }

    // 回填本地缓存
    c.local.Set([]byte(key), []byte(val), 60)

    return val, nil
}
```

### 4.2 缓存问题解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 缓存穿透 | 查询不存在的数据 | 布隆过滤器 / 缓存空值 |
| 缓存击穿 | 热点 key 过期 | 互斥锁 / 永不过期 / singleflight |
| 缓存雪崩 | 大量 key 同时过期 | 随机过期时间 / 多级缓存 |

## 六、JSON 优化

### 6.1 json-iterator

```go
import jsoniter "github.com/json-iterator/go"

var json = jsoniter.ConfigCompatibleWithStandardLibrary

// API 完全兼容标准库，性能提升 2-3 倍
data, _ := json.Marshal(&user)
```

### 6.2 流式处理大 JSON

```go
func processLargeJSON(r io.Reader) error {
    dec := json.NewDecoder(r)
    for dec.More() {
        var item Item
        if err := dec.Decode(&item); err != nil {
            return err
        }
        processItem(item)
    }
    return nil
}
```
