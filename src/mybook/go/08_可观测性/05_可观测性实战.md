# 可观测性实战

将日志、指标、链路追踪三大支柱整合，构建完整的可观测性体系。

---

## 一、三大支柱整合

### 1.1 架构图

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Logs     │     │  Metrics   │     │   Traces   │
│   日志      │     │   指标      │     │   链路      │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       └───────────────────┼───────────────────┘
                           │
                    ┌──────┴──────┐
                    │  Trace ID   │
                    │  关联纽带    │
                    └─────────────┘
```

### 1.2 关联方式

- 日志中包含 trace_id
- 指标标签包含 trace_id
- 通过 trace_id 串联所有信息

## 二、OpenTelemetry 集成

### 2.1 初始化

```go
import (
    "go.opentelemetry.io/otel"
    "go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc"
    "go.opentelemetry.io/otel/sdk/trace"
)

func initTracer() func() {
    exporter, _ := otlptracegrpc.New(context.Background(),
        otlptracegrpc.WithEndpoint("localhost:4317"),
        otlptracegrpc.WithInsecure(),
    )

    tp := trace.NewTracerProvider(
        trace.WithBatcher(exporter),
    )
    otel.SetTracerProvider(tp)

    return func() { tp.Shutdown(context.Background()) }
}
```

### 2.2 创建 Span

```go
func processOrder(ctx context.Context, orderID string) error {
    tracer := otel.Tracer("order-service")
    ctx, span := tracer.Start(ctx, "process_order")
    defer span.End()

    span.SetAttributes(
        attribute.String("order_id", orderID),
    )

    return nil
}
```

### 2.3 日志关联 Trace

```go
func LogWithTrace(ctx context.Context, logger *zap.Logger, msg string, fields ...zap.Field) {
    span := trace.SpanFromContext(ctx)
    if span.SpanContext().IsValid() {
        fields = append(fields,
            zap.String("trace_id", span.SpanContext().TraceID().String()),
            zap.String("span_id", span.SpanContext().SpanID().String()),
        )
    }
    logger.Info(msg, fields...)
}
```

## 三、Prometheus 指标集成

### 3.1 定义指标

```go
var (
    httpRequestsTotal = prometheus.NewCounterVec(
        prometheus.CounterOpts{
            Name: "http_requests_total",
            Help: "Total number of HTTP requests",
        },
        []string{"method", "path", "status"},
    )

    httpRequestDuration = prometheus.NewHistogramVec(
        prometheus.HistogramOpts{
            Name:    "http_request_duration_seconds",
            Help:    "HTTP request duration in seconds",
            Buckets: []float64{.01, .05, .1, .5, 1, 2.5, 5, 10},
        },
        []string{"method", "path"},
    )
)

func init() {
    prometheus.MustRegister(httpRequestsTotal)
    prometheus.MustRegister(httpRequestDuration)
}
```

### 3.2 中间件集成

```go
func PrometheusMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()

        c.Next()

        duration := time.Since(start).Seconds()
        status := strconv.Itoa(c.Writer.Status())

        httpRequestsTotal.WithLabelValues(c.Request.Method, c.FullPath(), status).Inc()
        httpRequestDuration.WithLabelValues(c.Request.Method, c.FullPath()).Observe(duration)
    }
}
```

## 四、完整示例

### 4.1 服务初始化

```go
func main() {
    shutdown := initTracer()
    defer shutdown()

    logger := initLogger()
    defer logger.Sync()

    r := gin.New()
    r.Use(TraceMiddleware())
    r.Use(LoggingMiddleware(logger))
    r.Use(PrometheusMiddleware())

    r.GET("/api/users", getUsers)

    r.GET("/metrics", gin.WrapH(promhttp.Handler()))

    r.Run(":8080")
}
```

### 4.2 Trace 中间件

```go
func TraceMiddleware() gin.HandlerFunc {
    tracer := otel.Tracer("gin-server")

    return func(c *gin.Context) {
        ctx, span := tracer.Start(c.Request.Context(), c.FullPath())
        defer span.End()

        c.Request = c.Request.WithContext(ctx)

        span.SetAttributes(
            attribute.String("http.method", c.Request.Method),
            attribute.String("http.url", c.Request.URL.String()),
        )

        c.Next()

        span.SetAttributes(
            attribute.Int("http.status_code", c.Writer.Status()),
        )
    }
}
```

### 4.3 业务处理

```go
func getUsers(c *gin.Context) {
    ctx := c.Request.Context()
    tracer := otel.Tracer("user-service")

    ctx, span := tracer.Start(ctx, "get_users")
    defer span.End()

    users, err := fetchUsersFromDB(ctx)
    if err != nil {
        span.RecordError(err)
        LogWithTrace(ctx, logger, "failed to fetch users", zap.Error(err))
        c.JSON(500, gin.H{"error": err.Error()})
        return
    }

    span.SetAttributes(attribute.Int("user_count", len(users)))
    LogWithTrace(ctx, logger, "users fetched", zap.Int("count", len(users)))

    c.JSON(200, users)
}
```

## 五、问题排查流程

### 5.1 发现问题

1. Prometheus 告警：错误率上升
2. Grafana 面板：P99 延迟增加

### 5.2 定位问题

1. 查看日志：通过 trace_id 筛选
2. 查看 Trace：Jaeger 分析调用链
3. 找到瓶颈：某个服务或数据库

### 5.3 解决问题

1. 分析代码：找到慢的原因
2. 优化代码：修复性能问题
3. 验证效果：观察指标变化

---

## 六、最佳实践

1. **统一 Trace ID**：所有日志、指标使用相同的 trace_id
2. **合理采样**：生产环境可降低采样率
3. **告警配置**：设置关键指标告警
4. **定期回顾**：分析系统瓶颈
5. **文档化**：记录排查流程和经验
