# 数据类型

## 一、基本数据类型

### 1.1 整型

| 类型 | 描述 |
|------|------|
| `int8` | 有符号 8 位整数（-128 ~ 127） |
| `int16` | 有符号 16 位整数 |
| `int32` | 有符号 32 位整数 |
| `int64` | 有符号 64 位整数 |
| `uint8` | 无符号 8 位整数（0 ~ 255） |
| `uint16` | 无符号 16 位整数 |
| `uint32` | 无符号 32 位整数 |
| `uint64` | 无符号 64 位整数 |
| `int` | 与平台相关，64位系统为 int64 |
| `uint` | 与平台相关，64位系统为 uint64 |
| `uintptr` | 无符号整数，用于存放指针 |

```go
var a int8 = -128
var b uint8 = 255
fmt.Printf("int8: %d, uint8: %d\n", a, b)

fmt.Println("int size:", unsafe.Sizeof(int(0)))
fmt.Println("uintptr size:", unsafe.Sizeof(uintptr(0)))
```

### 1.2 浮点型

| 类型 | 描述 |
|------|------|
| `float32` | 32 位浮点数，约 7 位精度 |
| `float64` | 64 位浮点数，约 15 位精度（默认） |

```go
var f1 float32 = 3.14
var f2 float64 = 3.141592653589793
fmt.Printf("float32: %.7f\n", f1)
fmt.Printf("float64: %.15f\n", f2)

fmt.Println(math.MaxFloat32)
fmt.Println(math.MaxFloat64)
```

### 1.3 复数

| 类型 | 描述 |
|------|------|
| `complex64` | 32 位实数 + 32 位虚数 |
| `complex128` | 64 位实数 + 64 位虚数（默认） |

```go
var c1 complex64 = 1 + 2i
var c2 complex128 = complex(1, 2)
fmt.Println(c1, c2)
fmt.Println(real(c2))
fmt.Println(imag(c2))
```

### 1.4 布尔值

```go
var b1 bool = true
var b2 bool
fmt.Println(b1)
fmt.Println(b2)

// Go 中布尔值不能与整数互转
// var b bool = 1  // 编译错误
```

- 布尔类型默认值为 `false`
- 布尔值不能与整数进行隐式转换
- 布尔值无法参与数值运算

### 1.5 字符串

```go
s1 := "hello"
s2 := "你好"

fmt.Println(len(s1))
fmt.Println(len(s2))

s3 := "hello world"
fmt.Println(s3[0])
fmt.Println(s3[0:5])

// 多行字符串
s4 := `
第一行
第二行
第三行
`
fmt.Println(s4)
```

- 字符串是不可变的字节序列
- `len()` 返回字节数，不是字符数
- 字符串默认编码为 UTF-8
- 多行字符串用反引号 `` ` ``

**字符串常用操作**：

| 操作 | 语法 | 说明 |
|------|------|------|
| 拼接 | `+` / `fmt.Sprintf` | 字符串拼接 |
| 分割 | `strings.Split` | 按分隔符分割 |
| 包含 | `strings.Contains` | 是否包含子串 |
| 前缀 | `strings.HasPrefix` | 是否以某前缀开头 |
| 后缀 | `strings.HasSuffix` | 是否以某后缀结尾 |
| 索引 | `strings.Index` | 子串首次出现位置 |
| 替换 | `strings.Replace` | 替换子串 |
| 大小写 | `strings.ToUpper/ToLower` | 转换大小写 |
| 去空格 | `strings.TrimSpace` | 去除两端空白 |
| 重复 | `strings.Repeat` | 重复 N 次 |
| Join | `strings.Join` | 用分隔符连接切片 |

### 1.6 byte 和 rune

```go
// byte 是 uint8 的别名，代表 ASCII 字符
// rune 是 int32 的别名，代表 Unicode 码点

s := "hello你好"
fmt.Println(len(s))
fmt.Println(utf8.RuneCountInString(s))

for i, ch := range s {
    fmt.Printf("%d: %c(%d)\n", i, ch, ch)
}

for i, ch := range []rune(s) {
    fmt.Printf("%d: %c\n", i, ch)
}
```

- `byte` = `uint8`，用于处理 ASCII 字符
- `rune` = `int32`，用于处理 Unicode 字符
- 中文字符在 UTF-8 下占 3 个字节
- `for range` 遍历字符串时按 rune 遍历

### 1.7 类型转换

```go
// Go 不支持隐式类型转换，必须显式转换
var a int = 10
var b float64 = float64(a)
var c int = int(b)

// 字符串与数值互转
s1 := strconv.Itoa(100)
n1, _ := strconv.Atoi("100")

s2 := strconv.FormatFloat(3.14, 'f', 2, 64)
f1, _ := strconv.ParseFloat("3.14", 64)

// 字符串与 []byte
bytes := []byte("hello")
str := string(bytes)

// 字符串与 []rune
runes := []rune("你好")
str2 := string(runes)
```

## 二、数组

### 2.1 定义与初始化

```go
var a [3]int
var b = [3]int{1, 2, 3}
var c = [...]int{1, 2, 3}
var d = [...]int{2: 3, 1: 2}
var e = [...]int{1, 2, 4: 5, 6}

fmt.Println(a)
fmt.Println(b)
fmt.Println(c)
fmt.Println(d)
fmt.Println(e)
```

### 2.2 遍历

```go
for i := range a {
    fmt.Printf("a[%d]: %d\n", i, a[i])
}

for i, v := range b {
    fmt.Printf("b[%d]: %d\n", i, v)
}

for i := 0; i < len(c); i++ {
    fmt.Printf("c[%d]: %d\n", i, c[i])
}
```

### 2.3 多维数组

```go
var a [2][3]int
a = [2][3]int{
    {1, 2, 3},
    {4, 5, 6},
}

for _, row := range a {
    for _, v := range row {
        fmt.Printf("%d ", v)
    }
    fmt.Println()
}
```

### 2.4 值类型特性

```go
a := [...]int{1, 2, 3}
b := a
b[0] = 100
fmt.Println(a)
fmt.Println(b)

modifyArray := func(x [3]int) {
    x[0] = 100
}
c := [3]int{1, 2, 3}
modifyArray(c)
fmt.Println(c)
```

- 数组是值类型，赋值和传参会复制整个数组
- 数组长度是类型的一部分，`[3]int` 和 `[5]int` 是不同类型

## 三、切片（Slice）

### 3.1 定义

```go
var a []int
var b = []int{}
var c = []int{1, 2, 3}
var d = c[:2]
var e = c[0:2:cap(c)]
var f = c[:0]
var g = make([]int, 3)
var h = make([]int, 2, 3)
var i = make([]int, 0, 3)

fmt.Println(a == nil)
fmt.Println(b == nil)
fmt.Println(len(a), cap(a))
fmt.Println(len(h), cap(h))
```

### 3.2 长度与容量

```go
s := []int{0, 1, 2, 3, 4, 5}
fmt.Println(len(s), cap(s))

s1 := s[1:4]
fmt.Println(len(s1), cap(s1))

s2 := s[1:4:4]
fmt.Println(len(s2), cap(s2))
```

- `len` 返回有效元素个数
- `cap` 返回底层数组从切片起始位置到末尾的容量
- 切片表达式 `s[low:high:max]` 可限制容量为 `max-low`

### 3.3 切片的本质

```go
type SliceHeader struct {
    Data uintptr
    Len  int
    Cap  int
}
```

- 切片是对底层数组的一个引用视图
- 切片截取后仍指向原始底层数组
- 使用 `s[low:high:max]` 限制容量可避免共享底层数组问题

```go
foo := []int{0, 0, 0, 42, 100}
bar := foo[1:4]
bar = append(bar, 99)

bar2 := foo[1:4:4]
bar2 = append(bar2, 99)
```

### 3.4 append 与 copy

```go
var a []int
a = append(a, 1)
a = append(a, 1, 2, 3)
a = append(a, []int{1, 2, 3}...)

a = append([]int{0}, a...)
a = append([]int{-3, -2, -1}, a...)

a = append(a, 0)
copy(a[i+1:], a[i:])
a[i] = x

b := make([]int, len(a))
copy(b, a)
```

### 3.5 删除元素

```go
a = []int{1, 2, 3}
a = a[:len(a)-1]
a = a[:len(a)-N]

a = []int{1, 2, 3}
a = a[1:]
a = a[N:]

a = []int{1, 2, 3}
a = append(a[:i], a[i+1:]...)
a = a[:i+copy(a[i:], a[i+1:])]
```

### 3.6 避免内存泄漏

```go
func FindPhoneNumber(filename string) []byte {
    b, _ := os.ReadFile(filename)
    b = regexp.MustCompile("[0-9]+").Find(b)
    return append([]byte{}, b...)
}
```

- 切片操作不复制底层数据
- 小切片可能引用大数组，导致内存无法回收
- 将需要的数据复制到新切片可避免此问题

## 四、映射（Map）

### 4.1 定义与初始化

```go
var m1 map[string]int
m1 = make(map[string]int)
m1["go"] = 1

m2 := map[string]int{
    "go":   1,
    "java": 2,
}

m3 := make(map[string]int, 10)
```

- 未初始化的 map 值为 nil，写入会 panic
- `make` 可指定初始容量减少扩容

### 4.2 基本操作

```go
m := make(map[string]int)
m["go"] = 1
m["java"] = 2

v := m["go"]
fmt.Println(v)

v, ok := m["python"]
fmt.Println(v, ok)

delete(m, "java")

fmt.Println(len(m))
```

### 4.3 遍历

```go
for k, v := range m {
    fmt.Println(k, v)
}

for k := range m {
    fmt.Println(k)
}
```

- map 遍历顺序不确定，每次运行结果可能不同
- 如需有序遍历，需先排序 key

```go
keys := make([]string, 0, len(m))
for k := range m {
    keys = append(keys, k)
}
sort.Strings(keys)
for _, k := range keys {
    fmt.Println(k, m[k])
}
```

### 4.4 元素为 map 的切片

```go
var s = make([]map[string]int, 3)
for i := range s {
    s[i] = make(map[string]int)
    s[i]["key"] = i
}
```

### 4.5 值为切片的 map

```go
var m = make(map[string][]int)
m["go"] = []int{1, 2, 3}
m["java"] = append(m["java"], 4, 5, 6)
```

### 4.6 并发安全

- map 不是并发安全的，并发读写会 panic
- 使用 `sync.Map` 或加锁保证并发安全

```go
var m sync.Map
m.Store("go", 1)
v, ok := m.Load("go")
m.Range(func(k, v interface{}) bool {
    fmt.Println(k, v)
    return true
})
```

## 五、类型别名

```go
type MyInt int64
type MyIntAlias = int64

var a MyInt = 100
var b MyIntAlias = 200

fmt.Printf("a type: %T\n", a)
fmt.Printf("b type: %T\n", b)
```

- `type NewType OldType`：自定义类型，与原类型不同
- `type Alias = OldType`：类型别名，与原类型完全相同
