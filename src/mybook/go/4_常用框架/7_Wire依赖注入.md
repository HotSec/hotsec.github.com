# Wire 依赖注入

---

## 一、Wire 简介

Wire 是 Google 出品的 **编译时依赖注入** 框架，通过代码生成在编译期完成依赖注入。

### 1.1 核心概念

| 概念 | 说明 |
|------|------|
| Provider | 提供依赖的函数（构造函数） |
| Injector | 注入器，组装所有 Provider |
| Bind | 接口绑定，将接口与实现关联 |
| Set | Provider 集合 |

### 1.2 Wire vs 运行时 DI

| 维度 | Wire (编译时) | dig/fx (运行时) |
|------|--------------|-----------------|
| 检查时机 | 编译期 | 运行时 |
| 错误发现 | 早 | 晚 |
| 性能 | 无反射开销 | 反射开销 |
| 调试 | 容易 | 较难 |
| 灵活性 | 较低 | 较高 |

## 三、基本使用

### 3.1 定义组件

```go
// internal/repository/user.go
type UserRepository struct {
    db *sql.DB
}

func NewUserRepository(db *sql.DB) *UserRepository {
    return &UserRepository{db: db}
}

func (r *UserRepository) FindByID(ctx context.Context, id int) (*User, error) {
    // ...
}
```

```go
// internal/service/user.go
type UserService struct {
    repo *UserRepository
}

func NewUserService(repo *UserRepository) *UserService {
    return &UserService{repo: repo}
}

func (s *UserService) GetUser(ctx context.Context, id int) (*User, error) {
    return s.repo.FindByID(ctx, id)
}
```

```go
// internal/controller/user.go
type UserController struct {
    service *UserService
}

func NewUserController(service *UserService) *UserController {
    return &UserController{service: service}
}
```

### 3.2 定义 Provider Set

```go
// internal/repository/wire.go
package repository

import "github.com/google/wire"

var ProviderSet = wire.NewSet(NewUserRepository)
```

```go
// internal/service/wire.go
package service

import "github.com/google/wire"

var ProviderSet = wire.NewSet(NewUserService)
```

```go
// internal/controller/wire.go
package controller

import "github.com/google/wire"

var ProviderSet = wire.NewSet(NewUserController)
```

### 3.3 定义 Injector

```go
// wire.go
//go:build wireinject

package main

import (
    "github.com/google/wire"
    "myapp/internal/controller"
    "myapp/internal/repository"
    "myapp/internal/service"
)

func InitializeApp(db *sql.DB) (*App, error) {
    wire.Build(
        repository.ProviderSet,
        service.ProviderSet,
        controller.ProviderSet,
        NewApp,
    )
    return nil, nil
}
```

### 3.4 生成代码

```bash
cd /path/to/project
wire
```

生成的 `wire_gen.go`：

```go
// Code generated by Wire. DO NOT EDIT.

func InitializeApp(db *sql.DB) (*App, error) {
    userRepository := repository.NewUserRepository(db)
    userService := service.NewUserService(userRepository)
    userController := controller.NewUserController(userService)
    app := NewApp(userController)
    return app, nil
}
```

### 3.5 使用

```go
func main() {
    db, _ := sql.Open("mysql", dsn)
    app, err := InitializeApp(db)
    if err != nil {
        log.Fatal(err)
    }
    app.Run()
}
```

## 四、接口绑定

### 4.1 定义接口与实现

```go
type UserRepository interface {
    FindByID(ctx context.Context, id int) (*User, error)
    Create(ctx context.Context, user *User) error
}

type mysqlUserRepository struct {
    db *sql.DB
}

func NewMysqlUserRepository(db *sql.DB) UserRepository {
    return &mysqlUserRepository{db: db}
}
```

### 4.2 Wire Bind

```go
var ProviderSet = wire.NewSet(
    NewMysqlUserRepository,
    wire.Bind(new(UserRepository), new(*mysqlUserRepository)),
)
```

## 五、结构体绑定

### 5.1 wire.Struct

```go
type App struct {
    Controller *UserController
    Service    *UserService
    Config     *Config
}

var ProviderSet = wire.NewSet(
    wire.Struct(new(App), "*"),
)
```

### 5.2 选择性绑定

```go
var ProviderSet = wire.NewSet(
    wire.Struct(new(App), "Controller", "Service"),
)
```

## 七、清理函数

### 7.1 返回清理函数

```go
func NewDB(cfg *Config) (*sql.DB, func(), error) {
    db, err := sql.Open("mysql", cfg.DSN)
    if err != nil {
        return nil, nil, err
    }
    cleanup := func() {
        db.Close()
    }
    return db, cleanup, nil
}
```

### 7.2 Injector 中的清理

```go
func InitializeApp(cfg *Config) (*App, func(), error) {
    wire.Build(
        NewDB,
        NewApp,
    )
    return nil, nil, nil
}
```

## 八、实战：Gin + Wire

### 8.1 项目结构

```
myapp/
├── cmd/
│   └── server/
│       ├── wire.go       # Injector 定义
│       ├── wire_gen.go   # 生成代码
│       └── main.go
├── internal/
│   ├── handler/
│   ├── service/
│   ├── repository/
│   └── model/
└── pkg/
    ├── database/
    └── config/
```

### 8.2 完整示例

```go
// cmd/server/wire.go
//go:build wireinject

package main

import (
    "github.com/google/wire"
    "myapp/internal/handler"
    "myapp/internal/repository"
    "myapp/internal/service"
    "myapp/pkg/config"
    "myapp/pkg/database"
)

func InitializeServer() (*Server, func(), error) {
    wire.Build(
        config.ProviderSet,
        database.ProviderSet,
        repository.ProviderSet,
        service.ProviderSet,
        handler.ProviderSet,
        NewServer,
    )
    return nil, nil, nil
}
```

```go
// cmd/server/main.go
package main

func main() {
    server, cleanup, err := InitializeServer()
    if err != nil {
        log.Fatal(err)
    }
    defer cleanup()
    server.Run()
}
```

```go
// cmd/server/server.go
package main

import "github.com/gin-gonic/gin"

type Server struct {
    engine  *gin.Engine
    handler *handler.Handler
}

func NewServer(engine *gin.Engine, h *handler.Handler) *Server {
    return &Server{engine: engine, handler: h}
}

func (s *Server) Run() {
    s.handler.RegisterRoutes(s.engine)
    s.engine.Run(":8080")
}
```

## 九、常见问题

### 9.1 循环依赖

Wire 不支持循环依赖，需要重构：

```go
// ❌ 循环依赖
// A 需要 B，B 需要 A

// ✅ 提取公共依赖
// A 需要 C，B 需要 C
```

### 9.2 可选依赖

```go
// 使用指针表示可选
func NewService(repo *UserRepository, cache *Cache) *UserService {
    // cache 可以为 nil
}
```

### 9.3 多个同类型绑定

```go
// 使用 wire.FieldsOf 提取结构体字段
var ProviderSet = wire.NewSet(
    wire.FieldsOf(new(*Config), "DB", "Redis"),
)
```

## 十、最佳实践

1. **每个包一个 ProviderSet**：便于管理
2. **接口绑定优于具体类型**：便于测试和替换
3. **Injector 文件放在 main 包**：靠近入口
4. **提交 wire_gen.go**：确保构建可复现
5. **使用 wire check**：检查依赖图是否正确

```bash
wire check ./...
```
