# Go 内存分配器

> 主要参考：《Go语言高级编程（第2版）》第4.3节 — 柴树杉、曹春晖 著

Go 内存分配器（Memory Allocator）是 Go 运行时的核心组件之一，负责高效地管理堆内存的分配和回收。它采用多级缓存设计，结合 TCMalloc 的思想，实现了高并发场景下的低延迟内存分配。

---

## 一、设计理念

### 1.1 TCMalloc 思想

Go 内存分配器借鉴了 Google 的 TCMalloc（Thread-Caching Malloc）：

```
┌─────────────────────────────────────────────────────────────┐
│                      TCMalloc 思想                          │
├─────────────────────────────────────────────────────────────┤
│  1. 线程本地缓存：每个线程有自己的缓存，减少锁竞争           │
│  2. 多级分配：小对象从线程缓存分配，大对象从堆分配           │
│  3. 大小类别：按对象大小分类，减少内存碎片                   │
│  4. 中心缓存：线程缓存不足时从中心缓存补充                   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心目标

- **低延迟**：小对象分配无锁
- **高并发**：多级缓存减少竞争
- **低碎片**：大小类别优化内存利用率
- **可扩展**：适应多核处理器

## 二、核心数据结构

### 2.1 mspan（内存块）

mspan 是内存分配的基本单位，包含多个相同大小的对象：

```go
type mspan struct {
    next     *mspan     // 链表下一个
    prev     *mspan     // 链表前一个
    list     *mSpanList // 所属链表
    
    startAddr  uintptr   // 起始地址
    npages     uintptr   // 页数（1页 = 8KB）
    manualFreeList gList // 手动释放链表
    
    nelems      uintptr  // 对象数量
    allocCount  uint16   // 已分配对象数
    spanclass   spanClass // 大小类别
    
    gcmarkBits  *gcBits  // GC 标记位图
    allocBits   *gcBits  // 分配位图
    
    sweepgen    uint32   // 清扫代数
    divMul      uint32   // 用于计算对象索引
}

type spanClass uint8

// 大小类别编码
// noscan: 是否包含指针
// sizeclass: 大小级别（0-67）
func makeSpanClass(sizeclass uint8, noscan bool) spanClass {
    return spanClass(sizeclass<<1) | spanClass(bool2int(noscan))
}
```

mspan 结构示意：

```
┌─────────────────────────────────────────────────────────────┐
│                        mspan                                │
│  npages = 2 (16KB), spanclass = 3 (24B), nelems = 682       │
├─────────────────────────────────────────────────────────────┤
│ Object │ Object │ Object │ ... │ Object │  Free  │  Free   │
│   0    │   1    │   2    │     │  681   │ Space  │ Space   │
│  24B   │  24B   │  24B   │     │  24B   │        │         │
└─────────────────────────────────────────────────────────────┘
allocBits:  11111111...1100  (前 682 个对象已分配)
gcmarkBits: 10101010...1000  (GC 标记状态)
```

### 2.2 mcache（本地缓存）

每个 P 都有一个 mcache，用于无锁分配小对象：

```go
type mcache struct {
    tiny       uintptr    // 微分配器起始地址
    tinyoffset uintptr    // 微分配器偏移
    local_tinyallocs uintptr // 微分配次数
    
    // 各大小类别的 mspan 缓存
    alloc [numSpanClasses]*mspan // 68 * 2 = 136 个
    
    // 栈缓存
    stackcache [_NumStackOrders]stackfreelist
    
    // 本地分配统计
    local_scan         uintptr
    local_tinyallocs   uintptr
    local_largeallocs  uintptr
    local_nsmallallocs [numSpanClasses]uintptr
    local_nlargeallocs uintptr
    local_largefree    uintptr
    local_nsmallfree   [numSpanClasses]uintptr
    
    // 刷新状态
    flushGen uint32
}
```

mcache 结构示意：

```
┌─────────────────────────────────────────────────────────────┐
│                        mcache                               │
├─────────────────────────────────────────────────────────────┤
│ tiny allocator (16B)                                        │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ [微对象分配区，用于 < 16B 的对象]                       │ │
│ └────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│ alloc[0] (noscan, 8B)   → mspan (8B objects)               │
│ alloc[1] (scan, 8B)     → mspan (8B objects)               │
│ alloc[2] (noscan, 16B)  → mspan (16B objects)              │
│ alloc[3] (scan, 16B)    → mspan (16B objects)              │
│ ...                                                        │
│ alloc[134] (noscan, 32KB) → mspan (32KB objects)           │
│ alloc[135] (scan, 32KB)   → mspan (32KB objects)           │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 mcentral（中心缓存）

mcentral 管理特定大小类别的 mspan：

```go
type mcentral struct {
    spanclass spanClass
    
    // 部分使用的 mspan 链表
    partial [2]spanSet
    
    // 完全使用的 mspan 链表
    full [2]spanSet
}

type spanSet struct {
    spine    []*spanSetBlock
    spineLen uintptr
    spineCap uintptr
    index    uintptr
}
```

mcentral 结构示意：

```
┌─────────────────────────────────────────────────────────────┐
│              mcentral (spanclass = 3, 16B)                  │
├─────────────────────────────────────────────────────────────┤
│ partial (有可用对象)                                         │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐                        │
│ │ mspan1  │→│ mspan2  │→│ mspan3  │                        │
│ │used:50%│ │used:75%│ │used:25%│                        │
│ └─────────┘ └─────────┘ └─────────┘                        │
├─────────────────────────────────────────────────────────────┤
│ full (无可用对象)                                            │
│ ┌─────────┐ ┌─────────┐                                     │
│ │ mspan4  │→│ mspan5  │                                     │
│ │used:100%│ │used:100%│                                     │
│ └─────────┘ └─────────┘                                     │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 mheap（堆管理器）

mheap 是全局的堆管理器，管理所有内存：

```go
type mheap struct {
    lock      mutex
    
    // 空闲页面链表
    free      mTreap
    
    // 已分配的 spans
    allspans []*mspan
    
    // arenas: 堆内存区域管理
    arenas   [1 << arenaL1Bits]*[1 << arenaL2Bits]*heapArena
    
    // 中心缓存数组
    central  [numSpanClasses]struct {
        mcentral mcentral
        pad      [(cpu.CacheLinePadSize - unsafe.Sizeof(mcentral{})%cpu.CacheLinePadSize) % cpu.CacheLinePadSize]byte
    }
    
    // 统计信息
    sweepgen     uint32
    sweepdone    uint32
    sweepers     uint32
    
    // 大对象分配
    largealloc   uint64
    nlargealloc  uint64
    largefree    uint64
    nlargefree   uint64
    
    // 小对象分配
    nsmallalloc  [numSpanClasses]uint64
}

type heapArena struct {
    bitmap     [heapArenaBitmapBytes]byte
    spans      [pagesPerArena]*mspan
    pageInUse  [pagesPerArena / 8]uint8
    pageMarks  [pagesPerArena / 8]uint8
    pageSpecials [pagesPerArena / 8]uint8
    checkmarks *checkmarksMap
    zeroed     bool
}
```

## 四、分配流程详解

### 4.1 mallocgc 入口

```go
func mallocgc(size uintptr, typ *_type, needzero bool) unsafe.Pointer {
    if gcphase == _GCmarktermination {
        throw("mallocgc during gc mark termination")
    }
    
    if size == 0 {
        return unsafe.Pointer(&zerobase)
    }
    
    // 获取当前 P
    mp := acquirem()
    pp := mp.p.ptr()
    
    // 判断是否为小对象
    if size <= maxSmallSize {
        if noscan && size < maxTinySize {
            // 微对象分配 (< 16B)
            return mallocgcTiny(size, pp)
        } else {
            // 小对象分配 (16B ~ 32KB)
            return mallocgcSmall(size, typ, pp)
        }
    } else {
        // 大对象分配 (> 32KB)
        return mallocgcLarge(size, typ, needzero, pp)
    }
}
```

### 4.2 微对象分配

```go
func mallocgcTiny(size uintptr, pp *p) unsafe.Pointer {
    // 微分配器：将多个微对象合并到一个 16B 块中
    off := pp.tinyoffset
    
    // 对齐
    if size&7 == 0 {
        off = alignUp(off, 8)
    } else if size&3 == 0 {
        off = alignUp(off, 4)
    } else if size&1 == 0 {
        off = alignUp(off, 2)
    }
    
    // 检查当前块是否有足够空间
    if off+size <= maxTinySize && pp.tiny != 0 {
        // 从当前块分配
        x := unsafe.Pointer(pp.tiny + off)
        pp.tinyoffset = off + size
        pp.local_tinyallocs++
        releasem(mp)
        return x
    }
    
    // 当前块空间不足，分配新的 mspan
    span := pp.mcache.alloc[tinySpanClass]
    if span == nil || span.allocCount == span.nelems {
        // 从 mcentral 获取新的 mspan
        span = mcache.refill(tinySpanClass)
    }
    
    // 从 mspan 分配
    x := span.malloc(size)
    pp.tiny = uintptr(x)
    pp.tinyoffset = size
    
    return x
}
```

### 4.3 小对象分配

```go
func mallocgcSmall(size uintptr, typ *_type, pp *p) unsafe.Pointer {
    // 计算大小类别
    sizeclass := size_to_class[size]
    spanclass := makeSpanClass(sizeclass, noscan)
    
    // 从 mcache 获取 mspan
    span := pp.mcache.alloc[spanclass]
    
    // mspan 无可用空间
    if span == nil || span.allocCount == span.nelems {
        span = mcache.refill(spanclass)
        pp.mcache.alloc[spanclass] = span
    }
    
    // 从 mspan 分配对象
    x := span.malloc(size)
    
    // 清零
    if needzero {
        memclrNoHeapPointers(x, size)
    }
    
    return x
}

// mcache.refill 从 mcentral 获取新的 mspan
func (c *mcache) refill(spanclass spanClass) *mspan {
    s := mheap_.central[spanclass].mcentral.cacheSpan()
    return s
}
```

### 4.4 大对象分配

```go
func mallocgcLarge(size uintptr, typ *_type, needzero bool, pp *p) unsafe.Pointer {
    // 计算需要的页数
    npages := size >> _PageShift
    if size&_PageMask != 0 {
        npages++
    }
    
    // 从 mheap 分配
    s := mheap_.alloc(npages, spanclass, noscan)
    if s == nil {
        throw("out of memory")
    }
    
    // 设置为大对象
    s.large = true
    
    // 分配内存
    x := unsafe.Pointer(s.startAddr)
    
    // 清零
    if needzero {
        memclrNoHeapPointers(x, size)
    }
    
    // 统计
    pp.local_largeallocs++
    pp.local_largefree += size
    
    return x
}
```

## 五、mcentral 与 mheap

### 5.1 mcentral.cacheSpan

```go
func (c *mcentral) cacheSpan() *mspan {
    // 尝试从 partial 列表获取
    s := c.partial.tryPop()
    if s != nil {
        return s
    }
    
    // 尝试从 full 列表获取（可能有 GC 释放的空间）
    s = c.full.tryPop()
    if s != nil {
        return s
    }
    
    // 从 mheap 分配新的 mspan
    s = c.grow()
    return s
}

func (c *mcentral) grow() *mspan {
    npages := class_to_allocnpages[c.spanclass.sizeclass()]
    size := class_to_size[c.spanclass.sizeclass()]
    n := (npages << _PageShift) / size
    
    // 从 mheap 分配
    s := mheap_.alloc(npages, c.spanclass, false)
    if s == nil {
        return nil
    }
    
    // 初始化 mspan
    s.limit = s.startAddr + npages*pageSize
    s.initHeapBits()
    
    return s
}
```

### 5.2 mheap.alloc

```go
func (h *mheap) alloc(npages uintptr, spanclass spanClass, noscan bool) *mspan {
    var s *mspan
    
    // 加锁
    lock(&h.lock)
    
    // 检查是否需要 GC
    if h.sweepdone == 0 {
        h.reclaim(npages)
    }
    
    // 从空闲链表分配
    s = h.allocSpan(npages, spanclass, noscan)
    
    unlock(&h.lock)
    
    return s
}

func (h *mheap) allocSpan(npages uintptr, spanclass spanClass, noscan bool) *mspan {
    // 尝试从空闲链表获取
    s := h.free.find(npages)
    if s != nil {
        return s
    }
    
    // 从操作系统分配新内存
    s = h.grow(npages)
    return s
}

func (h *mheap) grow(npages uintptr) *mspan {
    // 计算需要的内存大小
    size := npages << _PageShift
    
    // 从操作系统分配
    v := sysAlloc(size, &memstats.heap_sys)
    if v == nil {
        return nil
    }
    
    // 创建 mspan
    s := h.allocMSpanLocked()
    s.init(uintptr(v), npages)
    
    // 添加到 arenas
    h.setSpans(uintptr(v), npages, s)
    
    return s
}
```

## 六、内存回收

### 6.1 mspan.free

```go
func (s *mspan) free(x unsafe.Pointer) {
    // 计算对象索引
    objIndex := s.objIndex(x)
    
    // 更新分配位图
    s.allocBits.clear(objIndex)
    s.allocCount--
    
    // 添加到空闲链表
    s.manualFreeList.push(x)
}
```

### 6.2 mcentral.uncacheSpan

```go
func (c *mcentral) uncacheSpan(s *mspan) {
    // 如果 mspan 完全空闲，归还给 mheap
    if s.allocCount == 0 {
        lock(&mheap_.lock)
        mheap_.freeSpan(s)
        unlock(&mheap_.lock)
        return
    }
    
    // 否则放回 partial 列表
    c.partial.push(s)
}
```

### 6.3 mheap.freeSpan

```go
func (h *mheap) freeSpan(s *mspan) {
    // 从 arenas 移除
    h.setSpans(s.startAddr, s.npages, nil)
    
    // 合并相邻的空闲 span
    h.coalesce(s)
    
    // 放入空闲链表
    h.free.insert(s)
}
```

## 七、内存碎片管理

### 7.1 内部碎片

内部碎片是分配大小与实际使用大小的差值：

```go
// 对象大小 17B，分配到 24B 的 mspan
// 内部碎片 = 24 - 17 = 7B (29%)
```

Go 通过精细的大小级别减少内部碎片：

```
大小范围        碎片率
0-8B           0-50%
8-16B          0-50%
16-32B         0-50%
32-48B         0-33%
48-64B         0-25%
...
```

### 7.2 外部碎片

外部碎片是已分配对象之间的空闲空间：

```
┌─────────────────────────────────────────────────────────────┐
│                        mspan                                │
├─────────────────────────────────────────────────────────────┤
│ [已分配] [空闲] [已分配] [空闲] [已分配] [空闲] [空闲] [空闲]│
│  24B     24B    24B    24B    24B    24B    24B    24B       │
└─────────────────────────────────────────────────────────────┘
外部碎片 = 空闲空间 / 总空间
```

Go 通过以下方式减少外部碎片：
- **大小类别**：相同大小的对象放在一起
- **内存整理**：GC 时整理内存
- **span 合并**：相邻空闲 span 合并

## 八、性能优化

### 8.1 预分配

```go
// Bad: 频繁扩容
var s []int
for i := 0; i < 10000; i++ {
    s = append(s, i)
}

// Good: 预分配容量
s := make([]int, 0, 10000)
for i := 0; i < 10000; i++ {
    s = append(s, i)
}
```

### 8.2 对象池

```go
var bufferPool = sync.Pool{
    New: func() interface{} {
        return new(bytes.Buffer)
    },
}

func getBuffer() *bytes.Buffer {
    return bufferPool.Get().(*bytes.Buffer)
}

func putBuffer(b *bytes.Buffer) {
    b.Reset()
    bufferPool.Put(b)
}
```

### 8.3 减少逃逸

```go
// Bad: 返回指针，导致逃逸
func newPoint() *Point {
    return &Point{X: 1, Y: 2}
}

// Good: 返回值类型
func newPoint() Point {
    return Point{X: 1, Y: 2}
}
```
