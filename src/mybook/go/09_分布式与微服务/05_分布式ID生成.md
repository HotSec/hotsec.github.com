# 分布式 ID 生成

分布式系统中需要全局唯一的 ID，常见的方案有 UUID、雪花算法、Leaf 等。

---

## 一、ID 要求

- **全局唯一**：分布式环境下不重复
- **有序性**：便于索引和排序
- **高性能**：高并发下快速生成
- **可读性**：便于问题排查

---

## 二、UUID

### 2.1 生成方式

```go
import "github.com/google/uuid"

func main() {
    id := uuid.New()
    fmt.Println(id.String())
}
```

### 2.2 优缺点

优点：
- 本地生成，无网络开销
- 全局唯一

缺点：
- 无序，不利于索引
- 128 位，占用空间大
- 不易读

## 三、雪花算法（Snowflake）

### 3.1 结构

```
0 - 41位时间戳 - 10位机器ID - 12位序列号
```

- 1 位符号位
- 41 位时间戳（毫秒级）
- 10 位机器 ID（0-1023）
- 12 位序列号（0-4095）

### 3.2 实现

```go
type Snowflake struct {
    mu        sync.Mutex
    timestamp int64
    machineID int64
    sequence  int64
}

const (
    epoch         = int64(1704067200000)
    machineBits   = uint(10)
    sequenceBits  = uint(12)
    machineMax    = int64(-1 ^ (-1 << machineBits))
    sequenceMax   = int64(-1 ^ (-1 << sequenceBits))
    machineShift  = sequenceBits
    timestampShift = sequenceBits + machineBits
)

func NewSnowflake(machineID int64) *Snowflake {
    return &Snowflake{
        machineID: machineID & machineMax,
    }
}

func (s *Snowflake) Generate() int64 {
    s.mu.Lock()
    defer s.mu.Unlock()

    now := time.Now().UnixMilli() - epoch

    if now == s.timestamp {
        s.sequence = (s.sequence + 1) & sequenceMax
        if s.sequence == 0 {
            for now <= s.timestamp {
                now = time.Now().UnixMilli() - epoch
            }
        }
    } else {
        s.sequence = 0
    }

    s.timestamp = now
    return (now << timestampShift) | (s.machineID << machineShift) | s.sequence
}
```

### 3.3 优缺点

优点：
- 有序递增
- 64 位，占用空间小
- 高性能

缺点：
- 依赖时钟
- 机器 ID 需要分配

## 四、Leaf（美团）

### 4.1 号段模式

```go
type LeafSegment struct {
    db       *sql.DB
    key      string
    maxID    int64
    step     int64
    current  int64
}

func (l *LeafSegment) NextID() int64 {
    if l.current >= l.maxID {
        l.loadSegment()
    }
    l.current++
    return l.current
}

func (l *LeafSegment) loadSegment() {
    tx, _ := l.db.Begin()
    tx.QueryRow("SELECT max_id, step FROM leaf_alloc WHERE key = ? FOR UPDATE", l.key).Scan(&l.maxID, &l.step)
    tx.Exec("UPDATE leaf_alloc SET max_id = max_id + ? WHERE key = ?", l.step, l.key)
    tx.Commit()
    l.current = l.maxID - l.step
}
```

### 4.2 双 Buffer 优化

```go
type LeafDualBuffer struct {
    buffers [2]*Segment
    index   int
}

func (l *LeafDualBuffer) NextID() int64 {
    if l.buffers[l.index].isExhausted() {
        l.index = 1 - l.index
        go l.buffers[1-l.index].load()
    }
    return l.buffers[l.index].nextID()
}
```

## 五、Redis 生成

```go
func NextID(key string) int64 {
    return rdb.Incr(context.Background(), key).Val()
}

func NextIDWithDate(key string) string {
    date := time.Now().Format("20060102")
    seq := rdb.Incr(context.Background(), key+":"+date).Val()
    return fmt.Sprintf("%s%06d", date, seq)
}
```

## 六、方案对比

| 方案 | 性能 | 有序性 | 依赖 | 适用场景 |
|------|------|--------|------|---------|
| UUID | 高 | 无 | 无 | 非索引场景 |
| 雪花算法 | 高 | 有 | 时钟 | 通用 |
| Leaf 号段 | 高 | 有 | 数据库 | 高并发 |
| Redis | 中 | 有 | Redis | 中等并发 |

---

## 七、最佳实践

1. **机器 ID 分配**：使用 etcd/consul 自动分配
2. **时钟回拨处理**：等待或报错
3. **监控告警**：ID 生成异常告警
4. **预留 ID**：批量预分配提高性能
