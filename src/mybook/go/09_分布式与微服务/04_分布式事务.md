# 分布式事务

分布式事务保证跨多个服务的数据一致性。

---

## 一、分布式事务挑战

### 1.1 ACID vs BASE

| 特性 | ACID | BASE |
|------|------|------|
| 一致性 | 强一致 | 最终一致 |
| 可用性 | 优先一致 | 优先可用 |
| 适用场景 | 单机数据库 | 分布式系统 |

### 1.2 CAP 定理

- **C**onsistency：一致性
- **A**vailability：可用性
- **P**artition tolerance：分区容错

三者最多同时满足两个。

## 二、2PC（两阶段提交）

### 2.1 流程

```
协调者              参与者A              参与者B
   │                  │                    │
   │───Prepare───────>│                    │
   │                  │───Prepare─────────>│
   │<───Ready─────────│                    │
   │                  │<───Ready──────────│
   │                  │                    │
   │───Commit────────>│                    │
   │                  │───Commit──────────>│
   │<───Done──────────│                    │
   │                  │<───Done───────────│
```

### 2.2 问题

- 同步阻塞：参与者锁定资源
- 单点故障：协调者宕机
- 数据不一致：部分参与者收到 Commit

## 三、TCC（Try-Confirm-Cancel）

### 3.1 流程

```go
type TCCService interface {
    Try(ctx context.Context, req *Request) error
    Confirm(ctx context.Context, req *Request) error
    Cancel(ctx context.Context, req *Request) error
}

func ExecuteTCC(ctx context.Context, services []TCCService, req *Request) error {
    for _, s := range services {
        if err := s.Try(ctx, req); err != nil {
            for _, s2 := range services {
                s2.Cancel(ctx, req)
            }
            return err
        }
    }

    for _, s := range services {
        if err := s.Confirm(ctx, req); err != nil {
            return err
        }
    }
    return nil
}
```

### 3.2 示例：转账

```go
type AccountService struct {
    db *sql.DB
}

func (s *AccountService) Try(ctx context.Context, from, to string, amount int) error {
    tx, _ := s.db.BeginTx(ctx, nil)
    _, err := tx.Exec("UPDATE accounts SET balance = balance - ? WHERE id = ? AND balance >= ?", amount, from, amount)
    if err != nil {
        tx.Rollback()
        return err
    }
    _, err = tx.Exec("INSERT INTO frozen (account, amount) VALUES (?, ?)", from, amount)
    if err != nil {
        tx.Rollback()
        return err
    }
    return tx.Commit()
}

func (s *AccountService) Confirm(ctx context.Context, from, to string, amount int) error {
    tx, _ := s.db.BeginTx(ctx, nil)
    tx.Exec("DELETE FROM frozen WHERE account = ?", from)
    tx.Exec("UPDATE accounts SET balance = balance + ? WHERE id = ?", amount, to)
    return tx.Commit()
}

func (s *AccountService) Cancel(ctx context.Context, from, to string, amount int) error {
    tx, _ := s.db.BeginTx(ctx, nil)
    tx.Exec("DELETE FROM frozen WHERE account = ?", from)
    tx.Exec("UPDATE accounts SET balance = balance + ? WHERE id = ?", amount, from)
    return tx.Commit()
}
```

## 四、Saga 模式

### 4.1 编排式 Saga

```go
type SagaStep struct {
    Action  func() error
    Compensate func() error
}

func ExecuteSaga(steps []SagaStep) error {
    var executed []int
    for i, step := range steps {
        if err := step.Action(); err != nil {
            for j := len(executed) - 1; j >= 0; j-- {
                steps[executed[j]].Compensate()
            }
            return err
        }
        executed = append(executed, i)
    }
    return nil
}
```

### 4.2 协同式 Saga

```go
type OrderSaga struct {
    OrderService   *OrderService
    PaymentService *PaymentService
    InventoryService *InventoryService
}

func (s *OrderSaga) Execute(orderID string) error {
    if err := s.OrderService.CreateOrder(orderID); err != nil {
        return err
    }

    if err := s.PaymentService.ProcessPayment(orderID); err != nil {
        s.OrderService.CancelOrder(orderID)
        return err
    }

    if err := s.InventoryService.ReserveInventory(orderID); err != nil {
        s.PaymentService.RefundPayment(orderID)
        s.OrderService.CancelOrder(orderID)
        return err
    }

    return nil
}
```

## 五、本地消息表

### 5.1 实现方式

```go
func Transfer(from, to string, amount int) error {
    tx, _ := db.Begin()

    tx.Exec("UPDATE accounts SET balance = balance - ? WHERE id = ?", amount, from)
    tx.Exec("INSERT INTO outbox (event_type, payload, status) VALUES (?, ?, ?)",
        "transfer", fmt.Sprintf(`{"from":"%s","to":"%s","amount":%d}`, from, to, amount), "pending")

    return tx.Commit()
}

func OutboxWorker() {
    for {
        rows, _ := db.Query("SELECT id, event_type, payload FROM outbox WHERE status = 'pending'")
        for rows.Next() {
            var id int
            var eventType, payload string
            rows.Scan(&id, &eventType, &payload)

            if err := sendMessage(eventType, payload); err == nil {
                db.Exec("UPDATE outbox SET status = 'sent' WHERE id = ?", id)
            }
        }
        time.Sleep(time.Second)
    }
}
```

## 七、方案对比

| 方案 | 一致性 | 性能 | 复杂度 | 适用场景 |
|------|--------|------|--------|---------|
| 2PC | 强一致 | 低 | 中 | 传统数据库 |
| TCC | 最终一致 | 高 | 高 | 金融交易 |
| Saga | 最终一致 | 高 | 中 | 长流程业务 |
| 本地消息表 | 最终一致 | 中 | 低 | 简单场景 |
