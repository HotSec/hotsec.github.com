# 变量、常量与运算符

## 一、变量

### 1.1 变量声明

```go
var name string
var age int = 30
var isStudent = true

x := 42
```

### 1.2 变量声明方式对比

| 方式 | 示例 | 适用场景 |
|------|------|---------|
| `var` 完整声明 | `var name string = "Alice"` | 需要显式指定类型 |
| `var` 类型推导 | `var name = "Alice"` | 包级变量 |
| 短变量声明 | `name := "Alice"` | 函数内部 |

### 1.3 变量零值

```go
var i int
var s string
var b bool
var p *int
var sl []int
var m map[string]int
var ch chan int
var f func()
var err error
```

| 类型 | 零值 |
|------|------|
| int, float | `0` |
| string | `""` |
| bool | `false` |
| pointer, slice, map, chan, func, interface | `nil` |

### 1.4 多变量声明

```go
var (
    name   string
    age    int
    active bool
)

var x, y, z int

a, b, c := 1, 2, 3
```

## 二、常量

### 2.1 常量声明

```go
const Pi = 3.14159
const (
    StatusOK    = 200
    StatusError = 500
)

const (
    a = 1
    b
    c = 2
    d
)
```

### 2.2 iota 枚举

```go
const (
    Sunday = iota
    Monday
    Tuesday
    Wednesday
    Thursday
    Friday
    Saturday
)

const (
    _  = iota
    KB = 1 << (10 * iota)
    MB
    GB
    TB
)

const (
    Read   = 1 << iota
    Write
    Execute
)
```

### 2.3 无类型常量

```go
const a = 42

var x int = a
var y float64 = a
var z int64 = a
```

- 常量没有固定类型，在使用时根据上下文确定类型
- 这提供了更大的灵活性

## 三、运算符

### 3.1 算术运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `%` | 取模 | `a % b` |
| `++` | 自增 | `a++` |
| `--` | 自减 | `a--` |

注意：
- `++` 和 `--` 是语句而非表达式，不能用于赋值
- 整数除法结果仍为整数

### 3.2 关系运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |

### 3.3 逻辑运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `&&` | 逻辑与 | `a && b` |
| `\|\|` | 逻辑或 | `a \|\| b` |
| `!` | 逻辑非 | `!a` |

- 短路求值：`&&` 遇到 false 停止，`||` 遇到 true 停止

### 3.4 位运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `&` | 按位与 | `a & b` |
| `\|` | 按位或 | `a \| b` |
| `^` | 按位异或 | `a ^ b` |
| `&^` | 位清除 | `a &^ b` |
| `<<` | 左移 | `a << n` |
| `>>` | 右移 | `a >> n` |

```go
var a uint8 = 0b1010
var b uint8 = 0b1100

fmt.Printf("%b\n", a&b)
fmt.Printf("%b\n", a|b)
fmt.Printf("%b\n", a^b)
fmt.Printf("%b\n", a&^b)
```

### 3.5 赋值运算符

```go
a += b
a -= b
a *= b
a /= b
a %= b
a &= b
a |= b
a ^= b
a <<= n
a >>= n
```

### 3.6 运算符优先级

| 优先级 | 运算符 |
|--------|--------|
| 5 | `*` `/` `%` `<<` `>>` `&` `&^` |
| 4 | `+` `-` `\|` `^` |
| 3 | `==` `!=` `<` `>` `<=` `>=` |
| 2 | `&&` |
| 1 | `\|\|` |

## 四、标识符命名规则

### 4.1 命名规范

- 以字母或 `_` 开头
- 后面可跟字母、数字、 `_`
- 区分大小写
- 不能使用 Go 关键字

### 4.2 可见性

```go
var PublicVar int
var privateVar int

type PublicStruct struct{}
type privateStruct struct{}

func PublicFunc() {}
func privateFunc() {}
```

- 大写开头：导出（公开）
- 小写开头：未导出（私有）

### 4.3 命名惯例

| 类型 | 惯例 | 示例 |
|------|------|------|
| 包名 | 小写单词 | `fmt`, `http` |
| 变量 | 驼峰命名 | `userName`, `userID` |
| 常量 | 驼峰命名 | `maxSize`, `httpPort` |
| 接口 | `-er` 后缀 | `Reader`, `Writer` |
| 缩写 | 保持一致大小写 | `userID`, `URL`, `HTTP` |
