# 组合与继承

Go 语言没有传统的类继承机制，而是通过**组合（Composition）**和**嵌入（Embedding）**来实现代码复用和多态。

---

## 一、组合

### 1.1 什么是组合

组合是将一个结构体作为另一个结构体的字段，通过"has-a"关系实现代码复用。

```go
type Engine struct {
    Power int
}

func (e *Engine) Start() {
    fmt.Println("engine started, power:", e.Power)
}

type Car struct {
    Engine Engine
    Brand  string
}

func main() {
    c := Car{
        Engine: Engine{Power: 200},
        Brand:  "Tesla",
    }
    c.Engine.Start()
}
```

- 组合是显式的，需要通过字段名访问
- Car "has-a" Engine，但 Car 不是 Engine

### 1.2 组合 vs 继承

| 特性 | 组合 | 继承 |
|------|------|------|
| 关系 | has-a | is-a |
| 耦合度 | 低 | 高 |
| 灵活性 | 运行时组合 | 编译时确定 |
| 代码复用 | 委托 | 继承 |
| 多态 | 接口 | 虚函数 |

## 二、匿名嵌入（Embedding）

### 2.1 基本嵌入

```go
type Point struct{ X, Y float64 }

type ColoredPoint struct {
    Point
    Color color.RGBA
}

var cp ColoredPoint
cp.X = 1
fmt.Println(cp.Point.X)
cp.Point.Y = 2
fmt.Println(cp.Y)
```

- 匿名嵌入实现了类似继承的效果
- 可以直接访问嵌入字段的属性和方法
- 字段名冲突时需要显式指定

### 2.2 嵌入结构体的初始化

```go
type Address struct {
    City    string
    Country string
}

type Person struct {
    Name    string
    Address
}

p1 := Person{
    Name: "Alice",
    Address: Address{
        City:    "Beijing",
        Country: "China",
    },
}

p2 := Person{Name: "Bob"}
p2.City = "Shanghai"
p2.Address.Country = "China"
```

### 2.3 方法提升（Method Promotion）

```go
type Animal struct {
    Name string
}

func (a Animal) Speak() string {
    return a.Name + " speaks"
}

type Dog struct {
    Animal
    Breed string
}

func (d Dog) Speak() string {
    return d.Name + " barks"
}

d := Dog{Animal: Animal{Name: "Rex"}, Breed: "Labrador"}
fmt.Println(d.Speak())
fmt.Println(d.Animal.Speak())
```

- 嵌入结构体的方法会被"提升"到外层
- 外层方法会覆盖内层同名方法
- 可通过显式指定访问被覆盖的方法

## 三、方法集规则

方法集决定了接口实现和类型转换的规则：

| 类型 | 值接收者方法 | 指针接收者方法 |
|------|-------------|---------------|
| `T` 值 | ✅ 可调用 | ✅ 可调用（自动取地址） |
| `*T` 指针 | ✅ 可调用（自动解引用） | ✅ 可调用 |
| `T` 实现接口 | ✅ 包含 | ❌ 不包含 |
| `*T` 实现接口 | ✅ 包含 | ✅ 包含 |

```go
type Speaker interface {
    Speak() string
}

type Cat struct{ Name string }

func (c *Cat) Speak() string { return c.Name + " meows" }

var s Speaker = &Cat{Name: "Kitty"}
var s2 Speaker = Cat{Name: "Tom"}
```

## 四、接口组合

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

type ReadWriter interface {
    Reader
    Writer
}
```

- 接口也可以嵌入其他接口
- Go 标准库大量使用接口组合（io.ReadWriter、io.ReadWriteCloser）

## 五、组合模式实战

### 5.1 中间件链

```go
type Handler func(ctx *Context)

func WithLogging(next Handler) Handler {
    return func(ctx *Context) {
        log.Println("request:", ctx.Path)
        next(ctx)
    }
}

func WithAuth(next Handler) Handler {
    return func(ctx *Context) {
        if !ctx.IsAuthenticated {
            ctx.StatusCode = 401
            return
        }
        next(ctx)
    }
}

handler := WithLogging(WithAuth(actualHandler))
```

### 5.2 选项组合

```go
type Option func(*Server)

func WithPort(port int) Option {
    return func(s *Server) { s.Port = port }
}

func WithTimeout(d time.Duration) Option {
    return func(s *Server) { s.Timeout = d }
}

func NewServer(opts ...Option) *Server {
    s := &Server{Port: 8080}
    for _, opt := range opts {
        opt(s)
    }
    return s
}
```
