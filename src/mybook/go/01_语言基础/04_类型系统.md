# 类型系统

Go 是静态类型语言，变量在编译期就确定了类型。Go 的类型系统兼具强类型的安全性和类型推导的便利性。

## 二、类型别名与自定义类型

### 2.1 自定义类型 (type)

```go
type Age int

type User struct {
    Name string
    Age  Age
}

var a Age = 30
var b int = int(a)
```

- `type` 创建的是**新类型**，与底层类型不同，不能直接赋值
- 自定义类型不会继承底层类型的方法

### 2.2 类型别名 (type alias)

```go
type Text = string

var t Text = "hello"
var s string = t
```

- `type Alias = Original` 创建的是**别名**，与原类型完全等价
- Go 内置的别名：`byte = uint8`，`rune = int32`，`any = interface{}`

### 2.3 区别

| 特性 | `type NewType OldType` | `type Alias = OldType` |
|------|----------------------|----------------------|
| 是否新类型 | ✅ 是 | ❌ 否，只是别名 |
| 可直接赋值给原类型 | ❌ 需要转换 | ✅ 直接赋值 |
| 可定义新方法 | ✅ 可以 | ❌ 不可以 |
| 反射类型名 | `NewType` | `OldType` |

## 三、类型转换

### 3.1 显式转换

```go
var i int = 42
var f float64 = float64(i)
var u uint = uint(f)

type MyInt int
var m MyInt = MyInt(i)
```

### 3.2 数值转换规则

```go
var x int32 = 100
var y int64 = int64(x)
var z int8 = int8(x)
```

- 大范围→小范围可能溢出
- 浮点→整数截断小数部分

### 3.3 字符串转换

```go
s := strconv.Itoa(42)
n, _ := strconv.Atoi("42")

s2 := string([]byte{72, 101, 108, 108, 111})
b := []byte("Hello")

r := rune('中')
s3 := string(r)
```

## 四、类型推导

### 4.1 变量推导

```go
x := 42
y := 3.14
z := "hello"
```

| 字面量 | 推导类型 |
|--------|---------|
| 整数 | `int` |
| 浮点数 | `float64` |
| 字符 | `rune` |
| 字符串 | `string` |
| 布尔 | `bool` |

### 4.2 短变量声明中的类型

```go
x := int32(42)
y := float32(3.14)
```

### 4.3 常量推导

```go
const a = 42
const b = 3.14
const c = "hello"
```

- 常量没有固定类型，是**无类型常量**（untyped constant）
- 在使用时根据上下文确定类型

## 五、底层类型 (Underlying Type)

```go
type Age int
type Old Age
```

- `Age` 的底层类型是 `int`
- `Old` 的底层类型也是 `int`（不是 `Age`）
- 使用 `~Type` 约束底层类型（Go 1.18+）

```go
type Number interface {
    ~int | ~int8 | ~int16 | ~int32 | ~int64 |
    ~float32 | ~float64
}
```

## 六、零值

Go 的每个类型都有零值，声明但未赋值的变量自动初始化为零值：

| 类型 | 零值 |
|------|------|
| int, uint 等 | `0` |
| float32, float64 | `0.0` |
| bool | `false` |
| string | `""` |
| pointer, slice, map, chan, func, interface | `nil` |
| struct | 每个字段各自的零值 |
| array | 每个元素各自的零值 |

```go
var s []int
fmt.Println(s == nil)

var m map[string]int
fmt.Println(m == nil)

var p *int
fmt.Println(p == nil)
```

## 七、可比较与可排序

### 7.1 可比较 (comparable)

以下类型可以使用 `==` 和 `!=`：

- bool, int, float, complex, string
- pointer, channel, interface
- 数组（元素类型可比较）
- struct（所有字段可比较）

不可比较：
- slice, map, function

### 7.2 可排序 (ordered)

以下类型可以使用 `<`, `>`, `<=`, `>=`：

- int, uint, float, complex, string

Go 1.21+ 提供 `cmp.Ordered` 约束：

```go
import "cmp"

func Max[T cmp.Ordered](a, b T) T {
    if a > b {
        return a
    }
    return b
}
```
