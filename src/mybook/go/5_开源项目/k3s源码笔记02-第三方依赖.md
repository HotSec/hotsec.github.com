# 依赖包

## github.com/urfave/cli

包 cli 提供了一个用于创建和组织命令行 Go 应用程序的最小框架。CLI被设计得易于理解和编写，最简单的CLI应用程序可以写成如下：

```go

funcmain() {

  cli.NewApp().Run(os.Args)

}

```

当然，这个应用程序并没有做太多事情，所以让我们把它做成一个实际的应用程序：

```go

funcmain() {

  app := cli.NewApp()

  app.Name = "greet"

  app.Usage = "say a greeting"

  app.Action = func(c *cli.Context) error {

    println("Greetings")

    returnnil

  }


  app.Run(os.Args)

}

```

## github.com/sirupsen/logrus

软件包 logrus 是 Go 的结构化记录器，与标准库记录器完全 API 兼容。

使用 Logrus 的最简单方法就是使用包级导出的记录器：

```go

package main


import (

  log "github.com/sirupsen/logrus"

)


funcmain() {

  log.WithFields(log.Fields{

    "animal": "walrus",

    "number": 1,

    "size":   10,

  }).Info("A walrus appears")

}


Output:


time="2015-09-07T08:48:33Z"level=info msg="A walrus appears"animal=walrus number=1size=10

```

如需完整指南访问`https://github.com/sirupsen/logrus`

## github.com/spf13/pflag

软件包 pflag 是 Go 标志包的直接替代品，实现了 POSIX/GNU 风格的 --flags。

pflag 与 POSIX 对命令行选项建议的 GNU 扩展兼容。看http://www.gnu.org/software/libc/manual/html_node/Argument-Syntax.html

Usage:

pflag 是 Go 原生 flag 包的直接替代品。如果以“flag”的名义导入 pflag，则所有代码都应继续运行，无需更改。

`import flag "github.com/spf13/pflag"`

但有一个例外：如果直接实例化 Flag 结构，则需要设置另一个字段“Shorthand”。大多数代码从不直接实例化此结构，而是使用 String（）、BoolVar（） 和 Var（） 等函数，因此不受影响。

使用 flag 定义标志。String（）、Bool（）、Int（） 等。

这将声明一个整数标志 -flagname，该标志存储在指针 ip 中，类型为*int.

`var ip = flag.Int("flagname", 1234, "help message for flagname")`

如果您愿意，可以使用 Var（） 函数将标志绑定到变量。

```text

var flagvar int

func init() {

    flag.IntVar(&flagvar, "flagname", 1234, "help message for flagname")

}

```

或者，您可以创建满足 Value 接口（使用指针接收器）的自定义标志，并将它们耦合到标志解析

`flag.Var(&flagVal, "name", "help message for flagname")`

对于此类标志，默认值只是变量的初始值。

定义所有标志后，调用

`flag.Parse()`

将命令行解析为定义的标志。

然后可以直接使用标志。如果你使用标志本身，它们都是指针;如果绑定到变量，则它们是值。

`fmt.Println("ip has value ", *ip)`

`fmt.Println("flagvar has value ", flagvar)`

分析后，标志后面的参数可用作切片标志。Args（） 或单独作为标志。Arg（i） 中。参数的索引从 0 到 flag。NArg（）-1 中。

pflag 包还定义了一些不在 flag 中的新函数，这些函数为标志提供单字母的简写。您可以通过将“P”附加到定义标志的任何函数的名称来使用它们。

```text

var ip = flag.IntP("flagname", "f", 1234, "help message")

var flagvar bool

func init() {

    flag.BoolVarP(&flagvar, "boolname", "b", true, "help message")

}

flag.VarP(&flagval, "varname", "v", "help message")

```

速记字母可以在命令行上与单个破折号一起使用。布尔速记标志可以与其他速记标志结合使用。

命令行标志语法：

`--flag // boolean flags only`

`--flag=x`

与标志包不同，选项前的单破折号与双破折号的含义不同。单破折号表示旗帜的一系列速记字母。除最后一个速记字母外，所有字母都必须是布尔标志。

```text

// boolean flags

-f

-abc

// non-boolean flags

-n 1234

-Ifile

// mixed

-abcs "hello"

-abcn1234

```

标志解析在终止符“--”之后停止。与 flag 包不同，flags 可以穿插在命令行中此终止符之前的任何位置的参数中。

整数标志接受 1234、0664 0x1234，并且可能为负数。布尔标志（长格式）接受 1、0、t、f、true、false、TRUE、FALSE、True、False。持续时间标志接受任何对时间有效的输入。ParseDuration。

默认的命令行标志集由顶级函数控制。 FlagSet 类型允许定义独立的标志集，例如在命令行界面中实现子命令。FlagSet 的方法类似于命令行标志集的顶级函数。

## github.com/blang/semver

Semver for Golang

semver 是一个用 golang 编写的语义版本控制库。它完全涵盖了规范版本2.0.0

示例

```go

import github.com/blang/semver/v4


v, err := semver.Make("0.0.1-alpha.preview+123.github")

fmt.Printf("Major: %d\n", v.Major)

fmt.Printf("Minor: %d\n", v.Minor)

fmt.Printf("Patch: %d\n", v.Patch)

fmt.Printf("Pre: %s\n", v.Pre)

fmt.Printf("Build: %s\n", v.Build)


// Prerelease versions array

iflen(v.Pre) > 0 {

    fmt.Println("Prerelease versions:")

    fori, pre := range v.Pre {

        fmt.Printf("%d: %q\n", i, pre)

    }

}


// Build meta data array

iflen(v.Build) > 0 {

    fmt.Println("Build meta data:")

    fori, build := range v.Build {

        fmt.Printf("%d: %q\n", i, build)

    }

}


v001, err := semver.Make("0.0.1")

// Compare using helpers: v.GT(v2), v.LT, v.GTE, v.LTE

v001.GT(v) == true

v.LT(v001) == true

v.GTE(v) == true

v.LTE(v) == true


// Or use v.Compare(v2) for comparisons (-1, 0, 1):

v001.Compare(v) == 1

v.Compare(v001) == -1

v.Compare(v) == 0


// Manipulate Version in place:

v.Pre[0], err = semver.NewPRVersion("beta")

if err != nil {

    fmt.Printf("Error parsing pre release version: %q", err)

}


fmt.Println("\nValidate versions:")

v.Build[0] = "?"


err = v.Validate()

if err != nil {

    fmt.Printf("Validation failed: %s\n", err)

}

```

## github.com/gorilla/mux

软件包 gorilla/mux 是一个强大的 HTTP 路由器和 URL 匹配器，用于构建 Go Web 服务器

```text

package main


import (

    "net/http"

    "log"

    "github.com/gorilla/mux"

)


func YourHandler(w http.ResponseWriter, r *http.Request) {

    w.Write([]byte("Gorilla!\n"))

}


func main() {

    r := mux.NewRouter()

    // Routes consist of a path and a handler function.

    r.HandleFunc("/", YourHandler)


    // Bind to a port and pass our router in

    log.Fatal(http.ListenAndServe(":8000", r))

}
```
