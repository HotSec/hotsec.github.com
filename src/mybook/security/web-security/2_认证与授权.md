## 一、认证方式对比

| 方式 | 安全性 | 适用场景 | 状态 |
|------|--------|----------|------|
| API Key | 低 | 服务间调用 | 无状态 |
| Basic Auth | 低 | 内部系统 | 无状态 |
| Session-Cookie | 中 | 传统 Web | 有状态 |
| JWT | 中高 | API/微服务 | 无状态 |
| OAuth 2.0 | 高 | 第三方授权 | 无状态 |
| SSO | 高 | 企业内部 | 有状态 |

## 二、API Key

```go
func APIKeyAuth(c *gin.Context) {
    key := c.GetHeader("X-API-Key")
    if key == "" {
        key = c.Query("api_key")
    }

    if !validateAPIKey(key) {
        c.AbortWithStatusJSON(401, gin.H{"error": "invalid API key"})
        return
    }
    c.Next()
}
```

缺点：无法区分用户身份，无法设置权限范围，密钥泄露风险高。

## 三、Basic Auth

```go
func BasicAuth(c *gin.Context) {
    auth := c.GetHeader("Authorization")
    if auth == "" {
        c.Header("WWW-Authenticate", `Basic realm="Restricted"`)
        c.AbortWithStatus(401)
        return
    }

    decoded, err := base64.StdEncoding.DecodeString(strings.TrimPrefix(auth, "Basic "))
    if err != nil {
        c.AbortWithStatus(401)
        return
    }

    parts := strings.SplitN(string(decoded), ":", 2)
    if len(parts) != 2 || !checkCredentials(parts[0], parts[1]) {
        c.AbortWithStatus(401)
        return
    }
    c.Set("username", parts[0])
    c.Next()
}
```

**必须配合 HTTPS 使用**，否则凭据明文传输。

## 四、Session-Cookie

### 4.1 工作流程

```
1. 用户提交用户名/密码
2. 服务端验证，创建 Session，存入存储
3. 返回 SessionID（通过 Set-Cookie）
4. 浏览器自动携带 Cookie
5. 服务端根据 SessionID 查找 Session
```

### 4.2 实现

```go
// Session 存储
type SessionStore struct {
    sessions sync.Map
}

func (s *SessionStore) Create(userID string) string {
    sessionID := uuid.New().String()
    s.sessions.Store(sessionID, Session{
        UserID:    userID,
        CreatedAt: time.Now(),
        ExpiresAt: time.Now().Add(24 * time.Hour),
    })
    return sessionID
}

func (s *SessionStore) Get(sessionID string) (*Session, bool) {
    val, ok := s.sessions.Load(sessionID)
    if !ok {
        return nil, false
    }
    session := val.(Session)
    if time.Now().After(session.ExpiresAt) {
        s.sessions.Delete(sessionID)
        return nil, false
    }
    return &session, true
}

// Redis 存储
func (s *SessionStore) CreateRedis(userID string) string {
    sessionID := uuid.New().String()
    data, _ := json.Marshal(Session{UserID: userID})
    rdb.Set(ctx, "session:"+sessionID, data, 24*time.Hour)
    return sessionID
}
```

### 4.3 安全配置

```go
c.SetCookie("session_id", sessionID,
    86400,    // maxAge
    "/",      // path
    "",       // domain
    true,     // secure (HTTPS only)
    true,     // httpOnly (JS 不可访问)
)
c.SetSameSite(http.SameSiteStrictMode)
```

## 五、JWT (JSON Web Token)

### 5.1 结构

```
Header.Payload.Signature

eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkpvaG4gRG9lIiwiaWF0IjoxNTE2MjM5MDIyfQ.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
```

| 部分 | 内容 |
|------|------|
| Header | `{"alg":"HS256","typ":"JWT"}` |
| Payload | `{"sub":"123","name":"John","iat":1516239022}` |
| Signature | `HMACSHA256(base64(header)+"."+base64(payload), secret)` |

### 5.2 Payload 标准字段

| 字段 | 说明 |
|------|------|
| iss | 签发者 |
| sub | 主题（用户 ID） |
| aud | 受众 |
| exp | 过期时间 |
| nbf | 生效时间 |
| iat | 签发时间 |
| jti | 唯一标识 |

### 5.3 Go 实现

```go
import "github.com/golang-jwt/jwt/v5"

var secretKey = []byte("your-secret-key")

// 生成 Token
func GenerateToken(userID string) (string, error) {
    claims := jwt.MapClaims{
        "sub": userID,
        "exp": time.Now().Add(24 * time.Hour).Unix(),
        "iat": time.Now().Unix(),
        "jti": uuid.New().String(),
    }
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString(secretKey)
}

// 解析 Token
func ParseToken(tokenString string) (*jwt.MapClaims, error) {
    token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
        if _, ok := token.Method.(*jwt.SigningMethodHMAC); !ok {
            return nil, fmt.Errorf("unexpected signing method: %v", token.Header["alg"])
        }
        return secretKey, nil
    })

    if err != nil {
        return nil, err
    }

    if claims, ok := token.Claims.(jwt.MapClaims); ok && token.Valid {
        return &claims, nil
    }

    return nil, fmt.Errorf("invalid token")
}

// 中间件
func JWTAuth(c *gin.Context) {
    auth := c.GetHeader("Authorization")
    if auth == "" {
        c.AbortWithStatusJSON(401, gin.H{"error": "missing token"})
        return
    }

    tokenString := strings.TrimPrefix(auth, "Bearer ")
    claims, err := ParseToken(tokenString)
    if err != nil {
        c.AbortWithStatusJSON(401, gin.H{"error": "invalid token"})
        return
    }

    c.Set("userID", (*claims)["sub"])
    c.Set("claims", claims)
    c.Next()
}
```

### 5.4 JWT 安全注意事项

| 风险 | 防御 |
|------|------|
| 算法混淆攻击 | 严格检查 SigningMethod |
| 密钥爆破 | 使用强密钥（≥256位） |
| None 算法 | 拒绝 alg=none |
| Token 泄露 | 使用 HTTPS、短期有效期 |
| Token 无法吊销 | 黑名单机制 / 短有效期 + Refresh Token |
| jku 注入 | 不使用外部 jku，固定密钥 |

### 5.5 Token 黑名单

```go
var tokenBlacklist sync.Map

func RevokeToken(jti string) {
    tokenBlacklist.Store(jti, time.Now())
}

func isRevoked(jti string) bool {
    _, ok := tokenBlacklist.Load(jti)
    return ok
}

// Redis 实现（支持 TTL 自动清理）
func RevokeTokenRedis(jti string, ttl time.Duration) {
    rdb.Set(ctx, "blacklist:"+jti, "1", ttl)
}
```

## 六、OAuth 2.0

### 6.1 四种授权模式

| 模式 | 安全性 | 适用场景 |
|------|--------|----------|
| 授权码模式 (Authorization Code) | 最安全 | Web 应用 |
| PKCE 增强授权码 | 高 | SPA/移动端 |
| 隐式模式 (Implicit) | 低（已不推荐） | 旧 SPA |
| 密码模式 (Resource Owner Password) | 低 | 高度信任的第一方应用 |
| 客户端凭证 (Client Credentials) | 中 | 服务间调用 |

### 6.2 授权码模式流程

```
┌──────┐     1. 点击登录      ┌──────┐     3. 用户授权     ┌──────┐
│Client│ ──────────────────→ │Auth  │ ←────────────────── │User │
│  App │                     │Server│                      │     │
└──┬───┘                     └──┬───┘                      └─────┘
   │                            │
   │  2. 重定向到授权页面         │  4. 回调带 authorization_code
   │ ←──────────────────────── │ ──────────────────────→
   │                            │
   │  5. 用 code 换 token       │
   │ ────────────────────────→ │
   │                            │
   │  6. 返回 access_token      │
   │ ←──────────────────────── │
   │                            │
   │  7. 用 token 访问资源       │
   │ ──────────────────────────────────────────────→ ┌──────┐
   │                                                  │Resource│
   │  8. 返回资源数据                                  │ Server │
   │ ←────────────────────────────────────────────── └──────┘
```

### 6.3 Go 实现 OAuth2 客户端

```go
import "golang.org/x/oauth2"

var oauthConfig = &oauth2.Config{
    ClientID:     "your-client-id",
    ClientSecret: "your-client-secret",
    RedirectURL:  "http://localhost:8080/callback",
    Scopes:       []string{"openid", "profile", "email"},
    Endpoint: oauth2.Endpoint{
        AuthURL:  "https://accounts.google.com/o/oauth2/auth",
        TokenURL: "https://accounts.google.com/o/oauth2/token",
    },
}

// 登录入口
func LoginHandler(c *gin.Context) {
    url := oauthConfig.AuthCodeURL("random-state", oauth2.AccessTypeOffline)
    c.Redirect(http.StatusTemporaryRedirect, url)
}

// 回调处理
func CallbackHandler(c *gin.Context) {
    code := c.Query("code")
    token, err := oauthConfig.Exchange(c.Request.Context(), code)
    if err != nil {
        c.JSON(500, gin.H{"error": err.Error()})
        return
    }

    // 用 token 获取用户信息
    client := oauthConfig.Client(c.Request.Context(), token)
    resp, _ := client.Get("https://www.googleapis.com/oauth2/v2/userinfo")
    // ...
}
```

## 七、SSO (单点登录)

### 7.1 核心概念

- 一次登录，访问多个应用
- 认证中心统一签发令牌
- 支持协议：CAS / SAML / OIDC

### 7.2 OIDC 实现

```go
// 基于 OpenID Connect 的 SSO
// 1. 用户访问应用 A，未登录则重定向到认证中心
// 2. 用户在认证中心登录
// 3. 认证中心签发 ID Token + Access Token
// 4. 重定向回应用 A，携带 Token
// 5. 应用 A 验证 Token，建立本地会话
// 6. 用户访问应用 B，重定向到认证中心
// 7. 认证中心发现已有会话，直接签发 Token
// 8. 重定向回应用 B，无需再次登录
```

## 八、认证方案选型

| 场景 | 推荐方案 |
|------|----------|
| 单体 Web 应用 | Session-Cookie |
| API 服务 | JWT + Refresh Token |

| 企业内部 | SSO (OIDC/SAML) |
| 服务间调用 | mTLS / API Key |
