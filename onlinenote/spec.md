# 思维导图/知识图谱 Web 网站规格说明书

## 1. 项目概述

开发一个独立的思维导图/知识图谱 Web 网站，读取 `ALL.md` 文件中的 1-6 级标题，生成可交互的思维导图可视化。用户点击思维导图中的标题节点时，可跳转查看对应的 Markdown 内容。

## 2. 技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | 纯 HTML + CSS + JavaScript（无框架） | 轻量、独立部署、无构建依赖 |
| 思维导图库 | **markmap**（markmap-view + markmap-lib） | 专为 Markdown 标题生成思维导图设计，开箱即用，支持 1-6 级标题 |
| Markdown 渲染 | **marked** | 轻量级 Markdown 渲染库，CDN 可用 |
| 代码高亮 | **highlight.js** | 配合 marked 使用，支持代码块高亮 |
| 部署方式 | 静态文件，可直接打开或部署到任意静态服务器 | 零依赖部署 |

## 3. 数据源

- **文件路径**: `/ALL.md`（相对于网站根目录）
- **标题层级**: 解析 `#`（H1）到 `######`（H6）共 6 级标题
- **标题结构示例**:
  ```
  # 知识点总结（H1）
  ## 一、Go（H2）
  ### 1.1 语言基础（H3）
  #### 基础语法（H4）
  ##### ...（H5）
  ###### ...（H6）
  ```

## 4. 功能需求

### 4.1 核心功能

1. **Markdown 解析**: 读取 ALL.md 文件，提取 1-6 级标题层级结构
2. **思维导图生成**: 将标题层级结构渲染为交互式思维导图
3. **节点点击跳转**: 点击思维导图中的标题节点，右侧面板显示该标题对应的 Markdown 内容
4. **思维导图交互**: 支持缩放、拖拽、节点展开/折叠

### 4.2 页面布局

```
┌─────────────────────────────────────────────────────┐
│  顶部栏：标题 "知识图谱" + 工具按钮（全部展开/折叠）    │
├──────────────────────┬──────────────────────────────┤
│                      │                              │
│   思维导图区域        │   Markdown 内容预览区域       │
│   （markmap 渲染）    │   （点击节点后显示对应内容）   │
│   占 60% 宽度        │   占 40% 宽度                │
│                      │                              │
│                      │                              │
├──────────────────────┴──────────────────────────────┤
│  底部状态栏：当前选中节点路径                          │
└─────────────────────────────────────────────────────┘
```

### 4.3 交互行为

- **点击节点**: 右侧面板滚动到对应标题位置，高亮显示该节点的 Markdown 内容
- **悬停节点**: 显示 tooltip，预览该标题下的简要内容
- **双击节点**: 展开/折叠该节点的子节点
- **工具栏按钮**: 全部展开、全部折叠、重置视图、适应屏幕
- **面包屑导航**: 右侧面板顶部显示当前选中节点的层级路径

### 4.4 样式设计

- **配色**: 深色主题（暗色背景 + 亮色节点），护眼舒适
- **节点颜色**: 不同层级使用不同颜色（H1=金色, H2=蓝色, H3=绿色, H4=橙色, H5=紫色, H6=灰色）
- **选中状态**: 被点击的节点高亮显示，有明显的视觉反馈
- **字体**: 中文友好字体（系统默认中文字体栈）
- **响应式**: 窄屏（<768px）时上下布局，宽屏时左右布局

## 7. 核心逻辑

### 7.1 数据加载流程

```
页面加载 → fetch('ALL.md') → 解析 Markdown → 提取标题树 → markmap 渲染思维导图
```

### 7.2 标题解析算法

1. 按 `\n` 分行扫描
2. 正则匹配 `^(#{1,6})\s+(.+)$`
3. 构建树形结构：根据标题层级确定父子关系（子标题挂载到最近的上级标题下）
4. 为每个节点生成唯一 ID（基于标题文本的 slug）

### 7.3 点击跳转逻辑

1. 监听 markmap 节点点击事件
2. 获取被点击节点的标题文本
3. 在右侧面板中定位到对应标题
4. 滚动到该标题位置并高亮

### 7.4 Markdown 内容渲染

1. 将 ALL.md 完整内容用 `marked` 渲染为 HTML
2. 为每个标题元素添加 ID 属性（用于锚点定位）
3. 点击思维导图节点时，通过 `document.getElementById()` 定位并滚动

## 8. 约束与注意事项

- **单文件部署**: 所有代码在 `index.html` 中，便于分发和部署
- **本地文件访问**: 需通过 HTTP 服务器访问（fetch 不支持 file:// 协议），提供简易启动说明
- **ALL.md 同步**: 需将 `/Users/m5/Desktop/notebook/ALL.md` 复制到 `onlinenote/` 目录
- **编码**: ALL.md 为 UTF-8 编码，需确保正确读取中文内容
- **性能**: ALL.md 约 2000 行，markmap 渲染约 39 个标题节点，性能无压力
