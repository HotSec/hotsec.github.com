# 思维导图/知识图谱 Web 网站规格说明书

## 1. 项目概述

开发一个独立的思维导图/知识图谱 Web 网站，读取 `ALL.md` 文件中的 1-6 级标题，生成可交互的思维导图可视化。整个页面展示思维导图，用户点击思维导图中的标题节点时，弹出模态框显示该标题对应的 Markdown 内容。

## 2. 技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | 纯 HTML + CSS + JavaScript（无框架） | 轻量、独立部署、无构建依赖 |
| 思维导图库 | **markmap**（markmap-view + markmap-lib + d3@7） | 专为 Markdown 标题生成思维导图设计，开箱即用 |
| Markdown 渲染 | **marked** | 轻量级 Markdown 渲染库，CDN 可用 |
| 代码高亮 | **highlight.js** | 配合 marked 使用，支持代码块高亮 |
| 部署方式 | 静态文件，可直接打开或部署到任意静态服务器 | 零依赖部署 |

## 3. 数据源

- **文件路径**: `/ALL.md`（相对于网站根目录）
- **标题层级**: 解析 `#`（H1）到 `######`（H6）共 6 级标题
- **标题结构示例**:
  ```
  # 知识点总结（H1）
  ## 一、Go（H2）
  ### 1.1 语言基础（H3）
  #### 基础语法（H4）
  ##### ...（H5）
  ###### ...（H6）
  ```

## 4. 功能需求

### 4.1 核心功能

1. **Markdown 解析**: 读取 ALL.md 文件，提取 1-6 级标题层级结构
2. **思维导图生成**: 将标题层级结构渲染为全屏交互式思维导图
3. **节点点击弹窗**: 点击思维导图中的标题节点，弹出模态框显示该标题及其子内容的 Markdown 渲染
4. **思维导图交互**: 支持缩放、拖拽、节点展开/折叠

### 4.2 页面布局

```
┌─────────────────────────────────────────────────────┐
│  顶部栏：标题 "知识图谱" + 工具按钮（展开/折叠/适应）  │
├─────────────────────────────────────────────────────┤
│                                                     │
│                                                     │
│              思维导图（全屏）                         │
│              markmap 渲染                            │
│                                                     │
│                                                     │
│                          ┌──────────────────────┐   │
│                          │  弹出模态框（点击节点）│   │
│                          │  面包屑导航 + 关闭按钮 │   │
│                          │  Markdown 内容预览    │   │

│                          └──────────────────────┘   │

```

### 4.3 交互行为

- **点击节点**: 弹出模态框，显示该标题下的 Markdown 内容（含子标题内容）
- **模态框关闭**: 点击关闭按钮 / 点击遮罩层 / 按 Escape 键
- **面包屑导航**: 模态框顶部显示当前节点的层级路径，点击路径中的上级节点可跳转
- **工具栏按钮**: 全部展开、全部折叠、适应屏幕、重置视图
- **初始提示**: 页面加载后短暂显示"点击节点查看详情"提示

### 4.4 样式设计

- **配色**: 深色主题（暗色背景 + 亮色节点），护眼舒适
- **节点颜色**: 不同层级使用不同颜色（H1=金色, H2=蓝色, H3=绿色, H4=橙色, H5=紫色, H6=灰色）
- **模态框**: 半透明遮罩 + 毛玻璃效果，圆角卡片，进入动画（缩放+淡入）
- **字体**: 中文友好字体（系统默认中文字体栈）
- **响应式**: 窄屏时模态框宽度自适应

## 7. 核心逻辑

### 7.1 数据加载流程

```
页面加载 → fetch('ALL.md') → 解析 Markdown → 提取标题树 → markmap 渲染全屏思维导图
```

### 7.2 标题解析算法

1. 按 `\n` 分行扫描
2. 正则匹配 `^(#{1,6})\s+(.+)$`
3. 构建树形结构：根据标题层级确定父子关系
4. 为每个节点生成唯一 slug ID

### 7.3 点击弹窗逻辑

1. 监听 markmap SVG 的 click 事件
2. 通过 `e.target.closest('.markmap-node')` 找到被点击节点
3. 从 D3 绑定数据 `__data__.data.content` 获取节点文本
4. 匹配 headings 数组中的 slug
5. 调用 `getSectionContent(slug)` 提取该标题到下一个同级标题之间的内容
6. 用 marked 渲染为 HTML 并填入模态框
7. 显示模态框（添加 active class）

### 7.4 内容提取算法

1. 找到目标标题的行号 `startLine`
2. 向后扫描，找到下一个同级或更高级标题的行号 `endLine`
3. 截取 `[startLine, endLine)` 范围的 Markdown 文本
4. 用 marked 渲染为 HTML

## 8. 约束与注意事项

- **单文件部署**: 所有代码在 `index.html` 中，便于分发和部署
- **本地文件访问**: 需通过 HTTP 服务器访问（fetch 不支持 file:// 协议）
- **ALL.md 同步**: 需将 `/Users/m5/Desktop/notebook/ALL.md` 复制到 `onlinenote/` 目录
- **编码**: ALL.md 为 UTF-8 编码，需确保正确读取中文内容
- **性能**: ALL.md 约 2000 行，markmap 渲染约 39 个标题节点，性能无压力
