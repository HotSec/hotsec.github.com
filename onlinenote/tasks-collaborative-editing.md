# 协作编辑功能任务分解

## 阶段一：基础编辑功能（Week 1-2）

### Task 1: 项目重构与依赖安装

- **描述**: 重构项目结构，安装必要的依赖
- **子任务**:
  - 1.1 初始化 Node.js 项目（package.json）
  - 1.2 安装前端依赖（CodeMirror 6, Yjs, Socket.io Client）
  - 1.3 安装后端依赖（Express, Socket.io, Yjs）
  - 1.4 重构文件结构（public/, server/, data/）
  - 1.5 配置环境变量（.env）
- **验收**: 项目结构清晰，依赖安装成功，npm run dev 可启动

### Task 2: 集成 CodeMirror 6 编辑器

- **描述**: 将 CodeMirror 6 集成到现有应用中
- **子任务**:
  - 2.1 创建编辑器容器 DOM 结构
  - 2.2 初始化 CodeMirror 6 实例
  - 2.3 配置基础主题和样式
  - 2.4 实现 Markdown 语法高亮
  - 2.5 集成到模态框中（替换现有编辑功能）
- **验收**: 编辑器正常显示，支持基础输入，语法高亮正常

### Task 3: 实现编辑器工具栏

- **描述**: 添加 Markdown 格式化工具栏
- **子任务**:
  - 3.1 创建工具栏 UI（按钮组）
  - 3.2 实现加粗、斜体、标题按钮
  - 3.3 实现列表、引用、代码块按钮
  - 3.4 实现链接、图片插入按钮
  - 3.5 实现撤销/重做按钮
- **验收**: 所有工具栏按钮功能正常，点击可插入对应 Markdown 语法

### Task 4: 实现快捷键支持

- **描述**: 添加常用快捷键
- **子任务**:
  - 4.1 实现 Ctrl+B（加粗）
  - 4.2 实现 Ctrl+I（斜体）
  - 4.3 实现 Ctrl+K（链接）
  - 4.4 实现 Ctrl+S（保存）
  - 4.5 实现 Ctrl+Z/Y（撤销/重做）
- **验收**: 所有快捷键功能正常

### Task 5: 实现分屏布局

- **描述**: 创建编辑器和预览的分屏布局
- **子任务**:
  - 5.1 创建分屏容器 DOM 结构
  - 5.2 左侧：CodeMirror 编辑器
  - 5.3 右侧：Markdown 预览区域
  - 5.4 实现可调整分栏宽度（拖拽）
  - 5.5 响应式适配（移动端上下布局）
- **验收**: 分屏布局正常，可拖拽调整宽度

### Task 6: 实现实时渲染

- **描述**: 编辑器内容实时渲染到预览区域
- **子任务**:
  - 6.1 监听编辑器内容变化
  - 6.2 使用 Marked 渲染 Markdown
  - 6.3 应用 highlight.js 代码高亮
  - 6.4 实现防抖处理（300ms）
  - 6.5 更新预览区域 DOM
- **验收**: 输入后预览区域实时更新，延迟 < 100ms

### Task 7: 实现同步滚动

- **描述**: 编辑器和预览区域同步滚动
- **子任务**:
  - 7.1 监听编辑器滚动事件
  - 7.2 计算滚动比例
  - 7.3 同步预览区域滚动位置
  - 7.4 实现双向同步（可选）
  - 7.5 优化滚动性能
- **验收**: 滚动编辑器时预览区域同步滚动，位置准确

### Task 8: 实现自动保存

- **描述**: 自动保存编辑内容到文件系统
- **子任务**:
  - 8.1 监听编辑器内容变化
  - 8.2 实现防抖保存（2 秒）
  - 8.3 保存到 localStorage（临时）
  - 8.4 保存到服务器（后续）
  - 8.5 显示保存状态提示
- **验收**: 编辑后自动保存，刷新页面内容不丢失

### Task 9: 实现文件导出

- **描述**: 支持导出 Markdown 和 HTML 文件
- **子任务**:
  - 9.1 实现"导出为 .md"功能
  - 9.2 实现"导出为 .html"功能
  - 9.3 添加导出按钮到工具栏
  - 9.4 使用 Blob 和 download 属性
  - 9.5 测试导出文件完整性
- **验收**: 点击导出按钮可下载对应格式文件
